Before you start

        
    
            
  • Import the thread account's posting key into Steem Keychain. Keychain asks you to
                approve each post.
    • 
            
  • The chain accepts one root post per account every 5 minutes, so the page waits between posts.
                Keep this tab open until it finishes: 13 months of 4 families is about 4½ hours.
    • 
            
  • If a run stops, check again and create again: threads that exist are skipped.
