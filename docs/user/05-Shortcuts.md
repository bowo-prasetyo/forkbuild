# 05 — Keyboard Shortcuts

A complete reference for every keyboard shortcut in ForkBuild.

> **Note:** On macOS, use **Cmd** wherever you see **Ctrl**.

## General (Editor & World View)

| Shortcut | Action |
|---|---|
| `Ctrl + S` | Save |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` *(or `Ctrl+Shift+Z`)* | Redo |
| `Ctrl + C` | Copy selection |
| `Ctrl + V` | Paste |
| `Ctrl + A` | Select all bricks |
| `Escape` | Clear selection / cancel placement |
| `Home` | Reset camera view |

## Tools (Editor)

| Shortcut | Action |
|---|---|
| `1` | Switch to Select tool |
| `2` | Switch to Place tool |

## Selection (Select tool)

| Action | Result |
|---|---|
| **Click** | Select a brick (replaces selection) |
| `Ctrl` **+ Click** | Toggle a brick in the selection |
| `Shift` **+ Click** | Add a brick to the selection |
| `Shift` **+ Drag** | Box-select (replaces selection) |
| `Ctrl+Shift` **+ Drag** | Box-select and add to selection |

## Transforming (Select tool)

| Shortcut | Action |
|---|---|
| `Arrow keys` | Nudge selection (left/right/forward/back) |
| `Page Up` / `Page Down` | Nudge selection up / down |
| `R` | Rotate selection 90° clockwise |
| `Shift + R` | Rotate selection 90° counter-clockwise |
| `Delete` / `Backspace` | Delete selection |

## Camera

| Action | Result |
|---|---|
| **Drag** | Orbit the camera |
| **Scroll** | Zoom in / out |
| `Home` | Reset the view |

## World View extras

| Action | Result |
|---|---|
| **Click a brick** | Inspect it |
| **Click a Timeline entry** | Preview the world at that step |
| **Restore Here** | Make a previewed state your current one |
