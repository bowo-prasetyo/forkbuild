# ForkBuild User Guide

**Build. Fork. Share. Evolve.**

Welcome to ForkBuild — an open, browser-based building platform where you
create 3D worlds out of bricks, publish them, and let others fork and evolve
them. Think of it as **Git for 3D models**: every creation has a history, can
be copied, and can grow in new directions without ever losing the original.

This guide is for people who want to **use** ForkBuild. If you're looking for
the technical architecture, see `docs/Architecture.md` instead.

---

## What you can do

- 🧱 **Build** — Place, move, rotate, and delete bricks in a full 3D editor.
- 🌍 **Explore** — Fly through a shared spatial world where everyone's
  creations exist side by side.
- 📤 **Publish** — Share your creations so others can discover them.
- 🍴 **Fork** — Copy anyone's creation and make it your own, with full credit
  to the original.
- 👥 **Collaborate** — Every fork is tracked, so you can see a creation's
  whole family tree.

## New here? Start with this path

1. Read **[Getting Started](01-GettingStarted.md)** and place a few bricks.
2. Skim **[The Editor](02-TheEditor.md)** to learn selection and groups.
3. **[Publish](04-PublishingAndForking.md)** your first creation.
4. Open **[World View](03-WorldView.md)** and explore what others have built.

> **Tip:** You never need to install anything. ForkBuild runs entirely in your
> browser, and your work is saved locally on your device.
