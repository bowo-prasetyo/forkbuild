# 대화형 변환 기즈모

에디터에서 블록을 선택하면 선택의 피벗에 기즈모가 나타납니다. 핸들을 드래그하면
실시간 미리보기와 함께 선택을 이동하거나 회전하며, 놓으면 변경이 **실행 취소 한
단계**로 확정됩니다. 에디터에서
[구조물 인스턴스](02-TheEditor.md#구조물-인스턴스-실시간-참조) 하나를 선택해도
똑같은 기즈모가 나타나며, 차이는 하나뿐입니다: 초록색 Y축 핸들이 동작하지
않습니다. 배치의 높이는 항상 아래의 지형을 따르며 — 드래그하는 핸들이나
입력하는 값이 아닙니다.

기즈모는 에디터 전용입니다. [월드 보기](03-WorldView.md)는 읽기 전용 탐색
공간입니다. 거기서 찾은 것을 이어서 지으려면 **사본 편집** 버튼으로 여기,
에디터에서 여세요.

## 기즈모

```
    Y
    ↑
    │
    │
    ●──────→ X        ●  피벗
   /
  /
 Z

    ◯
  ◯ ● ◯               회전 고리 (Y축)
    ◯
```

| 핸들 | 색 | 하는 일 |
|---|---|---|
| 축 화살표 | 빨강 (X) | 드래그해 X 방향으로만 이동 |
| 축 화살표 | 초록 (Y) | 드래그해 Y 방향으로만 이동 |
| 축 화살표 | 파랑 (Z) | 드래그해 Z 방향으로만 이동 |
| 가운데 패드 | 주황 | 지면(X + Z)에서 자유 이동 |
| 회전 고리 | 보라 | 드래그해 피벗을 기준으로 회전 |

핸들은 커서를 올리면 강조 표시되고, 드래그하는 동안 더 밝게 빛납니다. 아무리 멀리
축소해도 기즈모는 보기 편한 화면 크기를 유지합니다.

## 피벗

기즈모 가운데의 흰 표시가 **피벗**입니다:

```
┌───────────────┐
│ ■           ■ │
│               │
│       +       │ ← 피벗 (선택 경계의 중심)
│               │
│ ■           ■ │
└───────────────┘
```

- 블록 하나를 선택하면 → 피벗은 그 블록의 중심에 있습니다.
- 블록 여러 개를 선택하면 → 피벗은 모두를 감싸는 상자의 중심에 있습니다.
- 회전은 항상 피벗을 기준으로 합니다.

피벗은 선택을 자동으로 따라갑니다: A를 선택하고, B를 추가하고, 이동을 실행
취소하면 — 기즈모는 매번 위치를 다시 잡습니다.

## 이동하기

1. 블록을 하나 이상 선택하세요.
2. 축 핸들을 잡으면 그 축을 따라, 가운데 패드를 잡으면 지면을 따라 자유롭게
   움직입니다.
3. 선택이 포인터를 실시간으로 따라옵니다.
4. 놓으면 확정됩니다.

## 회전하기

1. 블록을 하나 이상 선택하세요.
2. 보라색 고리를 드래그하세요. 드래그하는 동안 선택이 피벗을 기준으로 돕니다.
3. 놓으면 확정됩니다.

여러 개를 선택했다면 모든 블록이 공통 피벗 주위를 돌면서 *동시에* 같은 각도만큼
방향을 바꿉니다 — 배치 모양이 그대로 유지됩니다.

## 확정, 취소, 아무것도 안 하기

| 이렇게 하면… | 결과 |
|---|---|
| 마우스를 놓음 | 변경 확정 — 블록이 몇 개 움직였든 실행 취소 기록에 **정확히 한** 항목 |
| 드래그 중 `Escape`를 누름 | 취소 — 모든 것이 정확히 원래대로 돌아가며, 기록은 그대로 |
| 움직이지 않고 클릭했다 놓음 | 아무 일도 없음 — 명령도, 기록 항목도 없음 |

`Ctrl/Cmd+Z`는 동작 전체를 한 단계로 실행 취소하고, `Ctrl/Cmd+Y`(또는
`Ctrl/Cmd+Shift+Z`)는 다시 실행합니다.

## 드래그하는 동안은 동작이 포인터를 차지합니다

드래그하는 동안 카메라는 회전하지 않고, 다른 것은 선택할 수 없으며, 단축키는
무시됩니다 — 드래그가 실수로 카메라와 다툴 일이 없습니다. 놓으면(확정) 또는
`Escape`(취소)를 누르면 모든 것이 평소대로 돌아옵니다. 뷰포트 *밖*에서 마우스를
놓아도 깔끔하게 확정됩니다.

## 그룹

그룹을 선택하면 그 구성 블록이 선택되며 — 기즈모는 이를 다른 다중 선택과 똑같이
다룹니다:

- 드래그하면 모든 구성원이 이동하고, 회전하면 모든 구성원이 공통 피벗을 기준으로
  돕니다.
- 그룹 자체는 건드리지 않습니다: 변환 때문에 구성원이 바뀌는 일은 없습니다.
  (기즈모는 그룹이 있다는 것조차 모릅니다.)
- 실행 취소 한 번으로 모든 구성원이 원래 자리로 돌아갑니다.

## 스냅

드래그는 기본적으로 스냅됩니다 — 이동은 1 월드 단위(화살표 키로 조금씩 움직이는
것과 같은 간격), 회전은 15°(`R`의 90°보다 촘촘함). 드래그하는 동안 **Shift**를
누르면 **정밀 모드**가 됩니다: 평소 간격의 0.1배(0.1 월드 단위, 1.5°)로, 기본
격자로는 너무 거친 미세 조정에 씁니다.

**숫자 변환 패널**과 **정렬/배분**은 일부러 예외입니다 — 이미 정확한 값을
입력했거나 요청했으므로, 스냅하지 않고 요청한 정확한 값이나 정확한 기하학적
결과를 항상 그대로 적용합니다.

## 충돌하면 확정되지 않습니다

선택을 이동하거나 회전하면, 놓기 전에 결과를 선택 *밖*의 모든 블록과
대조합니다. 구성원 하나라도 이미 있는 것과 겹치게 되면 그 자리에서 놓아도 확정되지
않습니다 — 블록 하나를 이미 차 있는 칸에 놓으면 클릭이 거부되는 것처럼, 선택한
모든 블록이 원래 자리로 정확히 돌아가며 새 실행 취소 항목도 생기지 않습니다. 같은
선택 *안에서* 블록을 재배치하는 것(예: 회전으로 두 구성원이 자리를 맞바꿈)은
충돌로 취급하지 않습니다. 이 확인은 기즈모 드래그, 키보드 이동, 회전에 모두
적용됩니다. 정렬, 배분, 숫자 변환 패널은 자유로운 이동이 아니라 정확하고 의도된
결과를 계산하므로 이 확인을 거치지 않습니다.

## 기즈모가 하지 않는 것

- **크기 조절** — 블록의 크기는 바꿀 수 없으므로 크기 조절 핸들이 없습니다.
- **드래그 복제** — 드래그하면서 복사하는 수정 키는 없습니다. 먼저
  `Ctrl/Cmd+D`로 선택을 그 자리에 복제한 다음([에디터](02-TheEditor.md#복사-붙여넣기-복제)
  참고), 사본을 드래그하세요.

## 팁

- 세밀하게 조절하려면 회전 고리에 커서를 올리고 천천히 드래그하세요 — 회전은
  거리가 아니라 각도로 재므로, 피벗 근처의 작은 원호도 정확합니다.
- 두 좌표를 완벽하게 고정하고 싶을 때는 축 핸들을 쓰세요 — 제약은 눈대중이 아니라
  정확합니다.
- 방법을 섞어 쓰세요: 화살표 키로 한 단위씩 옮긴 다음, Shift+드래그로 미세하게
  위치를 마무리하세요. 실행 취소/다시 실행은 둘을 똑같이 다룹니다 — 동작마다 한
  단계.
