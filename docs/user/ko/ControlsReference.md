ForkBuild의 모든 마우스와 키보드 조작입니다. 휴대폰과 태블릿은
[터치스크린](#터치스크린)에서 다룹니다. 월드 보기는 둘러보고 이동하기 위한
곳이며, 모든 건축 조작(편집용 선택, 변환, 그룹, 클립보드, 배치, 명령 팔레트)은
에디터에서만 동작합니다. 에디터의 단축키는 명령 팔레트와 **⌨ 단축키** 오버레이에
나열된 것과 같습니다 — 이 페이지와 팔레트가 서로 다르다면 팔레트가 맞고 이
페이지에 버그가 있는 것입니다.

에디터에서 `Ctrl/Cmd+K`로 **명령 팔레트**를 열면 아래의 모든 편집 작업을
이름으로 검색할 수 있습니다.

## 카메라 (두 화면 공통)

| 입력 | 작업 |
|---|---|
| 빈 곳에서 왼쪽 드래그 | 회전 |
| 오른쪽 드래그 | 화면 이동 |
| 스크롤 휠 | 확대·축소 |
| `Home` | 에디터: 카메라 초기화(기즈모를 드래그하는 동안은 무시). 월드 보기: 카메라와 아바타를 지금 내 월드로 돌려보냄 — [월드 보기](03-WorldView.md#방향과-위치) 참고 |

## 명령 화면 (에디터 전용)

| 입력 | 작업 |
|---|---|
| `Ctrl/Cmd+K` | 명령 팔레트 |
| `?` | 키보드 단축키 오버레이(툴바의 “⌨ 단축키” 버튼으로도 열림) — 에디터의 모든 단축키 |

## 발견 (월드 보기)

키보드 단축키는 아니지만, 월드 보기에서 무언가를 찾는 방법입니다 — 자세한 설명은
[월드 보기](03-WorldView.md#월드-찾기)를 보세요.

| 컨트롤 | 작업 |
|---|---|
| 검색 패널, **찾기** | 제목/작성자로 게시물 검색, 원하면 한 좌표의 반경 안으로 한정 |
| **여기 탐색** | 카메라의 현재 위치를 중심으로 위치 탐색 대화 상자 열기 |
| **여기 무엇이 있나요?** | 같지만 작은 고정 반경 — “바로 여기에 뭐가 있나” |
| 결과의 **초점** | 카메라를 그곳으로 날려 보내고 활성(편집) 문서로 만들기 |
| 결과의 **선택** | 카메라를 움직이지 않고 활성 문서로 만들기 |
| 결과의 **살펴보기** | 그 자리에서 읽기 전용 요약 펼치기 |

## 방향과 이동 (월드 보기)

순수한 카메라 이동입니다 — 어느 것도 문서를 불러오거나, 선택을 바꾸거나, 무언가를
편집하지 않습니다. [월드 보기](03-WorldView.md#방향과-위치)를 보세요.

| 컨트롤 | 작업 |
|---|---|
| 나침반 표시 | 주변 구조물과 지형에 대한 상황 표시가 있는 읽기 전용 방향 |
| **홈** | 카메라와 아바타를 지금 내 월드로 돌려보냄(이번 세션에서 아직 내 월드에 초점을 맞춘 적이 없으면 공유 원점으로) — [월드 보기](03-WorldView.md#방향과-위치) 참고 |
| **위치** | 월드, 그 구조물, 랜드마크, 장소의 목록을 각각 **초점** 버튼과 함께 열기 |
| **?** | 카메라와 걷기 조작을 보이거나 숨기기 |
| 🔔 **알림**(앱 머리글, 모든 페이지) | **알림 기록** 열기 — 카메라 작업이 아닌 읽기 전용 기록, [월드 보기](03-WorldView.md#방향과-위치) 참고 |
| **카메라**: 자유 / 1인칭 / 3인칭 / 조감도 | 카메라를 직접 날리는 대신 내 아바타에서 일정하게 떨어진 위치에 고정. 켜진 것을 다시 클릭하면 자유로 돌아감 — [아바타와 접속 상태](06-AvatarsAndPresence.md#카메라-시점) 참고 |

### 상황에 맞는 위치 설명

월드를 돌아다니면 화면에 다음과 같이 도출된 상황이 표시됩니다:

- “**숲 · 집 근처**” — 숲 안, 구조물에서 50단위 이내
- “**초원 · 강**” — 강가의 탁 트인 지형
- “**초원 · 호수 · 헛간 근처**” — 지형, 물, 가장 가까운 구조물

이 설명은 위치, 지형 생태, 수계, 구조물 배치에서 계산되며 — 월드에는 아무것도
저장되지 않습니다.

|---|---|---|
| `M` | 소리 끄기 또는 켜기 | **소리** 버튼과 같음. 두 화면이 하나의 설정을 쓰며 이 기기에 기억됨. [월드 보기](03-WorldView.md#소리)와 [에디터](02-TheEditor.md#소리) 참고 |

## 아바타 이동 (월드 보기)

카메라를 날리는 대신 아바타를 직접 걷게 하기 —
[아바타와 접속 상태](06-AvatarsAndPresence.md#아바타-걷게-하기)를 보세요.

| 입력 | 작업 | 참고 |
|---|---|---|
| `W` / `A` / `S` / `D` | 이동 / 회전 | 주변 건물, 나무, 야생 동물, 주민이 벽처럼 막음 |
| `Shift` (누르고 있기) | 달리기 | |
| `Space` | 점프 | |
| `Alt` + `W` / `S` | 계속 앞으로/뒤로 걷기 시작 | 키를 놓아도 계속 움직임. Alt 없이 `W`/`S`를 그냥 탭하면 취소 |
| `Alt` + `Shift` + `W` / `S` | 계속 앞으로/뒤로 달리기 시작 | 취소 규칙은 위와 같음 |

## 탈것 (월드 보기)

[아바타와 접속 상태](06-AvatarsAndPresence.md#탈것)를 보세요. 아바타 조종 모드가
필요하며, 탈것에 탈 수 있을 만큼 가까이 가면 안내가 자동으로 나타납니다.

| 입력 | 작업 | 참고 |
|---|---|---|
| `E` | 근처 탈것에 타기, 또는 타고 있는 것에서 내리기 | 탈것이 범위 안에 있거나 타고 있을 때만 표시/동작 |
| `W` / `S` | 가속 / 후진 | 타는 동안 걷기를 대신함 |
| `A` / `D` | 아바타 자신의 방향 돌리기 | 걸을 때와 같은 회전 — 탈것 조향이 아님 |
| `←` / `→` (누름) | 탈것이 가려는 방향을 왼쪽/오른쪽으로 돌리기 | 누를 때마다 45° 한 번 — 누르고 있어도 계속 돌지 않음 |
| `Ctrl` (누르고 있기) | 브레이크 | |
| `Q` (탄 상태) | 타고 있는 탈것을 인벤토리에 보관 | 월드에서 사라지고 동시에 내림 |
| `Q` (타지 않은 상태, 탈것을 가지고 있음) | 현재 선택된 보관 탈것 꺼내기 | 현재 위치에 나타나며 바로 탐. 기본값은 가장 최근에 보관한 것 |
| `[` / `]` (탈것 2대 이상) | 꺼낼 탈것 선택을 이전 / 최근 보관한 것으로 돌리기 | 다음에 `Q`로 꺼낼 것만 바꿈 — 스스로 타거나 없애지 않음 |

## 동물 (월드 보기)

[아바타와 접속 상태](06-AvatarsAndPresence.md#동물)를 보세요. 아바타 조종 모드가
필요하며, 잡을 수 있는 동물이 근처에 있거나 동물을 가지고 있으면 안내가 자동으로
나타납니다.

| 입력 | 작업 | 참고 |
|---|---|---|
| `F` (잡을 수 있는 동물 근처) | 잡기 | 인벤토리에 추가하고 월드에서 없앰 |
| `F` (잡을 동물이 근처에 없고, 동물을 가지고 있음) | 가장 최근에 잡은 동물 놓아주기 | 현재 위치에 나타나며 다시 잡을 수 있음 |
| `G` (내가 놓아준 동물 근처) | 그 동물로 월드 장식 | 월드 콘텐츠에 장식으로 저장 — 더 이상 잡을 수 없음. 편집 권한 필요. `G`로 무언가 할 수 있으면 안내가 표시됨 |
| `G` (동물 장식 근처, 놓아준 동물은 근처에 없음) | 장식 취소 | 월드에서 제거하고 다시 잡을 수 있는 살아 있는 동물로 되돌림 |

## 주민 (월드 보기)

[아바타와 접속 상태](06-AvatarsAndPresence.md#주민)를 보세요. 아바타 조종 모드가
필요하며, 아바타 섹션의 **여기에 주민 추가** / **주민 제거**와 **말하기** 버튼은
없이도 같은 일을 합니다.

| 입력 | 작업 | 참고 |
|---|---|---|
| `R` (빈 땅, 바로 옆에 주민 없음) | 내가 선 곳을 집으로 하는 주민 추가 | 월드 콘텐츠에 저장. 편집 권한 필요. 지붕 위, 물속, 탈것을 탄 상태에서는 안 됨 |
| `R` (주민 옆) | 월드에서 제거 | 안내에 **[R] 주민 제거**가 표시됨. `Ctrl/Cmd+Z`로 실행 취소 |
| `T` (주민 옆) | 말하기: 주변에 무엇이 있는지 알려 줌 | 머리 위 말풍선에 표시. 다시 말을 걸면 다른 이야기. 아바타 섹션과 터치 패드의 **말하기** 버튼도 같음 |
| **초점: …** 버튼(주민의 말이 떠 있는 동안) | 언급한 것 보기 | 카메라만 움직이고 아바타는 그대로. 랜드마크, 구조물, 작품, 탈것에 제공 |

인벤토리, 놓아둔 탈것, 놓아준 동물은 이 기기에 저장되어 새로 고쳐도 남습니다 —
[아바타와 접속 상태](06-AvatarsAndPresence.md#새로-고쳐도-남는-것)를 보세요.

## 선택 (에디터. 월드 보기에서 블록을 클릭하면 살펴보기만 함)

| 입력 | 작업 | 참고 |
|---|---|---|
| 블록 클릭 | 그 블록 선택(선택 대체) | 월드 보기에서는 살펴보기 패널만 열림 — [월드 보기](03-WorldView.md#월드-보기는-읽기-전용입니다--짓기는-에디터에서) 참고 |
| `Shift`-클릭 | 블록을 선택에 추가 | |
| `Ctrl/Cmd`-클릭 | 블록을 선택에 넣거나 빼기 | |
| `Shift`-드래그 | 상자 선택(선택 대체) | `Ctrl/Cmd+Shift`-드래그는 선택에 추가. 그냥 드래그하면 카메라 회전 |
| `Ctrl/Cmd+A` | 모두 선택 | |
| `Esc` | 선택 해제 | 아래의 에디터 Escape 순서 참고 — 월드 보기의 Escape는 열려 있는 패널만 닫음 |
| `Delete` / `Backspace` | 선택 삭제 — **에디터 전용** | 실행 취소 한 단계. 월드 보기에는 키보드 동작이 전혀 없음 |
| 선택 패널의 **초점** 버튼 — **에디터 전용** | 선택한 블록이 화면에 들어오도록 카메라를 즉시 맞춤 | 키보드 단축키 없음. 카메라만 — 문서, 선택, 실행 취소 기록을 건드리지 않음. 블록 선택에만, 구조물 배치에는 해당 없음 |

## 변환 — 키보드 (에디터 전용)

| 입력 | 작업 |
|---|---|
| `→` / `←` | 선택을 월드 X를 따라 이동 |
| `↑` / `↓` | 선택을 월드 Z를 따라 이동 |
| `PgUp` / `PgDn` | 선택을 월드 Y를 따라 이동 |
| `R` | 선택 피벗을 기준으로 +90° 회전 |
| `Shift+R` | −90° 회전 |
| 기즈모 드래그 중 `Shift` | 정밀 모드(0.1배 단위) |

## 변환 — 기즈모 (에디터 전용)

| 입력 | 작업 |
|---|---|
| 핸들 위에 커서 올리기 | 강조 표시 |
| 축 핸들 드래그(빨강 X / 초록 Y / 파랑 Z) | 그 축을 따라 이동(스냅) |
| 가운데 패드 드래그(주황) | 지면에서 자유 이동 |
| 회전 고리 드래그(보라) | 피벗을 기준으로 회전(스냅) |
| 놓기 | 확정 — 정확히 실행 취소 한 단계 |
| 드래그 중 `Esc` | 취소 — 아무것도 바뀌지 않고, 기록도 없음 |

여러 블록을 드래그하거나 키로 이동할 때 그중 하나라도 선택 밖의 블록과 겹치게
되면, 그 자리에서 놓아도 확정되지 않고 취소됩니다 — 모든 블록이 처음 위치로
정확히 돌아가며, 새 실행 취소 항목도 생기지 않습니다. 같은 선택 안에서 블록을
재배치하는 것은 충돌로 취급하지 않습니다.

## 변환 — 숫자 패널 (에디터 전용)

선택 패널의 **정확한 위치와 회전** 섹션에 있습니다.

| 입력 | 작업 |
|---|---|
| X/Y/Z/R 입력란에 입력 | 정확한 값. 빈 입력란 = 바꾸지 않음 |
| 절대 / 오프셋 전환 | 피벗을 목표로 할지, 단순한 변화량으로 할지 |
| `Enter` 또는 적용 | 작업 하나, 실행 취소 한 단계 — 스냅하지 않음 |
| 입력란에서 `Esc`, 또는 **입력란 비우기** | 입력란 비우기(선택은 해제하지 않음) |

## 정렬과 배분 (에디터 전용)

선택 패널의 **정렬, 배분, 반복** 섹션과 팔레트에서 쓸 수 있습니다. 정렬은 블록
**2개 이상**, 배분은 **3개 이상**이 필요합니다. 둘 다 선택 전체의 경계를
**월드 축** 기준으로 다루며, 명령 하나로 확정됩니다.

## 반복 (에디터 전용)

역시 선택 패널의 **정렬, 배분, 반복** 섹션에 있습니다. 선택 항목의 사본을 **N**개
더 만들어 한 축을 따라 같은 간격으로 늘어놓으며, **실행 취소 한 단계**입니다 —
무엇이든 만들기 전에 전체를 충돌 확인하므로, 중간에 충돌이 있으면 사본 일부만
만드는 대신 반복 전체가 막힙니다.

| 입력 | 작업 |
|---|---|
| **사본 수** 입력란 | 추가로 만들 사본 수(원본은 건드리지 않음) |
| **간격** 입력란 | 사본 사이의 거리 |
| **X / Y / Z 반복** | 그 월드 축을 따라 반복 |

## 구조물 (빌드 라이브러리) — 에디터 전용

조합, 포크, 그리고 내 개인 라이브러리 —
[에디터](02-TheEditor.md#구조물-조합-포크-그리고-내-개인-라이브러리)를 보세요.

| 입력 | 작업 | 참고 |
|---|---|---|
| **구조물** 탭의 카드 클릭 | 구조물 배치 모드로 들어감. 유령 미리보기가 포인터를 따라감 | 기본 제공 구조물과 내 **내 구조물** 모두 |
| 배치 중 `R` / `Shift+R` | 대기 중인 유령을 ±90° 회전 | 블록과 같은 배치 미리보기 키 |
| 클릭 | 확정 — 구조물의 모든 블록이 실행 취소 한 단계로 놓임 | 이미 차 있는(빨간) 위치에서는 거부 |
| 배치 중 `Esc` | 취소 — 아무것도 추가되지 않음 | |
| 카드 **⋮** 메뉴, **새 문서로 포크** | 그 구조물의 사본으로 시작하는 완전히 새로운 문서 만들기 | 라이브러리 항목은 바뀌지 않음 |
| 기본 제공 카드 **⋮** 메뉴, **내 구조물로 포크** | 그대로 내 구조물에 추가 | 문서를 만들거나 무언가를 추출하지 않음 |
| 카드 **⋮** 메뉴, **정보** | 읽기 전용 이름/분류/블록/바닥 면적/높이/출처/설명 패널 표시 | 편집할 수 없음 |
| 블록 **1개 이상** 선택 후 **설계도 만들기**(선택 패널의 **그룹 및 설계도** 섹션, 또는 명령 팔레트) | 작은 대화 상자(이름 / 분류 / 설명 + 미리보기)를 열고, 선택을 **내 구조물**의 새 항목으로 저장 | |
| **내 구조물** 카드 **⋮** 메뉴, **이름 바꾸기** | 내 구조물의 이름 변경 | 내 구조물에만 |
| **내 구조물** 카드 **⋮** 메뉴, **제거** | 라이브러리에서 삭제 | 그것으로 이미 조합하거나 포크한 블록은 건드리지 않음 |
| 카드 **⋮** 메뉴, **설계도 내보내기** | 휴대용 JSON 파일로 다운로드 | 기본 제공이든 내 것이든 |
| **설계도 가져오기** 버튼(내 구조물 제목 옆) | 설계도 파일을 라이브러리에 새 항목으로 추가 | 다시 가져온 파일이라도 새 식별자 |

## 구조물 인스턴스 (에디터)

**구조물 인스턴스**는 저장한 문서 전체를 선택 가능한 단위 하나로 배치합니다 — 복사가
아니라 실시간 참조입니다 —
[에디터](02-TheEditor.md#구조물-인스턴스-실시간-참조)를 보세요.

| 입력 | 작업 | 참고 |
|---|---|---|
| 툴바 **최근 항목** 드롭다운, 문서의 **배치** 버튼 | 그 문서를 대상으로 구조물 배치 모드로 들어감 | 문서 이름을 클릭하면 대신 문서를 엶 |
| 배치 중 `R` / `Shift+R` | 대기 중인 인스턴스를 ±90° 회전 | 블록과 같은 배치 미리보기 키 |
| 배치된 인스턴스 클릭(선택 도구) | 블록 선택과 구분되는 단위 하나로 선택 | |
| 뷰포트에서 드래그, 또는 기즈모 | 인스턴스 이동 / 회전 | |
| `Ctrl/Cmd+D` | 복제 — 같은 문서의 인스턴스를 하나 더 배치 | [복제](#복제-에디터-전용) 참고 — 인스턴스 선택은 블록 사본 대신 새 인스턴스를 받음 |
| 인스턴스 패널 **X / Z / 회전** 입력란, 그리고 적용 | 정확한 위치/방향 지정 | Y(높이)는 항상 지형에서 정해지며 목표가 아님 |
| 인스턴스 패널 **원본 문서 편집** | 참조된 문서를 열어 블록 바꾸기 | 인스턴스는 실시간 참조이므로 모든 인스턴스가 업데이트됨 |
| `Delete` / `Backspace` | 인스턴스 제거 | 참조된 문서는 건드리지 않음 |

## 그룹 (에디터 전용)

선택 패널의 **그룹 및 설계도** 섹션에 있습니다. 아무것도 선택하지 않으면 패널에
그룹 목록이 나와, 하나를 클릭해 선택할 수 있습니다.

| 작업 | 쓸 수 있을 때 |
|---|---|
| 새 그룹 | 블록을 선택했을 때 |
| 그룹 이름 바꾸기 / 복제 / 삭제 | 그룹을 선택했을 때 |
| 그룹에 추가 / 그룹에서 제거 | 블록과 그룹을 모두 선택했을 때 |

그룹 변환(이동/회전/정렬/배분/숫자)은 해석된 구성 블록에 작용하며, 변환으로
구성원 자체가 바뀌지는 않습니다.

## 배치 (에디터 전용)

이 키들은 배치 도구에 속하므로 명령 팔레트에는 나오지 않습니다(거기서 `R`/`Shift+R`은
*선택*을 회전합니다). 월드 보기에는 배치 도구가 아예 없습니다.

| 입력 | 작업 | 참고 |
|---|---|---|
| 포인터 이동 | 미리보기가 커서 아래의 지면/블록 면을 따라감 | 위치가 이미 차 있으면 빨갛게 표시 |
| `R` | 대기 중인 미리보기를 +90° 회전 | 블록 종류를 바꿔도 유지되며, 배치 모드를 나가면 초기화. 아무것도 가리키기 전에 누르면 다음 미리보기가 돌아감 |
| `Shift+R` | 대기 중인 미리보기를 −90° 회전 | |
| 클릭 | 미리보기를 실제 블록으로 확정 | 이미 차 있는(빨간) 위치에서는 거부 |
| 빌드 라이브러리 **색상** 견본 | 다음에 놓을 블록의 색 고르기 | 다른 종류를 고르면 그 종류의 기본 색으로 초기화 — [블록 색상](02-TheEditor.md#블록-색상) 참고 |

이미 놓은 블록의 색을 바꾸려면, 선택한 다음 선택 섹션의 **색상** 견본을 쓰세요 —
변경마다 실행 취소 한 단계입니다.

## 터치스크린

휴대폰이나 태블릿에서는 같은 작업에 화면 컨트롤이 있습니다. 기기에 터치스크린이
있으면 항상 나타나므로, 터치 노트북에서는 키보드와 마우스 옆에 함께 보입니다.
너비 720픽셀 이하의 화면에서는 페이지 배치도 바뀝니다: 페이지 링크는 **메뉴**
버튼 뒤로 접히고, 월드 보기의 사이드 패널은 **패널** 버튼으로 열리며, 에디터의
사이드바는 **도구** 버튼으로 여는 서랍이 됩니다.

### 카메라 (두 화면 공통)

| 터치 | 작업 |
|---|---|
| 한 손가락 드래그 | 회전 |
| 두 손가락 드래그 | 화면 이동 |
| 핀치 | 확대·축소 |
| 탭 | 월드 보기: 탭한 것을 살펴보기. 에디터: 현재 도구로 클릭한 것과 같음 |

### 걷기 (월드 보기)

터치 패드는 아바타 조종 모드가 켜져 있는 동안 나타납니다. 조이스틱 위의 **걷기**
버튼으로 모드를, 그리고 함께 패드를 켜고 끕니다.

| 컨트롤 | 대신하는 키 | 참고 |
|---|---|---|
| 조이스틱 | `W` / `A` / `S` / `D` | 위로 밀면 앞으로 걷고, 옆으로 밀면 회전. 대각선은 두 키를 함께 누름 |
| 조이스틱을 가장자리까지 밀기 | `Shift` | 달리기 |
| **점프** | `Space` | |
| **자동 이동** | `Alt` + `W`, 그다음 `Alt` + `Shift` + `W`, 그다음 `W` | 탭할 때마다: 손 떼고 앞으로 걷기, 그다음 달리기, 그다음 멈춤. 켜져 있는 동안 **자동 이동: 걷기** / **자동 이동: 달리기**로 표시. 조이스틱을 앞이나 뒤로 밀어도 멈춤. 옆으로 밀면 방향만 바뀜 |
| **타기** / **내리기** | `E` | 탈것이 범위 안에 있거나 타고 있을 때 표시 |
| **보관** / **꺼내기** | `Q` | 타고 있는 탈것을 보관하거나 보관한 것을 꺼낼 수 있을 때 표시. 꺼내기에는 탈것 이름과, 둘 이상 가지고 있으면 목록에서의 순번(예: 2/3)이 붙음 |
| 꺼내기 옆의 **‹** / **›** | `[` / `]` | 탈것 2대 이상: 꺼낼 이전 또는 최근 것을 고름 |
| **잡기** / **놓아주기** | `F` | 근처에 잡을 수 있는 동물이 있거나 동물을 가지고 있을 때 표시 |
| **장식** / **장식 취소** | `G` | 내가 놓아준 동물이나 장식 근처에서 표시. `G`와 달리 장식이 거부되면(로그인 안 함, 편집 권한 없음) 이유를 알려 줌 |
| **↶** / **↷** | `←` / `→` | 탈것을 타는 동안: 탭할 때마다 45° 조향 |
| **브레이크** | `Ctrl` (누르고 있기) | 탈것을 타는 동안 |

패드의 버튼이 키보드 안내를 대신하며, 패드가 보이는 동안 키보드 안내는
숨겨집니다. 손 떼고 뒤로 걷기(`Alt` + `S`)에는 터치 버튼이 없습니다. 키보드로
시작하면 **자동 이동: 뒤로**로 표시되며, 탭하면 멈춥니다.

### 편집 (에디터)

탭은 클릭과 같은 일을 합니다: 선택 도구로는 선택하고, 배치 도구로는 놓습니다.
드래그는 카메라만 움직이므로, 회전하다가 실수로 블록을 놓거나 선택을 해제하는 일은
없습니다. 터치에는 커서 올리기가 없으므로 배치 도구는 탭하기 전에 미리보기를
보여 주지 않습니다. 블록은 탭한 곳에 놓입니다. 놓을 블록이나 구조물을 고르면 도구
서랍이 닫혀서, 다음 탭이 장면에 닿습니다. 뷰포트 아래쪽 막대가 키를 대신합니다:

| 버튼 | 같은 것 | 참고 |
|---|---|---|
| **실행 취소** / **다시 실행** | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | |
| **회전** | `R` | 배치 중에는 탭하기 전에 다음 블록이나 구조물을 돌림. 그 밖에는 선택을 회전 |
| **삭제** | `Delete` | |
| **다중** | `Ctrl/Cmd`-클릭 | 켜져 있으면 탭할 때마다 블록을 선택에 넣거나 뺌 |
| **영역** | `Shift`-드래그 | 켜져 있으면 한 손가락 드래그가 카메라를 움직이는 대신 선택 상자를 그림. **다중**도 켜져 있으면 상자가 선택에 추가됨(`Ctrl/Cmd+Shift`-드래그). 영역이 켜져 있는 동안 카메라는 고정되므로(두 번째 손가락은 확대·축소 대신 상자를 취소함), 다시 둘러보려면 끄세요 |
| **더 보기** | `Ctrl/Cmd+K` | 다른 모든 편집 작업에 닿는 명령 팔레트 |

기즈모 핸들은 **영역**이 켜져 있든 아니든 마우스와 똑같이 터치로 동작합니다:
핸들을 드래그하세요.

## Escape 우선순위 (에디터)

Escape는 상황에 따라 정확히 이 순서로 동작합니다:

1. **활성 텍스트 입력** — 입력란을 비우거나 포커스를 뺍니다.
2. **키보드 단축키 오버레이** — 오버레이를 닫습니다(`?`로도 닫힘).
3. **명령 팔레트** — 팔레트를 닫습니다.
4. **진행 중인 기즈모 동작** — 드래그를 취소합니다(기록 없음).
5. **진행 중인 상자 선택** — 상자 선택을 취소합니다.
6. **그 밖의 경우** — 선택을 해제합니다(배치 모드에서는 배치를 끝냄).

### 월드 보기의 Escape

활성 텍스트 입력은 여기서도 똑같이 Escape를 먼저 받습니다. 그 밖에는 열려 있는
월드 보기 패널(초점 패널, 이름 패널 등)을 닫습니다.
