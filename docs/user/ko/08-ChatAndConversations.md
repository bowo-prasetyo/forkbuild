ForkBuild의 직접 메시지는 P2P이며 **친구끼리만** 주고받습니다 — 먼저 누군가와
친구가 되는 방법은 [피어 연결과 친구](07-PeerConnectionsAndFriends.md)를
보세요.

## 대화 시작하기

채팅은 **피어** 페이지에 있는 친구의 **채팅** 버튼이나, 맨 위 막대의 **대화**
페이지에서 엽니다 — 월드 보기나 아바타에서 채팅으로 들어가는 곳은 없습니다.
지금 친구가 아닌(또는 차단된) 사람과 채팅을 열면 입력 상자 대신 설명이
나타납니다: 채팅을 여는 것은 온라인 여부가 아니라 친구 관계입니다.

## 대화 페이지

보여 줄 만한 모든 사람 — 기억해 둔 관계, 친구 관계(대기 중인 요청 포함), 또는
메시지 기록이 있는 사람 — 을 최근 활동 순으로 나열합니다. 각 줄에는 다음이
표시됩니다:

- 표시 이름과 **온라인 / 오프라인** 배지
- 관계 — 친구, 친구 요청 대기 중, 알려진 피어, 또는 연결한 적 없음
- 읽지 않은 메시지 수, 그리고 대기열에 있으면 “전송 대기 중인 메시지 N개”
- 마지막 활동 시각

차단하지 않은 현재 친구에게만 **채팅 열기** 버튼이 있으며, 다른 사람의 줄은
대신 피어로 안내합니다. 내가 차단한 친구는 버튼 대신 “⛔ 차단됨 — 다시
채팅하려면 피어에서 차단을 해제하세요.”가 표시되며, 차단하거나 해제하는 즉시
줄이 업데이트됩니다.

## 채팅 화면

나와 친구 한 명의 스크롤 가능한 대화 기록 하나입니다: “나” 또는 상대의 이름이
붙은 메시지 말풍선에 각각 시각이 표시되고, 아래에 입력 상자(최대 4,000자)가
있습니다. **세부 정보 표시**를 클릭하면 상대의 신원, 관계, 친구 관계, 실시간
연결 상태, 메시지/대기 수를 알려 주는 작은 패널이 나옵니다. 입력 중 표시, 편집,
삭제, 반응, 첨부 파일, 그룹 채팅은 없습니다 — 일부러 메시지만 있습니다.

## 음성 통화

그 친구가 지금 연결 가능한 기기 중 하나라도 음성을 지원하면 입력 상자 옆에
**📞 통화** 버튼이 있습니다 — 상대의 어느 기기가 실제로 받을지 알 필요는
없습니다. 통화는 특정 연결 하나가 아니라 상대의 신원에 닿습니다.

- **통화**를 클릭해 전화를 거세요 — 상대가 받을 때까지 **전화 거는 중…**이
  표시됩니다.
- 받는 쪽에서는 수신 전화에 **수락** / **거절**이 표시됩니다.
- 연결되면 막대에 **통화 중**과 **음소거** / **음소거 해제**가 표시되고 —
  마이크가 실제로 연결되면 — 어떤 **마이크**와 (브라우저가 지원하면)
  **스피커**를 쓸지 고르는 선택기가 나타납니다.
- 종료 버튼은 상대가 받기를 기다리는 동안 **취소**, 실제로 통화 중일 때는
  **통화 종료**로 표시됩니다.

이 기기 전체에서 한 번에 한 통화만 할 수 있습니다 — 통화 중에는 다른 사람의
통화 버튼이 비활성화됩니다. 통화 중에 마이크가 사라지면(연결이 빠지거나 권한이
취소됨) 작은 배너가 알려 주며, 다시 연결될 수도 있으니 통화 자체는 계속됩니다.

연결되기 전에 끝난 통화는 이유를 짧게 알려 줍니다:

| 메시지 | 의미 |
|---|---|
| **통화가 거절되었습니다.** | 상대가 거절을 클릭했습니다. |
| **상대가 이미 다른 통화 중입니다.** | 상대가 다른 곳에서 바쁩니다. |
| **응답이 없습니다.** | 제때 아무도 받지 않았습니다. |
| **마이크에 접근할 수 없습니다.** | 브라우저가 마이크 접근을 거부했거나 접근 권한이 없습니다. |
| **통화를 연결하지 못했습니다.** | 연결 수준의 실패입니다 — 다시 시도해 볼 만합니다. |

평범하게 끊으면(나든 상대든) 아무 메시지도 나오지 않습니다 — 통화 막대가
사라지는 것이 전부입니다.

## 상대가 오프라인일 때 보내기

오프라인인 친구에게도 메시지를 보낼 수 있습니다 — 상대가 지금 연결되어 있을
필요는 없습니다. 메시지는 로컬 대기열에 들어갔다가 다음에 둘 다 연결되면 자동으로
전달되며, 직접 다시 보낼 필요가 없습니다. 중간에 메시지를 보관하는 서버가
없으므로 *내* 기기에서 기다립니다: 전달되려면 양쪽 모두 동시에 ForkBuild가 열려
있어야 합니다. 7일이 지나도 전달되지 않은 메시지는 버려지고 **전달되지 않음 —
만료됨**으로 표시됩니다. 보내는 메시지마다 말풍선 아래에 상태가 표시됩니다:

| 상태 | 의미 |
|---|---|
| **대기 중 — 상대가 다시 연결되면 전송** | 상대가 온라인이 되기를 기다리는 중 |
| **보냄** | 네트워크에 넘김 — 도착은 아직 확인되지 않음 |
| **전달됨** | 상대 기기에 도착한 것이 확인됨 |
| **전달되지 않음 — 만료됨** | 제때 전달되지 않아 버려짐 |
| **읽음** | 상대가 대화를 열어 이 메시지까지 읽음 |

**읽음**은 완전히 자동입니다 — “읽음으로 표시” 버튼은 없습니다. 대화를 열거나
새로 고치는 것만으로 보낸 사람에게 읽었다고 알려 줍니다.

## 대화 기록

대화는 이 기기에 로컬로 저장되며, 새로 고친 뒤에도 메시지, 전달 상태 등 모든
것이 떠난 곳에서 그대로 이어집니다. 이 기록은 **이 기기에만** 있습니다: 다른
브라우저나 컴퓨터로 따라가지 않으며, 서버 쪽 사본도 없습니다. 대화마다 최근
메시지 500개를 보관하며, 저장 공간을 위해 더 오래된 것은 조용히 사라집니다.

누군가와 친구를 끊거나 차단하면 기반 연결이 기술적으로 아직 살아 있더라도
채팅은 즉시 멈춥니다 — 따로 “연결 해제” 단계를 할 필요가 없습니다.
