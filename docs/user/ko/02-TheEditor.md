에디터는 무언가를 짓는 곳입니다. 이 안내에서는 도구, 블록을 선택하고
변환하는 방법, 그룹으로 작품을 정리하는 방법을 다룹니다.

## 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│ 툴바: 저장 · 게시 · 새로 만들기 · 내보내기 · 가져오기 ·     │
│       최근 항목 · ⌨ 단축키                                  │
├──────────────────────┬──────────────────────────────────────┤
│ [선택 | 배치]        │                                      │
│ 문서 제목         ✎  │                                      │
│ 선택                 │            3D 뷰포트                 │
│ 빌드 라이브러리      │                                      │
│   [블록 | 구조물]    │                                      │
│                      │                                      │
└──────────────────────┴──────────────────────────────────────┘
```

- **툴바** — 저장, 게시, 새 작품 시작, 문서를 파일로 내보내거나 가져오기,
  최근 작품 다시 열기, **⌨ 단축키** 오버레이 열기(`?`로도 열림).
- **도구** — **선택**(`1`)과 **배치**(`2`) 사이를 전환합니다. 블록이나
  구조물을 배치하는 동안에는 **배치**가 강조 표시됩니다.
- **문서 제목** — 열려 있는 작품의 이름입니다. **✎**을 클릭하면 제목,
  설명, 라이선스를 편집할 수 있습니다. 저장 여부는 툴바에 표시됩니다.
- **선택** — 현재 선택한 것에 쓸 수 있는 것만 보여 줍니다. 아래의
  [선택 패널](#선택-패널)을 보세요.
- **빌드 라이브러리** — 검색창과 탭 두 개:
  - **블록** — 배치 도구로 놓을 수 있는 모든 것이 다섯 섹션(기본, 구조,
    지붕과 계단, 개구부, 장식)에 타일로 나열됩니다. 하나를 클릭하면
    선택되고(배치 도구로 전환됨), 색을 고를 수 있는 **색상** 견본이
    나타납니다 — 아래의 [블록 색상](#블록-색상)을 보세요.
    **경사 45°**, **계단**, **대각 버팀대 2x2**는 한쪽으로 올라갑니다.
    반대 방향으로 놓으려면 두 번 회전하세요(**R**, **R**). 대각 버팀대와
    180° 돌린 복사본을 함께 놓으면 X자가 됩니다.
  - **구조물** — 다섯 카테고리(주거, 농업, 상업, 공공, 기반 시설)에 걸친
    기본 제공 구조물 스무 개, 더 큰 **쇼케이스** 작품 세 개, 그리고 나만의
    **내 구조물**. 카드를 클릭하면
    배치됩니다 — 아래의
    [구조물: 조합, 포크, 그리고 내 개인 라이브러리](#구조물-조합-포크-그리고-내-개인-라이브러리)를
    보세요.

### 선택 패널

이 패널은 선택한 것에 따라 바뀌므로, 아직 아무것도 할 수 없는 버튼은
보여 주지 않습니다:

- **아무것도 선택하지 않았을 때** — 짧은 안내, **모두 선택**, 무언가를
  복사했다면 **붙여넣기**, 그리고 그룹 목록(하나를 클릭하면 그 블록이
  선택됨).
- **블록을 선택했을 때** — 몇 개인지, 어디에 있는지, 그리고 자주 쓰는
  작업: **회전 ↻ / ↺**, **복제**, **삭제**, **복사**, **붙여넣기**,
  **색상**, **초점**, **선택 해제**. 덜 자주 쓰는 도구는 그 아래 세
  섹션에 접혀 있습니다: **정확한 위치와 회전**, **정렬, 배분, 반복**,
  **그룹 및 설계도**.
- **구조물 인스턴스를 선택했을 때** — 대신 위치, 회전, 작업이 담긴 전용
  카드가 나타납니다([구조물 인스턴스](#구조물-인스턴스-실시간-참조) 참고).

> **팁:** 어디서든 `Ctrl/Cmd+K`를 누르면 **명령 팔레트**가 열립니다 — 이
> 안내에 나오는 모든 작업을 이름으로 검색할 수 있는 목록입니다.

## 나의 첫 작품

어떤 기기에서 에디터를 처음 열면 3D 보기의 왼쪽 아래에 **나의 첫 작품**
카드가 나타납니다(휴대폰에서는 왼쪽 위의 작은 **첫 작품 · 0/5** 버튼으로
접힌 채 시작합니다). 카드에는 다섯 단계가 있고, 다음 단계의 힌트가
나옵니다:

1. **블록 놓기**
2. **블록 위에 쌓기**: 블록 위에 다른 블록을 놓습니다.
3. **구조물 넣기**: 빌드 라이브러리의 **구조물** 탭에서 구조물을
   놓습니다.
4. **작품 저장하기**
5. **게시하고 링크 공유하기**: 게시한 다음 **링크 복사** 또는 **공유…**를
   씁니다.

각 단계는 순서와 상관없이 해낼 때마다 체크됩니다. 실행 취소와 다시 실행은
세지 않습니다. 다섯 단계를 모두 마치면 카드가 축하하고 **다른 작품 보기**나
**계속 만들기**를 제안한 뒤 사라집니다. **–**는 카드를 작은 버튼으로 접고,
**가이드 숨기기**는 이 기기에서 계속 숨깁니다. 다시 보려면 명령 팔레트
(**Ctrl+K**)를 열고 **첫 작품 가이드**를 실행하세요. 이미 저장한 작품이 있는
기기에서는 가이드가 숨겨진 채 시작합니다.

## 두 가지 도구

### 배치 도구 (`2`)

팔레트에서 블록을 고르고, 뷰포트 위에 커서를 올린 다음, 클릭해서 놓으세요.
반투명한 유령이 블록이 놓일 정확한 위치를 보여 줍니다. 기존 블록의 면 위에
커서를 올리면 쌓거나 붙일 수 있습니다.

> **팁:** **Escape**를 누르면 선택 도구로 돌아갑니다.

### 선택 도구 (`1`)

블록을 클릭해 선택한 다음 이동, 회전, 삭제하세요. 형태를 대강 잡은 뒤에는
대부분의 시간을 여기서 보내게 됩니다.

## 블록 선택하기

ForkBuild에서는 선택을 정밀하게 다룰 수 있습니다:

| 동작 | 결과 |
|---|---|
| 블록 **클릭** | 그 블록을 선택(현재 선택을 대체) |
| **Ctrl/Cmd + 클릭** | 그 블록을 선택에 넣거나 뺌 |
| **Shift + 클릭** | 그 블록을 선택에 추가 |
| **Shift + 드래그** | 상자를 그려 안에 있는 모든 것을 선택 |
| **Ctrl/Cmd + Shift + 드래그** | 상자로 선택해 현재 선택에 *추가* |
| **Ctrl/Cmd + A** | 작품의 모든 블록 선택 |
| **Escape** | 선택 해제 |

> **왜 중요할까요:** 블록 하나보다 큰 것을 지으려면 *많은* 블록을 한꺼번에
> 다뤄야 합니다. Shift+드래그 상자 선택을 일찍 익혀 두세요 — 벽 전체를
> 잡는 가장 빠른 방법입니다.

## 이동, 회전, 삭제

블록을 하나 이상 선택한 상태에서:

| 키 | 작업 |
|---|---|
| **화살표 키** | 왼쪽/오른쪽/앞/뒤로 조금씩 이동 |
| **Page Up / Page Down** | 위 / 아래로 조금씩 이동 |
| **R** | 시계 방향으로 90° 회전 |
| **Shift + R** | 반시계 방향으로 90° 회전 |
| **Delete / Backspace** | 선택한 블록 제거 |

여러 블록을 선택하면 **공통 중심**을 기준으로 회전하므로, 한 구역 전체가
한 덩어리로 돌아갑니다.

## 블록 색상

블록 종류마다 기본 색이 있지만, 직접 고를 수도 있습니다:

- **놓기 전** — 빌드 라이브러리의 **블록** 탭에서 블록을 선택한 다음
  **색상** 견본을 클릭해 색을 고르세요. 그 뒤에 놓는 모든 블록에 그 색이
  쓰이고, 배치 유령에도 미리 표시됩니다. 다른 블록 종류를 고르면 다시
  색을 고를 때까지 그 종류의 기본 색으로 돌아갑니다.
- **놓은 뒤** — 블록을 하나 이상 선택하고 **선택** 섹션의 **색상**
  견본으로 한꺼번에 색을 바꾸세요. 모든 변경은 다른 편집처럼 실행
  취소(`Ctrl/Cmd+Z`)할 수 있습니다. 구조물 인스턴스를 선택했을 때는
  견본이 나타나지 않습니다 — 대신 구조물의 원본 문서를 편집하세요(아래의
  [구조물 인스턴스](#구조물-인스턴스-실시간-참조) 참고).

블록 색상은 작품과 함께 저장되며, 게시하거나 공유할 때도 그대로
전달됩니다.

## 정밀 변환: 숫자 입력, 정렬, 반복

선택 패널의 접힌 섹션에서는 기즈모와 위의 키 외에 더 정확하게 선택을
움직이는 방법을 쓸 수 있습니다:

- **정확한 위치와 회전** — 드래그하는 대신 정확한 X/Y/Z/회전 값을
  입력하세요. **절대**(값이 선택 항목의 피벗/방향의 목표) 또는
  **오프셋**(값이 변화량으로 더해짐)을 고른 다음 **적용**을 누르세요(또는
  입력란에서 `Enter`). 빈 입력란은 0이 아니라 “바꾸지 않음”을 뜻합니다.
  **입력란 비우기**는 선택은 건드리지 않고 입력란만 비웁니다.
- **정렬과 배분**(**정렬, 배분, 반복** 아래) — 선택 전체의 가장자리나
  중심을 월드 축에 맞추는 버튼 아홉 개(왼쪽/가운데/오른쪽,
  아래/가운데/위, 앞/가운데/뒤)와, 고르게 펼치는 버튼 세 개(X/Y/Z
  배분)가 있습니다. 정렬은 블록 **2개 이상**, 배분은 **3개 이상**을
  선택해야 합니다.
- **반복**(역시 **정렬, 배분, 반복** 아래) — 선택 항목의 사본을 **N**개 더
  만들어 한 축을 따라 같은 간격으로 늘어놓습니다. 사본 하나라도 충돌하면
  사본을 하나도 만들지 않습니다.

이 작업들은 기즈모 드래그나 키보드 이동과 똑같이 각각 **실행 취소 한
단계**입니다 — 입력란별 자세한 동작은
[조작 참조](ControlsReference.md#변환--숫자-패널-에디터-전용)를 보세요.

선택 패널의 **초점** 버튼은 아무것도 바꾸지 않고 선택한 블록이 화면에
들어오도록 카메라를 맞춥니다.

> **충돌은 막힙니다.** 기즈모를 드래그하거나 키보드로 이동하면 결과를 선택
> 밖의 모든 블록과 대조합니다. 놓았을 때 선택된 블록 하나라도 다른 블록과
> 겹치게 되면, 이동 전체가 확정되지 않고 취소됩니다 — 선택한 모든 블록이
> 처음 위치로 정확히 돌아가며, 새 실행 취소 항목도 생기지 않습니다. 선택
> *안에서* 블록을 재배치하는 것(예: 회전으로 두 블록의 자리를 맞바꾸기)은
> 충돌로 취급하지 않습니다.

## 복사, 붙여넣기, 복제

| 키 | 작업 |
|---|---|
| **Ctrl/Cmd + C** | 선택한 블록 복사 |
| **Ctrl/Cmd + V** | 붙여넣기(보이도록 살짝 옆에) |
| **Ctrl/Cmd + D** | 선택 항목을 그 자리에 복제 — 복사와 붙여넣기를 한 번에 |

복사 후 붙여넣기는 반복되는 요소에 딱 맞습니다 — 창문 하나를 지은 다음
정면 전체에 복사해 붙이세요. **복제**는 같은 일을 한 동작, 실행 취소 한
단계로 처리하며 클립보드는 건드리지 않습니다: 다른 것을 복제한 뒤에도
앞서 Ctrl+C로 복사한 것을 그대로 붙여넣을 수 있습니다. 복제된 것이 새
선택이 되므로, 선택 → 복제 → 드래그하거나 키로 이동해 자리 잡기 순서로
자연스럽게 이어집니다. 복제는 흩어진 블록, 그룹 전체, 하나의
[구조물 인스턴스](#구조물-인스턴스-실시간-참조) 등 어떤 선택에도 됩니다.

## 실행 취소와 다시 실행

모든 변경이 기록되므로 언제든 되돌릴 수 있습니다:

| 키 | 작업 |
|---|---|
| **Ctrl/Cmd + Z** | 마지막 작업 실행 취소 |
| **Ctrl/Cmd + Y** *(또는 Ctrl/Cmd+Shift+Z)* | 다시 실행 |

블록 열 개를 옮겨도 실행 취소 **한** 단계이므로, 큰 작품에서도 실행 취소가
다루기 쉽습니다.

## 그룹

그룹을 쓰면 블록 묶음에 “지붕”이나 “창문” 같은 이름을 붙이고 다시 쓸 수
있습니다.

**그룹 만들기:**
1. 블록 몇 개를 선택하세요.
2. 선택 패널의 **그룹 및 설계도** 섹션을 열고 **새 그룹**을 클릭한 다음,
   **그룹 이름 바꾸기**(아래)로 이름을 붙이세요.

**그룹 사용하기:** 목록에서 그룹 이름을 클릭하면 그 그룹(과 블록)이
선택됩니다 — 아무것도 선택하지 않았을 때는 선택 패널에, 그 밖에는 **그룹
및 설계도**에 목록이 있습니다. 다음 버튼은 선택한 그룹에 적용됩니다:

| 버튼 | 하는 일 |
|---|---|
| **그룹 이름 바꾸기** | 그룹 이름 변경 |
| **그룹 복제** | 그룹 전체와 *그 블록까지* 복사 |
| **그룹 삭제** | 그룹 삭제(블록 자체는 남음) |
| **그룹에 추가** | 현재 선택을 그룹에 추가 |
| **그룹에서 제거** | 현재 선택을 그룹에서 제거 |

> **알아 두세요:** 그룹을 선택하면 그 블록이 선택될 뿐, 그룹은 바뀌지
> 않습니다. 그리고 그룹을 삭제하면 *라벨*만 사라지고 안에 있던 블록은
> 남습니다.

## 구조물: 조합, 포크, 그리고 내 개인 라이브러리

빌드 라이브러리의 **구조물** 탭(위의 [레이아웃](#레이아웃) 참고)에는
기본 제공 구조물 스무 개 — 집, 헛간, 우물, 시장, 방앗간, 다리 등 다섯
카테고리 — 와 더 큰 **쇼케이스** 작품 세 개(성, 항구 섬, 마을 광장),
그리고 작품에서 저장한 모든 것을 모아 둔 나만의 **내 구조물**이
있습니다. 어떤 구조물로든 서로 다른 일을 할 수 있으며, 각각 쓰임새가
다릅니다:

- **배치**(카드 클릭) — 구조물의 블록을 지금 작업 중인 문서에 바로
  복사해, 더 큰 작품의 일부로 만듭니다. 가장 자주 쓰는 작업입니다.
- **새 문서로 포크**(카드의 **⋮** 메뉴) — 그 구조물을 그대로 복사한 상태로
  시작하는 완전히 새롭고 독립된 문서를 만듭니다.
- **내 구조물로 포크**(기본 제공 카드만, **⋮** 메뉴) — 문서를 거치지 않고
  구조물을 나만의 **내 구조물**에 추가합니다. 아래의
  [내 구조물](#내-구조물-나만의-설계도-라이브러리)을 보세요.
- **정보**(카드의 **⋮** 메뉴) — 구조물의 이름, 카테고리, 블록 수, 바닥
  면적, 높이, 출처, 설명을 읽기 전용으로 봅니다.
- 내가 **저장한 문서**를 **구조물 인스턴스**로 배치하기 — 복사가 아닌
  실시간으로 이어지는 재사용 가능한 참조이며, 빌드 라이브러리가 아니라
  툴바의 **최근 항목** 드롭다운에서 합니다. 아래의
  [구조물 인스턴스](#구조물-인스턴스-실시간-참조)를 보세요.

### 문서에 구조물 배치하기

**구조물** 탭의 카드 — 기본 제공이든 **내 구조물**이든 — 를 클릭하면
구조물 전체의 반투명한 유령 미리보기가 나타나, 블록 하나를 놓을 때와
똑같이 지면 위에서 포인터를 따라다닙니다:

1. 포인터를 움직여 유령의 위치를 정하세요.
2. `R` / `Shift+R`로 90°씩 회전하세요.
3. 클릭해서 확정하세요 — 구조물의 모든 블록이 **실행 취소 한 단계**로
   문서에 추가됩니다. 이미 차 있는 위치에서는 유령이 빨갛게 변하고 클릭이
   거부됩니다. 블록 하나를 다른 블록 위에 놓을 수 없는 것과 같습니다.
4. `Escape`로 취소합니다 — 아무것도 추가되지 않고, 직전에 쓰던 도구로
   돌아갑니다.

놓인 블록은 그 순간부터 문서의 평범한 블록입니다 — 손으로 놓은 것과 전혀
다르지 않으며, 다른 블록처럼 자유롭게 편집, 선택, 그룹화, 삭제할 수
있습니다. 구조물 여러 개를 배치하면 장면을 빠르게 만들 수 있습니다: 집을
클릭해 놓고, 헛간을 클릭해 옆에 놓고, 우물을 클릭해 마당에 놓으세요.

### 구조물을 새 문서로 포크하기

카드의 **⋮** 메뉴를 열고 **새 문서로 포크**를 클릭하면, 그 구조물을
그대로 복사한 상태로 시작하는 나만의 새 작품이 만들어집니다 — 블록이
똑같고, 이 안내의 모든 도구로 편집할 수 있으며, 지금 열려 있는 문서에
섞이지 않고 별도의 문서가 됩니다. 포크해도 라이브러리의 원본은 바뀌지
않습니다: 집을 열 번 포크하면 각각은 포크를 클릭한 순간부터 독립된
작품입니다.

### 내 구조물: 나만의 설계도 라이브러리

다시 쓸 만한 것을 지었나요? 그것을 이루는 블록(건물 전체든 일부든)을
선택하고 **설계도 만들기**를 클릭하세요 — 블록을 선택하면 선택 패널의
**그룹 및 설계도** 섹션에 있고, 명령 팔레트(`Ctrl/Cmd+K`)에서는 언제든
찾을 수 있습니다. 작은 대화 상자가 **이름**, **분류**, 선택 사항인
**설명**을 묻고, 저장할 것의 실시간 미리보기를 보여 줍니다. **설계도
만들기**를 클릭하면 자체 원점을 기준으로 정리되어 곧바로 **내 구조물**에
저장됩니다. 내 구조물은 구조물 탭 맨 아래, 기본 제공 카테고리 바로 밑에
있는 새 섹션입니다.

선택할 것도, 먼저 지을 것도 없이 구조물을 내 구조물에 넣는 두 번째 방법도
있습니다: **기본 제공** 카드의 **⋮** 메뉴를 열고 **내 구조물로 포크**를
클릭하세요. 문서를 만들거나 무언가를 추출하지 않고 지금 모습 그대로
추가되므로, 라이브러리의 다른 항목처럼 바로 이름을 바꾸거나, 내보내거나,
배치할 수 있습니다.

**내 구조물**의 구조물은 기본 제공 구조물과 똑같이 동작합니다 — 클릭해서
현재 문서에 배치하거나 새 문서로 포크하세요. 여기에 **⋮** 메뉴의 작업
두 가지가 더 있습니다:

| 작업 | 하는 일 |
|---|---|
| **이름 바꾸기** | 이름 변경(분류와 설명은 그대로) |
| **제거** | 라이브러리에서 삭제 |

**내 구조물**은 *구조물 자체* — 이름과 블록 묶음 — 만 저장합니다. 하나를
제거해도 그것으로 이미 지은 것은 전혀 건드리지 않습니다: 이미 배치하거나
포크해 넣은 곳은 모두 그 블록을 그대로 유지합니다. 그리고 그 자리에서
편집하지도 않습니다 — 저장한 구조물이 실제로 짓는 것을 바꾸려면, 문서에
배치하고, 그 문서를 편집한 다음, 다시 **설계도 만들기**를 하세요(원하면
“농가 디럭스”처럼 새 이름으로 — 원본을 대체하지 않고 내 구조물에 별도
항목으로 들어갑니다).

> **알아 두세요:** 내 구조물은 이 기기에 있습니다. 신원과 묶여 있지 않고
> 어디에도 자동으로 동기화되지 않습니다 — 다른 기기로 옮기거나 다른
> 사람에게 건네는 방법은 아래의
> [설계도 공유하기](#설계도-공유하기-내보내기와-가져오기)를 보세요.

### 설계도 공유하기: 내보내기와 가져오기

어떤 구조물이든 — 기본 제공이든 내 것이든 — 공유된 게시 월드의 일부가
되지 않고도 휴대용 파일로 기기 밖으로 내보낼 수 있습니다:

- **설계도 내보내기**(카드의 **⋮** 메뉴)는 작은 JSON 파일로
  다운로드합니다 — 구조물의 이름, 분류, 태그, 설명, 블록을 담은 독립된
  스냅샷입니다.
- **설계도 가져오기**(**내 구조물** 제목 옆 버튼)는 설계도 파일을 읽어
  내 구조물에 새롭고 독립된 항목으로 추가합니다 — 고유한 식별자를 가진
  새 사본이며, 출처와 연결되지 않습니다. 같은 파일을 두 번 가져오면 하나가
  다른 하나를 몰래 덮어쓰지 않고 별도 항목 두 개가 생깁니다. 형식이
  잘못되었거나 알 수 없는 파일은 망가진 것을 조용히 만들지 않고, 이유와
  함께 거부됩니다.

이렇게 친구에게 작품을 건네거나, 내 기기들 사이에 구조물을 옮깁니다: 한쪽에서
내보내고, 원하는 방법으로 파일을 보내고, 다른 쪽에서 가져오세요.

**모두 내보내기**(내 구조물이 있으면 **설계도 가져오기** 옆에 나타남)는
내 구조물의 모든 구조물을 각각의 저작자 표시와 계보 클레임과 함께 파일
하나로 다운로드합니다. **설계도 가져오기**는 그 파일도 읽으며, 이미 내
구조물에 있는 디자인은 건너뛰므로 두 번 가져와도 중복이 생기지 않습니다.
그 밖의 모든 것도 사본으로 보관하려면 [내 데이터](13-YourData.md)를
사용하세요.

### 저작자 주장하기

설계도 식별자가 있는 구조물(저장한 것은 대부분 있음)은 **커뮤니티
저작자 표시** — 누가 그 디자인을 만들었다고 주장했는지에 대한 서명된
기록 — 도 가질 수 있습니다. 카드에서 구조물의 **정보** 패널을 열면 다음이
있습니다:

- **저작자 주장** — 현재 신원으로, 내가 저작자 중 한 명이라는 클레임에
  서명합니다. 여러 사람이 같은 디자인을 각자 주장할 수 있으며, 누구의
  클레임도 다른 사람의 것을 덮어쓰거나 대체하지 않습니다.
- **저작자 표시 내보내기** / **네트워크에 게시** — 주장한 뒤에는 그
  클레임을 파일로 공유하거나 연결된 피어에게 알리세요. **네트워크에
  게시** 후에는 패널에 **배포**가 나타나며, 클레임을 탈중앙 네트워크에도
  올립니다([작품 배포하기](Distribution.md) 참고).
- **이 디자인에 다시 서명** — 2026년 9월 28일 이전의 클레임은 다른
  디자인이 흉내 낼 수 있는 이전 방식의 디자인 지문을 썼기 때문에 더 이상
  집계되지 않으며, 패널에 그 개수가 표시됩니다. 그중 하나가 내 것이고
  정말 내 디자인이라면, 이 버튼으로 클레임에 다시 서명하세요. 먼저
  디자인을 확인하세요: 이 버튼은 이전 지문을 공유하는 모든 디자인에
  나타납니다.

이것은 선택 사항이며, 구조물을 배치하거나, 포크하거나, 공유하는 것과는
완전히 별개입니다 — 다른 사람이 그냥 믿는 것이 아니라 독립적으로 확인할 수
있는 방식으로 디자인에 내 이름을 붙이고 싶을 때를 위한 것입니다. 클레임을
게시한 뒤 어떻게 되는지, 독립적인 외부 증거를 붙이는 방법은
[게시물과 외부 증거](09-PublicationsAndEvidence.md)를 보세요.

## 구조물 인스턴스: 실시간 참조

배치(위)는 구조물의 블록을 문서에 한 번 복사합니다. 하지만 때로는 이미 지은
것 — 라이브러리의 것만이 아니라 저장한 어떤 문서든 — 의 **실시간** 사본,
볼 때마다 원본과 맞춰지는 사본을 원할 수도 있습니다. 그것이 **구조물
인스턴스**입니다: 블록을 복사하지 않고 원본 문서를 참조하므로, 나중에
원본을 편집하면 모든 인스턴스가 자동으로 업데이트됩니다.

1. 툴바의 **최근 항목** 드롭다운을 여세요. (문서를 한 번 이상 저장하면
   나타납니다.)
2. 저장된 문서 옆의 **배치**를 클릭하세요. 대신 문서 이름을 클릭하면
   그 문서가 열려 지금 열려 있는 것을 대체합니다.
3. 지면 위에 커서를 올리고, `R`로 회전하고, 클릭해서 놓으세요 — 블록을
   놓을 때와 똑같습니다.

인스턴스는 블록의 사본이 아니라 그 문서에 대한 실시간 *참조*입니다: 같은
문서를 몇 번이든 배치할 수 있고, 나중에 원본 문서의 블록을 편집하면 모든
인스턴스가 업데이트됩니다. 선택 도구(`1`)로 인스턴스를 선택하면
사이드바에 다음이 나타납니다:

| 컨트롤 | 하는 일 |
|---|---|
| 뷰포트에서 드래그, 또는 [기즈모](InteractiveTransformGizmo.md) | 블록과 똑같이 이동 / 회전 |
| 화살표 키 / Page Up / Page Down | 조금씩 이동 |
| **X / Z / 회전 ° 입력란, 그리고 적용** | 정확한 위치와 방향 지정 — 높이(지면 Y)는 항상 지형을 따르며 직접 정하는 값이 아님 |
| **회전 ↻ / ↺** | 정확히 90° 회전 |
| **복제** (`Ctrl/Cmd+D`) | 같은 구조물의 인스턴스를 하나 더 배치 |
| **삭제** | 이 인스턴스 제거 — 원본 문서는 그대로 |
| **원본 문서 편집** | 참조된 문서 자체를 열어, 모든 인스턴스의 모습을 바꾸기 |

배치된 구조물의 *내용*은 항상 원본 문서를 편집해서 바꿉니다 — 인스턴스의
블록을 직접 편집하는 방법은 없으며, 바로 그 덕분에 모든 인스턴스가 맞춰진
상태로 유지됩니다.

## 문서 속성

모든 작품에는 **제목**, 선택 사항인 **설명**, **라이선스**, **월드에
배치할 수 있는 사람** 설정이 있습니다 — 에디터 사이드바 맨 위의 문서 제목
옆 **✎** 버튼으로 여는 **문서 속성** 대화 상자에서 정하세요(월드 보기에서는
**메타데이터 편집** 버튼). 새 문서는 라이선스 없이 시작하며, 라이선스를
고르기 전까지는 다른 사람이 포크할 수 없습니다. 설명은 저장소 카드에 짧게
표시되고 검색도 됩니다. 라이선스는 다른 사람이 포크할 수 있는지, 어떻게
할 수 있는지를 정합니다. 각 라이선스의 뜻은
[게시와 포크](04-PublishingAndForking.md)를 보세요.

긴 설명은 약간의 서식을 쓰면 읽기 쉬워집니다. 서식은 문서 정보 패널, 월드
보기의 위치 탐색기, Steem과 Blurt 게시물에 표시됩니다.

| 이렇게 쓰면 | 결과 |
|---|---|
| 빈 줄 | 새 문단(한 번의 줄바꿈은 줄바꿈 그대로) |
| 줄 맨 앞의 `## 재료` | 제목 |
| 줄 맨 앞의 `- `(또는 `* `) | 목록 항목 |
| `**단어**` | **굵게** |
| `*단어*` | *기울임* |
| `\*`, `\#`, `\-` | 그 문자 자체 |

그 밖의 것은 서식이 아닙니다. 링크, 그림, HTML은 일반 텍스트로 남습니다.
저장소 카드에는 설명의 낱말이 서식 없이 한 줄로 표시됩니다.

**태그**는 `japanese temple garden`처럼 작품이 무엇인지 나타냅니다. 최대
5개를 공백이나 쉼표로 구분하며, 영문 소문자, 숫자, 하이픈으로 씁니다(악센트는
빠져서 `café`는 `cafe`가 됩니다). 태그가 없는 작품이면 대화 상자가 제목과
설명에서 제안한 태그로 칸을 채웁니다. 그대로 두거나 바꾸거나 지우면 되고,
칸 아래 버튼으로 다른 제안을 더할 수 있습니다. 포크해도 태그는 유지됩니다.
Blurt 게시물에는 ForkBuild 자체 태그 뒤에 표시되므로, Blurt를 태그로 둘러보는
사람이 작품을 찾을 수 있습니다.

## 소리

변경할 때마다 저마다 짧은 소리가 나므로, 보지 않고도 무슨 일이 있었는지 들을
수 있습니다: 블록이나 구조물을 놓으면 딸깍, 제거하면 퐁, 이동하면 틱,
돌리면 틱틱, 붙여넣기나 복제는 짧은 삑 소리 연속, 새 색상은 맑은 핑, 그룹화는
두 음, 장소에 이름 붙이기는 종소리, 실행 취소는 내려가는 삑, 다시 실행은
올라가는 삑, 저장하면 작은 화음이 납니다. 같은 문서에서 협업자가 한 변경은
소리가 나지 않습니다.

화면 오른쪽 위의 **소리** 버튼이나 `M` 키(키보드 단축키 오버레이 `?`에
나와 있음)로 소리를 켜고 끄세요. 옆의 슬라이더로 음량을 정합니다. 월드
보기와 같은 설정이며, 이 기기에 기억됩니다. 브라우저 정책에 따라 소리는 첫
클릭이나 키 입력부터 나기 시작합니다.

## 저장, 게시, 새로 시작

- **저장** (`Ctrl+S`) — 작업을 이 기기에 보관합니다.
- **게시** — 모두와 공유합니다([게시와 포크](04-PublishingAndForking.md)
  참고).
- **새로 만들기** — 새로 시작합니다: **빈 땅**, 또는 미리 지어진 작품(성,
  항구 섬, 마을 광장, 집, 방앗간, 다리) 중 하나를 내 사본으로, 전체가 보이게
  엽니다. 열려 있는 것에 저장하지 않은 변경 사항이 있으면 먼저
  알려 줍니다. 유지하려면 저장하세요.
- **내보내기** — 현재 작품을 JSON 파일로 다운로드해 사본으로 보관하거나 다른
  기기로 옮깁니다. 파일은 블록을 표 형태로 저장하는 간결한 형식을 씁니다.
- **3D 모델** — 작품을 다른 프로그램용 3D 모델로 내려받습니다
  ([3D 모델 내려받기](#3d-모델-내려받기) 참고).
- **가져오기** — 내보낸 파일을 고유한 식별자를 가진 새 작품으로 엽니다.
  **저장**하기 전까지는 아무것도 보관되지 않습니다. 이전 버전에서 내보낸
  파일도 열리지만(불러올 때 변환됨), ForkBuild 1.0.0 이하에서는 이 버전에서
  내보낸 파일을 열 수 없습니다.
- **최근 항목** — 전에 저장한 것을 다시 엽니다(처음 저장한 뒤에 나타나며,
  문서 이름을 클릭하면 열림). 저장한 문서가 충분히 많아지면 필터 상자가
  나타나 이름으로 바로 찾아갈 수 있습니다. 각 항목에는 **배치** 버튼도
  있어서 — [구조물 인스턴스](#구조물-인스턴스-실시간-참조) 참고 — 현재
  문서를 대체하는 대신 *현재* 문서에 추가할 수 있습니다. 맨 아래의 **모든
  문서 내보내기**는 저장된 모든 문서를 파일 하나로 다운로드합니다.
  **가져오기**는 그 파일을 다시 읽어, 이 기기에 없는 문서는 저장하고(최근
  항목에서 열기), 바뀌지 않은 채 이미 있는 것은 건너뛰고, 다른 버전으로
  있는 것은 그 옆에 사본으로 저장합니다. 저장하지 않은 변경 사항은 포함되지
  않으니 먼저 저장하세요.

## 3D 모델 내려받기

도구 모음의 **3D 모델**은 열려 있는 작품을 다른 3D 프로그램이 여는 파일로
내려받습니다. 파일은 이 기기에서 만들어지며 아무것도 올리지 않습니다.

- **glTF(.glb)** — 색상 포함. Blender, Windows 3D 뷰어, Godot와 Unity 같은
  게임 엔진, 온라인 모델 뷰어에서 열립니다. ForkBuild의 1단위는 1미터입니다.
- **3D 프린팅용(.stl)** — 단색, 1:100 축척의 밀리미터 단위(문 높이 20mm,
  정육면체 10mm), Z축이 위이고 출력 베드에 놓인 방향이라 슬라이서(Cura,
  PrusaSlicer, Bambu Studio 등)에서 바로 출력할 수 있습니다. 더 크게 하려면
  슬라이서에서 키우세요. 맞닿거나 겹치는 블록은 따로 된 조각으로 남고,
  슬라이서가 슬라이싱할 때 합칩니다.
- **OBJ(.obj)** — 색상 포함(정점 색상), 오래된 프로그램용.

각 블록은 ForkBuild에서의 모양과 색을 그대로 유지하고, 배치한 구조물은 이
기기에 있으면 함께 들어갑니다(빠진 것이 있으면 메시지가 알려 줍니다). 모든
파일에 작품 이름, 만든 사람, 라이선스, 리믹스 원본이 적힙니다: glTF는
copyright와 extras에, STL은 헤더에, OBJ는 주석에 들어갑니다. 공유된 작품의
페이지도 라이선스가 복사를 허용하면 같은 내려받기를 제공합니다
([링크를 열면 보이는 것](04-PublishingAndForking.md#링크를-열면-보이는-것) 참고).

## 카메라 조작

- **드래그** — 장면 주위를 회전
- **스크롤** — 확대와 축소
- **Home** — 카메라를 기본 시점으로 초기화

## 휴대폰이나 태블릿에서

에디터는 터치로도 동작합니다. 한 손가락으로 드래그하면 회전, 두 손가락으로
이동, 핀치로 확대·축소합니다. 탭하면 선택하거나 놓고, 드래그로는 그러지
않습니다. 좁은 화면에서는 장면 오른쪽 위의 **도구** 버튼으로 사이드바를
엽니다. 장면 아래쪽 막대에는 **실행 취소**, **다시 실행**, **회전**,
**삭제**, **다중**(탭할 때마다 블록을 선택에 넣거나 뺌), **영역**(드래그해
선택 상자를 그림, 끌 때까지 카메라가 고정됨), 그리고 명령 팔레트를 여는
**더 보기**가 있습니다. 자세한 내용은
[터치스크린](ControlsReference.md#터치스크린)을 보세요.
