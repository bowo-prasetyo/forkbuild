# 分发你的作品

你在 ForkBuild 中做的一切都从你自己的设备开始。**分发**会把它放到去中心化网络上，让没有与你连接的人也能找到它、获取它，
并确认它是你的。它是可选的，而且与发布是两回事。

本页说明你可以分发什么、可以发到哪里，以及需要什么。每个部分都链接到有详细说明的指南。

## 发布、共享、分发：三件不同的事

| 操作 | 去哪里 | 谁能得到 | 指南 |
|---|---|---|---|
| **发布** | 此设备，以及在你选择了作品的去处后，也会发到那里 | 在此之前没有其他人；之后是任何人 | [发布你的作品](04-PublishingAndForking.md#发布你的作品)、[去处](04-PublishingAndForking.md#去处发布时发送作品) |
| **与对等节点共享** | 直接发给与你连接的人 | 你在线时，已连接的对等节点 | [与已连接的对等节点共享](04-PublishingAndForking.md#与已连接的对等节点共享) |
| **分发** | 去中心化网络（IPFS、Arweave、Nostr、Steem、Blurt） | 任何人，不需要与你连接 | 本页 |

在你选择作品的去处之前，发布本身不会向任何地方发送任何东西。你在编辑器的**去处**中选择：勾选**每次发布都发送到这里**后，
每次发布已签名的作品也会分发到那里。取消勾选即可停止。

与对等节点共享不是分发。对等节点保留副本的时间完全由他们决定，其他人也找不到它。

## 网络扮演的三种角色

分发最多会用到三种网络，每种单独选择：

| 角色 | 好比…… | 作用 | 选项 |
|---|---|---|---|
| **内容**（存储） | 存放印刷本的地方 | 保存字节，比如你世界的积木，让别人可以获取 | **Arweave**、**Blurt** *（实验性）*、**IPFS（本地 Kubo）**、**IPFS（远程固定）**、**Steem** *（实验性）* |
| **公告 / 发现** | 图书馆目录中的条目 | 发布一条小小的签名通知，说明你的作品存在以及它的副本在哪里，让别人可以找到 | **Nostr**、**Arweave**、**Steem** *（实验性）*、**Blurt** *（实验性）* |
| **证明 / 锚定** *（实验性，可选）* | 公证人的印章 | 把你内容的哈希写入区块链，作为它在那个时间已经存在的证据。它不存储也不公告任何东西。 | **Bitcoin**、**Arweave**、**Base**、**Steem**、**Blurt** |

前两种都需要。存储了却没有公告的作品很难被找到，而只有公告却什么都没存储的话，公告就指向了空。
**分发**一次点击就能完成两者。锚定是额外的，要在**签名记录**页面上单独进行。

在[网络设置](10-NetworkSettings.md)下为每种角色设置你常用的选择：[内容服务](10-NetworkSettings.md#内容服务)、
[公告 / 发现服务](10-NetworkSettings.md#公告--发现服务)和[证明 / 锚定服务](10-NetworkSettings.md#证明--锚定服务)。
它们只会填入每个选择器的第一个选项。保存它们永远不会发送任何东西。

## 你可以分发什么

| 内容 | 内容存储 | 公告 / 发现 | 证明 / 锚定 | 在哪里操作 |
|---|---|---|---|---|
| **你世界的签名声明**（已发布世界的签名记录，称为共享世界） | Arweave、IPFS、Steem 或 Blurt | Nostr、Arweave、Steem 或 Blurt | — | 在编辑器中发布后的**分发**；世界视图中的**我的共享世界**；**签名记录**页面 |
| **你世界的快照**（它的积木），以及你把它放在哪里 | Arweave、IPFS、Steem 或 Blurt | Nostr、Arweave、Steem 或 Blurt | — | 同样的**分发**对话框（只发这一半请用**仅分发快照**） |
| **任何记录的内容哈希**（世界、作者声明或地名） | — | — | Bitcoin、Arweave、Base、Steem 或 Blurt | **签名记录**页面上该记录的卡片 |
| **结构的作者身份**（蓝图署名） | Arweave、IPFS、Steem 或 Blurt | Nostr、Arweave、Steem 或 Blurt | — | 结构**信息**面板中的**分发**，在你**发布到网络**后提供；**签名记录**页面 |
| **地名**（地名提议） | Arweave、IPFS、Steem 或 Blurt | Nostr、Arweave、Steem 或 Blurt | — | 世界视图命名面板中的**分发**，在你**发布一个名称**后提供（它会在你选择的网络上公告这个名称）；以上任何一项都可以在**签名记录**页面上操作 |
| 对发布内容的**评论** | — | Nostr、Arweave、Steem 或 Blurt，或者都不用（**仅本地和对等节点**） | — | 在“探索”或世界视图中**发表评论**，发到旁边选择的网络；之后可以在你自己的评论下**分发** |

世界的快照携带着你签名的放置，所以获取它的人会看到作品正好在你放置它的地方。

### 签名声明与快照：一个世界的两半

一个已发布的世界会分成两个独立的部分来分发：

| | 签名声明 | 快照 |
|---|---|---|
| **好比……** | 一张经过公证的目录卡片 | 书架上的印刷本，标明它放在哪里 |
| **包含什么** | 世界的标题、你作为作者、它的许可证、它改编自的世界（如果有）以及它的**内容哈希**（积木的指纹），全部用你的身份签名 | 世界的每一块积木，加上你签名的放置：你在世界视图中把它放在哪里 |
| **大小** | 几 KB | 与作品一样大：在 Arweave 上最多 256 KB，在 IPFS 上没有限制 |
| **证明什么** | 你发布了这个世界，并且指纹正是这个 | 本身不证明任何东西；任何获取它的人都会对照内容哈希检查积木 |
| **用途** | 分享链接，以及**发现共享世界**查找你的世界并检查它 | 在世界视图中，把你的作品显示在你放置的地方，给附近漫步的人看 |

内容哈希把两者联系在一起：任何持有积木的人都可以检查它们是否与你签名记录上的指纹相符。

两半都会用到两种角色：每一半都存储在你选择的内容网络上，并在你选择的公告 / 发现网络上公告。
例如选择 IPFS 和 Nostr 时，**分发**会把快照存储到 IPFS 并在 Nostr 上公告，然后把签名声明存储到 IPFS 并同样在 Nostr 上公告。

每一半单独都有用，这就是为什么**分发**对话框会分别报告它们，并允许你用**仅分发快照**或**仅分发签名声明**重试其中一半：

- **仅快照：** 你的作品会在世界视图中出现在附近的人面前，但它背后没有发布内容的签名记录。
- **仅签名声明：** 人们可以找到你的世界并确认它是你的，但无法从网络上获取它的积木。
  与你连接的对等节点在你在线时仍然可以直接从你这里获取。

详情：

- 签名声明和快照：[去处](04-PublishingAndForking.md#去处发布时发送作品)、
  [我的共享世界](WorldViewAdvancedTools.md#我的共享世界分发你自己的快照无需对等节点)，
  以及[分发对话框](WorldViewAdvancedTools.md#世界相遇你的对等节点正在共享的发布内容和化身)本身。
- 签名记录页面：[从签名记录页面分发](09-PublicationsAndEvidence.md#从签名记录页面分发)、
  [快照放置](11-EvidenceAndStorage.md#快照放置)和 [IPFS 发布](11-EvidenceAndStorage.md#ipfs-发布)。
- 锚定：[外部证据](11-EvidenceAndStorage.md#外部证据)、[Bitcoin 锚定流程](11-EvidenceAndStorage.md#bitcoin-锚定流程)
  和 [Base 锚定流程](11-EvidenceAndStorage.md#base-锚定流程)。
- 作者身份：[声明结构的作者身份](09-PublicationsAndEvidence.md#声明结构的作者身份)。
- 地名：[为地点命名](09-PublicationsAndEvidence.md#为地点命名)。
- 评论：[评论如何传播](09-PublicationsAndEvidence.md#评论如何传播)。

## 留在你或你的对等节点那里的东西

你做的东西并不都会被分发。以下内容永远不会发到上面那些网络：

| 内容 | 去哪里 | 指南 |
|---|---|---|
| 你**与对等节点共享**的世界 | 只发给你已连接的对等节点 | [与已连接的对等节点共享](04-PublishingAndForking.md#与已连接的对等节点共享) |
| 你化身的实时位置和外观 | 已连接的对等节点，按你的可见性设置 | [谁能看到你](06-AvatarsAndPresence.md#谁能看到你两个独立的设置) |
| 聊天消息和语音通话 | 直接发给与你交谈的朋友 | [聊天与对话](08-ChatAndConversations.md) |
| 你通过**与对等节点同步**交换的锚定和放置 | 只发给你已连接的对等节点 | [去中心化一览](09-PublicationsAndEvidence.md#去中心化一览) |
| 你的身份、保存的结构、你携带的载具和动物、好友、设置 | 此设备，除非你导出或备份它们 | [你的数据](13-YourData.md) |

要把这些转移到另一台设备，或交给别人，请使用[你的数据](13-YourData.md)中的导出和完整备份。

## 每个网络需要什么

分发由你自己安装的浏览器扩展或钱包签名；ForkBuild 永远看不到你的密钥。没有对应的扩展时，尝试会以一条说明无法完成的提示结束。

| 网络 | 角色 | 你需要 | 限制和说明 |
|---|---|---|---|
| **Nostr** | 公告 / 发现 | 一个 Nostr 签名扩展，比如 nos2x | 同时向 [Nostr 中继](10-NetworkSettings.md#nostr-中继)中的每个中继公告；中继越多，能找到你的人越多 |
| **Arweave** | 内容、公告 / 发现、证明 / 锚定 | 一个 Arweave 钱包扩展，比如 Wander | 每个快照最多存储 256 KB，约八千块积木；更大的会在签名前被拒绝。永久保存：你的电脑关机时仍然可用。新上传的内容可能需要几分钟才能到达各个网关。 |
| **IPFS（本地 Kubo）** | 内容 | 你自己的 IPFS 节点，默认位于 `http://127.0.0.1:5001` | 没有大小限制。只有在你的节点在线时可用，除非有别人固定了它。 |
| **IPFS（远程固定）** *（实验性）* | 内容 | 一个兼容 Pinata 的固定服务账户 | 没有大小限制。在[内容服务](10-NetworkSettings.md#内容服务)下设置一次服务；令牌每次访问询问一次，从不保存。 |
| **Steem** *（实验性）* | 内容、公告 / 发现、证明 / 锚定 | 带有你发帖密钥的 Steem Keychain 扩展，以及在[网络设置 → Steem](10-NetworkSettings.md#steem)下设置的账户 | 帖子是对 ForkBuild 每月帖子的回复；每篇帖子批准一次。每篇帖子约存储 2,500 块积木，20 篇帖子最多约 30,000 块积木。消耗资源积分，会恢复。 |
| **Blurt** *（实验性）* | 内容、公告 / 发现、证明 / 锚定 | 带有你发帖密钥的 Blurt Keychain 扩展（或 WhaleVault），以及在[网络设置 → Blurt](10-NetworkSettings.md#blurt)下设置的账户 | 每个作品从你自己的账户发一篇顶层帖子，保留收益；存储的数据放在它下面的回复中。每条回复约存储 2,500 块积木，最多约 30,000 块积木。每笔交易收取少量 BLURT 费用。 |
| **Bitcoin** *（实验性）* | 证明 / 锚定 | UniSat 扩展，以及在原生 SegWit（`bc1q…`）地址上用于支付手续费的比特币 | 通过签名记录页面上的钱包步骤完成 |
| **Base** *（实验性）* | 证明 / 锚定 | 一个在 Base 上的浏览器钱包，比如 MetaMask 或 Coinbase Wallet | 每个锚定都是一笔需要你审核并签名的交易 |

Steem 锚定快速且免费，但由 Steem 的见证人证明，而不是工作量证明：请把它与 Bitcoin 锚定一起使用，而不是取而代之。
见 [Steem](11-EvidenceAndStorage.md#steem)。Blurt 锚定也是如此，当你作品的 Blurt 帖子已经带有它的内容哈希时，它不花费任何东西；
见 [Blurt](11-EvidenceAndStorage.md#blurt)。

## 一条典型的路线

1. 在编辑器中**发布**你的世界（见[发布你的作品](04-PublishingAndForking.md#发布你的作品)）。
2. 点击出现的提示中的**分发**。你也可以以后在世界视图的**我的共享世界**下进行。
3. 选择一个**存储**和一个**公告 / 发现载体**：比如 IPFS 和 Nostr，或者两者都用 Arweave。点击**分发**。
4. 它会先发送快照，再发送签名声明，并为每一个显示结果。如果其中一半失败，用它自己的**仅……**按钮只重试那一半。
5. *可选：* 在**签名记录**页面上锚定这条记录（例如用**锚定到 Arweave**），记录它存在的时间。
6. 点击结果下方的**分享…**或**复制链接**。这个链接在任何设备上都能打开你的作品，可以改编或在里面四处走走。

对 Arweave 来说太大的作品（超过 256 KB）可以改放到 IPFS 上。与你连接的对等节点可以直接从你这里获取最大 64 MB 的作品。

## 检查是否成功

- **在你自己的卡片上。** 你作品在**探索**中的卡片会说明此设备记录的分发去处：例如**存储于 IPFS · 公告于 Nostr**，
  或者**此设备上没有分发记录**。见[你的发布内容](13-YourData.md#你的发布内容)。
- **对其他人来说。** 只要作品是以常用的发现标签 `forkbuild-publication` 公告的，他们的**探索**下次打开时就会在
  Nostr、Arweave、Steem 或 Blurt 上找到你的作品。见[他人分发的作品](04-PublishingAndForking.md#他人分发的作品)。
- **直接从网络上检查。** 世界视图中的**发现共享世界**会在 Arweave 和 Nostr 上查找你的世界并检查它：它真的在那里、而且完好无损吗？见
  [发现共享世界](WorldViewAdvancedTools.md#发现共享世界直接搜索去中心化网络)。
- **在签名记录页面上。** **验证 IPFS 内容**会把 IPFS 上传的内容取回来并与其哈希比较。**验证证据**会检查锚定。

分发无法撤销：一旦某样东西被存储或公告，其他人可能已经有了副本。**取消发布**只会把世界从你自己的目录中移除。
之后，此设备会记住在“探索”搜索网络时不再列出你分发出去的副本。
