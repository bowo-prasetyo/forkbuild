> **高级。** 搭建、分享、改编或和朋友一起四处走走都不需要这一章：[开始玩的章节](README.md#开始玩按顺序阅读)

ForkBuild 把你直接连接到其他人的浏览器——没有保管好友列表的中央服务器。打开**更多 → 对等节点**，
管理你与谁连接、认识谁、与谁是好友。

## 页面一览

```
对等节点                                 你的 ID …N6KbN  [复制完整 ID]

需要你处理                   等待你处理的连接、好友请求
人  [全部|好友|我关注的|在线]  每人一行
与新的人连接  [邀请|粘贴邀请|通过 ID 查找|公共大厅]
▸ 已屏蔽 (N)                 仅在你屏蔽了某人时显示
```

- **需要你处理**只在有东西等待时出现：正在进行的连接（附带它的步骤，例如“第 2/5 步：WebRTC 正在连接”）、
  等待你粘贴对方回复的连接、需要关闭的失败连接，或者有人请求成为你的好友（**接受** / **拒绝**）。
- **人**每人一行，无论你对他们知道多少。标签说明他们对你来说是什么——**好友**、**已记住**、**关注**、
  **已屏蔽**、**请求已发送**、**想成为好友**——绿点表示在线。在线的人排在最前面，然后是好友，然后是其他所有人。
  每一行都有它的主要操作（好友是**聊天**，对方离线时是**重新连接**，已连接的人是**加为好友**），
  **⋯** 菜单中有其余操作：**重命名**（或**命名并记住**）、**记住** / **忘记**、**删除好友**、
  **关注** / **取消关注**、**连接详情**、**断开连接**，以及**屏蔽** / **解除屏蔽**。
  **我关注的**筛选器显示这里你关注的人，并指向列出你关注的所有人的**关注**页面。
- **已屏蔽**收在底部，只在你屏蔽了某人时显示。

列表背后是五种相互独立的记录——实时连接、已知对等节点（你选择**记住**的人，一份从不与对方分享的私人备注）、
好友（互相的、签名的）、关注（见[关注他人](#关注他人)）和已屏蔽。一个人可以是好友而不被记住，以此类推；
那一行只显示适用的标签。你关注但从未连接过的人不会列在这里；**关注**页面会列出你关注的所有人。

## 寻找并连接某人

没有可以搜索的用户名——每个对等节点都以其密码学身份来识别，所以连接总是从通过你已经信任的某种渠道
（聊天、电子邮件、当面）交换身份信息开始。**与新的人连接**一次显示一种方式：

- **邀请**——点击**创建邀请**，然后复制并发送给某人。连接会在**需要你处理**下等待；对方回复后，
  把对方的回复粘贴到那里，然后点击**完成连接**。
- **粘贴邀请**——接收的一方：粘贴别人发给你的邀请，点击**连接**，然后把你得到的回复发回去。
- **通过 ID 查找**——在你或他人发布的候选中，按某人的完整身份 ID 搜索，然后点击**连接**。
  你的回复会通过会合服务器传回，所以连接会自动完成；只有在不可能这样做时（你的身份已锁定，
  或者候选来自一份保存的邀请），你才需要手动复制回复。下面收起的**保存邀请以便稍后使用**
  会把一份邀请加入这些搜索结果，但不进行连接。
- **允许被发现**（在同一个标签页中，**让别人找到你**下）——把你自己的身份发布到会合网络上，
  这样已经知道你身份 ID 的人不需要直接邀请就能找到并连接你。一次发布只响应一次连接尝试——
  要再次被找到，请再次打开它。当你的发布还在等待有人响应时，按钮显示**停止允许被发现**；
  一旦有人连接，或者提供关闭或其邀请过期，它会自动变回**允许被发现**。发布时你的身份必须已解锁：
  会合服务器只接受由其所声明的身份签名的发布，所以没有其他人能替你发布或撤回。默认的会合服务器只为托管的
  ForkBuild 网站服务；如果你从自己的地址（包括 `localhost`）运行 ForkBuild，请使用邀请，或者在
  **网络设置**的**会合服务器**下添加你自己的服务器。这个状态在整个应用中保持，所以离开对等节点页面再回来不会重置它。
- **公共大厅**——结识你没有其 ID 的人；见下文。

页面顶部的**你的 ID**以及**复制完整 ID**，是别人使用**通过 ID 查找**所需要的。各行上显示的缩短的
`…末尾14个字符`只是为了一眼区分不同的人，永远无法匹配真正的搜索。

无论你走哪条路，连接都会经过相同的步骤：**已通过会合服务器发现 → WebRTC 正在连接 → 对等节点已连接 →
正在认证身份 → 已认证**（或**失败**）。已连接的人的 **⋯** 菜单中的**连接详情**会显示对方的身份、公钥，
并提醒你*连接*本身只在本次会话中有效，尽管已知对等节点或好友记录会保留下来。“已在线 …”和“开始于 … 前”
计时器从连接实际建立时开始计算，所以即使你离开再回来，它们也会正确地继续计时。

## 公共大厅：结识你还不认识的人

“通过 ID 查找”需要某人的完整身份 ID。**公共大厅**用于结识你没有其 ID 的人。有一个面向所有人的大厅，
在**对等节点**页面的**与新的人连接 → 公共大厅**下；每个世界也有一个，在世界视图的**大厅**下。

- **加入大厅**会以你选择的显示名称把你列在那里，旁边是你身份 ID 的末尾部分。任何人都可以随意取名；
  连接真正核对的是身份。这个名字会被记住，供下次使用。
- 你在大厅中时，此设备保持可被发现：大厅里的任何人都可以对你点击**连接**；有人连接后，它会立即为下一个人做好准备。
- 在列表中某人身上点击**连接**，会以与“通过 ID 查找”相同的方式连接对方，不需要复制任何东西。
  对方的卡片会显示**正在连接…**，然后在握手证明对方身份后显示**已连接**。在大厅中看到某人本身永远不会连接对方。
  加入大厅确实会把你连接到那些可被发现的已知对等节点，无论他们在哪里（见[重新连接](#重新连接)）。
- **屏蔽**会把某人从你的大厅列表中隐藏，并像在本页其他地方一样屏蔽对方。
- **离开大厅**会立即让你离开。加入只在本次访问中有效：关闭应用会离开所有大厅（你的条目可能需要最多 10 分钟
  才会从其他人的列表中消失），再次打开时你也永远不会被重新放回大厅。

**从大厅连接你的人会得到什么。** 大厅连接就是一个普通的已连接对等节点，即使在你记住或加对方为好友之前也是如此。
对方会知道你的 IP 地址，按你的可见性设置看到你的化身和在线状态，你们的设备会**交换快照和地名公告以及发布元数据**，
与任何已连接的对等节点完全一样（见[隐私](Privacy.md)）。聊天和语音仍然需要成为好友。
你与对等节点共享的世界也会提供给对方，但只有对方点击**获取**时，对方的设备才会获取（见
[与已连接的对等节点共享](04-PublishingAndForking.md#与已连接的对等节点共享)）。
你的好友和已知对等节点共享的世界会自动为你获取；大厅里的陌生人共享的则永远不会。

**只在需要时使用中继。** 每个连接都会先尝试直连路径，只有在没有直连路径可用时才使用会合服务器的 TURN 中继。
你在大厅中等待时，你的设备从不请求中继凭据；只有连接你的人在需要时才会请求。这样能把中继每月的额度留给真正发生的连接。

大厅需要会合服务器（见**网络设置**中的**会合服务器**）和一个已解锁的身份。

## 记住、加好友、屏蔽

- **记住**某人（在对方的 **⋯** 菜单中），即可保留一份关于对方的私人本地备注——不需要对方同意。
  **重命名**会给对方一个只有你能看到的名字；对于你还没记住的人，**命名并记住**会同时做这两件事。
  **忘记**会删除这份备注，仅在本地。
- 已连接的人那一行上的**加为好友**会请求建立相互关系；对方会在**需要你处理**下看到它，并有**接受** / **拒绝**，
  在等待期间，你可以从 **⋯** 菜单中**取消好友请求**。**删除好友**会结束这种关系；这需要对方在线连接，
  因为对方必须收到它。好友会有一个**聊天**按钮——见[聊天与对话](08-ChatAndConversations.md)。
- **屏蔽**会阻止来自那个身份的一切——在线状态、资料、聊天，甚至好友请求——而不通知对方。
  屏蔽好友不会删除好友关系，只是让它静默；**解除屏蔽**（在 **⋯** 菜单中，或在**已屏蔽**列表中）
  会恢复接收对方的消息，但永远不会恢复屏蔽期间被静默的任何内容。

## 关注他人

**关注**让你随时了解某人的作品，就像在社交网络上关注一个账户一样，你们双方都不需要向对方请求任何东西。

- **在哪里关注。** **关注**出现在“探索”中的发布卡片上、作者页面上**签名者：…**的旁边、本页中某人的
  **⋯** 菜单中，以及世界视图中化身上的**关注对方的作品**。你关注的是一个*身份*，而不是输入的作者名字：
  几个人可以用同一个名字发布，所以作者页面会为在该名字下签名发布作品的每个身份各显示一个**关注**。
- **关注页面**（**更多 → 关注**）列出你关注的人，每人都有**取消关注**，下面是他们已经到达此设备的最新作品，
  最新的排在最前面。点击一个名字即可只看那个人的作品。
- **通知。** 当你关注的人的新作品到达此设备时，🔔 面板会收到一条**… 发布了新内容**，每个作品一条，
  并附带用于打开它的**探索**（如果你开启了[此设备上的通知](03-WorldView.md#此设备上的通知)，你的设备也会显示它）。
- **会为你获取他们共享的世界。** 你关注的人与已连接对等节点共享的世界会被自动获取，就像好友和已记住的对等节点的一样。
- **他们的公告会保留得更久。** 此设备会记录它见过的公告，每个发现标签有一个上限。当一个标签满了时，
  最久没见过的记录会先被丢弃，但你关注的人签名的建筑放置和地名会优先于其他记录保留。

**关注是私密的、单向的。** 这个列表保存在此设备上，属于你正在使用的名字。它从不发送到任何地方，
被你关注的人永远不会收到通知，也没有粉丝数：没有服务器，就没有人能诚实地统计它。关注也不会给对方任何东西：
不能聊天，看不到你的化身，没有办法联系到你。这些仍然是好友关系的用途。

**关注不会做什么。** 关注会从到达此设备的内容中挑出你关注的人的作品；它不会自己去获取他们的作品。
作品仍然通过通常的途径到达：世界视图中的世界发现、已连接的对等节点共享的世界，以及你打开的链接。
只有签名通过检查的作品才算，所以没有人能通过在自己的作品上写别人的名字或身份而出现在你的关注页面上。
你**屏蔽**的人的作品即使你关注了也会保持隐藏。

## TURN：为找不到直连路径的对等连接做中继

每个对等连接一开始都会尝试在两个浏览器之间协商一条直连路径，由 ForkBuild 自己默认的公共 STUN 服务器
帮助双方发现各自可访问的地址。这对大多数连接来说已经足够——但有些网络（对称 NAT、严格的企业防火墙）
从不暴露仅靠 STUN 就能找到的路径。如果你的会合服务器提供 TURN 中继，ForkBuild 会在你开始一个连接时
（而不是仅仅打开应用时）向它请求短期中继凭据，并自动使用它们。服务器每月发放的中继凭据数量有限；
用完后，连接仍然会尝试，只是不使用中继，直到下个月。要使用你自己的中继，请在**更多 → 网络设置**中打开
**TURN 服务器**（`/settings/turn-server`），并配置你自己的 TURN 中继：一个在无法建立直连路径时
真正转发连接数据的服务器。

```
TURN 服务器

你自己的 TURN 中继，用于无法建立直连或 STUN 协商路径的对等连接。
这个设置只影响连接建立；不会改变对等节点身份、认证或任何已有连接。

不需要填写这里也能获得中继：连接开始时，ForkBuild 已经会向你的
会合服务器（见“会合服务器”）请求一个短期 TURN 中继，并在对方提供
时使用。只有当你自己运营或付费购买了中继时，才需要在这里添加；它会
与对方的中继一起使用，而不是取而代之。

[ 每行一个 turn:/turns: URL，例如 turn:relay.example:3478 ]

用户名 [______________]
凭据 [______________]

[保存]   [清除]
```

输入一个或多个 `turn:`/`turns:` URL（每行一个）、一个**用户名**和一个**凭据**——同一对共享凭据会用于你列出的每个 URL，
而不是每个服务器单独一对——然后点击**保存**。设置后，当前中继会显示为“当前 TURN 中继（*N* 个 URL）：
`<你的 URL>`——用户名：`<你的用户名>`”——凭据本身一旦保存就永远不会再显示给你，只显示已配置了一个。
点击**清除**可以完全删除它。

**这里有意没有“恢复默认”按钮。** 默认中继来自会合服务器（如上所述），所以这个页面没有内置的东西可以恢复：
在这里内置一个 TURN 服务器，就意味着把它的凭据公布在应用中，任何人都能读取和使用。这个页面留空时，
在会合服务器提供中继时你仍然会得到它的中继；两边都没有中继时，连接只依赖 STUN 和直连。
你自己的中继是可选的，只有在即便如此与某些对等节点的连接仍然一直失败时，才需要你自己提供
（许多 WebRTC 托管服务商都提供）。与其他所有网络设置页面一样，这里的更改只在下次加载应用时生效。

## 重新连接

不在线的已知对等节点或好友会显示一个**重新连接**按钮，即使是你从未记住的好友也是如此。它会就在对方那一行上
打开与**邀请** / **粘贴邀请**相同的邀请交换，并且总是执行一次完整的、全新的握手，而不是重用旧的连接细节。
如果重新连接尝试认证出的身份与预期的*不同*，ForkBuild 会拒绝它，并以明确的错误关闭连接，而不是默默地信任应答的人。

ForkBuild 还会自动为已知对等节点中的每个身份尝试这件事：应用一启动、每当你记住、忘记或以其他方式改变已知对等节点关系时、
每次你自己点击**允许被发现**时，以及每次你点击**加入大厅**时，它都会悄悄检查每个人当前是否可被发现，
如果可以，就会连接，而不需要你自己点击“重新连接”。所以两个都点击了**允许被发现**、或者都加入了大厅（无论是不是同一个）
的朋友会连接上：第二次点击会找到第一次。保持在大厅中不会自己重复这项检查。当前不可被发现或无法连接的已知对等节点
会被直接放过——没有追着他们不停重试的循环，没有关于这次尝试的通知，一个身份失败也永远不会影响另一个。
当你想马上连接而不是等待下一次自动检查时，请使用**重新连接**。

## 接下来做什么？

交到朋友后，在**[聊天与对话](08-ChatAndConversations.md)**中和他们聊天。
