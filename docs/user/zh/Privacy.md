ForkBuild 没有账户，也不跟踪你。它把你的作品保存在你自己的浏览器中，只为需要的功能与其他计算机通信，
另外还有一项匿名访客计数：每天一次、在使用分享链接时，以及在安装时，以便开发者大致了解有多少人在使用和分享作品
（见下面的“访客计数”，以及如何关闭它）。本页列出它保存了什么，以及它可能联系的每个服务器和联系时机。

## 留在你设备上的内容

以下所有内容都存放在这个浏览器的存储中（名为 `forkbuild` 的 IndexedDB 数据库；没有 IndexedDB 的浏览器使用 `localStorage`，
键名以 `forkbuild:` 开头），除非你发布、导出或发送，否则永远不会离开设备：

- 你的文档、未保存更改的崩溃恢复副本，以及保存的结构；
- 你的身份：每个身份的公钥，以及它的私钥——除非你选择不设密码短语创建，否则私钥会用你的密码短语加密；
- 把你的作品发送给所有人的载体密钥（一把 Nostr 密钥，在你第一次在**谁能找到它？**下选择**所有人**时生成）。
  它不是你的身份，不为你的任何东西签名：任何拿到它的人只能发送笔记，而每个读者都会对照你身份自己的签名检查这些笔记；
- 你对**谁能找到它？**的回答；
- 在第一次发布或漫步时只用名字创建的身份，在你在**我的身份**中添加密码短语之前没有密码短语，所以任何能读取本网站存储的东西
  都能以它的身份签名；
- 已知对等节点、好友、你关注的人、屏蔽、聊天记录和排队的消息（被你关注的人不会收到通知，关于关注的任何信息都从不发送）；
- 你的化身资料（在取名字之前漫步世界视图时，你是访客：那个化身不保存在任何地方，连这里也不保存，也从不发送给任何人）、
  设置（包括世界视图是否播放声音、音量多大、3D 还是立体声、有没有音乐、世界视图是否显示高级工具、那里是否永远是白天、
  太阳和月亮是否在那里投下阴影、发布把你的作品发送到哪里、你选择的语言，以及外观是浅色、深色还是跟随设备；
  当你没有选择语言时，ForkBuild 会在设备上读取浏览器的偏好语言，并且不会把它发送到任何地方），
  以及你在**网络设置**下输入的 TURN 服务器用户名和凭据；
- 这个浏览器是否参与每日访客计数，以及它上次参与的日期；
- 此设备找到并验证过的其他人的发布内容，来自对等节点、链接、世界视图或“探索”对网络的搜索；
  对于在网络上找到的，还有每一条签名记录是在哪里读到的。
- 你在此设备上取消发布的发布内容 ID，以便“探索”搜索网络时不再列出你之前分发出去的副本。
- 对于你打开的每一周搭建挑战，在网络上找到的参赛作品 ID，以便它的页面在搜索之前再次列出它们。
- 此设备把你的每条评论发送到了哪些网络以及时间，以便每条评论都能说明它去了哪里。
- 此设备做出或接受的每一条爱心记录、为爱心选择的网络、你自己的每颗爱心被发送到了哪些网络（附带 Nostr 事件，
  以便收回爱心时可以请求中继删除它），以及第一颗爱心的说明是否已经显示过。
- 此设备知道哪些作品以作品笔记的形式存在于 Nostr 中继上（你自己的，在中继接受笔记之后；以及别人的，从笔记中打开过的），
  以便它们可以通过短链接分享。
- 对于你用**在这里搭建**开始的每个作品，你选择的世界和位置，以便发布时把它立在那里。
- 此设备第一次见到每个已发布作品的时间（它的 ID 和时间，最多 5000 个），以便区分一个只是标注日期较早的作品
  和一个真正先到这里的作品（**较早发布的相似作品**，以及 🔔 的 **… 发布了一个标注日期早于你的作品、且看起来很像的作品**）。
- 此设备上每个已发布作品的组成，以计数表示（多少块积木，以及每种各多少块，按内容哈希，最多 2000 个），
  以便无论新旧，都先比较最可能像你作品的那些。
- 字节还没有到达此设备的其他人作品的 ID 和内容哈希，以及从何时开始（最多 500 个，每个保留 30 天），
  以便它们的字节到达时仍然可以与你自己的作品比较，即使 ForkBuild 已经关闭过（🔔 的 **… 发布了一个看起来像你作品的作品**）。
- 对于从现成结构开始或作为某个作品副本开始的每个作品，以及放入其中的每个现成结构，它的积木是什么、放在哪里，
  以便发布时能区分你放置的积木和你开始时就有的积木（只会统计它们落在哪个区间；见“访客计数”）。
- 对于每个身份，朋友在你们一起搭建（**和我一起搭建**）时为它署名的作品：每个作品的标题、作者的名字和身份，以及时间，
  用于“我的世界”中的**你参与搭建的作品**和你自己的搭建者页面。它保存在你各台设备共享的身份下，
  当你的另一台设备（同一身份下的已授权设备）连接时，两者会互相交换列表；它从不发送到任何其他人的设备。
  首页上你的印章是根据这里已列出的内容计算的，不单独保存。

在浏览器中清除本网站的数据会删除这一切，没有其他副本，也无法恢复。请先用**你的数据 → 备份到文件**备份：
这个文件包含上述所有内容（除了你当时在使用哪个名字），用你选择的密码短语加密，并保存在你放置它的地方。
ForkBuild 从不上传它。**分享备份**会把文件交给你在设备上选择的应用。如果你选择了备份文件夹，浏览器会保留 ForkBuild 对它的权限，
ForkBuild 会在一个单独的 `forkbuild-backup` IndexedDB 数据库中保存这个文件夹，以及（如果你要求）一把由你的备份密码短语生成、
只能制作备份（永远不能打开备份）的密钥；你上次备份的时间和位置与其他数据保存在一起，但不包含在备份中。

在官方网站上，浏览器还会通过网站的 Service Worker 保留 ForkBuild 自己的文件（它的代码、样式表、图标以及你使用的语言），
以便 ForkBuild 在没有网络时也能打开，并且可以作为应用安装。这些文件对每个人都相同，不包含任何属于你的东西。
此设备上的通知是否开启，与你的设置保存在一起（见下面的“此设备上的通知”）。

## 其他人能看到什么

- **你发布的任何东西**都是公开的：它的内容、标题、描述、标签和许可证，以及为它签名的你身份的公钥。
  一旦别人有了副本，你就无法收回。
- **谁能找到它？**会在你第一次发布前询问。选择**所有人**时，你发布的每个已签名作品也会作为一条作品笔记
  （docs/Protocol.md 中的“Build notes”），连同它的标签以及它在世界中的位置，完整地发送到**网络设置**下的公共 Nostr 中继，
  这样任何使用 ForkBuild 的人都能在“探索”、挑战和世界中找到它。这条笔记用此设备的载体密钥签名，而不是用你的身份。
  中继会保留发给它们的内容；你无法收回一条笔记。选择**只有收到链接的人**时，什么都不会发送，作品只存在于它的链接中。
  这个选择会记在此设备上，可以在发布后的提示中更改。一旦你选择了作品的去处，每次发布也会把作品发送到那里；
  在此之前，发布不会发送任何东西。当你把它分发到 Nostr 或 Arweave 时，它的公告也会列出它的标签（形式为 `forkbuild-tag:<标签>`），
  这样任何人都能找到带某个标签的作品，比如某一周的挑战参赛作品。
- **你送出的爱心**是公开的：每一颗都表示你的身份喜欢那个作品（或不再喜欢），以你所用的名字、用你身份的密钥签名。
  它会发送给已连接的对等节点以及为爱心选择的网络（默认是 Nostr），任何人都能在那里读到，并作为通知发给搭建者。
  收回爱心会发送一条更新的记录；之前的那条可能仍然留在它被发送到的地方，而在 Nostr 上，删除请求只是一个请求。
- **你的时钟，告诉已连接的对等节点。** 你在连接期间，你的设备和每个已连接的对等节点会互相告知各自时钟的时间
  （连接时几次，之后每分钟一次），以便动物和居民在每个人的屏幕上都站在同一个位置。只发送时间。
- **你连接的对等节点**会知道你身份的公钥以及你的 IP 地址（直连需要它；TURN 中继会对对等节点隐藏它，但不会对中继隐藏）。
  已连接的对等节点可以按照可见性设置看到你的化身和在线状态，包括你正在骑哪辆载具（它的类型和 ID，只在在线状态会被发送时发送；
  你把载具停在哪里从不发送），你的好友可以给你发消息。他们还会收到你的设备发现的快照和地名公告，
  所以他们会知道你搜索过哪些世界区域的地名（docs/AnnouncementIndex.md）。
- **对等节点，针对你共享的世界。** “探索”中的**与对等节点共享**会把你已发布的某个世界提供给你现在连接的每个人，
  以及之后连接的任何人，包括大厅里的陌生人：他们会收到它的条目，并且可以在你连接期间从你的设备获取世界本身。
  你的好友和已知对等节点的设备会自动获取它；其他任何人的设备只有在他们点击**获取**时才会获取。只**发布**的世界从不发送给任何人。
- **和你一起漫步的朋友。** 在你生成的**和我一起在这里漫步**链接有效期间打开它的任何人，都会收到你所在的世界
  （它签名的发布内容和作品，与分享链接携带的一样）以及你的显示名称，并作为普通的已连接对等节点与你连接：
  他们会知道你的 IP 地址，并按你的可见性设置看到你的化身和在线状态。你也会以同样的方式知道他们的，以及他们漫步时使用的名字。
- **你在世界视图中说的话。** 你**说**的一句话会用你身份的密钥签名，并发送给按你的在线可见性可以看到你化身的已连接对等节点；
  设为隐藏时，这句话只留在你的屏幕上。它会显示几秒钟，在他们的记录中保留一分钟，没有任何东西保存它，所以后来到的人永远看不到。
- **和你一起搭建的朋友。** 在你生成的**和我一起搭建**链接有效期间打开它的任何人，都会以同样的方式与你连接，
  并收到你的显示名称、作品的标题，以及（在对方的编辑器请求后）作品本身，然后在你们一起搭建期间收到你们任何一方对它做的每一次更改、
  你的指针在哪里以及你选中了什么。他们会保留自己的副本。你也会以同样的方式知道他们的 IP 地址、他们搭建时使用的名字以及他们指向哪里。
  你的作品收入了其更改的每个朋友都会在作品上获得署名，以他们搭建时使用的名字和他们身份的公钥标注；你发布时，
  这份署名就是它签名的发布内容的一部分，任何看到这个作品的人都能读到（**和我一起搭建**链接打开的页面会在他们加入前说明这一点）。
  一起搭建期间，每个人的副本都会跟随这份列表，所以每个朋友都能看到还有谁获得了署名。
- **任何人，在你处于公共大厅期间。** 加入公共大厅（**对等节点**）或某个世界的大厅（世界视图中的**大厅**），
  会把你身份的公钥和你选择的显示名称列出来，供打开那个大厅的任何人查看。世界的大厅还会告诉他们你打开的是哪个世界。
  你的条目会一直保留到你离开、关闭应用（之后最多 10 分钟）或卡片过期为止。它不包含网络地址，但大厅里的任何人都可以连接你，
  而连接你的陌生人就是一个普通的已连接对等节点：他们会知道你的 IP 地址，按你的可见性设置看到你的化身和在线状态，
  并且在你记住或加他们为好友之前，**就与你交换快照和地名公告以及发布元数据，与任何已连接的对等节点完全一样**。
  聊天和语音仍然需要互为好友。大厅中的**屏蔽**会把某人从你的大厅列表中隐藏，并像在对等节点页面上一样屏蔽对方
  （在线状态、资料、聊天和好友请求）。

## 访客计数

每天一次，在 ForkBuild 当天第一次在此设备上打开时，官方网站（`https://bowo-prasetyo.github.io/forkbuild/`）会从 GoatCounter
（`forkbuild.goatcounter.com`，一个不设置 Cookie 的计数器）加载一张很小的图片。它只发送这一个请求：

- **GoatCounter 收到什么：** 与任何网络请求一样，你的 IP 地址和浏览器的 User-Agent，加上一个固定路径（`/`）
  和一个防止图片被缓存的随机数。不包含任何页面、文档、世界、身份、来源页或 ForkBuild 保存的任何东西，
  所以它无法知道你在应用中做了什么，甚至不知道你打开了哪个页面。
- **它保存什么：** 只有总数：每小时和每天的访客数，以及他们来自哪些浏览器、系统、国家和语言，每一项单独统计，
  所以无法相互关联。它的隐私政策（<https://www.goatcounter.com/help/privacy>）说明它从不保存 IP 地址或完整的 User-Agent：
  它只会把它们在内存中保留最多 8 小时，仅用于在不使用 Cookie 的情况下识别重复访问。
- **任何人都可以在公开仪表板上查看总数**：<https://forkbuild.goatcounter.com/>。

同一个计数器还会得知分享作品过程中的以下时刻，每一次都是同类的又一个图片请求，各有自己的固定路径：

- `/e/share-link`：用**复制链接**或**分享…**复制或分享了一个作品的链接；
- `/e/share-link-short`：那个链接是短链接（`/n/…`），与 `/e/share-link` 一同记录，从不代替它；
- `/e/opened-shared-link`：一个分享链接打开了一个作品；
- `/e/remix-from-link`：从分享链接打开的作品被复制到了编辑器（每次打开应用时，每个作品最多一次）。

它还会以同样方式得知 ForkBuild 被作为应用安装（`/e/installed`），以及嵌入在其他网站页面中的作品（见下面的“ForkBuild 联系的服务器”）：

- `/e/embed-code`：用**嵌入 → 复制嵌入代码**复制了作品的嵌入代码；
- `/e/embed-view`：嵌入的作品在某个页面上显示了；
- `/e/embed-open`：嵌入的作品从那个页面在 ForkBuild 中被打开了。

当有人参加每周搭建挑战时（**参加挑战**，或编辑器**新建**中的挑战）：`/e/challenge-join`；当有人在世界视图中打开某一周的挑战广场时：
`/e/plaza-visit`。每次打开世界视图时：`/e/world-visit`；以及每次访问一次，当别人的作品出现在视野中时（不是此设备发布、也不能编辑的作品；
广场周围的现成作品不算）：`/e/world-neighbour`。每次打开 ForkBuild 最多一次，当还没有名字的人以访客身份在那里漫步时：`/e/guest-walk`；
不会发送任何关于他们走到哪里的信息。每次打开 ForkBuild 最多一次，当编辑器打开时：`/e/editor-open`；当从首页或挑战页面上的链接把现成作品
作为你自己的副本在其中打开时：`/e/starter-open`；当你在那里做出第一次编辑时：`/e/editor-edit`；当你在首页的**欢迎回来**中按下
**继续搭建**回到你的上一个作品时：`/e/keep-building`。每次打开 ForkBuild 最多一次，当你按下**发布**（在工具栏中，或在现成作品的卡片上）时，
无论之后是否真的发布了作品：`/e/publish-start`。这些都不会说明是哪个作品，也不会说明改了什么。每次打开 ForkBuild 最多一次，
当有人使用某个附属系统时：游泳（`/e/swam`）、捕捉动物（`/e/animal-caught`）、用动物装饰作品（`/e/animal-decorated`）、
携带东西（动物或存放的载具，`/e/inventory-used`）、发送聊天消息（`/e/chat-sent`）、发起或接听语音通话（`/e/voice-call`），
或加入公共大厅（`/e/lobby-joined`）。这些都不会说明捕捉了什么、说了什么、打给谁或加入了哪里。当有人在世界视图中生成
**和我一起在这里漫步**链接时：`/e/walk-link`；当朋友通过它到达时：`/e/walk-joined`。当有人在编辑器中生成**和我一起搭建**链接时：
`/e/build-link`；当朋友通过它加入时：`/e/build-joined`；当一个一起搭建的作品第一次发布并为朋友署名时：`/e/publish-together`。
每次发布作品时：发送给所有人时为 `/e/publish-found`，仅限链接访问时为 `/e/publish-link-only`。

当一个作品第一次从这个浏览器发布时（之后再次发布不会发送任何东西）：

- 它的大小，以直接放置的积木数量（不含结构）所属的五个区间之一表示：`/e/publish-bricks-0`、`/e/publish-bricks-1`（1 到 9）、
  `/e/publish-bricks-10`（10 到 49）、`/e/publish-bricks-50`（50 到 199）或 `/e/publish-bricks-200`（200 或更多）。从不发送确切数量；
- 搭建者放置或修改的积木（不含开始时就有的或放入的现成积木）所属的同样五个区间：`/e/publish-placed-0` 到 `/e/publish-placed-200`；
- `/e/second-build`，当它是从这个浏览器发布的第二个作品时，只会发生一次；
- `/e/remix-published`，当它是这个浏览器没有发布过的某个作品的副本时。

这些是根据这个浏览器已经发布、并已经保存的作品计算的（见“留在你设备上的内容”），对于放置的积木，
还会用到一份每个作品开始时有哪些积木的记录，它保存在此设备上该作品旁边，从不发送到任何地方。

当 ForkBuild 通过它自己发布的推广帖中的链接打开时，链接以 `?ref=` 和发帖地点的名称结尾（`hn`、`producthunt`、`reddit`、`itch`、
`nostr`、`steem`、`blurt`、`edu`、`gamejolt`、`indiedb`、`youtube`、`bilibili`、`zhihu`、`qiita`、`note`、`x`、`facebook` 或 `github`；
其他任何值都会被忽略）：会发送一次 `/r/` 加上那个名称，比如 `/r/hn`。之后应用会把 `ref` 从地址中去掉，
所以重新加载或转发地址都不会再次发送。这只能说明哪些帖子带来了访客，而不会说明他们是谁或做了什么。

每个请求只发送它的路径和随机数：从不发送链接、作品、它的标题或作者。哪些作品是从链接打开的，只保存在打开页面的内存中，页面关闭后就会忘记。

以下情况下，这些请求都不会发送：

- 当你的浏览器发送“全球隐私控制”或“请勿跟踪”时；
- 当你关闭**你的数据 → 每日访客计数 → 统计此浏览器**时（这个选择只保存在这个浏览器中）；
- 从官方网站以外任何地方提供的 ForkBuild 副本，包括 `localhost`。

嵌入的作品无法读取**统计此浏览器**的选择：它不打开任何存储，而且浏览器本来就会在其他网站的页面中隔离一个网站的存储。
所以 `/e/embed-view` 和 `/e/embed-open` 只遵循另外两条规则：开启“全球隐私控制”或“请勿跟踪”时从不发送，而且只从官方网站发送。

相关代码是 `core/app/VisitorCount.js`、`core/app/LaunchChannel.js`、`application/settings/CountDailyVisit.js`、
`application/settings/CountLaunchChannel.js`、`application/settings/FunnelEventCounter.js`、`ui/counterHit.js`、`ui/start.js`
和 `ui/embed/embedBoot.js`。

**携带作品的链接**（在作品分发之前用**复制链接**或**分享…**生成）包含你签名的共享世界以及作品本身。
它指向会合服务器（`forkbuild-rendezvous.prazjp.workers.dev/b/…`），以便聊天应用和社交网站可以显示作品的标题和图片：
打开链接或网站预览链接时，会把它（也就是作品）发送到那个服务器，服务器会检查签名、绘制图片、把人们转到应用
（`#/s/…`，这部分地址浏览器从不发送给服务器），并且不保存任何东西。运营该服务器的 Cloudflare 可能会记录请求的地址。
生成链接不会联系任何东西。任何拥有这个链接的人都能看到作品、它的标题、描述和作者名，以及你身份的公钥，与你分发的任何共享世界一样。

**短链接**（作品发送给所有人后会改为提供，见上面的**谁能找到它？**）只包含作品发布内容的 ID
（`forkbuild-rendezvous.prazjp.workers.dev/n/…`）。打开它或网站预览它时，会把这个 ID 发送到会合服务器，
服务器会向公共 Nostr 中继请求作品的笔记，像检查携带作品的链接那样检查它、绘制图片、把人们转到应用（`#/n/…`），
并且不保存任何东西；之后应用会自己向中继请求这条笔记。作品本来就已经公开在这些中继上，短链接正是依赖这一点：
如果没有中继保留这条笔记，它就会失效。仅限链接访问的作品永远不会有短链接。

**嵌入的作品**（**嵌入**复制的代码：一个指向提供 ForkBuild 的网站上 `embed.html#…` 的 `<iframe>`）包含同样的内容，
即你签名的共享世界和作品。它被粘贴进去的页面会从那个网站加载嵌入，而那个网站既不知道作品（它在浏览器从不发送给服务器的那部分地址中），
也不知道周围的页面（框架不发送来源页）。在读者的浏览器中，嵌入会检查签名和作品、显示它，并且不保存任何东西；
它不启动应用的任何连接，所以不会联系任何对等节点、中继或其他网络。任何能看到这个页面的人都能看到这个作品，与它的链接一样。

**只在需要时使用中继。** 连接总是先尝试直连路径，然后尝试通过 STUN 找到的路径，只有两者都不行时才退而使用 TURN 中继。
你在大厅中等待时，你的设备准备好的提议从不请求中继凭据，所以待在大厅里不会消耗会合服务器每月发放的中继额度；
连接你的人在需要时才会请求。

## 此设备上的通知

如果你开启了**在此设备上通知我**（在 🔔 面板中），当 ForkBuild 在后台标签页中打开或作为已安装应用运行时，你的设备会自己显示你的新通知。
不使用任何推送服务，也不会为此向任何地方发送任何东西：打开的页面把通知交给你的浏览器，由浏览器通过你的操作系统显示。
之后通知的文字（比如作品的标题和作者的名字）可能会像任何应用的通知一样保存在你设备的通知历史中。在同一个面板中关闭它，
或者在浏览器的网站设置中阻止 ForkBuild 的通知。

## 如果你运行自己的副本

部署决定上面的默认值：它的会合服务器（`peer/RendezvousConfig.js`）、该服务器是否提供 TURN 中继（`server/rendezvous-worker/README.md`），
以及**网络设置**下的其他默认值。访客计数只在官方网站上运行，所以托管在其他地方的副本不会统计任何东西；
要统计你自己的访客，请更改 `core/app/VisitorCount.js` 中的地址以及 `index.html` 内容安全策略中的 `img-src` 条目。
默认的会合服务器只接受官方网站的来源，所以托管在其他地方的副本需要它自己的会合服务器（见
[docs/Deployment.md](../../Deployment.md)（英文））。如果你为他人托管 ForkBuild，请更新这个页面，写明你的服务器。
