> **高级。** 搭建、分享、改编或和朋友一起四处走走都不需要这一章：[开始玩的章节](README.md#开始玩按顺序阅读)
> 已经涵盖了这些。想知道底层运作方式时再继续阅读。

顶栏中的**网络设置**链接到每一个控制 ForkBuild 与哪些服务器通信的页面。大多数人永远不需要更改这里的任何东西：
默认设置开箱即用。当某个服务器出故障、你运行自己的服务器，或者想选择你的记录存储和公告在哪里时，再来这里。

关于每个服务器会了解你的哪些信息，请见[隐私](Privacy.md)。

## 各个页面

| 页面 | 路由 | 设置什么 |
|---|---|---|
| **内容服务** | `/settings/content-provider` | **存储到 …**和**使用偏好的服务**把新内容存储在哪里，以及发送到哪个 IPFS 节点——见[下文](#内容服务) |
| **公告 / 发现服务** | `/settings/announcement-discovery-provider` | 你的公告默认发到哪里：Nostr、Arweave、Steem 或 Blurt——见[下文](#公告--发现服务) |
| **证明 / 锚定服务** | `/settings/anchor-provider` | **锚定到 …**在哪里锚定——见[下文](#证明--锚定服务) |
| **Arweave 网关** | `/settings/arweave-gateway` | 读取 Arweave 内容的网关——见[下文](#arweave-网关) |
| **IPFS 网关** | `/settings/ipfs-gateway` | 读取 IPFS 内容的网关——见[下文](#ipfs-网关) |
| **Bitcoin 端点** *（实验性）* | `/settings/bitcoin-esplora` | Bitcoin 锚定使用的服务——见[下文](#bitcoin-端点) |
| **Nostr 中继** | `/settings/nostr-relay` | 通过 Nostr 发布和发现所用的中继——见[下文](#nostr-中继) |
| **Steem** *（实验性）* | `/settings/steem` | 你的 Steem 账户，以及从哪里读取 Steem——见[下文](#steem) |

## 显示实验性工具

页面顶部的**显示实验性工具**会列出 ForkBuild 中**实验性**的部分：这里的 **Bitcoin 端点**页面，
以及[签名记录页面](09-PublicationsAndEvidence.md#签名记录页面)上的**钱包与存档工具**面板。
在你打开之前它是关闭的，一旦更改就会立即保存在此设备上。关闭时，搭建、发布或分享所需的任何东西都不会被隐藏。

它下面的**钱包**为 ForkBuild 可以用来锚定的每种钱包各提供一个开关：**Bitcoin 钱包**和 **Base 钱包**。
每个开关在你打开之前都是关闭的，并保存在此设备上。某个开关关闭时，签名记录页面既不提供也不加载那个钱包的步骤，
Bitcoin 也不会作为[证明 / 锚定服务](#证明--锚定服务)提供。已经在 Bitcoin 或 Base 上完成的锚定，
无论如何都会被检查并显示。关闭某个开关会在下次打开签名记录页面时生效。

## 每个页面的共同行为

- **保存后重新加载。** 更改会在下次加载应用时生效（Steem 和 Blurt 账户除外）。打开着的世界视图或编辑器
  在你重新加载之前会继续使用旧设置。
- 每个页面都有自己的**保存**。保存失败时会显示原因，并保持之前的设置不变；保存成功时会显示“已保存。”
- 选项列表按字母顺序显示。
- **服务器列表带有默认值。** Arweave 网关、IPFS 网关、Bitcoin 端点、Nostr 中继、Steem、Blurt、STUN 和会合服务器页面
  一开始都有几个免费的公共服务器，所以某一个出故障时仍然能正常工作。页面会说明它是“正在使用默认……”还是“正在使用你保存的……”。
  没有保存任何东西时，文本框中是默认值，每行一个，可以直接编辑。在你更改之前**保存**保持禁用，
  这样你就能继续获得以后版本中改进的默认值。**恢复默认**会删除你的列表。
- **验证只检查格式。** 保存会拒绝任何不是正确类型的规范 URL 的内容，但不会检查服务器是否可用；
  错误的服务器之后会表现为读取失败。
- **默认值是第三方服务。** 每一个都能看到你的 IP 地址以及应用向它请求了什么。通过网关读取的内容会对照其内容哈希检查，
  所以网关无法替换成不同的字节。

## 内容服务

从此设备注册的后端中，选择**存储到 …**（记录**内容**区块中的第一个按钮）和**使用偏好的服务**把快照放置创建在哪个存储上（见
[使用偏好的服务](11-EvidenceAndStorage.md#使用偏好的服务)），然后点击**保存**。
不提供**本地**，因为每条记录都已经保存在此设备上。

**IPFS（远程固定）** *（实验性）*始终可选。它使用下面**远程固定服务**中设置的服务：设置了服务时，
**存储到 IPFS（远程固定）**和**使用偏好的服务**会把内容放到那里，作为普通的 IPFS 放置；没有设置时，它们会提示没有设置服务。
选择它也会在每个**分发**对话框中预先选择远程固定作为存储。

第二部分 **IPFS 节点**设置新的 IPFS 放置被发送到哪个节点。默认是位于 `http://127.0.0.1:5001` 的本地 Kubo 节点。
输入另一个节点的 API URL 并点击**保存**，或者点击**使用部署默认值**恢复。它不影响读取 IPFS 内容，读取使用的是
[IPFS 网关](#ipfs-网关)列表。

第三部分**远程固定服务** *（实验性）*设置 IPFS（远程固定）上传到的固定服务：它的**端点**，以及（如果服务需要）
文件的**请求字段**和存放 CID 的**响应字段**。**保存**会把这些保存在此设备上。**令牌**只保留到你关闭或重新加载页面为止，
从不保存；需要令牌的服务在你输入之前会拒绝上传。每个**分发**对话框和签名记录页面都默认使用这个服务，你仍然可以在那里更改。
**忘记服务**会删除它。

## 公告 / 发现服务

选择 **Arweave**、**Blurt**（实验性）、**Nostr** 或 **Steem**（实验性）作为公告你的记录（共享世界、蓝图署名和地名提议）、
快照和评论的默认位置。它只是一个默认值：每个**分发**对话框、“探索”中每张卡片的分发选择器以及**发表评论**旁边的网络选择器
都默认使用它，你可以为某一次操作切换。查找他人的内容时总会搜索所有网络。

第二部分**评论**为评论单独设置默认值。**与上面的公告 / 发现服务相同**是默认选项，让评论沿用上面的选择。
你也可以选择一个网络，或者选择**仅本地和对等节点**，让评论不进入任何网络，这样不需要网络账户。
每个评论框都默认使用它，你仍然可以在**发表评论**旁边为某条评论切换。

## 证明 / 锚定服务

选择**锚定到 …**（记录**证明 / 锚定**区块中的第一个按钮）在哪里创建外部证据：**Arweave**、**Bitcoin** *（实验性）*、
**Blurt** *（实验性）*或 **Steem** *（实验性）*，以此设备注册了的为准。从不提供 Base，因为每个 Base 锚定都需要你审核并签署一笔钱包交易。
选择 Bitcoin 时没有**锚定到 …**按钮：区块会显示所有选项并指向钱包步骤；真正的 Bitcoin 锚定请见
[Bitcoin 锚定流程](11-EvidenceAndStorage.md#bitcoin-锚定流程)。

## Arweave 网关

读取 Arweave 内容的网关，每行一个 `http://` 或 `https://` URL。默认值是 `https://arweave.net`、`https://ardrive.net`
和 `https://permagate.io`。

它们按顺序尝试：只有当前网关无法访问或返回错误时，读取才会转到下一个网关。Arweave 内容按交易 ID 寻址，
所以每个网关返回的字节都相同。

从去中心化来源获取记录的素材时，以及解析或实体化 Arweave 快照放置时，会使用这个列表。它不会改变你自己的内容上传到哪里。
Arweave 锚定使用列表中的第一个网关来创建和验证。

## IPFS 网关

读取 IPFS 内容的网关，每行一个 URL，与 Arweave 一样按顺序尝试。默认值是 `https://ipfs.filebase.io`、
`https://gateway.pinata.cloud`、`https://ipfs.io`、`https://dweb.link` 和 `https://4everland.io`。

这个列表用于解析或实体化 IPFS 快照放置、**验证 IPFS 内容**、打开指向 IPFS 上内容的分享链接，
以及“探索”和每周挑战读取在网络上找到、签名声明位于 IPFS 上的作品时。它不会改变你自己的内容固定在哪里。

有些网关（包括 `https://ipfs.io` 和 `https://dweb.link`）会拒绝来自网页的某些内容请求，或者用机器人检查拦截它们；
默认网关由不同的运营者运行，所以读取会转到下一个。如果对于你确定存在的内容，**验证**或**解析**一直以“Failed to fetch”失败，
请把你固定服务商的网关加到最前面。2026-10-08 之前保存的列表会保留它自己的顺序：**恢复默认**会恢复新的默认值。

## Bitcoin 端点

*实验性。* Bitcoin 锚定用来广播交易、检查确认、查询钱包资金以及验证锚定的 OP_RETURN 证明的 Esplora 兼容 API。
每行一个 `http://` 或 `https://` URL；默认值是 `https://blockstream.info/api` 和 `https://mempool.space/api`。

查询使用第一个响应的端点。只有在前一个端点无法访问时，广播才会转到下一个端点，在某个端点拒绝交易后则永远不会转到下一个。

## Nostr 中继

ForkBuild 通过 Nostr 发布或发现的一切所用的中继：记录（共享世界、蓝图署名和地名提议）、快照和评论。
每行一个 `ws://` 或 `wss://` URL；默认值是 `wss://relay.damus.io`、`wss://nos.lol` 和 `wss://relay.primal.net`。
**保存**会替换整个列表，如果有任何一行不是有效的 URL 就会拒绝。

与网关不同，中继不是按顺序尝试的：公告会同时发到每个中继，发现也会询问每个中继，所以每多一个中继，
即使另一个出故障，你的内容也能被更多人找到。这里没有每个中继的状态；**分发**结果会为每个中继列出一行**发现**。

## Steem

在新设备上，**发帖**下的**从此设备发布到 Steem**是关闭的。关闭时，ForkBuild 在你发布、评论、为地点命名、存储作品或创建锚定时
不会提供 Steem，不会向那里发布任何东西，并且会隐藏账户输入框。已经保存了 Steem 账户的设备一开始是打开的。
已经在 Steem 上的作品和评论无论如何都会被找到并显示。

*实验性。* 在**发帖**下设置**你的 Steem 账户**（立即生效，无需重新加载），在 Steem 上发帖或存储需要它——见
[Steem](11-EvidenceAndStorage.md#steem)。从 Steem 读取不需要账户。页面的其余部分设置从哪里读取 Steem：

- **API 节点**，每行一个 `https://` URL（默认值为 `https://api.steemit.com`、`https://api.justyy.com` 和
  `https://steemd.steemworld.org`），按顺序尝试。
- **发帖账户**，每行一个（默认 `forkbuild`）：读取谁的每月发现帖。如果某个社区运营着自己的帖子，可以再添加一个。
- **从哪个月开始读取**（默认 2026 年 9 月）：ForkBuild 会读取从那时到现在的每个月，最多最近 36 个月。

当无法连接任何 Steem 节点时，**检查新评论**和快照发现会说明 Steem 不可用，而不是报告什么都没找到。

## Blurt

在新设备上，**发帖**下的**从此设备发布到 Blurt**是关闭的。关闭时，ForkBuild 在你发布、评论、为地点命名、存储作品或创建锚定时
不会提供 Blurt，不会向那里发布任何东西，并且会隐藏账户输入框。已经保存了 Blurt 账户的设备一开始是打开的。
已经在 Blurt 上的作品和评论无论如何都会被找到并显示。

*实验性。* 在**发帖**下设置**你的 Blurt 账户**（立即生效，无需重新加载），在 Blurt 上发帖、存储或锚定需要它——见
[Blurt](11-EvidenceAndStorage.md#blurt)。从 Blurt 读取不需要账户。页面的其余部分设置从哪里读取 Blurt：

**API 节点**，每行一个 `https://` URL（默认值为 `https://rpc.blurt.blog`、`https://rpc.beblurt.com` 和
`https://rpc.drakernoise.com`），按顺序尝试。ForkBuild 通过 Blurt 的搜索索引 Nexus 查找帖子，它会保留每一篇帖子，
无论多旧；不提供 Nexus 的节点会被跳过。当没有节点提供 Nexus 时，它会退而使用 Blurt 自己的标签列表，
那个列表只在帖子结算收益之前（七天内）保留它，并从此设备上见过在该标签下发帖的账户的历史中查找更早的帖子。
即使 Nexus 有响应，ForkBuild 也会同时读取标签列表，以防 Nexus 漏掉某篇帖子；如果确实漏掉了，
ForkBuild 还会读取那个账户的历史，这样它更早的帖子也不会被遗漏。

当无法连接任何 Blurt 节点时，**检查新评论**和快照发现会说明 Blurt 不可用，而不是报告什么都没找到。
