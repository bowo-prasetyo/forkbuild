# 08 — 聊天与对话

> **高级。** 搭建、分享、改编或和朋友一起四处走走都不需要这一章：[开始玩的章节](README.md#开始玩按顺序阅读)
> 已经涵盖了这些。想知道底层运作方式时再继续阅读。

ForkBuild 中的私信是点对点的，并且**仅限好友**——如何先与某人成为好友，见
[对等连接与好友](07-PeerConnectionsAndFriends.md)。

## 开始对话

可以从**对等节点**页面上好友的**聊天**按钮，或从**对话**页面（**更多 → 对话**）进入聊天。
世界视图中没有文字聊天，但你可以在那里从朋友的化身上给对方打电话（见[语音通话](#语音通话)）。
与当前不是好友（或已被屏蔽）的人打开聊天时，会显示一段说明而不是输入框：解锁聊天的是好友关系，而不是是否在线。

## 对话页面

列出所有值得显示的人——任何与你有记住的关系、好友关系（包括待处理的请求）或消息历史的人，按最近活动排序。
每一行显示：

- 对方的显示名称和一个**在线 / 离线**标记
- 对方与你的关系——好友、好友请求待处理、已知对等节点，或之前没有连接过
- 未读消息数；如果有排队的消息，还会显示“N 条消息等待发送”
- 最后活动的时间

只有你没有屏蔽的当前好友才有**打开聊天**按钮；其他所有人的那一行会把你指回对等节点页面。
你屏蔽的好友会在按钮的位置显示“⛔ 已屏蔽——在对等节点中解除屏蔽后才能再次聊天。”，
你屏蔽或解除屏蔽对方后，这一行会立即更新。

## 聊天界面

一份可以滚动的、你和一位朋友的聊天记录：标注“你”或对方名字的消息气泡，每条都有时间戳，下面是输入框
（最多 4,000 个字符）。点击**显示详情**会出现一个小面板，报告对方的身份、关系、好友关系、实时连接状态以及消息/待发送数量。
没有“正在输入”提示、编辑、删除、表情回应、附件或群聊——它有意只做消息。

## 语音通话

只要那位朋友当前可连接的设备中至少有一台支持语音，输入框旁边就会有一个 **📞 通话**按钮——
你不需要知道对方的哪台设备会接听；通话打给的是对方的身份，而不是某一个特定的连接。

- 点击**通话**发起通话——在对方接听之前你会看到**正在呼叫…**。
- 在接收方，来电会显示**接听** / **拒绝**。
- 接通后，横条显示**通话中**以及**静音** / **取消静音**，并且——在你的麦克风真正接入后——
  可以选择使用哪个**麦克风**以及（如果你的浏览器支持）哪个**扬声器**。
- 结束按钮在你还在等对方接听时显示**取消**，真正通话后显示**挂断**。

**通话会跟着你。** 通话开始后，你可以离开聊天：通话和声音会在每个页面上继续，标题下方有一个小横条，
显示正在和谁通话、**静音**、**挂断**，以及返回的**打开聊天**。当你在别处（包括世界视图）时朋友打来电话，
会在那个横条中响铃，并显示**接听** / **拒绝**。在世界视图中，点击朋友的化身并选择 **📞 通话**，
就可以在一起漫步时给对方打电话。

在整台设备上你一次只能进行一个通话——通话期间，其他任何人的通话按钮都会被禁用。如果通话中麦克风断开了
（被拔掉、权限被撤销），会有一条小横幅提示；通话本身会继续进行，以防它重新连接。

在接通前结束的通话会简要说明原因：

| 提示 | 含义 |
|---|---|
| **通话被拒绝。** | 对方点击了拒绝。 |
| **对方正在另一个通话中。** | 对方在别处忙着。 |
| **无人接听。** | 没有人及时接听。 |
| **无法访问你的麦克风。** | 你的浏览器拒绝或没有麦克风访问权限。 |
| **通话连接失败。** | 连接层面的失败——值得再试一次。 |

普通的挂断（你或对方挂断）不显示任何提示——通话横条消失就说明了一切。

## 在对方离线时发送

你可以给离线的朋友发消息——不需要对方当前已连接。它会在本地排队，并在你们下次同时连接时自动送达；
你不需要自己重新发送。中间没有服务器保管它，所以它在*你的*设备上等待：双方必须同时打开 ForkBuild 才能送达。
7 天后仍未送达的消息会被丢弃，并标记为**未送达——已过期**。每条发出的消息都会在气泡下方显示自己的状态：

| 状态 | 含义 |
|---|---|
| **已排队——对方重新连接后发送** | 正在等对方上线 |
| **已发送** | 已交给网络——尚未确认到达 |
| **已送达** | 已确认到达对方的设备 |
| **未送达——已过期** | 没有及时送达，已被丢弃 |
| **已读** | 对方已经打开对话，并读到了这条消息 |

**已读**是完全自动的——没有“标记为已读”按钮。仅仅打开或刷新一个对话，就会告诉发送者你已经读过了。

## 你的历史记录

对话会保存在此设备的本地，重新加载后会从你离开的地方继续——消息、送达状态等一应俱全。
这份历史记录**只在此设备本地**：它不会跟着你到另一个浏览器或另一台电脑上，也没有服务器端的副本。
每个对话保留最近的 500 条消息；更早的会悄悄被移除，以控制存储空间。

删除好友或屏蔽某人会立即停止聊天，即使底层连接在技术上仍然活跃——你不需要单独的“断开连接”步骤。
