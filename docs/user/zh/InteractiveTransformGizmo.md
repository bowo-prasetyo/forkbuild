# 交互式变换操纵器

<!-- languages -->
[English](../InteractiveTransformGizmo.md) · [Deutsch](../de/InteractiveTransformGizmo.md) · [Español](../es/InteractiveTransformGizmo.md) · [Français](../fr/InteractiveTransformGizmo.md) · [Bahasa Indonesia](../id/InteractiveTransformGizmo.md) · [日本語](../ja/InteractiveTransformGizmo.md) · [한국어](../ko/InteractiveTransformGizmo.md) · [Português (Brasil)](../pt-BR/InteractiveTransformGizmo.md) · **中文（简体）**
<!-- /languages -->

每当在编辑器中选中积木时，所选内容的轴心处就会出现一个操纵器。拖动它的手柄会移动或旋转所选内容，并实时预览；
松开会把更改确认为**一步撤销**。在编辑器中选中单个[结构实例](02-TheEditor.md#结构实例一个实时引用)时，
会显示完全相同的操纵器，只有一点不同：绿色的 Y 轴手柄不起作用。放置的高度总是跟随它下方的地形——它从来不是你可以拖动的手柄
或可以输入的数值。

操纵器只在编辑器中使用。[世界视图](03-WorldView.md)是一个只读的探索界面；要在那里发现的东西的基础上继续搭建，
请使用它的**编辑副本**按钮，在这里（编辑器中）打开它。

## 操纵器

```
    Y
    ↑
    │
    │
    ●──────→ X        ●  轴心
   /
  /
 Z

    ◯
  ◯ ● ◯               旋转圆环（Y 轴）
    ◯
```

| 手柄 | 颜色 | 作用 |
|---|---|---|
| 轴箭头 | 红色（X） | 拖动以仅沿 X 移动 |
| 轴箭头 | 绿色（Y） | 拖动以仅沿 Y 移动 |
| 轴箭头 | 蓝色（Z） | 拖动以仅沿 Z 移动 |
| 中心方块 | 琥珀色 | 在地面上自由移动（X + Z） |
| 旋转圆环 | 紫色 | 拖动以绕轴心旋转 |

把鼠标悬停在手柄上时它会高亮，拖动时会更亮。无论你缩放得多远，操纵器在屏幕上都保持合适的大小。

## 轴心

操纵器中心的白色标记就是**轴心**：

```
┌───────────────┐
│ ■           ■ │
│               │
│       +       │ ← 轴心（所选内容边界的中心）
│               │
│ ■           ■ │
└───────────────┘
```

- 选中一块积木 → 轴心位于那块积木的中心。
- 选中几块积木 → 轴心位于包围它们全部的方框的中心。
- 旋转总是绕着轴心进行。

轴心会自动跟随你的选择：选中 A，再加上 B，然后撤销一次移动——操纵器每次都会重新定位。

## 移动

1. 选中一块或多块积木。
2. 抓住一个轴手柄沿该轴移动，或抓住中心方块沿地面自由移动。
3. 所选内容会实时跟随指针。
4. 松开即可确认。

## 旋转

1. 选中一块或多块积木。
2. 拖动紫色圆环。拖动时，所选内容会绕轴心旋转。
3. 松开即可确认。

对于多选，每块积木都会绕共同的轴心公转*并且*转过相同的角度——整体布局保持原有形状。

## 确认、取消、什么都不做

| 你…… | 结果 |
|---|---|
| 松开鼠标 | 更改被确认——无论移动了多少块积木，撤销历史中都**正好一条**记录 |
| 拖动中按 `Escape` | 取消——一切都精确地弹回原处；历史不受影响 |
| 点击后不移动就松开 | 什么都不发生——没有命令，也没有历史记录 |

`Ctrl/Cmd+Z` 会一步撤销整个操作；`Ctrl/Cmd+Y`（或 `Ctrl/Cmd+Shift+Z`）会重做它。

## 拖动期间，操作独占指针

拖动期间，镜头不会环绕，不能选择其他任何东西，快捷键也会被忽略——拖动不会意外地与镜头冲突。
松开（确认）或按 `Escape`（取消）会让一切恢复正常。在视口*外面*松开鼠标也能正常确认。

## 组

选中一个组会选中它的成员积木——操纵器对待它们与任何多选完全一样：

- 拖动会移动每个成员；旋转会让每个成员绕共同的轴心转动。
- 组本身不受影响：成员关系从不因变换而改变。（操纵器甚至不知道组的存在。）
- 一次撤销会把每个成员恢复到原来的位置。

## 吸附

拖动默认会吸附——移动为 1 个世界单位（与方向键微移的步长相同），旋转为 15°（比 `R` 转的 90° 更细）。
拖动时按住 **Shift** 进入**精确模式**：正常增量的 0.1 倍（0.1 个世界单位、1.5°），用于默认网格太粗而无法完成的精细调整。

**数值变换面板**和**对齐/分布**有意作为例外——它们总是应用你要求的确切数值或确切的几何结果，从不吸附，
因为你已经输入（或要求）了一个精确的值。

## 碰撞会阻止确认

移动或旋转所选内容时，会在允许它落下之前，把结果与所选内容*之外*的每块积木进行检查。如果任何成员会与已有的东西重叠，
在那里松开就不会确认——所选内容中的每块积木都会恢复到原来的位置，也不会新增撤销记录，就像用单块积木放置时
点击被占用的格子会被拒绝一样。在同一个选择*内部*重新排列积木（比如两个成员在旋转中互换位置）从不被视为碰撞。
这项检查同样适用于操纵器拖动、键盘微移和旋转；对齐、分布和数值变换面板不受它限制，因为它们计算的是确切的、有意的结果，
而不是自由移动。

## 操纵器不做什么

- **缩放**——积木不能改变大小，所以没有缩放手柄。
- **拖动复制**——没有拖动时复制的修饰键；请先用 `Ctrl/Cmd+D` 原地复制一份所选内容（见
  [编辑器](02-TheEditor.md#复制粘贴和复制一份)），然后拖动副本。

## 小贴士

- 把鼠标悬停在旋转圆环上并慢慢拖动，可以进行精细控制——在轴心附近的小幅指针弧线仍然很精确，因为旋转是按角度而不是距离计算的。
- 想让两个坐标完全保持不变时，请使用轴手柄——这个约束是精确的，而不只是视觉上的。
- 组合使用多种方式：先用方向键按整数单位微移，再用 Shift+拖动完成精细定位。撤销/重做对两者的处理方式相同——每个操作一步。
