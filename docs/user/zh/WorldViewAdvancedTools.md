# 世界视图：高级工具

本页介绍[世界视图](03-WorldView.md)中只有在你勾选侧面板底部的**显示高级工具**后才会出现的部分。
它们针对的是世界背后的网络：作品放在哪里、存储在哪里，以及其他人在附近公告了什么。

行走、搭建、改编或分享链接都不需要它们。勾选这个框会记在此设备上，对其他人没有任何影响。

**开启高级工具后，你会得到：**

| 工具 | 在哪里 | 用途 |
|---|---|---|
| [查看](#查看积木或已放置的结构) | 点击一块积木或一个已放置的结构 | 看看它是什么、来自哪里 |
| [镜头与编辑](#镜头与编辑) | 面板标题部分中的一行 | 看看你的下一次更改作用于哪个作品 |
| [关于此作品，以及放置](#作品信息与放置) | 标题部分下方 | 作品的详情，以及它立在哪里 |
| 坐标和**位置**搜索 | 视图上方，以及**搜索**中 | 按 X/Y/Z 位置查找东西 |
| [世界相遇](#世界相遇你的对等节点正在共享的发布内容和化身) | “探索”的**附近**部分 | 已连接的人正在共享什么 |
| [地名](#附近的地名发现任何人的提议) | “探索”的**附近**部分 | 其他人给你周围的地方起的名字 |
| [已声明的作品](#已声明的作品发布者说它们立在那里的他人作品) | “探索”的**附近**部分 | 在你附近公告的作品，以虚影显示 |
| [我的共享世界](#我的共享世界分发你自己的快照无需对等节点) | 面板下方 | 你自己作品的放置、把它发送出去，以及它的评论 |

高级工具还会增加无法加载的世界列表，以及**化身设置**下的化身诊断信息。

## 查看积木——或已放置的结构

点击任意积木即可打开**查看**面板。（没有高级工具时，点击只会选中另一个化身。）它会显示：

- 它是哪种积木；
- 它的位置和旋转；
- 它属于哪个世界和哪个作品；
- 谁做了那个世界。

**聚焦积木**会放大到这块积木。**聚焦世界**会带你去世界的起始位置。**编辑副本**会制作你自己的世界副本，
并在编辑器中打开；原作保持不变。

在世界内部点击空地会打开同样的面板，显示位置和世界，但没有积木详情。它也有**编辑副本**，所以你点击世界中的任何地方都能复制它。

**已放置的结构**是从编辑器放入世界中的一整个作品（见
[结构实例](02-TheEditor.md#结构实例一个实时引用)）。点击一个，面板就会显示它所指向的作品：它的标题、位置和旋转、
地面高度，以及它所在的世界。你不能在这里移动它。它有两个按钮：

- **打开源作品**会在编辑器中打开它所指向的作品。那个结构的每一份副本，无论放在哪里，都会显示你在那里所做的更改。
- **编辑副本**会改为制作那个作品的个人副本，原作以及它的每一份已放置副本都保持不变。

世界视图中的每一个**编辑副本**都做同样的事；见[编辑副本](03-WorldView.md#编辑副本把东西带进编辑器)。

## 镜头与编辑

标题部分会显示这样一行：

```
镜头：Alice 的城堡 · 编辑：Bob 的城堡
```

- **镜头**是你正在看的东西。飞到某个世界，或点击**聚焦**或**前往**，都会改变它。
- **编辑**是你的下一次更改所作用的作品：地标、区域、它的详情，或者发布。点击一块积木或一个放置，
  或者在搜索结果中点击**选择**，都会改变它而不移动镜头。

两者通常是一样的，因为**聚焦**会同时改变两者。当你选中了一个作品却在看另一个，或者两个作品正好立在同一个位置时，它们会不同：
聚焦第二个不会移动镜头，但这一行会显示你现在编辑的是另一个作品。环顾四周永远不会改变你编辑的对象；只有选择才会。

**前往**和**聚焦**是同一件事的两个名字：两者都会移动镜头。它们是否也会改变你编辑的对象取决于面板（在
[搜索](03-WorldView.md#搜索哪些发布内容符合这个)中，聚焦会改变）。

## 作品信息与放置

**关于此作品**会在你一到达你正在编辑的作品时就显示它，不需要点击任何东西。

点击一块积木、空地或一个已放置的结构，标题部分下方会为你点击的作品打开两个面板：

- **关于此作品**：它的标题、描述、标签、许可证、状态、作者，以及它改编自什么。**编辑元数据**可以更改标题、描述、许可证
  以及谁可以放置它。长描述在这里只显示开头；**阅读全文**会在旁边一个更宽的面板中（在手机上从底部）打开全部内容，
  世界仍然在视野中。**Esc** 或 **✕** 会关闭它。已发布的作品还会显示 **💬 评论**：它们在同一个面板中、描述下方打开，
  你可以在那里阅读并发表自己的评论，与在**探索**中它的卡片上一样。已发布的作品还会显示它的爱心（**♡**，以及谁喜欢它）；见
  [爱心](04-PublishingAndForking.md#爱心)。当有其他人在它之前发布的作品看起来很像它时，它下面会有一个面板列出这些作品，
  与作品页面一样；见[较早发布的相似作品](04-PublishingAndForking.md#较早发布的相似作品)。
- **放置**：作品在世界中立在哪里，以**世界单位**表示。这是 ForkBuild 自己的坐标，不是 GPS；一个世界单位是一米。
  **聚焦**会带你去那里。**移动**会打开**移动放置**，你可以在那里输入新的 X、Y 和 Z 值，或者把作品微移 1、10 或 100 个单位。
  **移到它的网格位置**会填入作品在世界网格上的专属位置，即作品发布时放置的地方；点击**移动**即可去那里。
  **从世界中移除**会移除这个放置。

之所以是两个面板，是因为作品*是什么*和它*立在哪里*是两回事。移动放置永远不会改变作品，修改作品也永远不会移动它。

### 世界位置

要把一个作品带回它在世界网格上的专属位置（2026 年 10 月 12 日至 17 日发布的作品被放在了挑战广场周围），
请打开**移动放置**，点击**移到它的网格位置**，然后点击**移动**。之后在**我的共享世界**中用**分发**再把它发送出去，
这样其他设备也会移动它。

如果你要移去的地方正好已经立着另一个作品，**移动放置**会在你确认前警告你并列出那里有什么。共享一个位置是允许的：
一个庭院场景和环绕它的建筑可以立在同一个地方。ForkBuild 只是确保你知道这一点。

### 不属于你的放置

当作品是别人放置的时，放置面板会显示 **🔒 由 &lt;名字&gt; 放置——你可以查看这个放置，但不能移动它**，
**移动**会变成灰色。你仍然可以聚焦它、查看它，并用**编辑副本**在它的基础上继续搭建。只有它立在哪里由对方来更改。

### 这里的作品

当放置面板说还有其他作品共享这个位置时，点击**查看**即可打开**这里的作品**：一个列出该位置所有作品的列表，
每个都有一个**聚焦**按钮。已取消发布的作品不会列出。

### 为什么我可以放置别人的作品？

真实的建筑不能被拿起来搬走，所以你可以把任何人已发布的作品放到你喜欢的任何地方，这可能看起来很奇怪。
但已发布的作品不是一个实体物品。它是固定的内容，以内容哈希来识别，就像一个文件。**放置**是一份单独的签名备注，
说“在这里显示这个作品”。它指向作品；而不是复制它。一个作品可以有很多放置，每一个显示的都是完全相同的内容。

所以放置别人的作品永远不会移动或改变对方的作品：

- **对方的放置留在对方放的地方。** 只有对方能移动它（见[不属于你的放置](#不属于你的放置)）。
- **你的放置由你签名。** 它只说明*你*在哪里显示对方的作品。
- **作品保留它的作者和历史。** 它仍然完全是对方发布的那个作品，任何人都可以对照它的哈希和签名来检查。

没有一张规定谁拥有哪块土地的中央地图。每个世界显示它所接受的放置。这就是为什么有人在你附近公告的作品，
在你选择**接受位置**之前只会显示为虚影（见
[已声明的作品](#已声明的作品发布者说它们立在那里的他人作品)）。没有你的同意，任何人都不能把作品放进你的世界。

放置不是你做的作品的一些理由：

- **策展**，比如一个陈列你喜欢的作品的画廊世界。
- **搭建场景**，比如把朋友的城堡放在你的村庄旁边。
- **原样使用。** 想让它保持不变时就放置它，想修改它时就用[编辑副本](03-WorldView.md#编辑副本把东西带进编辑器)。

不希望这样的发布者可以在发布时选择**只有我可以放置**（见
[选择谁可以放置它](04-PublishingAndForking.md#选择谁可以放置它)）。你仍然可以找到并查看对方的作品，
并在许可证允许时改编它，但你不能放置它。

### 为什么两个作品可以在同一个位置？

两座真实的建筑不能立在同一个地方。在 ForkBuild 中可以，因为放置不占用土地。它只是一份说“在这里显示这个作品”的签名备注，
两份备注可以指向同一个位置。

ForkBuild 有意允许这样：

- **没有人分配土地。** 没有中央服务器来决定谁先占了一个位置，ForkBuild 也从不在两个签名放置之间判定胜负。两者都有效。
- **每台设备知道的放置不同。** 在朋友设备上已被占用的位置，在对方的放置传到你这里之前，在你的设备上可能仍然是空的。
  严格的“一个位置一个作品”规则会在不同设备上得出不同的答案，所以 ForkBuild 不假装有这样的规则。
- **有时你就是想这样。** 建筑内部的庭院场景，或者在新版本的位置上显示的旧版本，本来就该在同一个位置。

这并不意味着任何人都能挤占你的作品：

- **你会先收到警告。** **移动放置**会在你确认前列出某个位置已有的东西，而且从不悄悄把你的作品移到别处（见[世界位置](#世界位置)）。
- **不会意外重复。** 当你所在的位置正好已经立着一个放置时，**在这里添加放置**会拒绝。
- **别人的声明只是虚影。** 由作品发布者本人以外的任何人公告的位置，只会显示为一个半透明的虚影，
  而且永远不会出现在此设备已经知道有真实放置的位置上（见
  [已声明的作品](#已声明的作品发布者说它们立在那里的他人作品)）。
- **只有所有者才能移动或移除放置**（见[不属于你的放置](#不属于你的放置)）。

ForkBuild 只检查正好在同一个点上的作品。两个稍微隔开、积木恰好接触的作品不会被标记。关于设计原因，请见
[Overlap Is A Fact; Collision Is A Policy Decision](../../principles/placement.md#overlap-is-a-fact-collision-is-a-policy-decision-0225)（英文）
以及其后的规则。

### 放置与改编

两者都会把别人的作品放进你的某个世界，但它们是不同的：

| | 放置 | 改编（改编，或编辑副本） |
|---|---|---|
| 创建了什么 | 一个放置：一份说明在哪里显示作品的小小签名备注 | 一个属于你的新作品，带有新的 ID |
| 作品 | 同一个共享世界，按发布时的样子显示 | 你自己的副本，附有一条链接回原作的说明 |
| 你能修改积木吗？ | 不能 | 能，在编辑器中 |
| 作者是谁 | 原发布者 | 你，原作被记录为它的父作品 |
| 由什么控制 | 发布者的**谁可以放置它**设置 | 许可证 |
| 发布它 | 不会发布任何新东西 | 以你的名字创建一个新的共享世界 |

放置就像链接到一个文件；改编就像为了修改而复制一份自己的文件。选择了**只有我可以放置**的人仍然可以通过许可证允许改编，
而改编作品由你随意放置。

## 世界相遇：你的对等节点正在共享的发布内容和化身

**世界相遇**是“探索”**附近**部分中的一个组。它是一张独立的小地图（不是世界地图），显示你
[已连接的对等节点](07-PeerConnectionsAndFriends.md)告诉你的东西：

- 放置在附近的**发布内容**（见[签名记录与外部证据](09-PublicationsAndEvidence.md)）；
- 其他人的**化身**；
- 一个代表你的标记。

在已连接的对等节点共享任何东西之前，这个组会显示**这里还没有可以相遇的东西。**

点击一个标记即可查看它：

- **发布内容**会显示它的标题、发布者、是否已签名、位置，以及它有多少个锚定和快照放置。
- **化身**会显示它的名字、所有者和位置。

如果不止一个对等节点提供同样的东西，**选择来源**可以让你挑选看谁的副本。这里的任何东西都不会移动你的镜头或改变任何东西。

### 素材与验证

选中一个发布内容后会多显示两行：

- **素材**：它的内容能否加载？**可用**或**不可用**。
- **验证**：内容是否与为它声明的一致？**已验证**或**无法验证**。

已经在此设备上的内容会立即加载并检查。对等节点只是给你看过的东西，通常会显示**不可用** / **无法验证**，
直到你用[发现共享世界](#发现共享世界直接搜索去中心化网络)查找它。如果在 Arweave 或 Nostr 上找到了，
这里也会使用它。当它找到不止一个地方时，**选择位置**可以让你挑一个；在你选择之前不会加载任何东西，而且这个选择只适用于这一个发布内容。

一行**来源**会说明内容来自哪里：**本地**（此设备）或**去中心化**（Arweave 或 Nostr）。这只是一个简单的事实，不是信任评分。

一旦对等节点的发布内容显示**可用**，它就会被加入“探索”和它作者的页面，就像你在那里找到它一样，并且重新加载后仍然保留。
没有任何东西标明它是通过对等节点找到的：你自己的设备已经检查过内容，所以它与其他任何内容都一样。

### 分发对话框

一旦此设备持有某个发布内容的内容，一个**分发**按钮就会打开**分发**对话框。对于你自己的作品，同一个对话框也可以从
[我的共享世界](#我的共享世界分发你自己的快照无需对等节点)打开。关于每个网络的作用，请见
[分发你的作品](Distribution.md)。

顶部有两个设置，用于对话框中的所有操作。两者都从你保存的偏好开始：

- **存储**：内容放到哪里。**Arweave**、**IPFS（本地 Kubo）**、**IPFS（远程固定）**，或者实验性的 **Steem** 或 **Blurt**（见
  [Steem](11-EvidenceAndStorage.md#steem) 和 [Blurt](11-EvidenceAndStorage.md#blurt)）。远程固定每次都会询问端点和凭据，
  从不保存。只会列出此设备真正能使用的存储。
- **公告 / 发现载体**：在哪里公告它，让别人能找到。**Arweave**、**Blurt**、**Nostr** 或 **Steem**。

对话框可以发送两样东西：

- **签名声明**，说明这是你发布的，以及
- **快照**，作品本身的一份副本（见[本地快照](09-PublicationsAndEvidence.md#本地快照)）。

两者都能发送时，主要的**分发**按钮会依次发送它们，因为两者可能都会请同一个钱包扩展签名。每一个都有自己的部分和自己的结果，
其中一个失败永远不会隐藏或阻止另一个。**仅分发签名声明**和**仅分发快照**只发送其中一个，比如用来重试失败的那一半。
只能发送一个时，它的按钮就只是**分发签名声明**或**分发快照**。

你需要一个浏览器扩展来签名：Arweave 需要 Arweave 钱包（比如 Wander），Nostr 需要 Nostr 签名器（比如 nos2x）。
没有它时，该部分会显示“无法完成分发。”以及原因。

- 在发送之前，**签名声明**部分的**素材**和**发现**显示为**缺失**。之后它会显示发布内容的 ID、它的素材在哪里，
  以及公告的 ID，每个 [Nostr 中继](10-NetworkSettings.md#nostr-中继)一行。
- **快照**部分会显示**内容哈希**、**定位符**和**公告** ID。“无公告”表示副本已存储但没有公告；这是部分结果，不是错误。
  真正的失败会显示“无法完成快照的分发。”

关闭对话框不会丢失任何东西：再次打开时结果仍然在那里。当你选择另一个发布内容或离开页面时，它们会被忘记。

## 发现共享世界：直接搜索去中心化网络

在世界相遇中，**共享世界发现**会打开**发现共享世界**面板。它不需要对等节点，也不需要标记。输入一个**共享世界 ID**，
保留**发现标签**（它默认是 ForkBuild 自己的标签，几乎总是对的），然后点击**发现共享世界**。ForkBuild 会直接询问 Arweave 和 Nostr。

随后**发现**一行会显示**不可用**、**已解析**或**有歧义**（同一个位置有不止一条线索）。解析后，它会显示与上面相同的素材、来源和验证行。

目前它只能解析你自己的发布内容：你签名并且仍然保存在此设备上的那些。可以把它理解为“我的作品真的在外面、而且完好无损吗？”，
而不是对所有人作品的搜索。

当结果显示**已验证**时，**选择共享世界**会把它标记为你正在处理的那一个，并在下方的一条备注中显示。它只做这一件事：
不会再发送或检查任何东西。它会一直保留，直到你选择另一个或离开页面。关闭面板会保留你输入和找到的内容。

## 附近的地名：发现任何人的提议

**地名**是“探索”**附近**部分中的一个组，显示人们为你周围的世界区域发布的名称。它在 Nostr 上查找，所以不需要已连接的对等节点。
它一开始是收起的，因为这些名称还没有经过检查。

每一行显示名称、大致位置、谁起的名以及时间：

- **导航**会把你的镜头移到那个区域，与**前往**相同。它不会重命名或接受任何东西。
- **采用**会在经过与已连接对等节点发来的名称相同的签名检查后（见[从对等节点接收](09-PublicationsAndEvidence.md#从对等节点接收)），
  把这个名称保存到此设备。之后按钮会显示 **✓ 已保存**。

当两个人为同一片土地起了名字时，两个名字都会显示。ForkBuild 从不判定胜负，采用其中一个也不代表它更正确。
如果查找失败，会有提示说明，你已经看到的名称会保留。要自己发布名称，请见[为地点命名](09-PublicationsAndEvidence.md#为地点命名)。

## 已声明的作品：发布者说它们立在那里的他人作品

你行走时，ForkBuild 会下载在你附近公告的快照（见[我的共享世界](#我的共享世界分发你自己的快照无需对等节点)）。
公告可能会说明作品立在哪里，但那只是一个**声明**：盲目相信它会让任何人都能把作品放在你的作品上面。
所以已声明的作品会显示为**虚影**，它的积木在声明的位置上是半透明的，而且永远不会自己变成真正的放置。

**有一个例外不需要点击。** 当发布者自己发送出自己的快照时，公告会携带他们**签名的放置**。一旦此设备知道那个作品的共享世界
（它在“探索”中，或者你点击了**验证**），ForkBuild 就会检查这个放置是否用那个共享世界的密钥签名。
如果是，作品就会实实在在地显示出来，正好在他们放置的地方。它仍然是他们的放置，所以你不能移动或移除它；
如果他们移动它并再次发送出去，它在你这里也会移动。由其他任何人签名的位置仍然是虚影。

只有在以下情况下才会画出虚影：

- 它在你附近（你所在的地图格子或相邻的格子，每个方向约 1,000 个单位），你走开后它会再次消失；
- 它的内容已下载并与其内容哈希相符；
- 此设备还没有那个作品的放置（一旦有了，就会改为显示真正的作品）；
- 此设备知道的任何东西都没有正好立在那个位置上。

你不能选择、查看、编辑或复制虚影。非常大的作品只会画出一部分（前几千块积木）。

每个虚影在**已声明的作品**中都有一行，最近的排在最前面：它的标题、距离、位置和“声明者 …”。
标题和作者来自作品本身，和它的位置一样未经检查。每一行都有：

- **导航**：把镜头移到声明的位置。不会改变别的任何东西。
- **验证**：在此设备没有该作品签名的共享世界时显示。它会在 Nostr 和 Arweave 上查找，并检查它是否有效签名、
  是否是这个作品的共享世界，以及它所指的内容是否与虚影显示的完全一致。如果是，它会被加入“探索”，
  这一行会显示“签名者 *名字*（密钥 did:key:…）”。如果不是，这一行会说明原因：没有公告任何东西（发布者可能只发送了快照）、
  没有一个副本经过有效签名，或者它所指的内容不同。“验证”不会接受位置，但如果发布者自己签名的放置也一并到来，
  作品现在就会实实在在地显示在他们放置的地方。
- **接受位置**：信任一个声明的唯一方式。它会用一个*你自己的*、由你签名的放置，把作品放在声明的位置上，
  从那以后它就是你世界中的一个普通作品。只有在此设备持有发布者签名并经过检查的共享世界，而且它所指的内容与虚影显示的完全一致时，
  它才会起作用。你可以通过**验证**、在对方[与你共享世界](04-PublishingAndForking.md#与已连接的对等节点共享)时，
  或者在对等节点关于它的[世界相遇](#世界相遇你的对等节点正在共享的发布内容和化身)显示**可用**时得到它。
  当发布者选择了**只有我可以放置**时，它也会保持关闭（见[选择谁可以放置它](04-PublishingAndForking.md#选择谁可以放置它)）。
  关闭时，这一行会说明原因。

  **“已验证”是什么意思。** 作品正是由所显示的密钥签名的某个共享世界的内容。它不能证明谁持有那个密钥
  （任何人都可以生成一个并自称“bob”），也不能证明位置，位置仍然只是声明。“接受位置”对你不认识的密钥也有效；
  是否信任它由你决定。
- **隐藏**：移除那个虚影及其所在行，直到你离开世界视图。不会报告或删除任何东西。

## 我的共享世界：分发你自己的快照，无需对等节点

**我的共享世界**位于面板下方、搜索和化身的下面，针对的是你打开的作品。作品发布后，它会显示作品的标题和作者，
无论周围有没有其他人都能使用。

最前面是**分发**和分享链接。**分发**会打开与世界相遇中相同的[分发对话框](#分发对话框)，但针对的是你自己的作品。
在作品发布之前，这个按钮是灰色的，并附有一条说明还没有可以发送的东西的备注。远程 IPFS 固定以及 Bitcoin 或 Base 锚定不在这里：
它们需要先有账户或钱包，所以放在签名记录页面上（见[IPFS 发布](11-EvidenceAndStorage.md#ipfs-发布)和
[Bitcoin 锚定流程](11-EvidenceAndStorage.md#bitcoin-锚定流程)）。

**更多 ▾**中有较少用的操作：

- **导出快照**和**检查快照是否匹配**。菜单关闭后，它们的结果仍然留在面板上。
- **诊断工具**（见[下文](#诊断工具)）。
- **取消发布…**会询问一次，然后把世界从目录中移除。它的放置、作品以及你已经发出去的任何副本都会保留；
  发出去的副本无法收回，但此设备会记住你取消发布了什么，所以“探索”不会再列出它们。**取消**会退出。

当你打开的世界是别人发布的（比如是某个对等节点与你共享的），面板叫作**共享世界**，并且没有**取消发布**或**分发**：
只有世界的发布者才能做这些。其他一切都保留，包括评论。

**▸ 评论（N）**会打开作品的评论；收起时计数也会保持最新。作品发布后你就可以发表评论。谁可以评论，请见
[评论](09-PublicationsAndEvidence.md#评论)。

### 放置

**放置（N）**列出这个共享世界立着的每一个地方：位置、修订版本，以及（已知时的）所有者。一个作品可以立在不止一个地方，
此设备知道的每一个放置都会列出。

- **移动…**会为那个放置打开**移动放置**，附带关于新位置上已有作品的警告。
- **移除…**会询问一次，然后把那个放置从世界中移除。作品及其其他放置都会保留。没有任何放置时，作品就不会在任何地方显示，
  直到你再次放置它。

在别人做的放置上，两者都是灰色的。

列表下方的**在这里添加放置**会把同一个作品*再次*放在你的化身所站的地方（没有化身时则在镜头下方）。它不会移动已有的放置，
也不会制作副本：它仍然是同一个共享世界（见[放置与改编](#放置与改编)）。它会说明把作品放在了哪里，以及现在有多少个放置。
如果你所在的位置正好已经立着一个放置，它会请你先移开，所以点两次也不会在同一个位置上叠放两个。

### 诊断工具

你行走时，ForkBuild 会自己找到快照（见下文）。**更多**下的**诊断工具**会手动执行同样的步骤，用于自动查找没有找到你预期的东西时。
每一步都需要单独点击，不会有任何东西自己运行：

1. **发现快照**会列出在 ForkBuild 共享标签下公告的所有内容。它不需要对等节点，也不需要你自己有已发布的作品。
2. **解析所选快照**会检查你挑选的那一个能否获取。
3. **为所选快照署名**会检查它是否与这个共享世界的内容哈希相符。**实体化所选快照**会把它保存到此设备上。
   你可以做其中任何一个，顺序不限。
4. **放置实体化的快照**，然后**登记已放置的快照**，会把它加入你所在的世界，无需重新加载。

挑选了一个之后的任何时候，**使用声明的位置**都会使用快照本身声明的位置（如果它有的话）。

**自动发生的事情。** 你行走时，ForkBuild 会不时检查快照，方式与**发现快照**相同。它会查看此设备拥有的、
已连接的对等节点仅因连接就共享的，以及 Nostr 报告的内容。通过检查的快照会自己走完同样的步骤，
并显示为一个[世界相遇](#世界相遇你的对等节点正在共享的发布内容和化身)标记；没有单独的列表或通知。

它只下载你附近的快照：放置在、或声称放置在你所在的地图格子或相邻格子中的快照（每个方向约 1,000 个单位），
再加上没有说明自己属于哪里的最新 20 个。更远的会在你走近时下载。一次最多下载四个。此设备已经有的快照，
会在经过同样的内容检查后从它自己的存储中读取。
