# 06 — 化身与在线状态

<!-- languages -->
[English](../06-AvatarsAndPresence.md) · [Deutsch](../de/06-AvatarsAndPresence.md) · [Español](../es/06-AvatarsAndPresence.md) · [Français](../fr/06-AvatarsAndPresence.md) · [Bahasa Indonesia](../id/06-AvatarsAndPresence.md) · [日本語](../ja/06-AvatarsAndPresence.md) · [한국어](../ko/06-AvatarsAndPresence.md) · [Português (Brasil)](../pt-BR/06-AvatarsAndPresence.md) · **中文（简体）**
<!-- /languages -->

你的**化身**是其他人在世界视图中看到的你——它的外观、位置以及移动方式。这份指南介绍如何自定义它、
控制谁能看到它，以及与其他所有人的化身互动。

## 自定义你的化身

打开**更多 → 我的化身**（或点击顶栏中你的名字）：

1. 从下拉菜单中选择一个**模板**——一种体型（例如“Humanoid 01”）。选择时，一个平面预览会实时更新。
2. 对于模板声明的每个部分（内置模板提供**皮肤、头发、上衣、裤子**），从它的下拉菜单中选一个选项，
   在模板允许的地方再选一种颜色。
3. 从清单中勾选模板提供的任何**配饰**。（任何允许同时选多个的部分都会像这样显示为清单；
   页面显示的正是所选模板声明的那些部分。）
4. 设置你的**显示名称**（最多 60 个字符）——这是显示在你的化身旁以及对等节点/对话中的名字。
5. 点击**保存**。

切换模板会把外观重置为该模板自己的默认值——选择不会在模板之间沿用。这里没有 3D 预览；
你（或其他人）第一次在世界视图中看到它时，才会看到你的实际化身。

## 谁能看到你：两个独立的设置

“我的化身”页面有两个独立的可见性控件。它们很容易混淆，所以请区分清楚：

| 设置 | 控制 |
|---|---|
| **在线可见性** | 谁会收到你的*实时位置*——你是否以及在哪里出现在世界视图中走动 |
| **资料可见性** | 谁会收到你的*外观*——模板、颜色、配饰、显示名称 |

两者都提供同样的四个级别，并且一开始都是**公开**：

- **公开**——任何已连接的人都能看到。
- **好友**——互为好友的人，加上你明确列出的任何身份（粘贴身份 ID，每行一个）。
  这是一个简单的允许列表，而不是请求/批准流程——“好友”的含义见
  [对等连接与好友](07-PeerConnectionsAndFriends.md)。
- **本地**——只有在同一个浏览器中打开的其他 ForkBuild 标签页；从不发送给任何对等节点，连好友也不行。
- **隐藏**——从不向任何人公开。这就是隐身的方法。

每个部分都有自己的**保存**按钮——保存一个永远不会保存另一个。保存后会出现“已保存。”，
一旦你再次更改那个部分它就会消失，所以它始终描述你正在看的内容。

成为某人的好友本身**不会**显示你的化身——这两个设置各自独立地决定实际分享什么。
而且它们只影响*以后的*更新：已经收到你位置或外观的人会保留他们拥有的内容；没有远程“忘记我”的功能。

你还可以直接在世界视图中切换**显示我的化身**和**显示其他化身**，它们只是简单的本地显示开关。
在你有自己的化身之前，世界视图的“化身”部分只显示**显示其他化身**以及如何创建化身的说明；
需要你化身的控件会在你有了化身之后出现。

## 在世界视图中看到其他人

任何你有资格接收其在线状态的人（取决于他们自己的在线可见性）都会在你四处移动时自动出现——
看到公开的化身不需要好友请求。点击一个化身（或**附近的化身**面板中的一个条目——附近所有人的简单列表，
附带距离和当前动作）即可打开它的**化身信息面板**：

- 显示名称和化身模板
- 一行状态——**在线 / 已过时 / 离开**，以及一个信任标签（**可信 / 未签名 / 存在冲突**），
  说明这个化身的数据经过了多大程度的验证
- 位置、距离（以世界单位表示）和当前动作（步行、空闲……）
- **跟随化身**——把你的镜头锁定在对方的移动上
- **打招呼 / 挥手 / 指向**——向那个化身发送一次性手势
- **关注对方的作品**——关注化身背后的身份，这样对方的新作品会显示在**关注**页面上（见
  [关注他人](07-PeerConnectionsAndFriends.md#关注他人)）。只有当化身的在线状态带有签名时才会出现，
  因为签名才能证明化身是谁的。

除此之外，远程化身只能查看——无法移动、编辑或删除别人的化身，只能查看、跟随和做手势。

附近的化身是否出现，取决于你的**镜头**当前看向哪里，而不是你自己的化身朝哪个方向走——
两者可能指向不同方向，最常见于你自由环绕镜头之后。正好站在你行走路线上的人，在你的镜头看向别处时
可能完全看不见；把镜头转回或环绕回他们那边，他们就会重新出现。

### 大声说话

在世界视图中按 **Enter**（或轻点 **💬 说话**），输入一句不超过 140 个字符的短句，然后再按 **Enter**。
它会在你化身上方的气泡中显示几秒钟，并出现在左下角的一个简短记录中，那里会保留最近几句话一分钟，
每句都注明是谁说的。**Escape** 会关闭输入行而不说任何话。

能看到你化身的人就能看到你说的话：也就是你的**在线可见性**允许看到你的那些人，所以如果设为隐藏，
一句话就只会显示给你自己，记录中也会注明。你屏蔽的人永远听不到你说话，你也听不到他们。
每句话都以你的身份签名，并像手势一样在到达时接受检查，所以没有人能把话塞进你化身的嘴里。
不会保留任何内容：说过的话不会保存，后来到的人看不到之前说了什么。访客需要先取个名字，
因为没有名字的化身没有人能看到。如果想真正出声说话，请给朋友**📞 通话**（见
[聊天与对话](08-ChatAndConversations.md#语音通话)）。

## 让你的化身行走

飞行镜头（[世界视图](03-WorldView.md#四处飞行)）是一种移动方式，但你也可以用**化身控制模式**直接让你的化身行走，
世界视图打开时它是开启的（**化身设置**下的**控制我的化身（WASD、Shift、空格）**）。
文本框获得焦点时会忽略这些按键——请先点击 3D 视图。

行走不需要名字。在你取名字之前，你以**访客**身份行走：一个默认外观、只有你自己能看到的化身，
不会告诉任何其他人。访客可以和居民交谈，但不能添加或移除居民，也不能用动物装饰世界，
因为这些是需要以名字签名的更改。取个名字（在发布时、通过**和我一起在这里漫步**，或通过顶栏中的**取个名字**），
你的化身就会在原地变成你的，换上**我的化身**中保存的外观，其他人也能看到它。
**切换名字 → 不用名字继续**会把它变回访客。

| 按键 | 操作 |
|---|---|
| **W / A / S / D** | 移动 / 转向 |
| **Shift** | 奔跑（更快地移动） |
| **空格** | 跳跃；在深水中向上游 |
| **C**（在深水中按住） | 下潜 |
| **Alt + W / S** | 自动持续向前/向后行走——松开按键后仍继续移动 |
| **Alt + Shift + W / S** | 同上，但是奔跑而不是行走 |

在手机或平板上，屏幕上的摇杆和按钮代替这些按键：推动摇杆即可行走，推到边缘即可奔跑，轻点**跳跃**即可跳跃。
见[触屏](ControlsReference.md#行走世界视图)。

行走会与附近已加载的建筑、树木和野生动物发生碰撞——你不能穿过在你周围加载进来的结构、
作为地形一部分生成的树木，也不能穿过在附近吃草的鹿或兔子（见[世界视图](03-WorldView.md#四处飞行)）。
无论动物走到哪里，它都只会像树一样挡住你的路——它可能会转过头来看你，但从不会给你让路或受到伤害，
而载具会直接穿过它；只有步行会被挡住。你已经捕捉的动物不再挡住任何东西。你的化身可以走过已放置的结构、
攀爬垂直表面，并在不平坦的地形上行进。你移动时镜头会自然地跟随你的化身。

门和拱门是入口。你走近时门会朝远离你的方向打开，你走过后它会在身后关上；它也会为居民和你看到的人打开，
而其他人看不到你打开的门。你可以从拱门的开口走过，而它的两侧和顶部和看起来一样结实。
小拱门太低，无法通过；倒向一侧的门或拱门会像其他积木一样挡住你。

**跟随化身**会让镜头在你的化身移动时锁定在它身上，而不是自由环绕。你也可以跟随其他玩家的化身，看看他们要去哪里。

### 游泳和潜水

不超过你化身身高一半的水可以涉水走过，越深走得越慢。比这更深时，你的化身会游泳：它浮着，头露出水面，
移动方式和在陆地上一样，只是更慢。按住 **C** 下潜，按住**空格**向上游回；两者都松开时，它会慢慢漂回水面。
在第一人称下，你漂浮时看到的是水上的世界，潜下去后看到的是水下的世界。

在水下，你的化身会屏住呼吸。视图顶部的**氧气**条显示还剩多少：从满气算起有两分半钟。
耗尽时，你的化身会被推到水面，并在那里停留几秒钟喘口气，然后才能再次潜水。游到岸边，它就会站起来走出水面。

其他人也能看到你游泳和潜水：你的化身在水中如何移动取决于它所在的位置，所以不会额外发送任何东西。

### 镜头视角

在“跟随化身”旁边是**镜头**，一排四个按钮——**自由**、**第一人称**、**第三人称**和**鸟瞰**——
用于把镜头锁定在相对于你自己化身的固定位置，而不是自己操纵飞行。与“跟随化身”一样，
它们需要一个本地化身（我的化身）才能启用。

- **自由**是普通的环绕镜头——世界视图的默认设置，也是本指南中其他所有镜头控制所假定的。
- **第一人称**把镜头放在你化身自己的视线高度，看向它面朝的方向。开启时不会画出你自己的化身，
  所以它的头、眼镜或帽子永远不会挡在你眼前；其他人仍然能看到它，离开第一人称后**显示我的化身**会再次生效。
- **第三人称**位于你化身的后上方，稍微向下看——经典的“看到你自己的角色”的取景。
- **鸟瞰**从高处正上方往下看，跟随你化身的位置，但有意忽略它的朝向，所以你转身时视图永远不会旋转。

点击已激活的按钮会恢复为**自由**。镜头视角纯粹是本地的——它从不与合作者共享，也从不影响他们看到的内容。

两种模式在你转身时的表现不同：锁定一个视角（第一人称或第三人称）时，每次移动镜头都会按你化身当前的朝向重新取景，
所以你的视图会和你一样转动。选择**自由**时，镜头有意不关心朝向——原地转身、行走或骑上载具永远不会自己移动或旋转它，
只有你自己的拖动/平移/缩放才会。如果你自由环绕看向一边，然后朝另一边走开，镜头会继续看着你最后指向的地方，
而不是跟随你。

### 自动持续移动

按住 **Alt** 的同时轻点 **W** 或 **S**，你的化身就会朝那个方向持续行走（如果同时按住 **Shift**，则是奔跑）——
即使你松开所有按键它也会继续，完全像定速巡航一样。*不*按 Alt 再轻点一次 **W** 或 **S** 会取消它，
恢复普通的按住按键移动；以同样方式轻点相反方向也会取消它，而不是倒退。在键盘上，屏幕上没有它正在运行的提示——
唯一的迹象是你的化身自己一直在走。

在手机或平板上，触控板的**巡航**按钮作用相同：轻点一次自动向前行走，再点一次奔跑，第三次停止。
运行时它会显示**巡航：行走**或**巡航：奔跑**。把摇杆向前或向后推也会停止它，与轻点 **W** 或 **S** 相同；
向两侧推只会让你转向，所以你可以边巡航边控制方向。

### 载具

有些世界放置了自行车、大小轮自行车、干草车或热气球，你的化身可以骑乘它们而不是走路。
走到足够近的地方，会出现一个提示告诉你用哪个键骑上去：

| 按键 | 操作 |
|---|---|
| **E**（在载具附近） | 骑上 |
| **E**（骑乘时） | 下车 |
| **W / S** | 加速 / 倒车 |
| **A / D** | 转向——载具连同你一起平滑、连续地转弯 |
| **← / →**（按下） | 掉头——每按一次载具转 45°；按住不放不会持续转动，每次转向都需要重新按一下 |
| **Ctrl**（按住） | 刹车 |

骑上之后，**W/S** 和 **Ctrl** 驾驶载具，**A/D** 和 **←/→** 让它转向——没有需要单独开启的“驾驶模式”。
你始终面朝载具指向的方向，其他玩家看到的也是这样。载具只在移动时转向，所以停着时转向不起作用；
倒车会让它向后移动而不会掉头。下车会让你的化身在载具旁边一个空着的位置重新步行。
载具的最高速度、加速、刹车和转向都取决于它是哪种载具，它的碰撞范围也与之匹配——目前有自行车、
大小轮自行车、干草车和热气球，这是世界中实际放置和绘制的四种载具。大小轮自行车比自行车快，也更难找到；
干草车更快、更稀有；热气球是最快也最稀有的。

热气球和其他三种一样，空闲时停在地面上，直到你骑上去并开始移动——按住 **W** 或 **S** 会让它离开地面；
松开会让它降回地面。升空后它会飞过树木，但高楼仍然会像挡住干草车一样挡住它，所以飞行并不意味着无视世界本身的几何形状。
你不能在半空中离开热气球——请先让它回到地面。

自行车、大小轮自行车和干草车会在水边停下。热气球可以继续飞过湖泊和大海，并让你降落在水面上：
降落后下来，你的化身就在游泳了。你在水中时不能从物品栏中取出带轮子的载具。

在陆地上，它们能像你走上去那样驶上坡道和积木：任何不超过一级台阶高度的东西，以及任何坡道或楼梯。
所以有人搭建的桥能载着干草车过一条它本来过不去的河。从平台边缘开下去，你会落回地面；在桥上下车，你会站在桥面上。

#### 携带载具

在离你以后需要它的地方很远的地方找到了一辆载具？骑乘时按 **Q** 把它存入你的物品栏——它会从世界中消失，
你也同时下车。走到其他任何地方，在没有骑乘时再按 **Q**，所选的存放载具就会在你站的地方出现，而且你已经骑在上面。
目前你能同时携带多少辆载具没有限制，存放的载具也永远不会重新出现在你找到它的地方。

默认情况下，**Q** 会放出你最近存放的那辆载具。如果你携带了不止一辆，按 **[** 或 **]** 可以在你携带的所有载具之间
向后或向前切换选择——提示会显示选中的是哪一辆以及它的位置（例如“放出自行车（1/3）”），
这样你就能找到较早的一辆，而不必一辆辆放出再存回去。切换只会改变 **Q** 下一次放出什么；它本身从不生成或移除任何东西。

#### 周围有其他人时骑乘

能看到你化身的人也能看到你骑的东西：你的自行车、大小轮自行车、干草车或热气球会在他们的屏幕上画在你身下，
朝向你前进的方向，他们还能听到它滚动或轰鸣的声音、你上下车和刹车的声音（见
[03 — 世界视图](03-WorldView.md)中的“声音”）。你也以同样的方式看到和听到他们的。
它遵循你的在线设置：看不到你的人也不会知道你骑着什么。

当别人骑着一辆载具时，你自己那份副本会消失，你也不能骑上去；你自己正在骑的载具始终是你的。
不过，没人骑时载具停在哪里是不共享的：一旦他们下车，它就会重新出现在你屏幕上你最后看到它停着的地方，
那可能不是他们离开它的地方。用 **Q** 存放或在新地方放出的载具，同样在主人骑上它之前只出现在主人的屏幕上。

### 动物

有些世界有野生动物——森林里的鹿，开阔草原上的兔子。野生动物在世界放置它们的地方附近慢慢游荡，
从不会走出几步远。如果一只动物的地盘上有作品，它就不在那里，也无法被捕捉，直到作品消失（见
[你周围有什么](03-WorldView.md#你周围有什么)）。走到足够近的地方，会出现一个提示告诉你按 **F** 捕捉它。
捕捉会把它加入你的物品栏（就是存放载具的同一个物品栏），并把它从世界中移除。

走到其他任何地方再按 **F**——附近没有可捕捉的东西时，这会在你站的地方放生最近捕捉的动物，
如果你想要回它，它马上又可以被捕捉。放生的动物会留在你放它的地方，但它并不是静止的：
它会吃草、四处张望、不时转向新的方向，你走近时还会转过头来看你。目前你能携带多少只动物没有限制，
而且捕捉动物永远不会干扰你同时携带的载具，反之亦然——它们共用同一个背包，但永远不会混在一起。

#### 用动物装饰世界

放生的动物只存在于你自己的会话中。要让它成为世界的永久部分——比如一只坐在你搭建的东西顶上的兔子——
站在你放生的动物旁边按 **G**。它会成为一个**动物装饰**：保存到世界自己的内容中，所以世界被发布或分发时它会被包含在内，
打开世界的每个人都能看到它，样子与它原来的动物完全相同。它会留在你选择的位置上（所以屋顶上的兔子永远不会走下来），
但会吃草、四处张望、原地转身，而且打开世界的每个人在同一时刻看到它做同样的事。

装饰只是装饰——不能用 **F** 捕捉。改主意了？站在它旁边再按一次 **G**：装饰会从世界中移除，
重新变成一只活生生、可以捕捉的动物。两者都在附近时，**G** 会先装饰一只刚放生的动物，正如 **F** 优先捕捉而不是放生。
只有你放生的动物才能用来装饰——世界自己放置的野生动物不行。当 **G** 会装饰或撤销附近的某样东西时，会显示一个提示。
与添加[地标](03-WorldView.md#地标标记值得记住的地方)一样，装饰需要名字以及对你所在世界的编辑权限。
在别人已发布的世界上，装饰会放进你自己的副本中——前提是它的许可证允许改编。如果这些条件都不满足，
**G** 什么都不会做；触控板的**装饰**按钮会改为告诉你原因。

### 居民

一个世界可以有**居民**：住在那里、在自己的家周围、在你的建筑之间散步的人。

**添加和移除居民。** 站在你希望他们居住的空地上，按 **R**，或点击**化身**部分中的**在这里添加居民**。
他们会出现在你身旁。要移除一位，站在它旁边再按 **R**（会显示提示 **[R] 移除居民**），或用 **Ctrl/Cmd+Z** 撤销。

- 你需要能够编辑你所在的世界。在别人已发布的世界上，居民会放进你自己的副本中。
- 居民需要干燥的空地：不能是屋顶或水面，也不能在你骑乘时添加。无法添加时，“化身”部分会说明原因。
- 居民是世界的一部分，就像[地标](03-WorldView.md#地标标记值得记住的地方)一样：
  它们会随世界一起保存、发布和复制。

**他们如何移动。** 居民待在离家约六步以内。他们会绕过墙、树和水走，从不穿过它们，偶尔停下来四处看看。
每个人在同一时刻看到的每位居民都在同一个位置，因为他们在哪里取决于世界和时钟。已连接的玩家会就同一个世界时钟达成一致，
所以时钟稍有偏差的设备也会显示相同的内容；它们之间只发送时间，从不发送居民在哪里。你会像碰到树一样碰到居民，
但它不会为你让路，所以你站着不动时，可能会有居民从你身上穿过。

**认路。** 居民会从门口走出去，绕过房子的拐角，沿着小路走到它喜欢的地方，遇到挡路的东西就绕过去。
入夜后，它会走回家，一直待到早晨。

**他们会注意到你。** 当你走到居民面前或身旁几步之内时，它会转过来面向你。走到跟前，它会挥手，
每次你走过来时挥一次。和动物一样，这只发生在你的屏幕上，而且只针对你自己的化身。

**和居民交谈。** 站在一位居民旁边按 **T**（会显示提示 **[T] 交谈**；“化身”部分和触控板上也有**交谈**按钮）。
它会在对话气泡中告诉你附近的某样东西：一辆自行车或一头鹿、一个地标、一个作品以及它的作者、附近的某个人、
它住的地方，或者更远处的一个作品。例如：*“东北边约 3.6 公里处有一个 bob 搭的作品，叫‘山丘堡垒’。”*

- 距离是四舍五入的。方向以居民所站的位置为准，北方就是指南针所指的方向。
- 再交谈一次，它会提到别的东西。气泡几秒钟后会消失，或者在你走开时消失。
- 对于固定不动的东西（地标、作品或载具），视图底部会出现一个**聚焦**按钮。它会把镜头转过去看看，
  就像“地点”中的**聚焦**一样。你的化身留在原地，如果开着“跟随化身”，走动会让镜头回来。

**关于街坊的想法。** 每交谈三次，或者在没有别的可说时，居民可能会自言自语地说起附近的土地上从来没有过的东西：
河上的一座桥、水边的一个码头、高地上的一座瞭望台，或者空地上的一口井、一座遮阴的凉亭、一个小摊或一座小屋。
例如：*“从来没有人在东边约 30 米处的河上建过桥。”*

- 它说这些话时，会出现一个按钮，比如**在那里建一座桥**。它会为那个位置在编辑器中打开一个属于你的新作品，
  从现成的村庄结构开始，就像世界视图中的**在这里搭建**一样。你发布后，它就会立在那里。
- 这只是一个想法，从来不是任务：不会记住任何东西，没有人检查，也没有奖励。
- 同一片土地会给每个人同样的想法。附近已经有作品的地方没有什么可期盼的。
- 一旦那里立起了东西，居民就会改为说起它，如果作品有标题还会说出标题，并附带一个查看它的按钮。例如：
  *“有人在东边约 14 米处盖了东西，就在我一直觉得该有一口井的地方。”*

**居民知道什么**取决于*你的* ForkBuild 副本知道什么：你目录中的作品、和你一起在这里的人，
以及没人拿走的载具和动物。别人和同一位居民交谈可能会听到不同的内容，其他人也看不到它告诉了你什么。
它从不会提到你存放的或有人正在骑的载具，也不会提到你捕捉的动物。作品会以标题和作者命名，与应用中其他地方一样。

居民不是真人。他们没有个人资料，从不出现在“人物”或“附近”中，也不能点击查看信息。
他们从不给你布置任务、差事或奖励：他们只是住在那里，在你问起时告诉你附近有什么。

#### 重新加载后保留什么

你的物品栏——你携带的每辆载具和每只动物——都保存在此设备上，你放置或骑到某处的载具以及你放生的动物也都留在你离开它们的地方。
重新加载页面或以后再回来，都会从你离开时的状态继续。

### 空间感知与活动

当其他人在场时，你会看到显示他们在做什么的情境提示：

- 当他们四处飞行或行走时，他们的化身附近会出现“**Bob——在附近探索**”。
- “**Alice——正在查看一块积木**”表示有人在仔细看某样东西，但没有改变它。

这些活动提示来自空间在线数据，能帮助你了解别人在看什么，而不需要明确的交流。

活动提示只描述某人在做什么；它们从不改变任何东西——见
[看到其他合作者](03-WorldView.md#看到其他合作者)。
