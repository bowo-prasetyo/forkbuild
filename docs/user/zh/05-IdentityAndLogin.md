# 05 — 你的名字与身份

> **高级。** 搭建、分享、改编或和朋友一起四处走走都不需要这一章：[开始玩的章节](README.md#开始玩按顺序阅读)
> 已经涵盖了这些。想知道底层运作方式时再继续阅读。

ForkBuild 没有密码，也没有账户。**你的名字背后是一个身份：保存在这个浏览器中的一对密码学密钥**——
它也是为你发布、发送消息或移动的一切签名的同一把密钥。这份指南介绍如何取名字、用密码短语保护它，以及备份它。

## 创建身份

还没有名字时，点击顶栏中的**取个名字**：输入一个名字并点击**以 … 的身份继续**，就会创建一个这个名字的身份，
在你添加密码短语之前它没有密码短语。如果想马上保护它，请改为点击**现在就用密码短语保护它**。

有名字后，点击顶栏中的名字，然后点击**切换名字**。对话框会列出此设备已有的所有身份——点击一个即可使用——
或者新建一个：

1. 输入一个**名字**。这是别人看到的；你可以拥有几个不同名字的身份。
2. 输入一个**密码短语**（至少 8 个字符），然后再输入一次确认。
3. 点击**使用这个名字**。

这会创建一个**受保护的**身份（显示 🔒）：密钥在存储时是加密的，只有在你输入密码短语后才会在内存中解密。

你可以不填密码短语，但只能通过勾选**不设密码短语直接创建**。这会创建一个**未受保护的**身份：
密钥以未加密的形式保存在这个浏览器中，随时可用，从不询问你任何东西，而任何能读取本网站存储的东西都能以你的身份签名。
你以后可以在**我的身份**中保护它。

> 没有密码重置。对于受保护的身份，密码短语*就是*解密密钥的唯一途径——如果你忘了，
> 那个身份就没了，连 ForkBuild 自己也无能为力。请选择一个你记得住的。

## 保险库：已锁定与无名字

受保护身份的解密密钥存放在一个叫**保险库**的地方。保险库可以**锁定**或**解锁**，
这与你正在使用哪个名字是完全不同的问题：

- **使用名字，已解锁**——一切正常运作。
- **使用名字，已锁定**（右上角你的名字旁边有 🔒）——你仍然是你自己：仍然可以浏览、搭建和保存，
  也仍然能看到你自己的爱心、关注和通知。任何需要新签名的操作（送出爱心、评论、关注、发布、允许被发现、
  加入大厅）都会显示**你的名字“…”已锁定**，并就地提供一个**解锁**按钮，它会打开与点击名字再点**解锁**
  相同的密码短语提示。然后再试一次。
- **无名字**——在**切换名字 → 不用名字继续**之后，你是访客；顶栏中的**取个名字**可以再次选择或解锁一个身份。

保险库会在**你解锁后 15 分钟**自动锁定，无论你是否还在使用应用（这不是闲置计时器），
或者在你自己在**我的身份**中点击**锁定**时锁定。重新加载页面总会让受保护的身份处于锁定状态——
解密后的密钥从不写入磁盘，只保存在内存中——即使应用仍然记得你在使用哪个名字。

## 管理身份：“我的身份”页面

打开**更多 → 我的身份**（或点击顶栏中你的名字），可以看到此设备持有的每个身份，以及它各自的锁定状态，
与你当前使用哪一个无关。在这里你可以：

- **创建**一个新身份（与取名对话框相同）。
- **用密码短语保护**——显示在未受保护的身份上（标记为 ⚠ 未受保护）。它会加密现有的密钥；
  身份本身不会改变，并且在你解锁之前处于锁定状态。
- 单独**锁定 / 解锁**任何身份。
- **更改密码短语**——替换受保护身份的密码短语（只有受保护的身份才提供这一项）。
  身份本身——它的 ID、公钥以及它做出的每一个签名——永远不会改变。
- **导出**——备份它。
- **导入**——从备份文件恢复或复制一个身份。
- **声明继任者** / **撤销**——把一个身份标记为退役、由另一个身份取代（粘贴继任者的 `did:key:z…` ID），
  或者用**撤销身份**彻底、永久地撤销它。声明继任者本身不会撤销任何东西——等到切换应当生效时再另行撤销。
  对于已锁定的受保护身份，两者都会询问它的密码短语，用它签名会解锁它，与你自己解锁完全一样。

这些表单（解锁、导出、更改密码短语、声明继任者、撤销）一次只会在一张身份卡片上打开一个。
打开另一个、按**取消**或完成操作都会关闭它并清空其中的每个输入框，所以你输入的密码短语永远不会留在页面上。
浏览器的密码管理器会被告知不要自动填写这个页面的输入框。

没有重命名或删除——身份应该一直存在；如果你想停止使用一个身份，请改为撤销它。

### 撤销会做什么，不会做什么

撤销会让一个身份不能再签署任何新内容，包括与他人开始新连接所需的证明。它**不会**阻止你使用它，
你之后仍然可以选择它——它在**我的身份**中的卡片只会显示**已撤销**。这是有意的，
这样你仍然可以打开它查看，或者最后一次**导出**它。要继续工作，请创建一个新身份并改用它。

撤销是永久性的，在此设备上以及在你恢复其备份的任何设备上都是如此。撤销时已经打开的连接不会被切断；
它们下次重新连接时，已撤销的身份将无法证明自己。如果你想让别人知道由哪个身份取代它，
请在撤销*之前*声明继任者——撤销之后，已撤销的身份就不能再签署这个声明了。

## 备份身份（导出和导入）

除非你备份，否则你的身份只存在于此设备上。**导出**会生成一个可下载的文件，其中包含你加密的私钥：

- 导出总会询问身份的密码短语，即使它当前已解锁。
- 如果身份未受保护，导出会请你当场设置一个密码短语（至少 8 个字符），只用来保护文件中的副本。

**导入**会把导出的身份带到另一台设备或另一个浏览器上：

1. 点击**导入身份**，然后选择导出的文件（或把它的 JSON 粘贴到下面的框中）。ForkBuild 会先显示一个安全的预览——
   名字、ID、算法，以及你是否已经拥有它——而不解密任何东西。
2. 输入导出时的密码短语，才会真正导入。

导入的身份总是处于**锁定**状态，ForkBuild 也不会自动切换到它——像其他受保护身份一样，
在“我的身份”或取名对话框中解锁它。

文件还携带身份签名的生命周期记录：它的撤销、它声明的继任者，以及它授权或停止授权的设备。
导入会恢复这些记录，所以已撤销的身份恢复后仍然是已撤销的，而不是活跃的。为你已有的身份导入较新的文件，
会添加设备上缺少的这些记录，不会改变其他任何东西。

要一次性备份所有身份以及其他一切，请使用[你的数据](13-YourData.md)。

旧版本 ForkBuild 导出的文件仍然可以导入。现在导出的文件使用旧版本无法读取的新格式，所以请先在另一台设备上更新 ForkBuild。

## 旧版本的密钥

在这个版本之前创建的受保护身份使用较弱的加密格式。它们仍然可以用同一个密码短语解锁，
第一次解锁（或导出）时，ForkBuild 会以当前格式重新加密它。身份本身不会有任何变化。

> 请把导出的文件*和*它的密码短语都妥善保管。只有其中一个是没有用的——而两个都丢了，
> 那个身份以及只有它才能签署的一切都将无法恢复。

## 密码短语错误

连续输错五次（解锁、导出或更改密码短语——每个身份共用一个计数）会触发 30 秒的冷却时间；
错误提示会倒数剩余的尝试次数，然后倒数剩余的锁定时间。重新加载后计数会重置。
