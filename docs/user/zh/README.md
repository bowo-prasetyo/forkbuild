## 开始玩（按顺序阅读）

搭建、分享、改编以及和朋友一起四处走走所需的一切。

1. **[入门](01-GettingStarted.md)**——打开应用，熟悉菜单，放置你的第一块积木，
   只在发布时才需要取名字。
2. **[编辑器](02-TheEditor.md)**——搭建工具箱：工具、选择、变换、积木颜色、组、
   积木库中的结构和你自己的蓝图、结构实例，以及作品的标题/描述/许可证。
3. **[世界视图](03-WorldView.md)**——每个已发布作品所在的共享 3D 世界：
   四处行走和飞行、寻找和查看东西、**在这里搭建**、**和我一起在这里漫步**、居民，
   以及用**编辑副本**把东西带进编辑器。它的网络工具有单独的页面，见下面的“高级”。
4. **[发布与改编](04-PublishingAndForking.md)**——发布并分享链接、选择作品的去处、
   许可证、改编、“探索”及其现成作品、每周挑战及其广场，以及家族树。
   关于作品可以发送到的所有地方，请见[分发你的作品](Distribution.md)。
5. **[化身与在线状态](06-AvatarsAndPresence.md)**——自定义你的化身、谁能看到你、
   行走、镜头视角、载具、动物以及你的物品栏。
6. **[你的数据](13-YourData.md)**——把这个浏览器保存的所有内容备份到一个加密文件
   并恢复、较小的导出，以及此设备在哪里记录了你的记录的分发情况。

## 高级

底层的机制：你身份的细节、与他人的直接连接、作品可以发送到的网络，以及实验性工具。
玩游戏并不需要这些。

- **[世界视图：高级工具](WorldViewAdvancedTools.md)**——**显示高级工具**会增加什么：
  查看积木、放置以及为什么任何人的作品都可以被放置、世界相遇、发现的地名、
  已声明的作品，以及从**我的共享世界**把你自己的作品发送出去。
- **[你的名字与身份](05-IdentityAndLogin.md)**——你的名字及其背后的密码学身份、
  保险库（锁定/解锁）、通过导出/导入来备份，以及在**我的身份**中管理身份。
- **[对等连接与好友](07-PeerConnectionsAndFriends.md)**——与他人直接连接、记住、
  加好友、关注、屏蔽、自动重新连接，以及你自己的 TURN 中继。
- **[聊天与对话](08-ChatAndConversations.md)**——仅限好友的直接消息、离线送达、
  已读回执和语音通话。
- **[签名记录与外部证据](09-PublicationsAndEvidence.md)**——技术性的可选层：
  签名的作者声明和地名提议、签名记录页面、评论，以及你的设备持有什么（本地快照）。
  页面的部分内容是*实验性*的，并有相应标记。
- **[网络设置](10-NetworkSettings.md)**——网关、中继、存储和公告服务，以及对等连接服务器。
  每个网络需要什么，汇总在[分发你的作品](Distribution.md#每个网络需要什么)中。
- **[证据与存储](11-EvidenceAndStorage.md)**——把内容存储到 IPFS 或 Arweave、
  快照放置、在 Arweave 上锚定，以及*实验性*的其他外部证据、Bitcoin 和 Base 钱包流程、
  远程 IPFS 固定、Steem 和 Blurt。
  [分发你的作品](Distribution.md)说明了它们如何组合在一起。
- **[存档与成就](12-ArchiveAndAchievements.md)**——*实验性*。观察存档、记录引用和成就。

## 在哪里搭建，在哪里探索

编辑器是 ForkBuild 中唯一可以搭建的地方；世界视图是只读的探索界面：

- **编辑器**（菜单中的**搭建**）——你的私人工作区。从积木库中放置积木，选中它们，
  用键盘或操纵器移动或转动它们。在工具栏中保存、打开和发布作品。
- **世界视图**（菜单中的**漫步**，或任何作品上的**探索**）——共享的世界。
  在已发布的作品之间行走或飞行，搜索并探索你周围的东西，让你的化身走过建筑和地形，
  并用**编辑副本**在编辑器中打开你找到的任何东西，在它的基础上继续搭建。

无论你在编辑器中做什么，每一次更改都是可以撤销的一步，`Ctrl/Cmd+Z` 可以收回它。

## 协作与探索

ForkBuild 让你能以化身的形式协作并发现世界：

- **行走和导航**——用 WASD 键让你的化身走过建筑和地形、跳跃、攀爬，并探索垂直空间。
- **一起搭建**——编辑器中的**和我一起搭建**会生成一个链接，在朋友的编辑器中打开你的作品，
  让你们实时一起搭建，每个人都能看到对方放下的积木，以及对方指着哪里（见
  [编辑器](02-TheEditor.md#和我一起搭建实时一起搭建)）。在世界视图中，
  可以看到其他搭建者的化身以及他们正在做什么，然后用**编辑副本**把你发现的东西带进编辑器，
  自己在它的基础上继续搭建。
- **发现世界**——用带有情境位置标记的指南针，找到附近的结构以及森林、河流和草原等地形特征。
- **跟随合作者**——锁定镜头，跟随某人的化身在世界中移动。

你看到的一切都由世界的确定性种子推导而来——地形、生态和水文对每个人的计算结果都相同，
不需要存储额外的数据，就能形成一个连贯的共享地方。

## 可重复使用的结构和蓝图

除了单块积木，编辑器的积木库还能让你一次用整个结构来搭建——二十二个现成的结构，
分布在五个类别中，再加上你自己保存的任何东西：

- 把一个结构直接**放置**到你正在搭建的东西中，或者把它**改编**成一个全新的作品。
- 把你自己的作品**保存**为**我的结构**（你的个人蓝图库）中可重复使用的结构。
- 把蓝图**导出和导入**为可携带的文件，与别人分享，或者带到另一台设备上。

完整的讲解请见[编辑器](02-TheEditor.md#结构组合改编和你的个人库)。
