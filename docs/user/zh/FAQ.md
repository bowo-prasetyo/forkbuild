# 常见问题

人们最常遇到的问题的简短回答，每个都链接到有完整说明的指南。

## 熟悉界面

### 编辑器、存储库和登录到哪里去了？

它们在菜单中改名了。**搭建**会打开编辑器，**探索**就是以前的存储库，**取个名字**（有了名字后则是你的名字）代替了登录。
**漫步**会在本周挑战广场上打开世界。见[熟悉界面](01-GettingStarted.md#熟悉界面)。

### 我找不到“我的化身”、“对等节点”或“网络设置”

它们在顶栏的**更多**下（在手机上是**菜单**下）：**你**中有我的作品、我的化身、我的身份和你的数据；**社区**中有对等节点、
关注和对话；**高级**中有签名记录和网络设置。点击右上角你的名字也能打开我的化身、我的身份和你的数据。

## 发布与分享

### 我发布了作品，但朋友在“探索”中找不到它

除非你第一次发布时保留勾选了**所有人都能找到**（见[谁能找到它？](04-PublishingAndForking.md#谁能找到它)），
否则发布只会把作品保存在你自己的设备上，并列在*你自己的*“探索”中。要把它送到朋友那里：

- **发送链接。** 发布后会显示**复制链接**（在你的设备能分享的地方还有**分享…**）；作品就在链接里，
  所以朋友可以在任何设备上打开它。见[分享链接](04-PublishingAndForking.md#分享链接)。
- **让所有人都能找到。** 点击发布后提示中的**让所有人都能找到**，它就会出现在所有人的“探索”、挑战和世界中。
- 在“探索”中你的作品下方点击**与对等节点共享**，会把它提供给与你连接的人。好友或已知对等节点的设备会自动加入它；
  其他人会在**与你共享的**下看到它，并点击**获取**。你们需要同时在线连接，它才能送达。
- **分发**会把它上传到 Arweave 或 IPFS（或实验性的 Steem 或 Blurt）并公告，让人们不用与你连接也能找到它。

见[发布与改编](04-PublishingAndForking.md#与已连接的对等节点共享)。

### 如何让所有人都能看到我的作品？

第一次发布时保留勾选**所有人都能找到**（见[谁能找到它？](04-PublishingAndForking.md#谁能找到它)），
或者发布后点击**让所有人都能找到**。之后你发布的每个作品都会发送给所有人，并出现在**探索**、每周挑战和世界中，不需要安装任何东西。

如果还想在去中心化存储网络上保留一份副本，请分发它：把它存储到 Arweave 或 IPFS（或实验性的 Steem 或 Blurt），
并在 Nostr 或 Arweave（或 Steem 或 Blurt）上公告。这需要你所选网络对应的签名浏览器扩展，比如 Arweave 用的 Wander
或 Nostr 用的 nos2x。[分发你的作品](Distribution.md)列出了你可以分发的一切、可以发到哪里，以及每个网络需要什么。

### 为什么没有人能改编我的作品？

新作品没有许可证，而没有许可证的作品不能被改编。打开**作品属性**（编辑器中作品标题旁边的 **✎**），
选择一个允许改编的许可证（除 CC BY-ND 以外的任何 CC 许可证），然后重新发布。这个设置是发布内容的一部分，
所以你已经发布的作品会保留它们原来的许可证。见[选择许可证](04-PublishingAndForking.md#选择许可证)。

### 发布失败了。这些提示是什么意思？

- **a title is required before publishing**（发布前需要标题）——在**作品属性**中给作品起个标题。
- **cannot publish an empty world**（无法发布空的世界）——请先放置至少一块积木。
- **你的名字“…”已锁定**——你的名字自动锁定了；点击提示旁边（或顶栏中你名字旁边）的**解锁**，然后再次发布。

### 发布需要名字吗？

实际上需要。发布的面板会推荐一个，你可以保留或改写，而且不需要账户。面板上**高级**下的**匿名发布**会在没有名字的情况下发布，
但结果没有作者也没有签名，所以没有链接，你也不能把它分享给对等节点或以后发送给所有人。见[取个名字](01-GettingStarted.md#取个名字)。

### 我可以取消发布吗？

可以：在世界视图中打开那个世界，然后在**我的共享世界**中选择**更多 ▾ → 取消发布…**。这会把它从你的“探索”中移除。
它无法收回别人已经收到的副本，也无法收回你分发到 Arweave、IPFS、Nostr、Steem 或 Blurt 上的任何东西。
此设备会记住你取消发布了什么，所以“探索”搜索网络时不会在这里再次列出那些副本；其他设备和其他人仍然可以找到它们。

### 有人把我的作品放到了他们的世界里。他们移动了我的作品吗？

没有。放置只说明*他们的*世界在哪里显示你的作品；你的作品仍然在你放置的地方，并保留你的名字和历史。
如果你不希望这样，请在发布前在**谁可以把它放到世界中**下选择**只有我可以放置**。见
[为什么我可以放置别人的作品？](WorldViewAdvancedTools.md#为什么我可以放置别人的作品)。

### 我可以把我的作品送给别人吗？

不能以作者的身份送。作品的作者是为它签名的身份，没有人能更改那个签名，所以你的作品永远会显示你是它的作者。
正是这一点让作品被改编时每个人的署名都保持真实。

如果作品的许可证允许改编，别人可以做的是用**编辑副本**或**改编**制作他们自己的副本。他们的副本由他们修改、发布和放置，
并且会显示它来自你的作品（见[改编：让它成为你的](04-PublishingAndForking.md#改编让它成为你的)）。
如果你更希望别人找到的是他们的那一份，你可以把你的作品从你的世界中移除并取消发布，不过已经发出去的副本会保留（见
[我可以取消发布吗？](#我可以取消发布吗)）。

你导出的文件也是如此：在许可证允许改编时，他们可以把它作为自己的副本导入；你也可以导出一份许可证比你发布时更开放的副本（见
[保存、发布、重新开始](02-TheEditor.md#保存发布重新开始)）。

**我的身份**下的**声明继任者**不会移交作品：它会让你的整个身份退役，由你自己的另一个身份取代。

### 为什么两个作品立在同一个位置？

放置并不认领土地，也没有中央服务器来判定谁先占了一个位置，所以两个放置可以指向同一个点。
在你把自己的作品移到已被占用的位置之前，会收到警告。见
[为什么两个作品可以在同一个位置？](WorldViewAdvancedTools.md#为什么两个作品可以在同一个位置)。

## 身份与你的数据

### 我忘了密码短语。可以重置吗？

不能。密码短语是解密那个身份密钥的唯一途径，而且没有服务器保存副本。如果你导出过这个身份，你仍然需要导出时设置的密码短语。
否则请创建一个新身份。见[你的名字与身份](05-IdentityAndLogin.md)。

### 为什么我的身份总是自己锁定？

受保护的身份会在**你解锁后 15 分钟**锁定，即使你正在忙着使用应用，而且每次重新加载页面也会锁定。
锁定时搭建和保存仍然可以进行；发布、允许被发现和加入大厅需要你再次解锁。

### 如何把我的作品转移到另一台电脑或另一个浏览器？

不会自动同步。要复制所有内容，请在**你的数据**的**复制到另一台设备**下点击**显示码**，在两台设备都在线时用另一台设备扫描这个码
（或在那里打开它的链接）。或者在这里备份，然后在另一台设备上恢复文件（见[你的数据](13-YourData.md)）。
如果只想转移某一类东西：

- **作品**：编辑器工具栏中的**导出**，或**最近**底部的**导出所有作品**，然后在另一台设备上**导入**。
- **你自己的结构**：卡片 **⋮** 菜单中的**导出蓝图**，或**我的结构**旁边的**全部导出**，然后**导入蓝图**。
- **身份**：**我的身份**上的**导出**，然后**导入身份**。

聊天记录、好友和设置只能通过完整备份转移。

### 清除浏览器数据会删除我的作品吗？

会。作品、身份、好友和聊天记录都保存在这个浏览器为本网站分配的存储中，清除它会永久删除它们。
请先用**你的数据 → 备份到文件**备份，并妥善保管文件和它的密码短语；同一页面上的**恢复**可以把一切找回来。
上次备份太久时 ForkBuild 会提醒你，在电脑上的 Chrome 或 Edge 中，它还可以每天自动备份到一个由云存储同步的文件夹。
见[你的数据](13-YourData.md)和[隐私](Privacy.md)。

### 我可以重命名或删除身份吗？

不能。身份应该一直存在。要停止使用一个身份，请在**我的身份**中声明继任者或撤销它。

### 我撤销了我的身份，为什么还能使用它？

这是正常的。撤销会让身份不能再签署任何新内容，包括与他人连接所需的东西，但你仍然可以在此设备上选择它。
这样你仍然可以查看或导出它。它在**我的身份**中会显示**已撤销**，而且永远不能取消撤销。请创建一个新身份继续工作。见
[撤销会做什么，不会做什么](05-IdentityAndLogin.md#撤销会做什么不会做什么)。

### 为什么旧版本的 ForkBuild 打不开我导出的作品？

作品现在以一种更新、更紧凑的格式保存。ForkBuild 1.0.0 及更早的版本无法读取它，所以请先更新另一个副本。
旧版本导出的文件在这里仍然可以打开。

## 世界视图与你的化身

### WASD 不能移动我的化身

世界视图打开时行走就是开启的，无论有没有名字：还没有名字的人以访客身份行走，只有自己的屏幕上能看到。如果按键不能移动你的化身：

1. 在世界视图的**化身设置**中，检查**控制我的化身（WASD、Shift、空格）**是否已勾选。
2. 点击 3D 视图，以免按键输入到了文本框中。

在触屏上，请改为轻点摇杆上方的**漫步**。见[让你的化身行走](06-AvatarsAndPresence.md#让你的化身行走)。

### 谁能看到我的化身？

默认情况下，任何与你连接的人：**在线可见性**和**资料可见性**一开始都是**公开**。在**我的化身**中更改它们；
**隐藏**会让你隐身。见[谁能看到你](06-AvatarsAndPresence.md#谁能看到你两个独立的设置)。

### 我驾驶载具时浏览器标签页关掉了

**Ctrl** 是刹车，**W** 是加速，而在 Windows 和 Linux 上，大多数浏览器按 **Ctrl+W** 会关闭标签页。刹车前请先松开 **W**。

### 我能在世界视图中修改任何东西吗？

只能修改标注：地标、区域名称和动物装饰。搭建在编辑器中进行；请用**编辑副本**把你正在看的东西带到那里。见
[世界视图](03-WorldView.md#编辑副本把东西带进编辑器)。

## 对等节点、好友与聊天

### 我自己运行 ForkBuild，找不到任何人

默认的会合服务器只为托管网站服务，所以从你自己的地址（包括 `localhost`）提供的副本无法使用它。
请用邀请连接（**对等节点 → 与新的人连接 → 邀请**），或者在**网络设置 → 会合服务器**下添加你自己的会合服务器。见
[对等连接与好友](07-PeerConnectionsAndFriends.md)。

### 我的朋友不会自动重新连接

自动重新连接只适用于你**记住**的人（已知对等节点），并且只在他们**允许被发现**时才能找到他们。
你没有记住的好友会改为显示一个**重新连接**按钮。在对方的 **⋯** 菜单中选择**记住**，然后让你们双方都点击**允许被发现**。

### 我的消息一直显示“已排队”

消息在你的设备上等待，而不是在服务器上，所以只有当双方都打开着 ForkBuild 并且已连接时才会送达。
7 天内没有送达的消息会被丢弃，并标记为**未送达——已过期**。见
[聊天与对话](08-ChatAndConversations.md#在对方离线时发送)。

### 为什么我不能和已连接的人聊天？

聊天和语音通话只限好友。在**对等节点**中对方那一行上点击**加为好友**；对方接受后，就会出现**聊天**按钮。

### 我改了网络设置，但什么都没变

网络设置（服务器、中继、网关）在应用启动时读取。保存后请重新加载页面。见[网络设置](10-NetworkSettings.md)。

## 设备与浏览器

### ForkBuild 能在手机或平板上用吗？

能。两种视图都有触控操作，在窄屏上菜单和侧面板会收起来。见[触屏](ControlsReference.md#触屏)。

### ForkBuild 能离线使用吗？可以安装吗？

可以，在托管网站上。第一次访问后，ForkBuild 在没有网络时也能打开，首页上的**安装 ForkBuild**会把它作为应用添加到你的设备上。
搭建、保存以及你保存的作品和现成作品都可以离线使用；寻找作品和人、分发和聊天需要网络。见[安装 ForkBuild](01-GettingStarted.md#安装-forkbuild)。

### 我可以 3D 打印我的作品，或者在 Blender 中打开它吗？

可以。编辑器工具栏中的**文件 → 3D 模型**可以把它下载为用于 3D 打印的 STL（以毫米为单位，立在打印平台上），
或者用于 Blender 和其他软件的彩色 glTF 或 OBJ。见[下载 3D 模型](02-TheEditor.md#下载-3d-模型)。

### 我需要加密货币钱包吗？

不需要。搭建、保存、发布、分享链接、把作品发送给所有人、改编、对等节点和聊天都不需要。只有当你选择自己把作品分发到存储网络
（Arweave 需要像 Wander 这样的 Arweave 钱包；Nostr 需要像 nos2x 这样的签名扩展），以及使用
[证据与存储](11-EvidenceAndStorage.md)中的实验性锚定功能时，才需要钱包或签名扩展。

### 我可以出售我的作品，或者把它做成 NFT 吗？

ForkBuild 没有商店、没有价格，也没有 NFT，它不帮助出售作品，也不推荐任何地方去做这件事，无论在游戏内还是游戏外。
在 ForkBuild 之外达成的任何约定都是你和对方之间的事，游戏对此一无所知：它不会改变作品的作者是谁、谁可以复制它或谁可以放置它。

你的作品始终可以由你带走：你可以把它导出为文件，或者下载为 3D 模型（见
[保存、发布、重新开始](02-TheEditor.md#保存发布重新开始)和[下载 3D 模型](02-TheEditor.md#下载-3d-模型)）。

在 ForkBuild 中，其他人可以对已发布的作品做什么，由它的许可证（见[选择许可证](04-PublishingAndForking.md#选择许可证)）
和**谁可以把它放到世界中**（见[选择谁可以放置它](04-PublishingAndForking.md#选择谁可以放置它)）决定。
每个 ForkBuild 副本都遵守它们，但两者都不是一把锁，已经发出去的副本也无法收回（见[我可以取消发布吗？](#我可以取消发布吗)）。

如果你的作品是改编作品，它带有原作的许可证，所以那个许可证的条款仍然适用：比如 CC BY-NC 作品就不能用于商业用途。
