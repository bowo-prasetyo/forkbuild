ForkBuild 中的每一种鼠标和键盘操作；手机和平板请见[触屏](#触屏)。世界视图用于环顾和导航；
所有搭建操作（用于编辑的选择、变换、组、剪贴板、放置和命令面板）都只在编辑器中有效。
编辑器的快捷键与它的命令面板和 **⌨ 快捷键**浮层中列出的完全相同——如果这个页面与命令面板不一致，
以命令面板为准，说明这个页面有错误。

在编辑器中按 `Ctrl/Cmd+K` 打开**命令面板**，可以按名称搜索下面的每一个编辑操作。

## 镜头（两种视图）

| 输入 | 操作 |
|---|---|
| 在空白处左键拖动 | 环绕 |
| 右键拖动 | 平移 |
| 滚轮 | 缩放 |
| `Home` | 编辑器：查看整个作品，让整个作品进入视野（作品为空时显示起始视角），与视图左上角的 **⌂ 整个作品**相同（拖动操纵器时忽略）。世界视图：把镜头和化身带回你自己当前的世界——见[世界视图](03-WorldView.md#方位与地点) |

## 命令界面（仅编辑器）

| 输入 | 操作 |
|---|---|
| `Ctrl/Cmd+K` | 命令面板：按名称或其他说法（*颜色*、*音乐*、*镜头*）查找所有操作，包括保存、发布、新建、导出、导入、各种工具、声音和查看内部 |
| `I` | 描述作品：它由什么组成，会显示出来并由屏幕阅读器朗读——见[描述作品](02-TheEditor.md#描述作品) |
| `V` | 说出命令：按下、说话、再按一次——见[说出命令（语音）](02-TheEditor.md#说出命令语音)。在世界视图中，说出要去哪里——见[说出要去哪里（语音）](03-WorldView.md#说出要去哪里语音) |
| `?` | 键盘快捷键浮层（也可以从工具栏的“⌨ 快捷键”按钮打开）——列出编辑器的所有快捷键 |

## 发现（世界视图）

不是键盘快捷键，而是世界视图自己寻找东西的方式——完整说明见[世界视图](03-WorldView.md#寻找世界)。

| 控件 | 操作 |
|---|---|
| 搜索面板，**查找** | 按标题/作者搜索发布内容，可以限定在某个坐标的半径内 |
| **探索这里** | 以镜头当前位置为中心打开“探索位置”对话框 |
| **这里有什么？** | 同上，但使用一个固定的小半径——“基本上就在这里有什么” |
| 结果的**聚焦** | 把镜头飞过去，并让它成为当前（编辑中的）作品 |
| 结果的**选择** | 让它成为当前作品，但不移动镜头 |
| 结果的**查看** | 就地展开一个只读摘要 |

## 方位与导航（世界视图）

纯粹的镜头导航——这些都不会加载作品、改变选择或编辑任何东西。见[世界视图](03-WorldView.md#方位与地点)。

| 控件 | 操作 |
|---|---|
| 指南针 | 只读的朝向显示，带有附近结构和地形特征的情境标记 |
| **首页** | 把镜头和化身带回你自己当前的世界（如果本次会话中你还没有聚焦过自己的世界，则回到共享原点）——见[世界视图](03-WorldView.md#方位与地点) |
| **地点** | 打开一个列表，列出世界、它的结构、地标和地方，每项都有一个**聚焦**按钮 |
| **?** | 显示或隐藏镜头和行走操作说明 |
| 🔔 **通知**（应用标题栏，每个页面都有） | 打开你的**通知历史**——一份只读记录，不是镜头操作；见[世界视图](03-WorldView.md#方位与地点) |
| **镜头**：自由 / 第一人称 / 第三人称 / 鸟瞰 | 把镜头锁定在相对于你自己化身的固定位置，而不是自己操纵飞行；再次点击已激活的按钮即可回到自由——见[化身与在线状态](06-AvatarsAndPresence.md#镜头视角) |

### 情境位置描述

你在世界中移动时，界面会显示推导出的情境，比如：

- “**森林 · 在房屋附近**”——你在森林中，距离某个结构 50 个单位以内
- “**草原 · 河**”——河边的开阔地形
- “**草原 · 湖 · 在谷仓附近**”——地形、水域和最近的结构

这些描述根据你的位置、地形生态、水文和结构放置计算得出——世界中不存储任何东西。

## 声音（两种视图）

| 输入 | 操作 | 说明 |
|---|---|---|
| `M` | 关闭或打开声音 | 与**声音**按钮相同；两种视图共用一个设置，会记在此设备上。见[世界视图](03-WorldView.md#声音)和[编辑器](02-TheEditor.md#声音) |

## 化身移动（世界视图）

直接让你的化身行走，而不是飞行镜头——见[化身与在线状态](06-AvatarsAndPresence.md#让你的化身行走)。

| 输入 | 操作 | 说明 |
|---|---|---|
| `W` / `A` / `S` / `D` | 移动 / 转向 | 会被附近的建筑、树木、野生动物和居民挡住，与墙一样 |
| `Shift`（按住） | 奔跑 | |
| `空格` | 跳跃 | 在深水中：向上游 |
| `C`（按住） | 下潜 | 只在足以游泳的深水中 |
| `Alt` + `W` / `S` | 开始持续向前/向后行走 | 松开按键后仍继续移动；不按 Alt 普通地轻点 `W`/`S` 会取消 |
| `Alt` + `Shift` + `W` / `S` | 开始持续向前/向后奔跑 | 取消规则同上 |

## 载具（世界视图）

见[化身与在线状态](06-AvatarsAndPresence.md#载具)。需要化身控制模式；当你离载具足够近、可以骑上去时，会自动出现提示。

| 输入 | 操作 | 说明 |
|---|---|---|
| `E` | 骑上附近的载具，或从正在骑的载具上下来 | 只在载具在范围内或你正在骑乘时显示/生效 |
| `W` / `S` | 加速 / 倒车 | 骑乘时代替步行 |
| `A` / `D` | 让载具连同你一起转向 | 平滑、连续地转弯；只在载具移动时有效 |
| `←` / `→`（按下） | 让载具连同你一起向左/向右转 | 每按一次转 45°——按住不放不会持续转动 |
| `Ctrl`（按住） | 刹车 | |
| `Q`（骑乘时） | 把你正在骑的载具存入物品栏 | 把它从世界中移除；同时让你下车 |
| `Q`（未骑乘，携带着载具） | 放出当前选中的存放载具 | 在你当前的位置生成并骑上它；默认是最近存放的那一辆 |
| `[` / `]`（携带 2 辆以上载具） | 把要放出的选择切换到较早 / 较新的存放载具 | 只改变 `Q` 下一次放出哪一辆——它本身从不骑上或移除任何东西 |

## 动物（世界视图）

见[化身与在线状态](06-AvatarsAndPresence.md#动物)。需要化身控制模式；附近有可捕捉的动物或你正携带着动物时，会自动出现提示。

| 输入 | 操作 | 说明 |
|---|---|---|
| `F`（在可捕捉的动物附近） | 捕捉它 | 把它加入你的物品栏，并从世界中移除 |
| `F`（不在可捕捉的动物附近，携带着动物） | 放生最近捕捉的动物 | 在你当前的位置生成它，它又可以被捕捉了 |
| `G`（在你放生的动物附近） | 用它装饰世界 | 把它作为装饰保存到世界的内容中——不能再被捕捉；需要编辑权限。当 `G` 会起作用时会显示提示 |
| `G`（在动物装饰附近，附近没有放生的动物） | 撤销装饰 | 把它从世界中移除，变回一只活生生、可以捕捉的动物 |

## 居民（世界视图）

见[化身与在线状态](06-AvatarsAndPresence.md#居民)。需要化身控制模式；“化身”部分的**在这里添加居民** / **移除居民**
和**交谈**按钮在没有它时也能做同样的事。

| 输入 | 操作 | 说明 |
|---|---|---|
| `R`（在空地上，身旁没有居民） | 添加一位以你所站位置为家的居民 | 保存到世界的内容中；需要编辑权限。不能在屋顶上、水中或骑乘时添加 |
| `R`（在居民旁边） | 把它从它的世界中移除 | 会显示提示 **[R] 移除居民**；用 `Ctrl/Cmd+Z` 撤销 |
| `T`（在居民旁边） | 交谈：它会告诉你附近有什么 | 显示在它头顶的气泡中；再交谈一次会说别的东西。“化身”部分和触控板上的**交谈**按钮作用相同 |
| **聚焦：…**按钮（居民说话时） | 看看它提到的东西 | 只移动镜头；你的化身留在原地。针对地标、结构、作品和载具提供 |
| **在那里建一个…**按钮（居民自言自语时） | 在它说的位置开始一个属于你的作品 | 打开编辑器，带着一个可以修改的现成村庄结构；发布后它就立在那里 |

你的物品栏、放置的载具和放生的动物都保存在此设备上，重新加载后仍然保留——见
[化身与在线状态](06-AvatarsAndPresence.md#重新加载后保留什么)。

## 选择（编辑器；在世界视图中点击积木只会查看它）

| 输入 | 操作 | 说明 |
|---|---|---|
| 点击一块积木 | 选中它（替换当前选择） | 在世界视图中只会打开“查看”面板——见[世界视图](03-WorldView.md#世界视图是只读的搭建在编辑器中进行) |
| `Shift`+点击 | 把积木加入选择 | |
| `Ctrl/Cmd`+点击 | 把积木加入或移出选择 | |
| `Shift`+拖动 | 框选（替换当前选择） | `Ctrl/Cmd+Shift`+拖动会加入当前选择；普通拖动会环绕镜头，不改变选择；点击空地会清除选择 |
| `Ctrl/Cmd+A` | 全选 | |
| `Esc` | 清除选择 | 编辑器自己的 Escape 顺序见下文——世界视图自己的 Escape 只会关闭当前打开的面板 |
| `Delete` / `Backspace` | 删除所选——**仅编辑器** | 一步撤销；在世界视图中完全没有对应的按键 |
| “选择”面板的**聚焦**按钮——**仅编辑器** | 立即让镜头对准所选积木 | 没有键盘快捷键；只影响镜头——从不改动作品、选择或撤销历史；只适用于选中的积木，不适用于结构放置 |

## 变换 — 键盘（仅编辑器）

| 输入 | 操作 |
|---|---|
| `→` / `←` | 沿世界 X 移动所选内容 |
| `↑` / `↓` | 沿世界 Z 移动所选内容 |
| `PgUp` / `PgDn` | 沿世界 Y 移动所选内容 |
| `R` | 绕所选内容的轴心旋转 +90° |
| `Shift+R` | 旋转 −90° |
| `T` | 把每块所选积木翻到下一个侧面，底部保持不变 |
| `Shift+T` | 向另一个方向倾斜 |
| 拖动操纵器时按住 `Shift` | 精确模式（0.1 倍增量） |

## 变换 — 操纵器（仅编辑器）

| 输入 | 操作 |
|---|---|
| 悬停在手柄上 | 高亮它 |
| 拖动轴手柄（红色 X / 绿色 Y / 蓝色 Z） | 沿该轴移动（吸附） |
| 拖动中心方块（琥珀色） | 在地面上自由移动 |
| 拖动一块已选中的积木 | 对整个选择做同样的自由移动；点击而不拖动只会选中那一块积木 |
| 拖动旋转圆环（紫色） | 绕轴心旋转（吸附） |
| 松开 | 确认——正好一步撤销 |
| 拖动中按 `Esc` | 取消——什么都不改变，不留历史 |

如果多块积木拖动或微移中的某个成员会落在所选内容之外的积木上，在那里松开会取消这个操作而不是确认——
每块积木都会恢复到原来的位置，也不会新增撤销记录。在同一个选择内部重新排列积木从不被视为碰撞。

## 变换 — 数值面板（仅编辑器）

在“选择”面板的**精确位置和旋转**部分中。

| 输入 | 操作 |
|---|---|
| 在 X/Y/Z/R 输入框中输入 | 精确数值；空的输入框 = 保持不变 |
| 绝对值 / 偏移切换 | 以轴心为目标，还是普通增量 |
| `Enter` 或“应用” | 一次操作，一步撤销——从不吸附 |
| 在输入框中按 `Esc`，或**重置输入框** | 清空输入框（从不清除选择） |

## 对齐与分布（仅编辑器）

在“选择”面板的**对齐、分布、重复**部分中，也可以通过命令面板使用。对齐需要 **2 块以上**积木；分布需要 **3 块以上**。
两者都作用于整个所选内容在**世界轴**上的边界，并作为一个命令确认。

## 重复（仅编辑器）

同样在“选择”面板的**对齐、分布、重复**部分中。沿一条轴以相等间距再制作 **N** 个所选内容的副本，作为**一步撤销**——
在创建任何东西之前会对整批副本进行碰撞检查，所以中途的一次碰撞会阻止整个重复，而不是创建一部分副本。

| 输入 | 操作 |
|---|---|
| **副本数**输入框 | 额外制作多少个副本（原件永远不会被改动） |
| **间距**输入框 | 每个副本之间的距离 |
| **沿 X / Y / Z 重复** | 沿该世界轴重复 |

## 结构（积木库）— 仅编辑器

组合、改编和你的个人库——见[编辑器](02-TheEditor.md#结构组合改编和你的个人库)。

| 输入 | 操作 | 说明 |
|---|---|---|
| 点击**结构**标签页中的一张卡片 | 进入结构放置模式，预览跟随指针 | 适用于内置结构或你自己**我的结构**中的结构 |
| 放置时按 `R` / `Shift+R` | 把待放置的预览旋转 ±90° | 与积木的放置预览按键相同 |
| 点击 | 确认——结构中的每块积木作为一步撤销落下 | 在被占用（红色）的位置会被拒绝 |
| 放置时按 `Esc` | 取消——不添加任何东西 | |
| 卡片的 **⋮** 菜单，**改编为新作品** | 开始一个全新的作品，一开始是该结构的副本 | 从不修改库中的条目 |
| 内置卡片的 **⋮** 菜单，**改编到“我的结构”** | 把它原样加入“我的结构” | 不创建作品，也不提取任何东西 |
| 任意卡片的 **⋮** 菜单，**信息** | 显示只读的名称/类别/积木/占地/高度/来源/描述面板 | 永远不可编辑 |
| 选中 **1 块以上积木**，然后**创建蓝图**（“选择”面板的**组和蓝图**部分，或命令面板） | 打开一个小对话框（名称 / 类别 / 描述 + 预览）；把所选内容保存为**我的结构**中的一个新条目 | |
| **我的结构**卡片的 **⋮** 菜单，**重命名** | 更改个人结构的名称 | 仅限个人结构 |
| **我的结构**卡片的 **⋮** 菜单，**移除** | 从你的库中删除它 | 从不触碰已经用它组合或改编出的积木 |
| 任意卡片的 **⋮** 菜单，**导出蓝图** | 把它下载为可携带的 JSON 文件 | 内置或个人结构均可 |
| **导入蓝图**按钮（在“我的结构”标题旁边） | 把一个蓝图文件作为新条目加入你的库 | 全新的身份，即使是重新导入的文件 |

## 结构实例（编辑器）

**结构实例**把一整个已保存的作品作为一个可以选择的单元放置——一个实时引用，而不是副本——见
[编辑器](02-TheEditor.md#结构实例一个实时引用)。

| 输入 | 操作 | 说明 |
|---|---|---|
| 工具栏的**最近**下拉菜单，作品的**放置**按钮 | 进入以该作品为目标的结构放置模式 | 点击作品名称则会打开它 |
| 放置时按 `R` / `Shift+R` | 把待放置的实例旋转 ±90° | 与积木的放置预览按键相同 |
| 点击一个已放置的实例（选择工具） | 把它作为一个单元选中，与积木选择不同 | |
| 在视口中拖动，或使用操纵器 | 移动 / 旋转实例 | |
| `Ctrl/Cmd+D` | 复制一份——再放置一个相同作品的实例 | 见[复制一份](#复制一份仅编辑器)——选中实例时得到的是一个新实例，而不是一份新的积木副本 |
| 实例面板的 **X / Z / 旋转**输入框，然后点“应用” | 设置精确的位置/朝向 | Y（高度）始终由地形决定，从不是目标值 |
| 实例面板的**编辑源作品** | 打开被引用的作品来修改它的积木 | 每个实例都会更新，因为实例是实时引用 |
| `Delete` / `Backspace` | 移除这个实例 | 从不触碰被引用的作品 |

## 组（仅编辑器）

在“选择”面板的**组和蓝图**部分中；未选择任何东西时，面板会列出你的组，你可以点击一个来选中它。

| 操作 | 可用条件 |
|---|---|
| 新建组 | 选中了积木；会询问组名（推荐*组 1*），新组一开始就处于选中状态 |
| 重命名 / 复制 / 删除组 | 选中了一个组；重命名在同一个输入框中询问，双击组名也一样 |
| 加入组 / 移出组 | 选中了积木并且选中了一个组 |

组的变换（移动/旋转/对齐/分布/数值）作用于确定的成员积木；变换本身从不改变成员关系。

## 剪贴板（仅编辑器）

| 输入 | 操作 | 说明 |
|---|---|---|
| `Ctrl/Cmd+C`，或“选择”面板的**复制** | 复制 | 需要有选择 |
| `Ctrl/Cmd+V`，或“选择”面板的**粘贴** | 粘贴 | 剪贴板中有内容后才会出现这个按钮 |

## 复制一份（仅编辑器）

| 输入 | 操作 | 说明 |
|---|---|---|
| `Ctrl/Cmd+D` | 原地复制一份当前所选内容——一步撤销 | 适用于散落的积木或确定的组；选中结构实例时也可以复制一份——见[结构实例](#结构实例编辑器)。不改动剪贴板（以及任何待定的粘贴偏移） |

复制出的副本会成为当前选择，所以可以立即拖动或微移它。

## 历史

| 输入 | 操作 | 适用于 |
|---|---|---|
| `Ctrl/Cmd+Z` | 撤销 | 编辑器和世界视图 |
| `Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` | 重做 | 编辑器和世界视图 |

在电脑上的编辑器中，**撤销**和**重做**也是工具栏中最前面的两个按钮；把鼠标指向它们，会说明它会收回或放回哪一步。
触屏设备则在触控栏中提供它们。

在世界视图中，撤销和重做作用于它的标注编辑：地标、区域名称和动物装饰。它的历史面板（见
[世界视图](03-WorldView.md#历史预览和恢复之前的状态)）也可以预览和恢复它们。

|---|---|

## 放置（仅编辑器）

这些按键属于放置工具，所以不会出现在命令面板中（在命令面板中，`R`/`Shift+R` 旋转的是*所选内容*）。
世界视图完全没有放置工具。

| 输入 | 操作 | 说明 |
|---|---|---|
| 移动指针 | 预览跟随所悬停的地面/积木面 | 位置当前被占用时会染成红色 |
| `R` | 把待放置的预览旋转 +90° | 切换积木时保持；离开放置模式时重置。在悬停任何东西之前按下，会转动下一个预览 |
| `Shift+R` | 把待放置的预览旋转 −90° | |
| `T` | 把待放置的预览翻到下一个侧面 | 离开放置模式时重置 |
| `Shift+T` | 把待放置的预览向另一个方向倾斜 | |
| 点击 | 把预览确认为一块真正的积木 | 在被占用（红色）的位置会被拒绝 |
| `Shift`+拖动 | 把积木首尾相接摆成一排，作为一步撤销 | 沿你拖得更远的方向延伸，高度与第一块积木相同；如果有任何位置被占用，会变红并被拒绝；拖动时按 `Esc` 可放弃 |
| 在作品中的积木上 `Alt`+点击（Mac 上为 `Option`+点击） | 拾取它的类型、颜色、朝向和倾斜，并打开放置 | 在选择工具下也能用；在空地上不会拾取任何东西 |
| 积木库的**颜色**色块 | 为接下来放置的积木选择颜色 | 换成另一种积木时会恢复为该积木的默认颜色——见[积木颜色](02-TheEditor.md#积木颜色) |

要为已经放置的积木重新上色，请选中它们，然后使用“选择”部分中的**颜色**色块——每次更改一步撤销。

## 触屏

在手机或平板上，同样的操作有屏幕上的控件。只要设备有触屏，它们就会出现，所以触屏笔记本电脑会在键盘和鼠标之外同时显示它们。
在宽度为 720 像素或更窄的屏幕上，页面还会重新排列：页面链接收进一个**菜单**按钮，世界视图的侧面板从**面板**按钮打开，
编辑器的侧边栏变成一个覆盖视图下半部分的面板，从**工具**按钮打开。

### 镜头（两种视图）

| 触控 | 操作 |
|---|---|
| 单指拖动 | 环绕 |
| 双指拖动 | 平移 |
| 双指捏合 | 缩放 |
| 轻点 | 世界视图：查看你轻点的东西。编辑器：与用当前工具点击相同 |

### 行走（世界视图）

化身控制模式开启时会出现触控板；摇杆上方的**漫步**按钮会开关这个模式以及触控板。

| 控件 | 对应的按键 | 说明 |
|---|---|---|
| 摇杆 | `W` / `A` / `S` / `D` | 向上推即向前走，向两侧推即转向；斜推相当于同时按两个键 |
| 摇杆推到边缘 | `Shift` | 奔跑 |
| **跳跃** | `空格` | 在深水中显示为**向上游** |
| **下潜** | `C` | 游泳时显示 |
| **巡航** | `Alt` + `W`，然后 `Alt` + `Shift` + `W`，然后 `W` | 每轻点一次：自动向前行走，然后奔跑，然后停止。运行时显示**巡航：行走** / **巡航：奔跑**。把摇杆向前或向后推也会停止它；向两侧推只会转向 |
| **骑乘** / **下车** | `E` | 载具在范围内或骑乘时显示 |
| **收起** / **放出** | `Q` | 可以收起你正在骑的载具或放出一辆存放的载具时显示。“放出”会注明载具名称，携带不止一辆时还会注明它在列表中的位置（比如 2/3） |
| “放出”旁边的 **‹** / **›** | `[` / `]` | 携带 2 辆以上载具时：选择较早或较新的一辆来放出 |
| **捕捉** / **放生** | `F` | 附近有可捕捉的动物或携带着动物时显示 |
| **装饰** / **撤销装饰** | `G` | 在你放生的动物或装饰附近时显示。与 `G` 不同，装饰被拒绝时（没有名字、没有编辑权限）它会说明原因 |
| **↶** / **↷** | `←` / `→` | 骑乘时：每轻点一次转向 45° |
| **刹车** | `Ctrl`（按住） | 骑乘时 |

触控板的按钮代替了键盘提示，触控板显示时键盘提示会隐藏。自动向后行走（`Alt` + `S`）没有触控按钮；
从键盘开始的自动后退会显示为**巡航：后退**，轻点它即可停止。

### 编辑（编辑器）

用选择工具时轻点即可选中。放置需要轻点两次，因为触控没有悬停，无法先显示预览：第一次轻点会在积木或结构将要放置的地方显示预览，
在预览上再点一次，或者点**放置**，就会把它放下。在别处轻点会把预览移到那里。拖动只会移动镜头，所以环绕永远不会意外地放置积木
或清除选择。选择一块积木或一个结构来放置时会关闭工具抽屉，这样下一次轻点就会落在场景上。视口底部的横条代替了按键：

| 按钮 | 相当于 | 说明 |
|---|---|---|
| **撤销** / **重做** | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | |
| **旋转** | `R` | 放置时，在放下之前转动预览；否则旋转所选内容 |
| **倾斜** | `T` | 放置积木时，把它的预览翻到下一个侧面（结构不能倾斜）；否则倾斜所选积木 |
| **放置** | 点击 | 放置时：把积木放到预览所在的地方。放置时，**放置**和**取消**会代替**删除**、**多选**和**框选** |
| **取消** | `Escape` | 放置时：停止放置，不放下任何东西，并回到选择工具 |
| **删除** | `Delete` | |
| **多选** | `Ctrl/Cmd`+点击 | 开启时，每次轻点都会把一块积木加入或移出选择 |
| **框选** | `Shift`+拖动 | 开启时，单指拖动会画出选择框，而不是移动镜头；同时开启**多选**时，框选会加入当前选择（`Ctrl/Cmd+Shift`+拖动）。框选开启时镜头保持不动（第二根手指会取消框选而不是缩放），所以要四处移动时请关掉它 |
| **更多** | `Ctrl/Cmd+K` | 命令面板，可以使用其他所有编辑操作 |

操纵器手柄在触控下与鼠标一样可用，无论**框选**开或关：拖动手柄即可。

要像 `Alt`+点击那样从作品中拾取积木，请用手指在它上面按住半秒不动。

## Escape 优先级（编辑器）

Escape 取决于情境，严格按照以下顺序：

1. **正在输入的文本框**——清空/取消聚焦这个输入框。
2. **键盘快捷键浮层**——关闭浮层（`?` 也可以关闭它）。
3. **命令面板**——关闭面板。
4. **正在进行的操纵器操作**——取消拖动（不留历史）。
5. **正在进行的框选**——取消框选。
6. **其他情况**——清除选择（在放置模式下：退出放置）。

### 世界视图中的 Escape

正在输入的文本框仍然以同样的方式优先处理 Escape；否则 Escape 会关闭当前打开的世界视图面板（聚焦面板、命名面板等）。
