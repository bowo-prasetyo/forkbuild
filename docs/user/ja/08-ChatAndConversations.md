# 08 — チャットと会話

<!-- languages -->
[English](../08-ChatAndConversations.md) · [Deutsch](../de/08-ChatAndConversations.md) · [Español](../es/08-ChatAndConversations.md) · [Bahasa Indonesia](../id/08-ChatAndConversations.md) · **日本語**
<!-- /languages -->

ForkBuild の直接メッセージはピアツーピアで、**友達どうしだけ** のもの
です。先に誰かと友達になる方法は
[ピア接続と友達](07-PeerConnectionsAndFriends.md) を参照してください。

## 会話を始める

チャットは、**ピア** ページの友達の **チャット** ボタンか、上部のバーの
**会話** ページから開きます。ワールドビューやアバターからチャットを
始める入り口はありません。今は友達でない人（またはブロックしている人）と
チャットを開くと、入力欄の代わりに説明が表示されます。チャットを使える
ようにするのは、オンラインかどうかではなく、友達関係です。

## 会話ページ

表示する価値のある人全員、つまり記憶している関係、友達関係（保留中の
リクエストを含む）、メッセージの履歴のいずれかがある人を、最近の
やり取り順に一覧表示します。各行には次のものが表示されます。

- 表示名と **オンライン / オフライン** のバッジ
- 関係 — 友達、友達リクエスト保留中、既知のピア、未接続
- 未読メッセージの数と、送信待ちのものがあれば「送信待ちのメッセージ
  N件」
- 最後のやり取りの時刻

**チャットを開く** ボタンが表示されるのは、ブロックしていない現在の
友達だけです。それ以外の人の行は、代わりにピアページを案内します。
ブロックした友達の行には、ボタンの代わりに「⛔ ブロック中 — 再び
チャットするには、ピアでブロックを解除してください。」と表示され、
ブロックやブロック解除をするとすぐに行が更新されます。

## チャット画面

あなたと 1 人の友達とのやり取りを、1 本のスクロールできる記録として
表示します。メッセージの吹き出しには「あなた」または相手の名前と
時刻が付き、下に入力欄（最大 4,000 文字）があります。**詳細を表示** を
クリックすると、相手のアイデンティティ、関係、友達関係、現在の接続
状態、メッセージと送信待ちの数を示す小さなパネルが開きます。入力中の
表示、編集、削除、リアクション、添付ファイル、グループチャットは
ありません。あえてメッセージだけにしています。

## 音声通話

その友達の今つながるデバイスのうち、少なくとも 1 台が音声に対応して
いれば、入力欄の横に **📞 通話** ボタンが表示されます。相手のどの
デバイスが実際に応答するかを知る必要はありません。通話は特定の接続
ではなく、相手のアイデンティティに届きます。

- **通話** をクリックすると発信します。相手が応答するまで
  **発信中…** と表示されます。
- 受ける側には、着信に **応答** / **拒否** が表示されます。
- つながると、バーに **通話中** と **ミュート** / **ミュート解除** が
  表示され、マイクが実際に接続されると、使う **マイク** と（ブラウザーが
  対応していれば）**スピーカー** を選べるようになります。
- 終了ボタンは、相手の応答を待っている間は **キャンセル**、実際に
  話しているときは **通話を終了** になります。

このデバイス全体で、同時にできる通話は 1 つだけです。通話中は、ほかの
人の通話ボタンは使えません。通話中にマイクがなくなった（外れた、許可が
取り消された）場合は、小さなバナーでそれを知らせます。再接続する
かもしれないので、通話自体は続きます。

つながる前に終わった通話は、理由を短く表示します。

| メッセージ | 意味 |
|---|---|
| **通話が拒否されました。** | 相手が拒否をクリックしました。 |
| **相手はすでに別の通話中です。** | 相手はほかで話し中です。 |
| **応答がありません。** | 時間内に誰も応答しませんでした。 |
| **マイクにアクセスできませんでした。** | ブラウザーがマイクへのアクセスを拒否したか、アクセスできません。 |
| **通話を接続できませんでした。** | 接続レベルの失敗です。もう一度試す価値があります。 |

普通に通話を終えた場合（どちらが終えても）は、メッセージは何も表示され
ません。通話バーが消えるだけです。

## 相手がオフラインのときに送る

オフラインの友達にもメッセージを送れます。相手が今接続している必要は
ありません。メッセージはデバイス上で送信待ちになり、次に二人が接続した
ときに自動で届きます。自分で送り直す必要はありません。間で保管する
サーバーはないので、メッセージは *あなたの* デバイスで待ちます。届く
には、両方で同時に ForkBuild が開いている必要があります。7 日たっても
届かないメッセージは破棄され、**未配信 — 期限切れ** と表示されます。
送ったメッセージには、吹き出しの下にそれぞれの状態が表示されます。

| 状態 | 意味 |
|---|---|
| **保留中 — 相手が再接続したら送信します** | 相手がオンラインになるのを待っています |
| **送信済み** | ネットワークに渡しました。届いたことはまだ確認されていません |
| **配信済み** | 相手のデバイスに届いたことが確認されました |
| **未配信 — 期限切れ** | 時間内に届かず、破棄されました |
| **既読** | 相手が会話を開き、このメッセージまで読みました |

**既読** は完全に自動です。「既読にする」ボタンはありません。会話を
開いたり再読み込みしたりするだけで、読んだことが送り手に伝わります。

## 履歴

会話はこのデバイスに保存され、再読み込みしても、メッセージも配信状態も
含めて、そのまま続きから表示されます。この履歴は **このデバイスだけの
もの** です。別のブラウザーやコンピューターには引き継がれず、サーバー側の
コピーもありません。各会話は最新の 500 件のメッセージを保持し、
ストレージを抑えるために、それより古いものは静かに消えていきます。

友達を解除したりブロックしたりすると、内部の接続が技術的にはまだ
有効でも、チャットはすぐに止まります。別に「切断」する必要はありません。
