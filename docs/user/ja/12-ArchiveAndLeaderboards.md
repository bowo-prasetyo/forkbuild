> **実験的です。** ここにあるものはすべて、今後のバージョンで変わったり
> 削除されたりすることがあり、作ったものが引き継がれないこともあります。
> 公開物ページでは **ウォレット・アーカイブ用ツール** のパネルに
> **実験的** のバッジが付きます。

[証拠とストレージ](11-EvidenceAndStorage.md) の Bitcoin、Base、IPFS の
道具は、観測したことをこのデバイスの永続的なアーカイブに記録します。
このガイドでは、そのアーカイブと、その上に作られたもの（公開物の間の
参照、実績）について説明します。

これらのカードのほとんどは、公開物ページの
**ウォレット・アーカイブ用ツール** の **アーカイブツール** と
**参照と実績** のタブにあります。保持しているものが再読み込みしても
残るカードには **ローカルに保存** と表示されます。

全体を通して使う言葉: **公開物のアイデンティティ** とは、Bitcoin または
Base のアンカーの公開の記録 1 つのことです
（[Bitcoin アンカーの公開](11-EvidenceAndStorage.md#bitcoin-アンカーの公開)
を参照）。チェーン上の記録であり、人ではありません。

## 公開物の観測アーカイブ

IPFS、Bitcoin、Base の道具が観測した事実を、このデバイスに永続的に
記録したものです。保持するのは公開物のアイデンティティと観測だけで、
ウォレットの接続、鍵、ピン留めの認証情報は決して保持しません。

### 観測のアーカイブ

**観測のアーカイブ** カードには、保持している **公開** と **観測** の
数が表示されます。

- **アーカイブを表示** は **アーカイブ済みの観測タイムライン** を開き
  ます。IPFS へのすべての公開と検証、Bitcoin のすべてのブロードキャスト、
  承認、内容の証明、Base のすべての取り込みの観測を時系列で並べ、それぞれ
  にドメイン、状態、（該当する場合は）ロケーター、txid、ブロックの高さを
  示します。開いてもネットワークには接続しません。
- **アーカイブをクリア** は、アーカイブから何かを削除する唯一の方法
  です。ほかのものはすべて追加するだけです。アーカイブが空のときは
  使えません。

### Bitcoinアンカーの過去の証拠

**ブロックチェーンへのアンカリング** タブのカードで、同じ Bitcoin の事実を
アンカー ID ごとにまとめて表示します。**過去のアンカーを表示** で
アンカー ID を選ぶと、その **ブロードキャストの履歴**、**承認の履歴**、
**内容の証明の履歴**、**チェーン上の位置の比較**、**観測の一貫性** が、
5 つの数をまとめた **統合した証拠** の概要とともに表示されます。数は
どれだけ記録されたかを示すもので、どれだけ信頼できるかを示すものでは
ありません。

### アーカイブのエクスポート、インポート、調査

**公開のアーカイブ** カードは、アーカイブを JSON ファイルにします。

- **アーカイブをエクスポート** は、JSON と
  **アーカイブのエクスポートをダウンロード** のリンクを表示します。
- **アーカイブをインポート** は、ファイルか貼り付けた JSON を受け取り、
  そこに含まれる公開物と観測の数を、現在のアーカイブと比べてプレビュー
  します。適用するのは **現在のアーカイブを置き換える** だけです。
  インポートは現在のアーカイブを **置き換え**（統合はしません）、元に
  戻せません。無効なファイルは拒否され、何も変わりません。

**外部のアーカイブを調べる** は、インポートせずにエクスポートの中を
見ます。ファイルのスキーマのバージョン、ドメインごとの事実の数（IPFS の
公開と検証、Bitcoin のブロードキャスト、承認、内容の証明、公開物の
アイデンティティ、Base の取り込みと公開物のアイデンティティ）、ローカルと
インポートした事実の数、インポートの記録、フィンガープリント、そして
含まれている Bitcoin のアンカー ID、IPFS の記録のインデックス、Base の
トランザクションのハッシュが表示されます。そこから次のことができます。

- **現在のアーカイブと比較** は、ドメインごとに **同一**、**変更**、
  **現在のみ**、**外部のみ**、**出所が異なる** ものを一覧表示します。
- **置き換えを確認**（比較のあと）は、置き換えると何が変わるかを、
  両方のアーカイブの数とフィンガープリントとともにプレビューします。
  その **現在のアーカイブを置き換える** ボタンは、上と同じインポートです。
  置き換えるとすべての事実が新しくインポートされたものとして扱われる
  ので、結果のフィンガープリントはファイルのものと違います。

### アーカイブの出所

事実の出どころを示します。**ローカルの事実**（このデバイスで観測した
もの）と **インポートした事実**（**現在のアーカイブを置き換える** による
もの）です。一度でもインポートしたことがあれば、
**アーカイブのインポート** に各インポートの時刻、事実の数、スキーマの
バージョンが並びます。どちらの種類も、より信頼できるとは見なされません。

### アーカイブのフィンガープリント

アーカイブのすべての事実と出所のタグの SHA-256 ダイジェストです。
**フィンガープリントをコピー** でコピーします。ほかから（たとえばピア
から）来たフィンガープリントと比べるには、**別のフィンガープリントと
比較** の下に貼り付けて **比較** をクリックします。

| 結果 | 意味 |
|---|---|
| **MATCH** | 2 つのアーカイブの中身はまったく同じです。 |
| **DIFFERENT** | 同じではありません。 |
| **INVALID_FINGERPRINT** | 貼り付けたものが 64 文字の SHA-256 フィンガープリントではありません。 |

一致は中身が同じという意味でしかなく、正しいという意味ではありません。
また、どちらのアーカイブが新しいかはここではわかりません。

## 公開の参照

ある公開物のアイデンティティが、別のものを指していることを記録します。

**公開の参照 → 参照を表示** でフォームが開きます。知っている Bitcoin と
Base の公開物のアイデンティティ（たとえば「Bitcoin — a1b2…c3d4 —
content 9f8e…」）から、**参照元の公開（参照する側）** と
**参照先の公開（参照される側）** を選び、**参照を記録** をクリックします。
公開物が自分自身を参照することはできません。参照を作るのはあなただけで、
自動で作られることはなく、アプリのほかの場所でフォークしても作られ
ません。

参照はあえてフォークとは呼びません。ポインターがあることを記録する
だけで、それが何を意味するか（フォーク、引用、返信）は記録しません。

記録した参照は古い順に、両側のチェーン、短いアイデンティティ、内容の
ハッシュ、記録した時刻とともに並びます。重複は別々の参照として残り
ます。

**公開の参照グラフ** は、同じ参照を公開物ごとにまとめます。
**エッジ**、**公開**、**異なる参照元**、**異なる参照先** の合計と、各
公開物の **参照している数** と **参照されている数** があり、展開すると
個々の参照が表示されます。数は順位ではありません。

## 実績

公開物のアイデンティティは、しきい値を超えた瞬間にバッジを獲得します。
受け取る手続きはありません。

**実績 → 実績を表示** に、これまでに獲得したバッジが並びます。バッジの
名前はアプリでは英語で表示されます。

| バッジ | アイコン | 獲得する条件 |
|---|---|---|
| First publication（最初の公開） | 🏆 | 最初の Bitcoin または Base のアンカーの公開の記録。 |
| Bitcoin publisher（Bitcoin の公開者） | ₿ | 最初の Bitcoin のもの。 |
| Base publisher（Base の公開者） | 🔵 | 最初の Base のもの。 |
| Multi-chain publisher（複数チェーンの公開者） | 🌐 | 2 つ以上のチェーンでの記録。 |
| Ten publications（10 件の公開） | 🔟 | Bitcoin と Base を合わせて 10 件目。 |
| One hundred publications（100 件の公開） | 💯 | 100 件目。 |

バッジをクリックすると、その **元の公開**（チェーン、内容のハッシュ、
チェーン上の参照、作成時刻）と、利用できる場合は
**上で公開のライフサイクルを見る** が表示され、その記録のライフサイクル
に移動できます。

さらに 5 つの実績が参照から得られ、まだバッジはありません。
**First reference created**（最初の参照を作成）、
**First reference received**（最初の参照を受けた）、
**Referenced by 10 publications**（10 件の公開から参照された）、
**Referenced by 100 publications**（100 件の公開から参照された）、そして
**First cross-chain reference**（最初のチェーン間の参照。Bitcoin と Base の
公開物の間）です。これらは **実績プロフィール** に名前で並びます。そこでは
公開物のアイデンティティを選ぶと、その実績の数と完全な一覧が、それぞれ
獲得した時刻とともに表示されます。

実績は人ではなく公開物のアイデンティティに属します。ここには公開物を
人と結び付けるものは何もありません。

## 終了した機能: リーダーボード、照合、公開者ラベル

以前のバージョンにはリーダーボードのページがありました。公開者の
リーダーボード、署名付きの公開者スナップショットの主張、照合の作業スペースと
リーダーボード、証拠エクスポートの比較です。ForkBuild は人を順位付けせず、
スコアも付けないため（[柱](../../Pillars.md#what-we-are-not-making)）、これらは削除されました。それらのページへの
古いリンクはホームを開きます。それらがあった頃に保存したアーカイブも、ほかの
記録はすべてそのまま読み込み・インポートできます。含まれていたリーダーボードの
主張と照合の決定は破棄されます。

それらのページのために公開物に公開者の名前のラベルを付ける「公開者の関連付け」
も削除されました。アーカイブにあったラベルも同じように破棄されます。
