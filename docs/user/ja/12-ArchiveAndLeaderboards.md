> **実験的です。** ここにあるものはすべて、今後のバージョンで変わったり
> 削除されたりすることがあり、作ったものが引き継がれないこともあります。
> 公開物ページでは **ウォレット・アーカイブ・公開者向けツール** のパネルに
> **実験的** のバッジが付き、リーダーボードのページには **実験的機能です。**
> のバナーが表示されます。

[証拠とストレージ](11-EvidenceAndStorage.md) の Bitcoin、Base、IPFS の
道具は、観測したことをこのデバイスの永続的なアーカイブに記録します。
このガイドでは、そのアーカイブと、その上に作られたもの（公開物の間の
参照、実績、公開者ラベル、リーダーボードのページ）について説明します。

これらのカードのほとんどは、公開物ページの
**ウォレット・アーカイブ・公開者向けツール** の **アーカイブツール** と
**参照と実績** のタブにあります。保持しているものが再読み込みしても
残るカードには **ローカルに保存** と表示されます。

全体を通して使う言葉: **公開物のアイデンティティ** とは、Bitcoin または
Base のアンカーの公開の記録 1 つのことです
（[Bitcoin アンカーの公開](11-EvidenceAndStorage.md#bitcoin-アンカーの公開)
を参照）。チェーン上の記録であり、人ではありません。

## 公開物の観測アーカイブ

IPFS、Bitcoin、Base の道具が観測した事実を、このデバイスに永続的に
記録したものです。保持するのは公開物のアイデンティティと観測だけで、
ウォレットの接続、鍵、ピン留めの認証情報は決して保持しません。

### 観測のアーカイブ

**観測のアーカイブ** カードには、保持している **公開** と **観測** の
数が表示されます。

- **アーカイブを表示** は **アーカイブ済みの観測タイムライン** を開き
  ます。IPFS へのすべての公開と検証、Bitcoin のすべてのブロードキャスト、
  承認、内容の証明、Base のすべての取り込みの観測を時系列で並べ、それぞれ
  にドメイン、状態、（該当する場合は）ロケーター、txid、ブロックの高さを
  示します。開いてもネットワークには接続しません。
- **アーカイブをクリア** は、アーカイブから何かを削除する唯一の方法
  です。ほかのものはすべて追加するだけです。アーカイブが空のときは
  使えません。

### Bitcoinアンカーの過去の証拠

**ブロックチェーンへのアンカリング** タブのカードで、同じ Bitcoin の事実を
アンカー ID ごとにまとめて表示します。**過去のアンカーを表示** で
アンカー ID を選ぶと、その **ブロードキャストの履歴**、**承認の履歴**、
**内容の証明の履歴**、**チェーン上の位置の比較**、**観測の一貫性** が、
5 つの数をまとめた **統合した証拠** の概要とともに表示されます。数は
どれだけ記録されたかを示すもので、どれだけ信頼できるかを示すものでは
ありません。

### アーカイブのエクスポート、インポート、調査

**公開のアーカイブ** カードは、アーカイブを JSON ファイルにします。

- **アーカイブをエクスポート** は、JSON と
  **アーカイブのエクスポートをダウンロード** のリンクを表示します。
- **アーカイブをインポート** は、ファイルか貼り付けた JSON を受け取り、
  そこに含まれる公開物と観測の数を、現在のアーカイブと比べてプレビュー
  します。適用するのは **現在のアーカイブを置き換える** だけです。
  インポートは現在のアーカイブを **置き換え**（統合はしません）、元に
  戻せません。無効なファイルは拒否され、何も変わりません。

**外部のアーカイブを調べる** は、インポートせずにエクスポートの中を
見ます。ファイルのスキーマのバージョン、ドメインごとの事実の数（IPFS の
公開と検証、Bitcoin のブロードキャスト、承認、内容の証明、公開物の
アイデンティティ、Base の取り込みと公開物のアイデンティティ）、ローカルと
インポートした事実の数、インポートの記録、フィンガープリント、そして
含まれている Bitcoin のアンカー ID、IPFS の記録のインデックス、Base の
トランザクションのハッシュが表示されます。そこから次のことができます。

- **現在のアーカイブと比較** は、ドメインごとに **同一**、**変更**、
  **現在のみ**、**外部のみ**、**出所が異なる** ものを一覧表示します。
- **置き換えを確認**（比較のあと）は、置き換えると何が変わるかを、
  両方のアーカイブの数とフィンガープリントとともにプレビューします。
  その **現在のアーカイブを置き換える** ボタンは、上と同じインポートです。
  置き換えるとすべての事実が新しくインポートされたものとして扱われる
  ので、結果のフィンガープリントはファイルのものと違います。

### アーカイブの出所

事実の出どころを示します。**ローカルの事実**（このデバイスで観測した
もの）と **インポートした事実**（**現在のアーカイブを置き換える** による
もの）です。一度でもインポートしたことがあれば、
**アーカイブのインポート** に各インポートの時刻、事実の数、スキーマの
バージョンが並びます。どちらの種類も、より信頼できるとは見なされません。

### アーカイブのフィンガープリント

アーカイブのすべての事実と出所のタグの SHA-256 ダイジェストです。
**フィンガープリントをコピー** でコピーします。ほかから（たとえばピア
から）来たフィンガープリントと比べるには、**別のフィンガープリントと
比較** の下に貼り付けて **比較** をクリックします。

| 結果 | 意味 |
|---|---|
| **MATCH** | 2 つのアーカイブの中身はまったく同じです。 |
| **DIFFERENT** | 同じではありません。 |
| **INVALID_FINGERPRINT** | 貼り付けたものが 64 文字の SHA-256 フィンガープリントではありません。 |

一致は中身が同じという意味でしかなく、正しいという意味ではありません。
また、どちらのアーカイブが新しいかはここではわかりません。

## 公開の参照

ある公開物のアイデンティティが、別のものを指していることを記録します。

**公開の参照 → 参照を表示** でフォームが開きます。知っている Bitcoin と
Base の公開物のアイデンティティ（たとえば「Bitcoin — a1b2…c3d4 —
content 9f8e…」）から、**参照元の公開（参照する側）** と
**参照先の公開（参照される側）** を選び、**参照を記録** をクリックします。
公開物が自分自身を参照することはできません。参照を作るのはあなただけで、
自動で作られることはなく、アプリのほかの場所でフォークしても作られ
ません。

参照はあえてフォークとは呼びません。ポインターがあることを記録する
だけで、それが何を意味するか（フォーク、引用、返信）は記録しません。

記録した参照は古い順に、両側のチェーン、短いアイデンティティ、内容の
ハッシュ、記録した時刻とともに並びます。重複は別々の参照として残り
ます。

**公開の参照グラフ** は、同じ参照を公開物ごとにまとめます。
**エッジ**、**公開**、**異なる参照元**、**異なる参照先** の合計と、各
公開物の **参照している数** と **参照されている数** があり、展開すると
個々の参照が表示されます。数は順位ではありません。

## 実績

公開物のアイデンティティは、しきい値を超えた瞬間にバッジを獲得します。
受け取る手続きはありません。

**実績 → 実績を表示** に、これまでに獲得したバッジが並びます。バッジの
名前はアプリでは英語で表示されます。

| バッジ | アイコン | 獲得する条件 |
|---|---|---|
| First publication（最初の公開） | 🏆 | 最初の Bitcoin または Base のアンカーの公開の記録。 |
| Bitcoin publisher（Bitcoin の公開者） | ₿ | 最初の Bitcoin のもの。 |
| Base publisher（Base の公開者） | 🔵 | 最初の Base のもの。 |
| Multi-chain publisher（複数チェーンの公開者） | 🌐 | 2 つ以上のチェーンでの記録。 |
| Ten publications（10 件の公開） | 🔟 | Bitcoin と Base を合わせて 10 件目。 |
| One hundred publications（100 件の公開） | 💯 | 100 件目。 |

バッジをクリックすると、その **元の公開**（チェーン、内容のハッシュ、
チェーン上の参照、作成時刻）と、利用できる場合は
**上で公開のライフサイクルを見る** が表示され、その記録のライフサイクル
に移動できます。

さらに 5 つの実績が参照から得られ、まだバッジはありません。
**First reference created**（最初の参照を作成）、
**First reference received**（最初の参照を受けた）、
**Referenced by 10 publications**（10 件の公開から参照された）、
**Referenced by 100 publications**（100 件の公開から参照された）、そして
**First cross-chain reference**（最初のチェーン間の参照。Bitcoin と Base の
公開物の間）です。これらは **実績プロフィール** に名前で並びます。そこでは
公開物のアイデンティティを選ぶと、その実績の数と完全な一覧が、それぞれ
獲得した時刻とともに表示されます。

実績は人ではなく公開物のアイデンティティに属します。ここには公開物を
人と結び付けるものは何もありません。

## 公開者のアイデンティティ

**公開者の関連付け** では、下の公開者のカードとリーダーボードのために、
あなたの自己申告で、公開物に公開者の名前のラベルを付けられます。

公開者の識別子は、単なる自己申告のラベルで、検証されたアイデンティティ
でもログインでもありません。照合は完全一致で、`Alice`、`alice`、
`ALICE` は 3 人の別々の公開者です。ウォレット、内容、名前から何かが
推測されることはありません。

**公開者の関連付けを表示** のあと:

1. **公開者の識別子** — ラベルを入力するか、前に使ったものを選びます。
2. **公開物** — 自分の Bitcoin か Base の公開物のアイデンティティを
   1 つ選びます。
3. **公開を追加** — 関連付けを記録します。

**記録された関連付け** に、古い順に並びます。
**公開者に関連付けられた公開** には、選んだ公開者のすべての公開物が、
内容のハッシュと関連付けた時刻とともに表示されます。

[リーダーボード](#リーダーボードのハブ) のページにある 3 つのカードは、
これらの関連付けに基づいていて、それぞれに **公開者を選択** の
ドロップダウンがあります。

| カード | 表示するもの |
|---|---|
| **公開者の実績プロフィール** | その公開者が主張するいずれかの公開物が獲得したすべての実績と、どの公開物が獲得したか。 |
| **公開者の実績バッジ** | 同じものを、バッジのある実績に絞ったもの。それぞれ公開物ページのライフサイクルにリンクします。 |
| **公開者の実績の統計** | 関連付けた公開物、実績、実績の種類、バッジ、バッジの種類の数、チェーンごとの公開物の数、種類ごとの実績の数。 |

まだ関連付けがない場合、どのカードもそう表示し、公開者の関連付けを
案内します。これらが示すのは公開者が何を *主張* しているかで、誰が
公開物を管理しているかではなく、どれも誰かを順位付けしません。

## リーダーボードのハブ

**リーダーボード** のページ（`/leaderboard`）には、下のページへの
リンクと、上の 3 つの公開者のカードがあります。上部のバーにはありません。
公開物ページの **公開のアーカイブ** カードの下にある **リーダーボード**
のリンクから開きます。

### 公開者の実績リーダーボード

`/publisher-leaderboard` は、このデバイスが記録したものに基づいて公開者を
順位付けします。**順位**、**公開者**、**実績**、**実績の種類**、
**公開** で、ページを開くたびに計算し直され、保存されることはありません。
公開物を関連付けると、その公開者が表示されます。名前はあなた自身の
ラベルで、検証されたアイデンティティではありません。

### 公開者のスナップショットの主張

`/publisher-snapshot-claim` は、今のリーダーボードのスナップショットに
ついての主張に署名し、ピアがそれと比べられるようにします。サインインして
いる必要があります。

1. **主張を生成して署名** — スナップショットを計算し、それについての
   主張に署名します。署名者と、証拠、ポリシー、スナップショットの
   フィンガープリントを表示します。**やり直す** で破棄します。
2. **主張をエクスポート** — 主張を JSON として、**主張をダウンロード**
   のリンク付きで表示します。ピアの
   [照合ワークスペース](#照合ワークスペース) に貼り付けるか、ファイルと
   して送ります。

### 照合ワークスペース

`/reconciliation-workspace`: ピアがエクスポートした主張を
**ピアの証拠のJSON** に貼り付けて **照合** をクリックします。その主張を
あなたのアーカイブと比べ、照合の候補が見つかると、判定と再検証の観測を
アーカイブに記録し、**リーダーボードで見る** を表示します。照合するものが
なければ、その理由を示します。**結果をクリア** で結果を閉じます。

### 照合候補のリーダーボード

`/reconciliation-leaderboard` は読み取り専用です。照合の候補ごとに、
あなたのアーカイブが持つ証拠を、必要ならピアのアーカイブと比べて表示
します。

**候補** とは、同じ内容についての外部の証拠のクレームとローカルの
スナップショットの記録を比べた箇所です。

| 候補のラベル | 意味 |
|---|---|
| **Claim *X* ↔ Snapshot #*N*** | 比べて食い違ったクレームとスナップショット。 |
| **Claim *X* (no corresponding Snapshot)** | 比べるスナップショットのないクレーム。 |
| **Snapshot #*N* (no corresponding Claim)** | 比べるクレームのないスナップショット。 |

候補は照合ワークスペースから来ます。そこでピアの主張を照合するまで、
ページには「表示する照合の候補はありません。」と表示されます。

**列。** **判定の証拠**（どちらの側を信頼したかの記録された選択）と
**観測の証拠**（その判定のあとの再確認）には、それぞれ 3 つの数が
あります。**共通**（両方のアーカイブにある）、**比較元のみ**（あなたの
ものだけ）、**比較先のみ**（ピアのものだけ）です。行は、証拠の多さでは
なく見つかった順に並びます。これは順位ではありません。

**ピアと比べる。** ピアのアーカイブのエクスポートを **ピアのアーカイブ**
に貼り付けて **ピアのアーカイブとして使う** をクリックします。無効な
貼り付けは拒否されます。ピアのアーカイブがなければ、すべて比較元のみと
して数えられます。表の上の行が、どの場合かを示します。

| バナー | 意味 |
|---|---|
| *ピアのアーカイブが指定されていません — 下の数はすべてこのレプリカだけのものです。* | まだピアのアーカイブがありません。 |
| *ピアのアーカイブが指定されましたが、証拠が記録されていません — 下の数はすべてこのレプリカだけのものです。* | 本物のアーカイブですが、空です。 |
| *指定したピアのアーカイブと比較しています。* | 本当の比較です。 |

行の **証拠を調べる**（その後は **証拠を隠す**）は、その数の背後にある
判定と観測の記録を、共通、比較元のみ、比較先のみに分けて一覧表示します。
各観測には、照らし合わせた計画のフィンガープリント（`計画:
abcdef012345…` など）と、記録されたとおり、候補が **存在** したか、
**計画と一致** したかが表示されます。似て見える記録も別々のままです。

**証拠の絞り込み。** 2 つのドロップダウンで表示するものを絞り込みます。
**証拠の種類**（**すべて**、**判定**、**観測**）と **レプリカ間の関係**
（**すべて**、**共通**、**比較元のみ**、**比較先のみ**）です。その関係で
その種類の証拠がある行が残ります。**レプリカ間の関係** が **すべて** なら
何も絞り込まれず、**証拠の種類** が **すべて** なら、どちらかの種類が
選んだ関係を持っていれば行が一致します。絞り込みは各行の
「証拠を調べる」の一覧も絞り込みます。行や記録を隠すだけで、行の数が
変わることはありません。

**証拠のエクスポート。** **証拠をエクスポート** は、絞り込みで表示されて
いるものをそのまま JSON ドキュメントにし、比較の状態と使った絞り込みを
記録して、**証拠のエクスポートをダウンロード** のリンク
（`reconciliation-candidate-leaderboard-evidence-export.json`）を表示
します。何もアップロードされません。**エクスポートした証拠を比較** は
[証拠エクスポートの比較](#証拠エクスポートの比較) を開きます。

**証拠のエクスポートをインポートする。** エクスポート（自分のものでも
ピアのものでも）を貼り付けて **証拠をインポート** をクリックすると、
その比較の状態と、候補、判定、観測の数が表示されます。無効な貼り付けは
拒否され、前の概要が残ります。**インポートした証拠をクリア** で閉じます。
これは上の表には影響しません。

ページは開いたときに一度だけアーカイブを読みます。新しい記録を見るには
開き直してください。ピアのアーカイブ、絞り込み、開いた行、インポート
した概要は保存されません。

## 証拠エクスポートの比較

`/evidence-export-comparison` は、2 つの証拠のエクスポートどうしを
比べます。たとえば先週のものと今日のもの、自分のものとピアのものです。
あなたのアーカイブは読まず、リーダーボードにも影響しません。

2 つのドキュメントを **比較元の証拠エクスポート** と
**比較先の証拠エクスポート** に貼り付けて **証拠を比較** をクリック
します。無効な側はその側だけが拒否され、もう一方は残ります。
**比較をクリア** でページを空にします。

- **比較の状態** と絞り込みには、各ドキュメントに記録された比較の状態と
  絞り込み、そしてそれらが同じかどうかが表示されます。
- 3 つの表（**候補の有無**、**判定の証拠**、**観測の証拠**）は、それぞれ
  比較元のみ、共通、比較先のみを数え、まとめられることはありません。
- **記録を調べる**（その後は「記録を隠す」）は、表の数の背後にある記録を
  一覧表示します。判定や観測の記録では、**IDを調べる** が、それを特定
  するフィールドを表示します。

| 記録 | 特定するフィールド |
|---|---|
| 判定 | `decided`、`candidate`、`decision`、`decidedAt` |
| 観測 | `candidate`、`decision`、`planIdentity`、`candidatePresent`、`candidateType`、`candidateMatchesPlan`、`observedAt` |

**記録の明示的なペアリング。** 特定の 2 つの記録を比べるには、判定か
観測について、比較元と比較先の記録を（どの区分からでも）1 つずつ選んで
**ペアを追加** をクリックします。**削除** でペアを外します。自動で
ペアになるものはなく、同じペアを 2 回追加することもできます。
**ペアにした記録の違い** の下で、各 **判定のペア N** や **観測のペア N**
には、いくつの特定フィールドが違うか（または **違いはありません**）が
表示されます。**違いを調べる** はそれらの名前を示すか、
**名前の付いたすべてのフィールドが同一です。** と表示します。どちらの
側が正しいかは決して示しません。
