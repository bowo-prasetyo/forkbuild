ForkBuild にはアカウントがなく、あなたを追跡しません。作業はあなた自身の
ブラウザーに保存し、他のコンピューターと通信するのは、それが必要な機能の
ためだけです。例外は 1 日 1 回の匿名の訪問者数のカウントで、開発者が
おおよその利用者数を知るためのものです（下の「訪問者数のカウント」に、
オフにする方法も含めて説明しています）。このページでは、何を保存するか、
そして接続しうるすべてのサーバーとそのタイミングを説明します。

## デバイスに残るもの

以下はすべてこのブラウザーのストレージ（IndexedDB の `forkbuild`
データベース。IndexedDB のないブラウザーでは `localStorage` の、
`forkbuild:` で始まるキー）にあり、あなたが公開、エクスポート、送信
しない限りデバイスの外に出ることはありません。

- ドキュメント、未保存の変更のクラッシュ復旧用コピー、保存した構造物。
- アイデンティティ: それぞれの公開鍵と秘密鍵。秘密鍵は、パスフレーズ
  なしで作成することを選んだ場合を除き、パスフレーズで暗号化されます。
- 既知のピア、友達、フォローしている人、ブロック、チャットの履歴、
  送信待ちのメッセージ（フォローしても相手に知らされることはなく、
  フォローについての情報は一切送信されません）。
- アバターのプロフィール、設定（ワールドビューで音を鳴らすか、音量、
  3D かステレオか、選んだ言語を含みます。言語を選んでいない場合、
  ForkBuild はデバイス上でブラウザーの優先言語を読みますが、どこにも
  送りません）、そして **ネットワーク設定** で入力した場合は TURN
  サーバーのユーザー名と認証情報。
- このブラウザーが 1 日の訪問者数のカウントに参加するかどうかと、最後に
  数えられた日。

ブラウザーでこのサイトのデータを消去すると、これらはすべて削除され、
ほかにコピーはなく、復旧する方法もありません。先に
**あなたのデータ → ファイルにバックアップ** でバックアップしてください。
ファイルには、どのアイデンティティでログインしているかを除く上記の
すべてが、あなたが選んだパスフレーズで暗号化されて入り、あなたが
置いた場所にとどまります。ForkBuild がそれをアップロードすることは
ありません。**バックアップを共有** は、デバイス上であなたが選んだ
アプリにファイルを渡します。バックアップフォルダーを選んだ場合、
ブラウザーはそのフォルダーへの ForkBuild の許可を保持し、ForkBuild は
そのフォルダーと、希望すればバックアップのパスフレーズから作った鍵を、
別の IndexedDB データベース `forkbuild-backup` に保持します。この鍵は
バックアップを作ることしかできません（開くことはできません）。
最後にいつ、どこへバックアップしたかは、ほかのデータとともに保存
されますが、バックアップには含まれません。

## 他の人に見えるもの

- **あなたが公開したもの** はすべて公開されます: その内容、タイトル、
  説明、ライセンス、そしてそれに署名したアイデンティティの公開鍵です。
  他の人がコピーを持ったあとは、取り消すことはできません。
- **あなたが接続したピア** は、あなたのアイデンティティの公開鍵と
  IP アドレスを知ります（直接接続には IP アドレスが必要です。TURN
  リレーは相手のピアからは IP アドレスを隠しますが、リレー自身からは
  隠しません）。接続しているピアには、公開範囲の設定に従ってあなたの
  アバターと在席状況が見え、乗っている乗り物（種類と ID。在席状況が
  送られるときだけ送られます。乗り物を置いた場所は決して送られません）
  も含まれます。また、友達はあなたにメッセージを送れます。
  ピアは、あなたのデバイスが見つけたスナップショットと地名の告知も
  受け取るので、あなたがワールドのどの地域の地名を探したかがわかります
  （docs/AnnouncementIndex.md）。
- **共有したワールドについて、ピア。** リポジトリの **ピアと共有** は、
  公開したワールドの 1 つを、今接続している全員と、あとから接続する
  全員（ロビーで会った見知らぬ人を含む）に提供します。相手はその一覧
  情報を受け取り、あなたが接続している間、あなたのデバイスから
  ワールドそのものを取得できます。友達と既知のピアのデバイスは自動で
  取得します。それ以外の人のデバイスは、その人が **取得** をクリック
  したときだけ取得します。**公開** しただけのワールドが誰かに送られる
  ことはありません。
- **公開ロビーにいる間は、誰にでも。** 公開ロビー（**ピア**）や
  ワールドのロビー（ワールドビューの **ロビー**）に参加すると、
  あなたのアイデンティティの公開鍵と、あなたが選んだ表示名が、その
  ロビーを開いた人なら誰にでも表示されます。ワールドのロビーでは、
  あなたがどのワールドを開いているかもわかります。この掲載は、
  あなたが退出するか、アプリを閉じる（その場合は最大 10 分後）か、
  カードの期限が切れるまで続きます。ネットワークアドレスは含まれません
  が、ロビーにいる誰もがあなたに接続でき、接続してきた見知らぬ人は
  通常の接続中のピアになります。つまり、あなたの IP アドレスを知り、
  公開範囲の設定が許す範囲であなたのアバターと在席状況を見て、
  **他の接続中のピアとまったく同じように、スナップショットと地名の
  告知、公開物のメタデータをあなたと交換します**。これは、あなたが
  その人を記憶したり友達になったりする前から行われます。チャットと
  音声通話には、引き続き相互の友達関係が必要です。ロビーの
  **ブロック** は、その人をロビーの一覧から隠し、ピアページと同じように
  ブロックします（在席状況、プロフィール、チャット、友達リクエスト）。

## 訪問者数のカウント

1 日に 1 回、その日このデバイスで初めて ForkBuild を開いたとき、公式サイト
（`https://bowo-prasetyo.github.io/forkbuild/`）は、Cookie を使わない
カウンターである GoatCounter（`forkbuild.goatcounter.com`）から小さな
画像を 1 つ読み込みます。送信するのはこのリクエストだけです。

- **GoatCounter が受け取るもの：** あらゆる Web リクエストと同じく、
  あなたの IP アドレスとブラウザーの User-Agent、それに固定のパス（`/`）
  と、画像がキャッシュされないようにするための乱数です。ページ、
  ドキュメント、ワールド、ID、リファラー、ForkBuild が保存しているものは
  何も含まれないため、アプリで何をしているかはもちろん、どのページを
  開いたかもわかりません。
- **保存するもの：** 合計だけです。1 時間ごと・1 日ごとの訪問者数と、どの
  ブラウザー・システム・国・言語からのものかを、互いに結び付けられない
  よう別々に集計します。GoatCounter のプライバシーポリシー
  （<https://www.goatcounter.com/help/privacy>）によれば、IP アドレスや
  User-Agent 全体は保存せず、Cookie を使わずに再訪問を見分けるためだけに、
  最大 8 時間メモリー上に保持します。
- **合計は誰でも見られます。** 公開ダッシュボード
  <https://forkbuild.goatcounter.com/> をご覧ください。

次の場合は送信されません。

- ブラウザーが Global Privacy Control または Do Not Track を送っているとき
- **あなたのデータ → 1日の訪問者数 → このブラウザーを数える** をオフに
  したとき（この選択はこのブラウザーにだけ保存されます）
- 公式サイト以外（`localhost` を含む）から提供される ForkBuild のコピー

コードは `core/VisitorCount.js`、`application/settings/CountDailyVisit.js`、
`ui/start.js` にあります。

## ForkBuild が接続するサーバー

スクリプト、スタイル、フォントはすべて、アプリを配信しているサイトから
読み込まれます（[docs/Deployment.md](../../Deployment.md)（英語）を参照）。
自動で始まるものが 1 つだけあります。アプリを開いて約 10 秒後と、
そのタブが表示されている間は数分ごとに、**ネットワーク設定** で設定
された Nostr リレー、Arweave ゲートウェイ、Steem ノードから新しい告知を
読み込みます（docs/AnnouncementIndex.md）。読むのは告知（小さな
ポインターと署名済みのクレーム）だけで、コンテンツは読まず、何も
公開しません。それ以外はすべて、あなたがその機能を使ったときだけ
行われ、各サーバーは **ネットワーク設定** で変更できます。各サーバーには、
あなたの IP アドレスと、何を要求したかが見えます。

| いつ | サーバー（既定） | 受け取るもの |
| --- | --- | --- |
| 公式サイトでアプリを開いたとき、多くても 1 日 1 回（「訪問者数のカウント」を参照） | GoatCounter（`forkbuild.goatcounter.com`） | 固定のパスで、リファラーも Cookie もない画像リクエスト 1 回 |
| **ピア** で自分を見つけてもらえるようにするか、誰かを探したとき | ランデブーサーバー（`forkbuild-rendezvous.prazjp.workers.dev`） | あなたのアイデンティティの公開鍵と接続の申し出（最長 15 分保持）。探したアイデンティティ。見つけた人に接続するときは、あなたの接続の応答（ネットワークアドレスを含みます）。これを受け取れるのは相手だけです |
| 公開ロビーに参加するか、のぞいたとき | 同じランデブーサーバー | 署名されたロビーのカード（公開鍵、表示名、どのロビーか）。最長 15 分保持され、ロビーにいる間は更新されます。どのロビーをのぞいたか |
| ピア接続が始まるとき | STUN サーバー（`stun.l.google.com`） | あなたのパブリック IP アドレスの問い合わせだけ |
| ピア接続を始めるとき、ランデブーサーバーがリレーを提供している場合 | ランデブーサーバーの `/turn-credentials`、次にその TURN リレー（Cloudflare） | 短時間有効なリレーの認証情報の要求（多くても 1 時間に 1 回程度）。リレーされる通信は WebRTC によってエンドツーエンドで暗号化されます |
| アプリが開いていてタブが表示されているとき（バックグラウンドでの告知の同期） | Nostr リレー（`relay.damus.io`）、Arweave ゲートウェイ（`arweave.net`）、Steem ノード（`api.steemit.com`） | ForkBuild の発見用タグの問い合わせ: 共有のスナップショットとコメントのタグ、あなたが訪れた地名の地域と地図のセル |
| Nostr で公開物を配信または発見するとき | Nostr リレー（`relay.damus.io`） | あなたが公開する署名済みの告知。あなたの問い合わせ |
| Arweave にコンテンツを保存または取得するとき | Arweave ゲートウェイ（`arweave.net`） | あなたが公開するコンテンツ。取得するもの |
| IPFS からコンテンツを取得するとき | IPFS ゲートウェイ（`ipfs.io`）、または自分の IPFS ノード（`127.0.0.1:5001`） | 取得または追加するもの |
| リモートのピン留めサービスでコンテンツをピン留めするとき（*試験的*） | あなたが入力したサービス | コンテンツと、そのアップロード 1 回のために入力したトークン（保存されません） |
| Steem で保存、告知、アンカーするとき、または Steem の告知を発見するとき（*試験的*） | Steem API ノード（`api.steemit.com`、次に `api.justyy.com`）。署名は Steem Keychain 拡張機能を通して行われます | あなたの Steem アカウント名。投稿したもの（告知、保存したコンテンツ、アンカー）はチェーン上でずっと公開され、編集しても以前の版が履歴に残ります |
| 公開物の署名済みクレームを Steem で配信するとき（*試験的*） | Steem の画像ホスト（`steemitimages.com`）。ブラウザーから直接届かないときは、何も保存しないランデブーサーバーの `/steem-image` 中継を経由 | 投稿のプレビュー用の 320×200 の作品の画像。Steem の投稿鍵で署名されます |
| 公開物への共有リンク（`#/view/…`）を開いたとき | リンクが示す Steem ノード、Arweave ゲートウェイ、または IPFS ゲートウェイ。次に、その作品を見つけるための告知の基盤 | どの投稿、トランザクション、CID を開いたか |
| Bitcoin で証拠をアンカーまたは検証するとき（*試験的*） | Esplora API（`blockstream.info`） | ブロードキャストまたは照会するトランザクション |
| Base で証拠を検証するとき（*試験的*） | Base の JSON-RPC エンドポイント（`mainnet.base.org`） | 照会するトランザクション |
| ブラウザーのウォレットを接続するとき（*試験的*） | あなたが選んだウォレット拡張機能 | 承認を求められたもの |

ForkBuild は、あなたの秘密鍵、パスフレーズ、保存したドキュメントを、
これらのサーバーに送ることはありません。

**リレーは必要なときだけ使われます。** 接続はまず必ず直接の経路を試し、
次に STUN で見つけた経路を試し、どちらもうまくいかないときだけ TURN
リレーに切り替えます。ロビーで待っている間、あなたのデバイスが用意して
おく接続の申し出はリレーの認証情報を求めないので、ロビーに滞在しても、
ランデブーサーバーが毎月配るリレーの割り当てを使い切ることはありません。
必要であれば、あなたに接続してくる側が認証情報を求めます。

## 自分のコピーを運用する場合

上記の既定値は、デプロイごとに決まります。ランデブーサーバー
（`peer/RendezvousConfig.js`）、そのサーバーが TURN リレーを提供するか
（`server/rendezvous-worker/README.md`）、そして **ネットワーク設定** の
その他の既定値です。既定のランデブーサーバーは公式サイトのオリジン
しか受け付けないので、別の場所でホストするコピーには独自のものが必要
です（[docs/Deployment.md](../../Deployment.md)（英語）を参照）。
ForkBuild を他の人のためにホストする場合は、このページ（英語版を含む）を
更新して、あなたのサーバーを記載してください。

訪問者数のカウントは公式サイトでしか動かないため、他の場所でホストした
コピーは何も数えません。自分の訪問者を数えるには、`core/VisitorCount.js`
のアドレスと、`index.html` の Content Security Policy の `img-src` を
変更してください。
