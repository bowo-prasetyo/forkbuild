## 公開と共有

### 作品を公開したのに、友達のリポジトリに表示されません

公開しても、作品は自分のデバイスに保存され、*自分の* リポジトリに
載るだけです。自分で選ぶまで、どこにも送られません。

- リポジトリの作品の下にある **ピアと共有** は、接続している人に作品を
  提供します。友達や既知のピアのデバイスは自動で追加します。それ以外の
  人には **あなたと共有されたもの** に表示され、その人が **取得** を
  クリックします。届くには、同じ時間に接続している必要があります。
- **配信** は作品を Arweave や IPFS（試験的には Steem や Blurt）にアップロードして
  告知するので、あなたと接続していなくても見つけてもらえます。

[公開とフォーク](04-PublishingAndForking.md#接続中のピアと共有する)を参照してください。

### 自分の作品を誰でも見られるようにするには？

配信します。作品を Arweave や IPFS（試験的には Steem や Blurt）に保存し、Nostr や
Arweave（または Steem や Blurt）で告知すれば、あなたと接続していなくても、誰でも
見つけて確かめられます。公開した直後に **配信** をクリックするか、
ワールドビューの **自分の共有ワールド** から配信します。選んだ
ネットワークに対応した署名用のブラウザー拡張機能が必要です（Arweave なら
Wander、Nostr なら nos2x など）。配信できるもの、その行き先、各ネットワーク
に必要なものは [作品を配信する](Distribution.md)に
まとめてあります。

### 自分の作品を誰もフォークできないのはなぜですか？

新しいドキュメントにはライセンスがなく、ライセンスのない作品は
フォークできません。**ドキュメントのプロパティ**（エディターの
ドキュメントタイトルの横にある **✎**）を開き、フォークを許可する
ライセンス（CC BY-ND 以外の CC ライセンスならどれでも）を選んで、
もう一度公開してください。この設定は公開される内容の一部なので、
すでに公開した作品は当時のライセンスのままです。
[ライセンスの選び方](04-PublishingAndForking.md#ライセンスを選ぶ)を参照してください。

### 公開に失敗しました。メッセージの意味は？

「公開に失敗しました:」に続く理由は英語で表示されます。

- **a title is required before publishing**（公開にはタイトルが必要です）
  — **ドキュメントのプロパティ** で作品にタイトルを付けてください。
- **cannot publish an empty world**（空のワールドは公開できません） —
  まずブロックを 1 つ以上置いてください。
- **cannot sign, identity is locked**（アイデンティティがロックされて
  いるため署名できません） — アイデンティティが自動でロックされました。
  上部のバーで名前の横にある **ロック解除** をクリックし、もう一度
  公開してください。

### 公開するにはログインが必要ですか？

ログアウトしていても公開はできますが、作者も署名もない状態になるので、
ピアと共有したり、あとで配信したりできません。公開する前にログイン
してください。

### 公開を取り消せますか？

はい。ワールドビューでワールドを開き、**自分の共有ワールド** で
**その他 ▾ → 公開を取り消す…** を選びます。リポジトリから削除されます。
ただし、他の人がすでに受け取ったコピーや、Arweave、IPFS、Nostr、Steem、Blurt
に配信したものを取り戻すことはできません。ただし、このデバイスは公開を
取り消したものを覚えているので、リポジトリによるネットワークの検索で
そのコピーがここに再び表示されることはありません。ほかのデバイスや
ほかの人は引き続き見つけられます。

### 誰かが自分の作品を自分のワールドに配置しました。私の作品が動かされたのですか？

いいえ。配置は、*その人の* ワールドのどこにあなたの作品を表示するかを
示すだけです。あなたの作品はあなたが置いた場所のままで、名前と履歴も
保たれます。これを望まない場合は、公開する前に **ワールドに配置できる人**
で **自分だけが配置できる** を選んでください。
[なぜ他の人の作品を配置できるの？](03-WorldView.md#なぜ他の人の作品を配置できるの)を参照してください。

### 2 つの作品が同じ場所に重なっているのはなぜですか？

配置は土地の所有権を主張するものではなく、どちらが先にその場所を
取ったかを決める中央サーバーもないため、2 つの配置が同じ地点を指す
ことがあります。自分の作品をすでに使われている場所に動かそうとすると、
その前に警告が出ます。
[なぜ 2 つの作品が同じ場所にあるの？](03-WorldView.md#なぜ-2-つの作品が同じ場所にあるの)を参照してください。

## アイデンティティとデータ

### パスフレーズを忘れました。リセットできますか？

できません。パスフレーズは、そのアイデンティティの鍵を復号する唯一の
手段で、コピーを持っているサーバーもありません。アイデンティティを
エクスポートしていた場合でも、エクスポート時に選んだパスフレーズが
必要です。そうでなければ、新しいアイデンティティを作成してください。
[アイデンティティとログイン](05-IdentityAndLogin.md)を参照してください。

### アイデンティティが勝手にロックされるのはなぜですか？

保護されたアイデンティティは、アプリを使っている最中でも **ロック解除
してから 15 分後** に、またページを再読み込みするたびにロックされます。
ロック中でも作品づくりと保存はできます。公開、見つけてもらえるように
すること、ロビーへの参加には、もう一度ロック解除が必要です。

### 作品を別のコンピューターやブラウザーに移すには？

自動では何も同期されません。すべてをコピーするには、両方のデバイスが
オンラインの状態で、**あなたのデータ** の **別のデバイスにコピー** で
**コードを表示** をクリックし、もう一方のデバイスでコードをスキャン
（またはリンクを開く）します。または、そこでバックアップし、そのファイルを
別のデバイスで復元します（[あなたのデータ](13-YourData.md) を参照）。一部だけを移すには:

- **ドキュメント**: エディターのツールバーの **エクスポート**、または
  **最近** の一番下にある **すべての作品をエクスポート** を使い、
  別のデバイスで **インポート** します。
- **自分の構造物**: カードの **⋮** メニューの **ブループリントを
  エクスポート**、または **マイ構造物** の横の **すべてエクスポート** を
  使い、**ブループリントをインポート** します。
- **アイデンティティ**: **マイアイデンティティ** の **エクスポート** を
  使い、**アイデンティティをインポート** します。

チャットの履歴、友達、設定は、完全なバックアップでしか移せません。

### ブラウザーのデータを消去すると作品も消えますか？

はい。ドキュメント、アイデンティティ、友達、チャットの履歴は、すべて
このサイト用のブラウザーのストレージにあり、消去すると完全に失われ
ます。先に **あなたのデータ → ファイルにバックアップ** でバックアップし、
ファイルとそのパスフレーズを大切に保管してください。同じページの
**復元** ですべて元に戻せます。ForkBuild は最後のバックアップが古く
なると知らせてくれます。また、パソコンの Chrome や Edge では、
クラウドストレージが同期するフォルダーに毎日自動でバックアップする
こともできます。[あなたのデータ](13-YourData.md) と
[プライバシー](Privacy.md) を参照してください。

### アイデンティティの名前を変えたり、削除したりできますか？

できません。アイデンティティは長く使い続けるためのものです。使うのを
やめるには、**マイアイデンティティ** で後継を宣言するか、失効させて
ください。

### 古い ForkBuild でエクスポートしたドキュメントが開けないのはなぜですか？

ドキュメントは現在、より新しくコンパクトな形式で保存されます。
ForkBuild 1.0.0 以前ではこの形式を読めないので、先にもう一方を更新して
ください。古いバージョンでエクスポートしたファイルは、このバージョンで
引き続き開けます。

## ワールドビューとアバター

### WASD でアバターが動きません

歩く機能は、オンにするまでオフです。

1. ログインし、**マイアバター** でアバターを保存します。
2. ワールドビューの **アバター** セクションで **自分のアバターを操作
   （WASD、Shift、Space）** にチェックを入れます。
3. キー入力がテキスト欄に入らないよう、3D ビューをクリックします。

タッチ画面では、代わりにジョイスティックの上にある **歩く** をタップ
します。[Walking your avatar](06-AvatarsAndPresence.md#アバターを歩かせる)を参照してください。

### 自分のアバターは誰に見えますか？

既定では、接続している全員です。**在席状況の公開範囲** と
**プロフィールの公開範囲** はどちらも **公開** から始まります。
**マイアバター** で変更でき、**非表示** にすると見えなくなります。
[Who can see you](06-AvatarsAndPresence.md#誰に見えるか-2-つの独立した設定)を参照してください。

### 乗り物を運転中にブラウザーのタブが閉じました

**Ctrl** がブレーキで **W** が加速です。Windows や Linux のほとんどの
ブラウザーは **Ctrl+W** でタブを閉じます。ブレーキをかける前に **W** を
離してください。

### ワールドビューで何かを変更できますか？

変更できるのは注釈（ランドマーク、地域名、動物の飾り）だけです。作品を
作るのはエディターです。見ているものをエディターに持ち込むには
**コピーを編集** を使います。
[ワールドビュー](03-WorldView.md#コピーを編集--エディターに持ち込む)を参照してください。

## ピア、友達、チャット

### 自分で ForkBuild を動かしていて、誰も見つかりません

既定のランデブーサーバーは公開サイトにしか応答しないので、自分の
アドレス（`localhost` を含む）から配信しているコピーでは使えません。
招待で接続するか（**ピア → 新しい人と接続 → 招待**）、
**ネットワーク設定 → ランデブーサーバー** で自分のランデブーサーバーを
追加してください。[ピア接続と友達](07-PeerConnectionsAndFriends.md)を参照してください。

### 友達と自動で再接続されません

自動再接続の対象は **記憶済み** の人（既知のピア）だけで、相手が
**見つけてもらえるようにする** を有効にしている間しか見つけられません。
記憶していない友達には、代わりに **再接続** ボタンが表示されます。
その人の **⋯** メニューで **記憶する** を選び、二人とも
**見つけてもらえるようにする** をクリックしてください。

### メッセージが「保留中」のままです

メッセージはサーバーではなく自分のデバイスで待機するので、両方で
ForkBuild が開いていて接続している間にしか届きません。7 日以内に届か
なかったメッセージは破棄され、**未配信 — 期限切れ** と表示されます。
[Sending while someone's offline](08-ChatAndConversations.md#相手がオフラインのときに送る)を参照してください。

### 接続している人とチャットできないのはなぜですか？

チャットと音声通話は友達どうしだけのものです。**ピア** のその人の行で
**友達に追加** をクリックします。相手が承認すると **チャット** ボタンが
表示されます。

### ネットワーク設定を変えたのに何も変わりません

ネットワーク設定（サーバー、リレー、ゲートウェイ）はアプリの起動時に
読み込まれます。保存したあと、ページを再読み込みしてください。
[ネットワーク設定](10-NetworkSettings.md)を参照してください。

## デバイスとブラウザー

### ForkBuild はスマートフォンやタブレットで使えますか？

はい。どちらのビューにもタッチ操作があり、狭い画面ではメニューと
サイドパネルが折りたたまれます。
[タッチ画面](ControlsReference.md#タッチ画面) を参照してください。

### ForkBuild はオフラインで使えますか？インストールできますか？

はい、ホストされたサイトなら使えます。最初に訪れたあとは接続なしでも
開け、ホーム画面の **ForkBuild をインストール** でデバイスにアプリとして
追加できます。作品づくり、保存、保存した作品や既製の作品はオフラインで
使えます。作品や人を見つける、配信、チャットには接続が必要です。
[ForkBuild をインストールする](01-GettingStarted.md#forkbuild-をインストールする) を参照してください。

### 作品を 3D プリントしたり、Blender で開いたりできますか？

できます。エディターのツールバーの **3D モデル** から、3D プリント用の
STL（ミリメートル単位、ベッドに置いた向き）か、Blender などのソフト向けの
カラーの glTF や OBJ をダウンロードできます。
[3D モデルをダウンロードする](02-TheEditor.md#3d-モデルをダウンロードする) を参照してください。

### 暗号資産のウォレットは必要ですか？

いいえ。作品づくり、保存、公開、フォーク、ピア、チャットには不要です。
ウォレットや署名用の拡張機能が必要なのは、
[証拠とストレージ](11-EvidenceAndStorage.md)にある試験的な
配信とアンカリングの機能だけです。
