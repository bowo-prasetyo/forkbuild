ブラウザーで ForkBuild を使うためのガイドです。はじめての方は
**[はじめに](01-GettingStarted.md)** から読んでください。アプリを開いて
から、最初の作品の中を歩くまで 5 分ほどです。

## 遊ぶ（順番に読んでください）

作る、共有する、リミックスする、友達と歩き回る。そのために必要なことはすべてここにあります。

1. **[はじめに](01-GettingStarted.md)** — アプリを開き、メニューの見方を
   覚えて、最初のブロックを置くまで。名前を決めるのは公開するときだけです。
2. **[エディター](02-TheEditor.md)** — 作品づくりの道具一式:
   ツール、選択、変形、ブロックの色、グループ、ビルドライブラリの構造物と
   自分のブループリント、構造物のインスタンス、作品のタイトル・説明・
   ライセンス。
3. **[ワールドビュー](03-WorldView.md)** — 公開されたすべての作品がある共有の 3D ワールド。歩いたり飛んだり、ものを見つけて眺めたり、**ここに建てる**、**ここで一緒に歩こう**、住人、そして何かをエディターに持ち込む **コピーを編集**。ネットワークのツールには、下の「詳細」に専用のページがあります。
4. **[公開とリミックス](04-PublishingAndForking.md)** — 公開とリンクの共有、作品の送り先の選び方、ライセンス、リミックス、**さがす** とそのできあがった作品、毎週のチャレンジとその広場、家系図。作品を送れる先のすべては [作品を配信する](Distribution.md) を参照。
5. **[アバターと在席状況](06-AvatarsAndPresence.md)** —
   アバターのカスタマイズ、誰に見えるか、歩くこと、カメラの視点、乗り物、
   動物、持ち物。
6. **[あなたのデータ](13-YourData.md)** — このブラウザーが保持する
   すべてを暗号化した 1 つのファイルにバックアップして復元する方法、
   より小さなエクスポート、このデバイスが署名付き記録を配信した履歴。

## 詳細

下で動いているしくみです。アイデンティティの詳しい話、ほかの人との直接接続、作品を送れるネットワーク、試験的なツール。遊ぶためにはどれも必要ありません。

- **[ワールドビュー：詳細ツール](WorldViewAdvancedTools.md)** —
  **詳細ツールを表示** で加わるもの：ブロックを調べる、配置と、誰の作品
  でも配置できる理由、ワールドでの出会い、見つかった地名、主張された
  作品、**自分の共有ワールド** から自分の作品を送ること。
- **[名前とアイデンティティ](05-IdentityAndLogin.md)** — 名前と
  その裏にある暗号学的なアイデンティティ、保管庫（ロックとロック解除）、
  エクスポートとインポートによるバックアップ、**マイアイデンティティ**
  での管理。
- **[ピア接続と友達](07-PeerConnectionsAndFriends.md)** —
  他の人との直接接続、記憶、友達、フォロー、ブロック、自動再接続、
  自分の TURN リレー。
- **[チャットと会話](08-ChatAndConversations.md)** — 友達
  どうしの直接メッセージ、オフライン時の配信、既読、音声通話。
- **[署名付き記録と外部証拠](09-PublicationsAndEvidence.md)** —
  技術的で任意の層: 署名された作者情報と地名のクレーム、署名付き記録ページ、
  コメント、デバイスが保持するもの（ローカルスナップショット）。
  ページの一部は *試験的* で、そのように示されています。
- **[ネットワーク設定](10-NetworkSettings.md)** —
  ゲートウェイ、リレー、ストレージと告知のプロバイダー、ピア接続用の
  サーバー。
  各ネットワークに必要なものは
  [作品を配信する](Distribution.md#各ネットワークに必要なもの)
  にまとめてあります。
- **[証拠とストレージ](11-EvidenceAndStorage.md)** — IPFS
  や Arweave へのコンテンツの保存、スナップショットの配置、Arweave でのアンカリング、*試験的* な
  そのほかの外部証拠、Bitcoin と
  Base のウォレットパイプライン、リモート IPFS
  ピン留め、Steem、Blurt。
  これらの関係は [作品を配信する](Distribution.md)で
  説明しています。
- **[アーカイブと実績](12-ArchiveAndAchievements.md)**
  — *試験的*。観測アーカイブ、記録の参照、実績。

## リファレンス

- **[作品を配信する](Distribution.md)** —
  分散型ネットワークに置けるものすべて（ワールド、作者情報と地名のクレーム、
  コメント、アンカー）、ネットワークが担う 3 つの役割（内容、告知 / 発見、
  証明 / アンカリング）、各ネットワークに必要なもの、詳しいガイドへの
  リンク。
- **[よくある質問](FAQ.md)** — よく出会う疑問への短い答え: 共有、
  ライセンス、パスフレーズを忘れたとき、別のデバイスへの移行、アバターを
  歩かせる、友達との再接続。
- **[操作リファレンス](ControlsReference.md)** — エディターとワールド
  ビューでのマウスとキーボードの操作をすべて 1 つの表にまとめたもの。
  このページとアプリ内のコマンドパレット（`Ctrl/Cmd+K`）の内容が
  食い違う場合は、パレットが正しく、このページに誤りがあります。
  ぜひ報告してください。
- **[インタラクティブ変形ギズモ](InteractiveTransformGizmo.md)**
  — ビューポート内で直接ドラッグして選択を移動・回転する方法:
  ハンドル、回転軸、スナップ、確定、キャンセル、元に戻す、グループの
  扱い。

## 作る場所、探索する場所

ForkBuild で作品を作るのはエディターだけです。ワールドビューは読み取り
専用の探索の場です。

- **エディター**（メニューの **つくる**） — あなた専用の作業場所。
  ビルドライブラリからブロックを置き、選択し、キーボードやギズモで
  動かしたり回したりします。ツールバーから作品を保存、開く、公開します。
- **ワールドビュー**（メニューの **歩く**、または作品の **探索**） —
  共有のワールド。公開された作品の間を歩いたり飛んだりし、周りにある
  ものを検索して探索し、建物や地形の上でアバターを歩かせ、
  **コピーを編集** で見つけたものをエディターで開いて、そのまま続きを
  作れます。

エディターでの変更はすべて 1 回ずつ元に戻せる操作で、`Ctrl/Cmd+Z` で
取り消せます。

## 共同作業と探索

ForkBuild では、アバターを通じた共同作業とワールドの発見ができます。

- **歩いて移動する** — WASD キーでアバターを建物や地形の上で歩かせ、
  ジャンプし、登り、高い場所を探索します。
- **一緒に作る** — エディターの **一緒に作ろう** で、あなたの作品を友だちの
  エディターで開くリンクを作れます。ライブで一緒に作り、相手のブロックが
  現れるところや相手が指している場所がお互いに見えます
  （[エディター](02-TheEditor.md#一緒に作ろう-ライブで一緒に作る) を参照）。
  ワールドビューでは、他の作り手のアバターと何に取り組んでいるかを見て、
  **コピーを編集** で見つけたものをエディターに持ち込んで、自分で続きを
  作ります。
- **ワールドを発見する** — 場所に応じたマーカー付きのコンパスで、近くの
  構造物や、森・川・草原などの地形を見つけます。
- **共同作業者についていく** — カメラを誰かのアバターに固定し、その人の
  移動についていきます。

目に見えるものはすべて、ワールドの決定論的なシードから導かれます。
地形、生態、水系は誰にとっても同じように計算されるので、余分なデータを
保存しなくても、一貫した共有の場所が生まれます。

## 再利用できる構造物とブループリント

エディターのビルドライブラリでは、ブロック 1 つずつではなく、構造物
まるごとで作ることもできます。5 つのカテゴリーにわたる 22 種類の
既製の構造物と、自分で保存したものが使えます。

- 構造物を作品の中に **配置** するか、まったく新しい作品として
  **リミックス** します。
- 自分の作品を、再利用できる構造物として **マイ構造物**（自分専用の
  ブループリントライブラリ）に **保存** します。
- ブループリントを持ち運べるファイルとして **エクスポート・インポート**
  し、他の人と共有したり、別のデバイスに持っていったりします。

詳しい手順は
[エディター](02-TheEditor.md#構造物-組み立てリミックス自分のライブラリ)
を参照してください。
