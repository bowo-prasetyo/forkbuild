# 07 — ピア接続と友達

ForkBuild は、あなたを他の人のブラウザーに直接つなぎます。友達リストを
保管する中央サーバーはありません。上部のバーで **ピア** を開くと、
接続中の人、記憶している人、友達を管理できます。

## ページの概要

```
ピア                                    あなたのID …N6KbN  [完全なIDをコピー]

対応が必要                あなたを待っている接続、友達リクエスト
人  [すべて|友達|フォロー中|オンライン]   1 人につき 1 行
新しい人と接続            [招待|招待を貼り付け|IDで探す|公開ロビー]
▸ ブロック中 (N)          誰かをブロックしたときだけ
```

- **対応が必要** は、何かが待っているときだけ表示されます。進行中の
  接続（「step 2 of 5: WebRTC接続中」のように、その段階付き）、相手の
  返答を貼り付けるのを待っている接続、閉じるべき失敗した接続、
  友達になりたいという人（**承認** / **拒否**）です。
- **人** には、その人について知っていることがいくつあっても、1 人に
  つき 1 行が表示されます。タグはその人があなたにとって何かを示します。
  **友達**、**記憶済み**、**フォロー中**、**ブロック中**、
  **リクエスト送信済み**、**友達リクエストが届いています** です。緑の
  点はオンラインを意味します。オンラインの人が先に、次に友達、それから
  ほかの人が並びます。各行には主な操作（友達には **チャット**、
  オフラインなら **再接続**、接続中の人には **友達に追加**）があり、
  **⋯** メニューに残りがあります。**名前を変更**（または
  **名前を付けて記憶**）、**記憶する** / **忘れる**、**友達をやめる**、
  **フォロー** / **フォロー解除**、**接続の詳細**、**切断**、
  **ブロック** / **ブロック解除** です。**フォロー中** の絞り込みでは、
  ここにいる人のうちフォローしている人が表示されます。
- **ブロック中** は一番下に折りたたまれていて、誰かをブロックしている
  ときだけ表示されます。

一覧の裏には、互いに独立した 5 つの記録があります。現在の接続、既知の
ピア（あなたが **記憶する** を選んだ人。相手には共有されない個人的な
メモです）、友達（相互で署名済み）、フォロー中（[人をフォローする](#人をフォローする)
を参照）、ブロック中です。記憶していない友達、ということもあり得ます。
行には当てはまるものが表示されるだけです。フォローしているけれど一度も
接続したことのない人は、ここには表示されません。フォローしている全員は
**フォロー中** ページに表示されます。

## 誰かを見つけて接続する

検索できるユーザー名はありません。どのピアも暗号学的なアイデンティティ
で指定されるので、接続は常に、すでに信頼している何らかの経路（チャット、
メール、直接会う）でアイデンティティの情報を交換することから始まります。
**新しい人と接続** には、方法が 1 つずつ表示されます。

- **招待** — **招待を作成** してコピーし、相手に送ります。接続は
  **対応が必要** で待機します。相手が返答したら、その返答をそこに
  貼り付けて **接続を完了** をクリックします。
- **招待を貼り付け** — 受け取る側です。送られてきた招待を貼り付けて
  **接続** をクリックし、表示される返答を送り返します。
- **IDで探す** — あなたや他の人が公開した候補の中から、相手の完全な
  アイデンティティ ID で検索し、**接続** します。あなたの返答は
  ランデブーサーバーを通って戻るので、接続は自動で完了します。返答を
  手でコピーするのは、それができないとき（アイデンティティがロック
  されている、または候補が保存した招待から来たもの）だけです。下に
  折りたたまれている **後で使うために招待を保存** は、接続せずに招待を
  この検索結果に追加します。
- **見つけてもらえるようにする**（同じタブの **他の人に見つけてもらう**
  の下） — あなた自身のアイデンティティをランデブーネットワークに公開
  するので、あなたのアイデンティティ ID をすでに知っている人が、
  直接の招待なしにあなたを見つけて接続できます。1 回の公開は 1 回の
  接続の試みに応えます。また見つけてもらうには、もう一度オンにします。
  公開がまだ誰かの応答を待っている間、ボタンは
  **見つけてもらえないようにする** になり、誰かが接続するか、申し出が
  閉じるか招待の期限が切れると、自動で **見つけてもらえるようにする**
  に戻ります。公開するには、アイデンティティのロックを解除している
  必要があります。ランデブーサーバーは、そこに書かれたアイデンティティ
  自身が署名した公開しか受け付けないので、ほかの誰かがあなたの代わりに
  公開したり取り下げたりすることはできません。既定のランデブー
  サーバーは公開されている ForkBuild のサイトにしか応答しません。自分の
  アドレス（`localhost` を含む）から ForkBuild を動かしている場合は、
  招待を使うか、**ネットワーク設定** の **ランデブーサーバー** で自分の
  サーバーを追加してください。この状態はアプリ全体で保持されるので、
  ピアページを離れて戻ってきてもリセットされません。
- **公開ロビー** — ID を知らない人と出会います。下記を参照してください。

ページ上部の **あなたのID** と **完全なIDをコピー** が、相手が
**IDで探す** に必要なものです。行に表示される短縮形の
`…末尾14文字` は、ひと目で人を見分けるためだけのもので、実際の検索に
一致することはありません。

どの方法でも、接続は同じ段階を経ます。
**ランデブーで発見 → WebRTC接続中 → ピア接続済み →
アイデンティティを認証中 → 認証済み**（または **失敗**）です。接続中の人の
**⋯** メニューの **接続の詳細** には、相手のアイデンティティ、公開鍵、
そして既知のピアや友達の記録は残っても、*接続* 自体はこのセッション
だけのものだという注意が表示されます。「オンライン時間」と「…前に
開始」のタイマーは、その接続が実際に確立したときから数えるので、
ページを離れて戻ってきても正しく数え続けます。

## 公開ロビー: まだ知らない人と出会う

IDで探すには、相手の完全なアイデンティティ ID が必要です。
**公開ロビー** は、ID を知らない人と出会うための場所です。全員共通の
ロビーが **ピア** ページの **新しい人と接続 → 公開ロビー** に 1 つ、
そしてワールドごとのロビーがワールドビューの **ロビー** にあります。

- **ロビーに参加** すると、あなたが選んだ表示名で、アイデンティティ ID の
  末尾と並んでそこに表示されます。名前は誰でも自由に付けられます。
  接続が実際に確認するのはアイデンティティです。名前は次回のために
  記憶されます。
- ロビーにいる間、このデバイスは見つけてもらえる状態のままです。
  ロビーにいる誰でもあなたの **接続** をクリックでき、誰かが接続すると、
  すぐに次の人を受け入れる準備をします。
- 一覧の誰かの **接続** は、IDで探すと同じ方法で、何もコピーせずに
  接続します。相手のカードには **接続中…** と表示され、ハンドシェイクで
  相手が誰かが証明されると **接続済み** になります。ロビーで誰かを
  見かけただけで、自動で接続することはありません。ただし、参加すると、
  今見つけてもらえる状態の既知のピアには、どこにいても接続します
  （[再接続](#再接続) を参照）。
- **ブロック** は、その人をロビーの一覧から隠し、このページのほかの
  場所と同じようにブロックします。
- **ロビーから退出** で、すぐに抜けます。参加はこの訪問の間だけ有効
  です。アプリを閉じるとすべてのロビーから抜け（他の人の一覧から
  あなたが消えるまで最大 10 分かかることがあります）、次に開いたときに
  ロビーに戻されることはありません。

**ロビーから接続してきた人が得るもの。** ロビーでの接続は、あなたが
相手を記憶したり友達になったりする前から、通常の接続中のピアです。
相手はあなたの IP アドレスを知り、公開範囲の設定が許す範囲であなたの
アバターと在席状況を見ます。そして、ほかの接続中のピアとまったく同じ
ように、あなたたちのデバイスは **スナップショットと地名の告知、公開物の
メタデータを交換します**（[プライバシー](Privacy.md) を参照）。チャット
と音声には、引き続き友達関係が必要です。ピアと共有したワールドは
その人にも提供されますが、相手のデバイスが取得するのは、相手が
**取得** をクリックしたときだけです
（[接続中のピアと共有する](04-PublishingAndForking.md#接続中のピアと共有する) を参照）。
友達と既知のピアが共有したワールドは自動で取得されますが、ロビーで
会った見知らぬ人のものが自動で取得されることはありません。

**リレーは必要なときだけ。** どの接続もまず直接の経路を試し、直接の
経路がどれもうまくいかないときだけ、ランデブーサーバーの TURN リレーを
使います。ロビーで待っている間、あなたのデバイスはリレーの認証情報を
求めません。あなたに接続してくる人が、必要な場合にだけ求めます。
こうして、リレーの毎月の割り当てを、実際に行われる接続のために残して
おきます。

ロビーには、ランデブーサーバー（**ネットワーク設定** の
**ランデブーサーバー** を参照）と、ロックを解除したアイデンティティが
必要です。

## 記憶する、友達になる、ブロックする

- 誰かを **記憶する**（その人の **⋯** メニュー）と、その人について
  個人的なローカルのメモを残せます。相手の同意は必要ありません。
  **名前を変更** は、あなたにだけ見える名前を付けます。記憶していない
  人には、**名前を付けて記憶** で両方を一度に行えます。**忘れる** は、
  メモをローカルでだけ削除します。
- 接続中の人の行の **友達に追加** は、相互の関係を申し込みます。相手には
  **対応が必要** に **承認** / **拒否** 付きで表示され、待っている間は
  **⋯** メニューから **友達リクエストを取り消す** ことができます。
  **友達をやめる** で関係を終えます。相手が受け取る必要があるので、
  相手が接続している必要があります。友達には **チャット** ボタンが
  表示されます — [チャットと会話](08-ChatAndConversations.md) を参照
  してください。
- **ブロック** は、そのアイデンティティからのすべて（在席状況、
  プロフィール、チャット、友達リクエストまで）を、相手に知らせずに
  止めます。友達をブロックしても友達関係は削除されず、黙らせるだけです。
  **ブロック解除**（**⋯** メニューか **ブロック中** の一覧）で再び相手の
  声が届くようになりますが、ブロック中に止められていたものが戻ることは
  ありません。

## 人をフォローする

**フォロー** すると、SNS でアカウントをフォローするように、誰かの作品の
最新情報を受け取れます。どちらも相手に何かを頼む必要はありません。

- **フォローする場所。** **フォロー** は、リポジトリの公開物のカード、
  作者ページの **署名者: …** の横、このページの人の **⋯** メニューに
  あり、ワールドビューのアバターでは **作品をフォロー** として表示され
  ます。フォローするのは *アイデンティティ* で、入力された作者名では
  ありません。同じ名前で公開する人が何人もいる可能性があるので、作者
  ページには、その名前で作品に署名したアイデンティティごとに 1 つずつ
  **フォロー** が表示されます。
- **フォロー中ページ**（上部のバーの **フォロー中**）には、フォロー
  している人がそれぞれ **フォロー解除** 付きで表示され、その下に、
  このデバイスに届いたその人たちの新しい作品が新しい順に並びます。
  名前をクリックすると、その人の作品だけが表示されます。
- **通知。** フォローしている人の新しい作品がこのデバイスに届くと、
  🔔 パネルに **Publication followed author published**（フォローして
  いる作者が公開しました）の項目が、作品ごとに 1 回、開くための
  **探索** 付きで追加されます。
- **共有したワールドは自動で取得されます。** フォローしている人が接続中の
  ピアと共有したワールドは、友達や記憶したピアのものと同じように、
  自動で取得されます。
- **告知が長く保持されます。** このデバイスは、見た告知の記録を、発見用
  タグごとに上限まで保持します。タグがいっぱいになると、最も長く見て
  いない記録から削除されますが、フォローしている人が署名した作品の
  配置と地名は、ほかより優先して残されます。

**フォローは非公開で一方向です。** 一覧はこのデバイスに、サインインして
いるアイデンティティごとに保存されます。どこにも送られず、フォロー
している人に知らされることもなく、フォロワー数もありません。サーバーが
なければ、誰も正直に数えられないからです。フォローしても相手には何も
与えられません。チャットも、あなたのアバターを見ることも、あなたに
連絡する手段もありません。それは引き続き友達関係の役割です。

**フォローがしないこと。** フォローは、このデバイスに届いたものの中から
フォローしている人の作品を拾い出すだけで、自分から作品を取りに行くことは
ありません。作品は普段どおりの経路で届きます。ワールドビューでの
ワールドの発見、接続中のピアが共有したワールド、あなたが開くリンク
です。署名が確認できた作品だけが対象なので、誰かが作品に他人の名前や
アイデンティティを書き込んでも、あなたのフォロー中ページに入り込む
ことはできません。**ブロック** した人の作品は、フォローしていても
隠されたままです。

## TURN: 直接の経路が見つからないピア接続を中継する

どのピア接続も、まず 2 つのブラウザーの間で直接の経路を交渉すること
から始まり、ForkBuild の既定の公開 STUN サーバーが、それぞれの側が
自分に到達できるアドレスを見つけるのを手伝います。ほとんどの接続は
これで十分ですが、一部のネットワーク（対称型 NAT、制限の厳しい社内
ファイアウォール）では、STUN だけで見つけられる経路が決して現れません。
ランデブーサーバーが TURN リレーを提供している場合、ForkBuild は接続を
始めるときに（アプリを開いただけでは決して求めません）短期間有効な
リレーの認証情報をそこに求め、自動で使います。サーバーが毎月配る
リレーの認証情報の数には限りがあり、使い切ると、翌月まではリレーなしで
接続を試みます。自分のリレーを使うには、上部のバーの
**ネットワーク設定** から **TURNサーバー** を開き
（`/settings/turn-server`）、自分の TURN リレーを設定します。直接の
経路を確立できないときに、接続のデータを実際に転送するサーバーです。

```
TURNサーバー

直接の経路やSTUNでネゴシエーションした経路を確立できないピア接続に使う、
自分のTURNリレーです。この設定は接続の確立にのみ影響し、ピアのアイデン
ティティ、認証、既存の接続は変わりません。

リレーを使うためにここを入力する必要はありません: 接続を始めるとき、
ForkBuildはランデブーサーバー（「ランデブーサーバー」を参照）に短期間の
TURNリレーを求め、提供されればそれを使います。自分でリレーを運用して
いるか料金を払っている場合にのみ、ここに追加してください。追加した
リレーはランデブーサーバーのものと併用され、置き換えることはありません。

[ 1行に1つの turn:/turns: のURL（例: turn:relay.example:3478） ]

ユーザー名 [______________]
認証情報   [______________]

[保存]   [クリア]
```

`turn:`/`turns:` の URL を 1 つ以上（1 行に 1 つ）、**ユーザー名**、
**認証情報** を入力して **保存** をクリックします。同じ認証情報の組が、
書いたすべての URL に送られます。サーバーごとに別々の認証情報は使え
ません。設定すると、現在のリレーが「現在のTURNリレー（URL *N* 件）:
`<あなたの URL>` — ユーザー名: `<あなたのユーザー名>`」と表示されます。
認証情報そのものは、保存後に表示されることはなく、設定されていることが
わかるだけです。**クリア** で完全に削除します。

**ここにはあえて「既定に戻す」ボタンがありません。** 既定のリレーは、
上で説明したようにランデブーサーバーから来るので、このページには
戻すべき組み込みの値がありません。ここに TURN サーバーを組み込むと、
その認証情報を誰でも読んで使えるようにアプリに公開することになります。
ページを空のままにしても、ランデブーサーバーがリレーを提供していれば
それを使えます。どちらからもリレーがなければ、接続は STUN と直接の
接続だけに頼ります。自分のリレーは任意で、それでも特定のピアとの接続が
失敗し続ける場合にだけ、自分で用意するもの（多くの WebRTC ホスティング
業者が提供しています）です。ほかのネットワーク設定のページと同じく、
ここでの変更は次にアプリを読み込んだときに反映されます。

## 再接続

オンラインでない既知のピアや友達には、記憶していない友達であっても、
**再接続** ボタンが表示されます。これは **招待** / **招待を貼り付け** と
同じ招待のやり取りをその行で開き、古い接続情報を使い回さず、常に完全に
新しいハンドシェイクを行います。再接続の試みが予想と *異なる*
アイデンティティとして認証された場合、ForkBuild は応答した相手を黙って
信頼するのではなく、明示的なエラーで拒否して接続を閉じます。

ForkBuild は、既知のピアにいるすべてのアイデンティティについて、これを
自動でも試みます。アプリの起動直後、既知のピアの関係を記憶・忘れるなど
で変更したとき、自分で **見つけてもらえるようにする** をクリック
するたび、そして **ロビーに参加** をクリックするたびに、それぞれが今
見つけてもらえる状態かを静かに確認し、そうであれば、あなたが再接続を
クリックしなくても接続します。そのため、二人の友達がどちらも
**見つけてもらえるようにする** をクリックするか、どちらもロビーに参加
すれば（同じロビーでなくてもかまいません）、2 回目のクリックが 1 回目を
見つけて接続します。ロビーに参加したままでいても、この確認が自動で
繰り返されることはありません。
今見つけてもらえる状態でない、または到達できない既知のピアは、その
ままにされます。追いかけて再試行し続けることも、試みについての通知も
なく、1 つのアイデンティティの失敗がほかに影響することもありません。
次の自動確認を待たずに今すぐ接続したいときは、**再接続** を使って
ください。
