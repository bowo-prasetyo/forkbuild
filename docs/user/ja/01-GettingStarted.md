までを、5 分ほどで案内します。

## ForkBuild を開く

ForkBuild は最新のウェブブラウザーならどれでも動きます。公開されている
URL を開くと **ホーム** 画面が表示されます。自分でコピーを動かすには、
フォルダーを HTTP で配信してください（たとえば
`python3 -m http.server 8000` を実行して <http://localhost:8000/> を
開きます）。`index.html` をディスクから直接開いても動きません。
ブラウザーは `file://` のページからモジュールを読み込まないためです。
既定のランデブーサーバーは公開サイトにしか応答しないので、自分のコピー
ではそれを使って人を見つけることはできません。代わりに招待で接続するか、
自分のランデブーサーバーを用意してください
（[ピア接続と友達](07-PeerConnectionsAndFriends.md)を参照）。

**ホーム** 画面では、小さな村が3Dでゆっくり回っていて、始め方が3つあります。
**今すぐ試す：家から始める** は、できあがった家を自分用のコピーとして
エディターで開き、すぐに変えられます。**ゼロから始める** は空き地の
エディターを開き、**作品を見る** はリポジトリを開きます。
**できあがった作品から始める** の各カード（城、港の島、村の広場、家、
製粉所、橋）も、同じようにその作品の自分用のコピーを開きます。
リポジトリ、マイワールド、エディターの **新規** でも同じ作品を選べます。
自分で選ぶまで、何も公開されず、どこにも送られません。
ホームには **今週の建築チャレンジ** も表示されます。作るテーマと
**チャレンジに参加** があります（[毎週の建築チャレンジ](04-PublishingAndForking.md#毎週の建築チャレンジ)を参照）。

作品を公開すると、ホームに **あなたのスタンプ** も表示されます。だれかに
リミックスされたときの **リミックスされた**、週替わりチャレンジに参加したときの
**チャレンジャー**、100 個以上のブロックを使った作品の **大きな建築家** など、
自分の作品についての事実です。このデバイスの記録から計算され、あなたにだけ
表示されます。ほまれであって、点数や順位ではありません。

上部のバーは常に表示されています。

`ForkBuild ホーム エディター リポジトリ チャレンジ マイワールド その他 ▾ 🔔 [ログイン]`

- **ホーム** — 最初に表示されるページ
- **エディター** — 作品を作る場所
- **リポジトリ** — みんなが公開した作品を見る
- **チャレンジ** — 今週の建築チャレンジとその応募作品。
  [毎週の建築チャレンジ](04-PublishingAndForking.md#毎週の建築チャレンジ)を参照
- **マイワールド** — このデバイスで実際に訪れたワールド。
  [マイワールド](03-WorldView.md#マイワールド--実際に訪れたワールド)を参照

**その他** を開くと、残りのページが 4 つのグループで表示されます。**あなた**（マイアバター、
マイアイデンティティ、あなたのデータ）、**人**（ピア、フォロー中、会話）、
**詳細**（公開物、ネットワーク設定）、**アプリ**（言語、ForkBuildについて、ブラウザーがインストールできる場合は **ForkBuild をインストール**）です。
スマートフォンでは **メニュー** にすべてが一度に表示されます。

- **マイアバター** — ワールドビューで他の人からどう見えるか。
  [アバターと在席状況](06-AvatarsAndPresence.md)を参照
- **マイアイデンティティ** — このデバイスに保存されている暗号学的な
  アイデンティティ。[アイデンティティとログイン](05-IdentityAndLogin.md)を参照
- **ピア** — 接続中の人、記憶している人、友達。
  [ピア接続と友達](07-PeerConnectionsAndFriends.md)を参照
- **会話** — 直接メッセージ。
  [チャットと会話](08-ChatAndConversations.md)を参照
- **公開物** — 署名された作者情報や地名のクレーム、それらを保存・告知する
  場所、そして（*試験的*）外部証拠。
  [公開物と外部証拠](09-PublicationsAndEvidence.md)を参照
- **ネットワーク設定** — ゲートウェイ、リレー、プロバイダー、ピア接続用の
  サーバー。[ネットワーク設定](10-NetworkSettings.md)を参照
- **言語** — このデバイスで ForkBuild が表示する言語。自分で選ぶまでは
  ブラウザーの言語設定に従います。保存するとページが再読み込みされる
  ので、先に作業を保存してください。ForkBuild は英語、ドイツ語、
  スペイン語、フランス語、インドネシア語、日本語、韓国語、ブラジルポルトガル語で使えます（[Translating ForkBuild](../../Translating.md)（英語）を参照）。
- **ForkBuildについて** — バージョン情報

## ForkBuild をインストールする

ForkBuild はアプリとしてインストールできます。インストールすると、
ホーム画面、Dock、アプリ一覧から専用のウィンドウで開き、オフラインでも
動きます。ホーム画面（または **その他** の中）の **ForkBuild を
インストール** をクリックし、ブラウザーのダイアログで確定してください。
iPhone や iPad の Safari では、ボタンが代わりに方法を案内します。
**共有** をタップし、**ホーム画面に追加** を選んでください。ブラウザーが
アプリをインストールできない場合や、ForkBuild がすでにインストール
済みの場合、ボタンは表示されません。

- **オフライン。** 最初に ForkBuild を開いたとき、ブラウザーがその
  ファイルを保持するので、インストールしていてもいなくても、次からは
  接続なしで開けます。ホーム、エディター、保存した作品、既製の作品が
  使えます。ネットワークが必要なもの（作品や人を見つける、配信、
  チャット、通話）は、オンラインに戻るまで待ちます。
- **アップデート。** 新しいバージョンが出ると、上部に **ForkBuild の
  新しいバージョンの準備ができました** と表示されます。**再読み込み** で
  開始するか、次に ForkBuild を開いたときに自動で開始します。
- **通知。** インストールした ForkBuild（またはバックグラウンドのタブで
  開いている ForkBuild）は、デバイスを通じて通知を表示できます。
  [このデバイスでの通知](03-WorldView.md#このデバイスでの通知) を参照してください。

これはホストされたサイトの場合です。フォルダーから直接動かすコピー
（上記）はインストールもオフライン動作もできません。
`node scripts/build.mjs` でビルドしたコピーはできます
（[デプロイ](../../Deployment.md) を参照）。

## ログインする

作品を作り始めるのにログインは要りません。はじめて **公開** をクリック
すると、公開は作品に署名するので、ForkBuild が公開に使う名前をたずねます。
名前を入力して **…として公開** をクリックすると、その名前のアイデンティティ
がこのデバイスに作成され、作品が公開されます。鍵は、パスフレーズを付ける
まではパスフレーズなしでこのブラウザーに保存されます。公開のあとにエディター
がそう知らせ、**マイアイデンティティ** の **パスフレーズで保護** でいつでも
付けられます。最初からパスフレーズを決めたいときは、**今パスフレーズで守る**
をクリックしてください。一緒に歩くリンクも同じように **…として歩く** で
たずねます。

いつでも自分でログインすることも
できます。
右上の **ログイン** をクリックします。ForkBuild はパスワードも中央の
アカウントも使いません。代わりに、**あなたのアイデンティティは、この
デバイスに保存された暗号学的な鍵ペアです**。ログインのダイアログには、
このブラウザーがすでに持っているアイデンティティがすべて表示されます。
使うものをクリックするか、新しく作成します。

1. **表示名** を入力します。これが他の人に見える名前です。
2. 8 文字以上の **パスフレーズ** を 2 回入力します。パスフレーズはこの
   デバイス上で鍵を暗号化します。リセットはできないので、忘れないものを
   選んでください。（省略するには **パスフレーズなしで作成** にチェックを
   入れます。その場合、鍵は暗号化されずにこのブラウザーに保存されます。）
3. **作成してログイン** をクリックします。

これでサインインできました。作ったもの、公開したもの、送ったものは
すべて、このアイデンティティで署名されます。

パスフレーズが何を守るのか、ロックとロック解除、アイデンティティの
バックアップについては、
[アイデンティティとログイン](05-IdentityAndLogin.md)で説明しています。

## ひと回りしてみる

ForkBuild には主に次の場所があります。

| 場所 | 用途 |
|---|---|
| **エディター** | 自分の作品を作り、編集する |
| **リポジトリ** | 公開された作品を検索、閲覧、開く、フォークする、探索する |
| **作者のページ** | ある人が作ったものをすべて見る（作者名をクリックすると開きます） |
| **ワールドビュー** | すべての作品が 3D 空間に存在する共有のワールドを飛び回り、検索や探索でものを見つける |
| **マイアバター / ピア / 会話** | 他の人からどう見えるか、誰と接続しているか、直接メッセージ。上のリンク先のガイドを参照 |

## 最初のブロックを置く

はじめてエディターを開くと、3D ビューの隅に **はじめての作品** カードが
表示され、5 つのステップを案内し、済んだものからチェックを付けます。
[はじめての作品](02-TheEditor.md#はじめての作品) をご覧ください。

1. 上部のバーで **エディター** をクリックします。
2. 左のサイドバーで **配置** ツールが選ばれていることを確認します
   （`2` を押します）。
3. その下の **ビルドライブラリ** で **ブロック** タブを開き、ブロックを
   クリックします。たとえば **基本** の **キューブ** です。
4. マウスを 3D ビューポートに動かします。ブロックの半透明の
   **ゴースト** がグリッドに沿ってついてきます。
5. **クリック** して置きます。

おめでとうございます。最初のブロックが置けました！🎉

### ブロックを積み上げる

地面の上だけに作る必要はありません。置いてあるブロックの **面** に
ポインターを合わせると、ゴーストがその面に吸い付きます。クリックすると
上に積んだり、横に付けたりできます。壁や塔や屋根はこうして作ります。

## 作業を保存する

**Ctrl+S** を押します（またはツールバーの **保存** をクリックします）。
**● 未保存の変更** の表示が **保存済み** に変わります。

作品はブラウザーに保存されるので、次に来たときもそこにあります。
編集中、ForkBuild は未保存の変更のクラッシュ復旧用コピーも保持していて、
保存する前にページが閉じた場合は復元を提案します。

ブラウザーは、各サイトが保存できる量を、通常はディスクの一定の割合に
制限しています。ForkBuild の割り当てがいっぱいになると、保存と
クラッシュ復旧はその旨のメッセージを出して止まります。開いているものが
失われることはありません。ツールバーの **エクスポート** を使って、
ドキュメントのコピーをファイルとして残してください。初めて保存すると
き、ブラウザーによっては ForkBuild がデータを永続的に保持してよいか
尋ねます。許可すると、ディスクの空きが少なくなったときにブラウザーが
データを消すことがなくなります。

作品を作るだけならログインは不要です。ログインが重要になるのは、公開
したり他の人と作業したりするときです。ログアウトした状態で公開した
作品には作者も署名もないので、ピアと共有したり、あとで配信したりする
ことができず、リンクもありません。公開すると、先にログインするよう
求められます。
