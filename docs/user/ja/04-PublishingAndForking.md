# 04 — 公開とフォーク

<!-- languages -->
[English](../04-PublishingAndForking.md) · [Deutsch](../de/04-PublishingAndForking.md) · [Español](../es/04-PublishingAndForking.md) · [Français](../fr/04-PublishingAndForking.md) · [Bahasa Indonesia](../id/04-PublishingAndForking.md) · **日本語** · [한국어](../ko/04-PublishingAndForking.md) · [Português (Brasil)](../pt-BR/04-PublishingAndForking.md)
<!-- /languages -->

ここが ForkBuild の中心です。**公開** は、あなたの作品を世界と共有
します。**フォーク** は、誰でも作品をコピーして発展させられるように
します。履歴はすべて保たれます。

## 作品を公開する

1. エディターで何かを作ります。
2. ログインし、アイデンティティのロックが解除されていることを確認します
   （[アイデンティティとログイン](05-IdentityAndLogin.md) を参照）。公開
   すると、作品にそのアイデンティティで署名されます。ログインして
   いない場合、**公開** は先にログインするか、アイデンティティを作成する
   よう求めます。そこで **署名せずに公開** を選ぶと、作者もリンクもない
   状態で公開されます。
3. タイトルを付けます（公開はタイトルのない作品や空の作品を拒否します）。
   必要なら説明とライセンスも付けます。サイドバーのドキュメント
   タイトルの横にある **✎** をクリックすると **ドキュメントのプロパティ**
   が開きます。新しいドキュメントにはライセンスがありません。初めて
   公開するとき、ほかの人のリミックスを許可するか ForkBuild が尋ねます
   （[ほかの人のリミックスを許可する](#ほかの人のリミックスを許可する) を参照）。
4. **保存** を押して保存します。
5. **公開** をクリックします。

作品はこのデバイスの **自分のリポジトリ** に表示され、あなたを作者と
して検索、開く、フォークができるようになります。ほかの人に見えるのは、
共有か配信をしたあとだけです（下の注を参照）。共有のワールドの中での
位置も自動で割り当てられるので、**探索** は常に誰かをどこかへ案内でき
ます — [ワールドを見つける](03-WorldView.md#ワールドを見つける)を参照
してください。

> **注:** 公開しても、ドキュメント/ワールドはこのデバイスにしか保存
> されません。リポジトリのカードには、このデバイスがそれをどこに配信
> したと記録しているか（たとえば **保存先: IPFS · 告知先: Nostr**）、
> または **このデバイスには配信の記録がありません。** と表示されます。
> それまでの間は、[あなたのデータ](13-YourData.md) でバックアップして
> コピーを残してください。
> 公開しただけで何かがどこかに送られることはありません。コピーした
> [リンク](#リンクを共有する) は、渡した相手に作品を届けます。別々の、任意の
> 2 つの操作がそれを行います。後で説明する **配信** は、公開物を
> Arweave や IPFS に送り、Nostr や Arweave で告知するので、あなたと
> 接続していない人でも見つけられるようになります。そして
> [**ピアと共有**](#接続中のピアと共有する) は、接続している人に
> 公開物を提供します。

## リンクを共有する

**公開** が成功するとすぐ、エディターのお知らせには **共有…**（デバイスに
共有メニューがある場合）、**リンクをコピー**、**画像を保存**、**埋め込み** も表示され、
その下にリンクが表示されます。同じボタンはワールドビューの
**自分の共有ワールド** にもあります。

- **作品はリンクの中に入っています。** 先に配信する必要はなく、ウォレットも
  アカウントも使いません。リンクは署名済みの共有ワールドと作品
  そのものを運びます。リンクを開いた人は、どのデバイスでも、あなたの
  作品にたどり着きます（[リンクを開くと表示されるもの](#リンクを開くと表示されるもの) を参照）。ForkBuild は何かを表示する前に、署名と、作品がそれに一致することを
  確かめます。変更されたリンクや途中で切れたリンクは、そう表示されます。
- **リンクが中身を見せます。** チャットアプリ、メール、投稿に貼り付けると、
  リンクには作品のタイトル、あなたの名前、作品の画像が表示されます。画像は
  ForkBuild のリンクサーバーが描き、リンクを開いた人を ForkBuild へ案内
  します。変更されたリンクには「A shared build」とだけ表示されます。
- **署名が必要です。** ログインした状態で公開してください。ログアウトした
  状態で公開した作品にはリンクがありません。
- **サイズ。** 約 500 ブロックまでの作品が入ります。用意されたお城のリンクは
  約 3,700 文字です。メールや多くのチャットアプリ、SNS はこの長さのリンクを
  そのまま扱えますが、Discord と Telegram はメッセージの長さに制限があり
  ます。それより大きい作品は、リンクには大きすぎると表示されます。配信
  すればリンクを得られます。
- **配信した後は**、共有ワールドの保存場所を示す短いリンクがボタンから
  提供され、配置も一緒に運ばれます（[配信](Distribution.md) を参照）。作品を
  中に持つリンクは配置を運ばないので、ワールドビューは配置のない作品を
  置く場所に作品を置きます。
- **画像を保存** は、作品の 1200 × 630 の PNG をダウンロードします。下部に
  タイトルと「ForkBuildでリミックスしよう」が入っていて、リンクだけでは
  画像が表示されない場所に投稿できます。

リンクのコピーや共有、リンクを開くことは、1 日の訪問と同じように匿名で
数えられます。[1日の訪問者数](13-YourData.md#1日の訪問者数) をご覧ください。

### リンクを開くと表示されるもの

作品へのリンクは、作品そのものを運ぶものでも、保存場所を示すもので
も、その作品専用のページを開きます。

- ゆっくり回転する作品
- タイトルと作者
- リミックスなら **…の「…」のリミックス**、このデバイスがその
  リミックスを見つけていれば **N回リミックスされました**
  （[リミックスの回数](#リミックスの回数) を参照）
- 大きなボタンの **コピーを編集**: 自分用のコピーがエディターで開き、
  すぐに変更できます。アカウントは不要です。コピーは元の作品を記録する
  ので作者のクレジットも残り、**ワールドに戻る** で元の作品に移れます。
- **ワールドで見て回る**: ワールドビューで作品を見ます。

ライセンスがコピーを認めていれば、ページには **3D モデルとして
ダウンロード**（glTF、3D プリント用の STL、OBJ。[3D モデルをダウンロードする](02-TheEditor.md#3d-モデルをダウンロードする) を
参照）も表示されます。作品のライセンスがコピーを許可していない場合、ページはそう伝え、見て
回ることだけを提案します。

### 作品をウェブページに埋め込む

リンクに作品が入っている場合、その作品はブログ記事やウェブページの中にも表示
できます。読者はページを離れずに、回る作品を見られます。

1. リンクの下で **埋め込み** を選びます。貼り付けるコードがその下に表示されます。
2. **埋め込みコードをコピー** を選び、ページの HTML や埋め込み（`<iframe>`）
   を受け付ける場所に貼り付けます。

ページの上で作品はゆっくり回り、横にドラッグすると手で回せます。下部には
タイトルと作者、そして **ForkBuildでリミックス**（ライセンスがコピーを許して
いない場合は **ForkBuildで開く**）が並び、これを選ぶと新しいタブの ForkBuild
で作品のページが開きます（[リンクを開くと表示されるもの](#リンクを開くと表示されるもの)
を参照）。

- **作品はコードの中に入っています。** リンクと同じく、何も配信する必要は
  なく、埋め込みは表示する前に署名と作品を確認します。
- **静かに動きます。** 埋め込みは ForkBuild の接続をひとつも始めず、読者の
  ブラウザーに何も保存しません。[プライバシー](Privacy.md) を参照してください。
- **リンクを自分で埋め込むサイト**（Notion や Ghost など oEmbed に対応した
  サイト）には、代わりに **リンクをコピー** のリンクを渡せます。サイトが
  ForkBuild のリンクサーバーに埋め込みを問い合わせます。
- **`<iframe>` のコードを取り除くサイト**（ほとんどの SNS）では表示できません。
  そこではリンクか画像を共有してください。

埋め込みコードのコピーと、埋め込みの表示や ForkBuild で開かれたことも、匿名で
カウントされます。

## エディターから直接配信する

**公開** が成功すると、エディターのその場に「共有ワールドを公開しました。」
という小さなお知らせが表示され、横に **配信** ボタンと、何もせずに
閉じるための **閉じる** があります。**配信** をクリックすると、たまに
しか使わない選択肢や結果でオーバーレイを散らかす代わりに、**配信**
ダイアログが開きます。ダイアログを閉じても（**閉じる**、外側をクリック、
または Escape）、そこで作られたものは失われません。もう一度開くと、
閉じたときとまったく同じ結果、エラー、または進行中の状態が表示され
ます。

このダイアログはワールドビューと同じものです。**ストレージ** と
**告知 / 発見の基盤** の設定、まとめて行う **配信** ボタン、そして別々の
**スナップショットのみ配信** / **署名済みクレームのみ配信** ボタンは、
すべて
[ワールドでの出会い](03-WorldView.md#ワールドでの出会い--ピアが共有している公開物とアバター)
で説明しているとおりに動きます。ここでは 2 つの点が違います。常に、
直前の公開のクリックで作られたその共有ワールドを対象にすること、そして
**スナップショット** のセクションが先に来るので、まとめて行うボタンは
スナップショットを先に、次に署名済みクレームを実行することです。

署名済みクレームの結果は、専用のセクションに表示されます。

| 項目 | 意味 |
|---|---|
| **共有ワールド** | 共有ワールド自体の ID — この結果がどの共有ワールドについてのものかを確認できます。 |
| **データ** | アップロードでできた場所。完了しなかった場合は「未アップロード」。 |
| **発見** | 告知の ID。完了しなかった場合は「未告知」。複数のリレーを設定していると、リレーごとに 1 行になります。 |
| **リポジトリ** | ワールドビューでこの公開物のページに直接移動する **探索** ボタン — 公開物に探索できる場所があるときに表示され、実際には常に表示されます。 |

**大きな作品。** Arweave のストレージに入るスナップショットは最大
256 KB、およそ 8,000 個のブロックです。それより大きいものには、サイズの
制限がない IPFS のストレージ（ローカルの IPFS ノードかリモート
ピン留め）を選んでください。それでも Arweave を選ぶと、スナップショット
のセクションに作品の大きさが表示され、IPFS を選ぶよう求められ、何も
アップロードされません。接続しているピアは、64 MB までの作品なら、
ストレージなしであなたから直接取得できます。

スナップショット自体の結果（**コンテンツハッシュ**、**ロケーター**、
**告知** の ID、または告知なしで成功した配置では「告知なし」）は、
まったく別のものです。スナップショットは、署名済みクレームの配信とは
独立して配置・発見されるからです。この区別の意味は
[ローカルスナップショット](09-PublicationsAndEvidence.md#ローカルのスナップショット)
を参照してください。

このアプリのほかの配信ボタンと同じく、配信には署名用のブラウザー拡張
機能が必要です。Arweave のウォレット（Wander など）か Nostr の拡張機能
（nos2x など）です。どちらもないと、「…を完了できませんでした。」という
お知らせで終わります。公開自体が勝手に何かを配信することはありません。
配信は、あとで別にはっきりクリックしたときにだけ行われます。もう一度
公開すると、オーバーレイ全体が新しい公開物のための新しいものに置き換わり
ます。閉じたりページを離れたりすると消え、お知らせもどちらのセクションの
結果も、どこにも記憶されません。

## 接続中のピアと共有する

公開したワールドが表示されるのは、Nostr、Arweave、Steem、Blurt で配信する
（[配信](Distribution.md) を参照）までは *あなたの* リポジトリだけです。
配信すると、誰のリポジトリでも見つかるようになります
（[ほかの人が配信した作品](#ほかの人が配信した作品) を参照）。接続
している人（[ピア接続と友達](07-PeerConnectionsAndFriends.md) を参照）の
リポジトリに入れるには、リポジトリでそのワールドの下にある
**ピアと共有** をクリックします。このボタンは、自分が公開したワールドに
だけ表示されます。

- 共有すると、今接続している全員と、あとから接続する全員にワールドが
  提供されます。**共有済み ✓ · もう一度共有** は、今接続している人に
  もう一度知らせます。
- 相手の側では、**友達** か **既知のピア** が共有したワールドは、
  **探索** に必要なものすべてと一緒に、自動でリポジトリに追加されます。
  それ以外の人が共有したワールドは、相手が **取得** をクリックするまで、
  リポジトリの一番上の **あなたと共有されたもの** で待ちます。誰の
  デバイスも、頼まれないのに見知らぬ人のワールドをダウンロードする
  ことはありません。それぞれタイトル付きで表示されるので、相手は選ぶ
  ことができます。相手のデバイスは、取得したワールドがそのタイトルの
  ワールドであることを確かめます。タイトルが含まれるようになる前に
  共有したワールドは、あなたが **もう一度共有** をクリックするまで
  「…さんが共有したワールド」と表示されます。
- ワールドはあなたからだけ、あなたが接続している間だけ取得されます。
  あなたがオフラインなら、**取得** はあなたが戻るまで待ち、友達や既知の
  ピアは、あなたが再接続するとすぐに受け取ります。相手のデバイスは、
  追加する前にワールドがあなたの署名付きであることを確認するので、
  誰もコピーを自分のものと偽ることはできません。
- ほかの公開と同じく、すでに受け取った人から共有を取り消すことは
  できません。

## ライセンスを選ぶ

### ほかの人のリミックスを許可する

ライセンスのない作品を初めて公開するとき、ForkBuild は何かを公開する
前に **ほかの人のリミックスを許可しますか？** と尋ねます。

- **はい、リミックスを許可する** を選ぶと **CC BY 4.0** になります。
  クレジットを表示すれば誰でもコピーして変更でき、各リミックスには
  あなたの作品が元であることが表示されます。
- **いいえ、見るだけにする** を選ぶと **All Rights Reserved** になります。
  周りを歩いて見ることはできますが、コピーはできません。
- **今はしない** を選ぶと何も公開されません。

答えは作品のライセンスとして保存されるので、尋ねられるのは一度だけです。
**ドキュメントのプロパティ** でいつでも変更できます。フォークは元の作品の
ライセンスを引き継ぐので、フォークを公開するときには尋ねられません。

### すべてのライセンス

公開した作品には、**ドキュメントのプロパティ** のダイアログで選んだ
ライセンスが常に表示されます。

| ライセンス | 意味 |
|---|---|
| **CC0 1.0 — パブリックドメイン** | 権利を一切留保しません — 誰でも何をしてもかまいません |
| **CC BY 4.0 — 表示** | あなたのクレジットを表示すれば、誰でもフォークして再利用できます |
| **CC BY-SA 4.0 — 表示・継承** | フォークにも同じライセンスを引き継ぐ必要があります |
| **CC BY-NC 4.0 — 表示・非営利** | フォークはできますが、商用利用はできません |
| **CC BY-ND 4.0 — 表示・改変禁止** | 見ることはできますが、**フォークはできません** |
| **All Rights Reserved（無断転載禁止）** | 見ることはできますが、フォークはできません |
| **ライセンス指定なし** | ライセンスを設定するまでフォークはできません |

ライセンスを付けないままにしても、ほかの人は作品を開いて探索できます。
ただ、フォークを許可するライセンスを選ぶまで、フォークはできません。

## 誰が配置できるかを選ぶ

ほかの人は通常、あなたが公開した作品を自分のワールドに配置できます。
それはあなたの作品の配置を追加するもので、コピーではなく、あなたの
作品を動かしたり変えたりすることもありません
（[なぜ他の人の作品を配置できるの？](03-WorldView.md#なぜ他の人の作品を配置できるの)
を参照）。フォークは別のもので、ライセンスで決まります
（[配置とフォークの違い](03-WorldView.md#配置とフォークの違い)を参照）。
配置してほしくない場合は、**ドキュメントのプロパティ** を開いて
**ワールドに配置できる人** を設定します。

| 設定 | 意味 |
|---|---|
| **誰でも配置できる** | 既定です。誰でも、自分のワールドの好きな場所に配置できます |
| **自分だけが配置できる** | 配置できるのはあなただけです。ほかの人も見つけたり見たり、（ライセンスが許せば）フォークしたりはできますが、ForkBuild は配置させません |

この設定は公開するときに公開物の一部として署名されるので、あとから
誰も削除したり変更したりできません。つまり、選んだあとに公開したもの
にだけ適用されます。すでに出ている公開物は公開時の設定のままなので、
新しい設定を適用したい場合はもう一度公開してください。

これはライセンスのフォークの許可と同じ仕組みです。どの ForkBuild も
これを守りますが、鍵ではありません。アプリのコードを変えた人は無視
できますし、あなたが選ぶ前に誰かが行った配置を取り消すこともできません。

どちらの場合でも、ワールドビューから、または公開直後にエディターからスナップショットを **配信** すると、
ほかの人には *あなたが* 置いた場所に作品が見えます。告知にはあなたの
署名付きの配置が含まれていて、相手の ForkBuild があなたの共有ワールドを
知った時点で、作品がそこに表示されます。動かしてもう一度配信すると、
相手の側でも動きます。

## 公開した作品を編集する

公開した作品は **変更できません**。あとから変わることは決してありません。
続きを作るには、**フォーク**（下記）するか、ワールドビューで
**コピーを編集** を使います。ワールドビューでは、公開されたワールドに
初めて変更を加えると（メタデータ、ランドマークや地域名、動物の飾り）、
*「&lt;元の名前&gt;のフォーク」* というタイトルの自分のコピーが自動で
作られ、短い確認（「編集可能なあなた専用のコピーを作成しました — 「…」は
変更されていません」）が表示されます。
[ここでも保存と公開](03-WorldView.md#ここでも保存と公開)
を参照してください。

コピーをどれだけ変えても、元の作品には一切触れません。

## リポジトリ

**リポジトリ** は、このデバイスが知っているすべての公開作品の、検索
できるカタログです。自分のもの、ピアが共有してくれたもの、分散型
ネットワークで見つけたものが含まれます。作品が 10 個でも 1 万個でも
使いやすいように作られています。

### できあがった作品

いちばん上の **できあがった作品から始める** には、ForkBuild に付属する
作品（城、港の島、村の広場、家、製粉所、橋）が並びます。まだ何も公開
されていなくても、見つかっていなくても表示されます。どれか
（**リミックス**）をクリックすると、自分用のコピーがエディターで開きます。
自分で公開するまで、何も公開されません。見出しをクリックすると、この列を
たためます。

### ほかの人が配信した作品

リポジトリ（または作者ページ）を開くたびに、ほかの人が Nostr、Arweave、
Steem、Blurt に配信した作品を探し、検証できたものを追加します。リストの上の
1 行に、何をしているところか、そして見つかった新しい作品の数が表示
されます。**もう一度確認** でもう一度探します。

- 追加されるのは、署名付きの記録の確認に通った作品だけです。記録が
  示す鍵で署名されていて、告知された作品そのものであることが条件です。
  それ以外は飛ばされ、確認に失敗した記録はもう一度取得されません。
- 一度に確認する新しい作品は 20 個までです。それより多いときは、
  次回に残っている数がその 1 行に表示されます。
- こうして見つかった作品は、再読み込みしてもリポジトリに残ります。
- その作品のビルドはまだデバイスにありません。**探索** すると、保存
  場所から取得して確認してから、共有リンクを開いたときと同じように
  ワールドビューで開きます。

```
検索 [________________]  ☐ 説明も含める  [検索]

並べ替え: [公開が新しい順 ▾]   グループ: [なし ▾]   [カード] [リスト]

公開物 1,248件

┌─────────────────────────────────────────┐
│  [プレビュー]  Ancient City              │
│             A reconstruction of a        │
│             Roman city showing…          │
│             🔒 公開済み  by alice        │
│             8/16/2026 · CC BY 4.0        │
│             [開く] [フォーク] [探索]     │
└─────────────────────────────────────────┘

        [← 前へ]  1 2 3 4 5 … 125  [次へ →]
```

- **検索** は、既定ではタイトルと作者を対象にします。**説明も含める** に
  チェックを入れると説明の中も検索します。一覧に普段必要な以上のものを
  読むので、少し時間がかかることがあります。
- **並べ替え** には 5 つの順序があります。公開が新しい順、公開が古い順、
  タイトル A–Z、タイトル Z–A、作者 A–Z です。
- **グループ** は、今のページの結果を作者、日付、ライセンスでまとめます。
  見やすくするためだけのもので、見つかるものやページ数は変わりません。
- **カード** は見た目で眺めるのに向いています。**リスト** はコンパクトな
  表で、たくさんの結果をすばやく見ていくときに切り替えます。
- ページ送りは、終わりのないスクロールではなく、1 ページずつはっきり
  分かれています。なので「5 ページ目」は、あとで戻ってきても同じものを
  指します。

どの作品にも 3 つの操作があります。

| ボタン | 動作 |
|---|---|
| **開く** | そのドキュメントをエディターに読み込みます |
| **フォーク** | 編集できる自分の作品としてコピーします |
| **探索** | ワールドビューでそこへ飛びます |

（**マイワールド** の **探索を続ける** ボタン —
[マイワールド](03-WorldView.md#マイワールド--実際に訪れたワールド)
を参照 — は、ここの **探索** と同じことをします。初めて見つけたワールド
ではなく、すでに訪れたワールド向けの言い方になっているだけです。）

**作者の名前** をクリックすると、その人の **作者のページ** が開きます。
その人が作ったものすべて（オリジナルと、そこから育ったすべてのフォーク）
のポートフォリオで、リポジトリとまったく同じ検索・並べ替え・ページ送り
のカタログを、その作者だけに絞って使います。

署名が確認できたカードには **フォロー** ボタンもあり、作者のページには、
その名前で公開したアイデンティティごとに **署名者: …** と **フォロー**
が表示されます。誰かをフォローすると、その人の新しい作品が
**フォロー中** ページと通知に表示されます。
[人をフォローする](07-PeerConnectionsAndFriends.md#人をフォローする)
を参照してください。

リポジトリにあるのは、このデバイスから公開したものや直接見つけたもの
だけではありません。ワールドビューの
[ワールドでの出会い](03-WorldView.md#ワールドでの出会い--ピアが共有している公開物とアバター)
の地図でピアが見せてくれた分散型のリポジトリの作品も、その内容が実際に
解決されると、この検索とその作者のページに加わり、再読み込みしても
残ります。ここにあるほかのものと区別されずに表示されます。

## フォーク: 自分のものにする

**フォーク** こそが ForkBuild の特別なところです。作品をフォークすると、

- 自由に編集できる **まったく新しい、独立したコピー** が手に入ります。
- **元の作品には触れません** — あなたの変更が元に影響することは
  ありません。
- コピーは **どこから来たかを覚えている** ので、クレジットが失われる
  ことはありません。

Git でプロジェクトをフォークするのとまったく同じです。枝分かれして
自分のことをし、家系図が全員を記録します。（ワールドビューでは、公開
されたワールドを変更した瞬間に自動でも行われます。上の
[公開した作品を編集する](#公開した作品を編集する) を参照してください。）

> **ワールドビューでは「コピーを編集」とも呼ばれます。** どちらも内部では
> 同じ操作で、ライセンスのルールも
> [フォークできません](#フォークが完了できないとき) の扱いも同じです。
> ワールドビューでの手順は
> [コピーを編集](03-WorldView.md#コピーを編集--エディターに持ち込む)
> を参照してください。

### フォークのしかた

1. **リポジトリ**（またはワールドビュー）で作品を見つけます。
2. **フォーク** をクリックします。
3. コピーが *「&lt;元の名前&gt;のフォーク」* というタイトルでエディターに
   開きます。
4. 続きを作り、保存して、自分の作品として公開します。

公開したフォークには **…の「…」のリミックス** という表示が付き、元の作品に
リンクします。

### リミックスの回数

作品のページとリポジトリのカードには、その作品が何回リミックスされたか
（**3回リミックスされました**）が表示されます。これは、その作品から
フォークされて公開された別々の作品を、このデバイスがいくつ見つけたかです。
2回公開されたリミックスは1回と数え、誰もリミックスしていない作品には何も
表示されません。回数はこのデバイスが知っている分だけなので、別のデバイス
では違う数になることがあり、何を先に表示するかを決めることはありません。

このデバイスが、ほかの人によるあなたの作品のリミックスを見つけると、
🔔 に **…があなたの作品をリミックスしました** の項目がリミックスごとに
1 回追加されます（[このデバイスでの通知](03-WorldView.md#このデバイスでの通知) をオンにして
いれば、デバイスにも表示されます）。

### フォークが完了できないとき

フォークがうまくいかないことがたまにあります。多いのは、普通の
リポジトリの項目ではなく、ピアや分散型ネットワークで見つけた共有
ワールド（[公開物と外部証拠](09-PublicationsAndEvidence.md) を参照）を
フォークするときです。ForkBuild は、無関係な空のエディターの
ドキュメントにあなたを放り込む代わりに、何がうまくいかなかったかを
はっきり示す **フォークできません** ダイアログを表示します。

- **この共有ワールドは、そのライセンスによりフォークできません。** —
  フォークしようとしたものに付いているライセンスが、それを許可して
  いません（上の [ライセンスを選ぶ](#ライセンスを選ぶ) を参照）。
- **この共有ワールドのデータは現在利用できません。** — ライセンスは
  フォークを許可していますが、実際の内容がまだこのデバイスにありません
  （または接続中のピアから届きません）。

どちらの場合も、ダイアログの唯一のボタン **共有ワールドに戻る** で、
見つけた場所（配置されていたワールド、または共有ワールドそのもの）に
戻れます。作るものが何もないエディターに取り残されることはありません。

## 家系図

どのフォークも親を記録しているので、ForkBuild は作品の系譜全体を
描けます。**作者のページ** には **フォークの木** が表示されます。

```
Medieval House（オリジナル）
└─ Medieval Houseのフォーク（Bob）
   └─ …のフォークのフォーク（Carol）
```

つまり、すばらしい作品からバリエーションの生態系がまるごと生まれ、
つながりの中の全員にクレジットが与えられるのです。

## よくある作品づくりの流れ

全体の流れをひとつにまとめると、こうなります。

1. エディターで作品を **作り** ます。
2. **保存** します。
3. リポジトリに **公開** します。
4. 誰かがそれを、検索で、ワールドビューで近くを探索して、またはあなたの
   作者ページを眺めて **見つけ**、**フォーク** します。
5. その人がフォークを **公開** します。
6. ほかの人がワールドビューで両方を **探索** し、木が育っていきます。

これが、ForkBuild が目指すオープンな作品づくりの生態系です。
