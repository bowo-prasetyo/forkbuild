# 03 — ワールドビュー

<!-- languages -->
[English](../03-WorldView.md) · [Deutsch](../de/03-WorldView.md) · [Español](../es/03-WorldView.md) · [Français](../fr/03-WorldView.md) · [Bahasa Indonesia](../id/03-WorldView.md) · **日本語** · [한국어](../ko/03-WorldView.md) · [Português (Brasil)](../pt-BR/03-WorldView.md)
<!-- /languages -->

ワールドビューは、**公開されたすべての作品が並んで存在する** 共有の 3D
空間です。飛び回り、探しているものを検索し、ほかの人が近くに作った
ものを見つけ、そのブロックを調べられます。ワールドビューは読み取り専用の
探索の場で、作品を作るもう 1 つの場所ではありません。何かを変えたく
なったら、**コピーを編集** で独立したコピーをエディターに渡します。
ForkBuild で作品を作るのはエディターだけです。下の
[コピーを編集](#コピーを編集--エディターに持ち込む) を参照してください。

例外は、作品づくりではなく注釈だけです。ワールドの地域と
[ランドマーク](#ランドマーク--覚えておきたい場所に印を付ける) に名前を
付けることと、放した動物を **G** でワールドの飾りにすること
（[アバターと在席状況](06-AvatarsAndPresence.md#動物でワールドを飾る) を
参照）です。

## ワールドビューを開く

**リポジトリ** で作品の **探索** をクリックするか、ワールドの URL を
直接開きます。共有のワールドの中で、その作品の横に現れます。

## 飛び回る

- **左ドラッグ** — カメラを回転
- **右ドラッグ** — 平行移動
- **スクロール** — ズームイン・アウト
- **Home**（キー、またはパネルのボタン） — 自分のワールドに戻る（下記を
  参照）

移動すると、近くのワールドが自動で **読み込まれたり外れたり** します。
左のパネルは上から順に、今見ているもの（ヘッダー）、行ける場所（ホーム、
場所、探索 / 地図 / 地名のタブ）、周りにあるもの（近く）、そして自分の
道具（検索、アバター、自分の共有ワールド）です。一番下には次のものが
表示されます。

- **表示中のワールド** — 今周りに読み込まれているほかのワールド（読み
  込まれているのが今いるワールドだけのときは、ヘッダーにすでに名前が
  あるので隠れます）
- **近くのワールド** — クリックするとそこへまっすぐ飛びます

探索の **近く** セクションの一番上には、**ここを探索** と
**ここに何がある？** の 2 つのボタンもあります。下の
[ワールドを見つける](#ワールドを見つける) を参照してください。

ワールドにポインターを合わせると、ポインターの下にあるものがビューの
右下の小さなカードに表示されるので、マウスを動かしてもパネル自体が
動くことはありません。

地面そのものは、共有のシードから誰にとっても同じように生成されます。
草地、砂浜、岩場、森、農地、湖、曲がりくねった川、そして外海は、どれも
ランダムな配置ではなく、地形自体の高さと湿り気に従っています。原点の
周りの土地はいつも陸地です。千ユニットほど離れると海岸に着き、地面は
大陸棚を下って、深い濃い青色の海へと続きます。アバターは湖や海に歩いて
入ることができ、水が深くなるほど遅くなり、水深が背丈の半分を超えると
泳ぎ始めます（[泳ぐ・潜る](06-AvatarsAndPresence.md#泳ぐ潜る)を参照）。
潜ると青緑色の水中の景色に変わります。海藻が底で揺れ、小さな魚の群れが
開けた水の中を回っています。魚は誰にとっても同じ場所に同じようにいます。
これは景色で、編集できるところはなく、誰がいつ見てもまったく同じに
見えます。

森の地面には、同じシードから決まる木の種類の組み合わせがあります。
湿り気の多いところには針葉樹、乾いたところには広葉樹、草原の縁には
低木です。鹿（森）とウサギ（草原）も、同じくシードで決まる景色として
並んで現れます。木は置かれた場所から動きません。動物は置かれた場所の
周りをゆっくり歩き回り、そこから数歩以上離れることはなく、ときどき
止まったり向きを変えたりします。ウサギは跳ね、鹿は首を振りながら歩き
ます。立ち止まっている間は、頭を下げて草を食べたり、顔を上げて周りを
見回したりします（ウサギは後ろ足で立ち上がります）。近づくと、首を
向けてあなたを見ます。草を食べていた鹿は食べるのをやめて頭を上げ、
ウサギはそばまで来ると立ち上がります。ただし、真後ろからは見えません。
動物があなたのせいで逃げたり居場所を変えたりすることはありません。
反応はあなたの画面だけのもので、ほかの人の画面の動物はその人を見ます。
ウサギには長く立った耳と綿のような尻尾があり、鹿は耳を横に張り出し、
尻尾は短めです。動物の歩く道も同じシードと時刻から決まるので、同じ
瞬間に同じ場所を見ている人は、同じ動物を同じ場所に見ます。野生動物は、
どこへ歩いていっても、徒歩のあなたの道を木と同じようにふさぎます
（[アバターを歩かせる](06-AvatarsAndPresence.md#アバターを歩かせる) を
参照）。編集できるものはありません。

ワールドには **住人** もいます。そこに暮らし、家の周りを散歩し、建物は
通り抜けずに回り込み、近づくとあいさつしてくれる人たちです。話しかけると、
周りに何があるかを教えてくれます。野生動物と違い、住人はワールド自体の
内容の一部で、作者が追加します。
[住人](06-AvatarsAndPresence.md#住人) を参照してください。

## サウンド

ワールドビューでは、今いる場所に合った静かな環境音が流れます。高く
岩の多い場所では風、森では鳥のさえずり、畑や草原では虫の声、湖では
打ち寄せる水、川の横では流れる水の音です。周りの木は種類ごとに聞こえ
ます。広葉樹の林や低木では葉のざわめき、針葉樹では梢を渡る風の音で、
近いほど大きく聞こえます。ある種類の土地から別の種類へ歩いていくと、
すべてが移り変わります。

アバター自身も音を立てます。足音は歩きや走りに合わせて鳴り、足元に
よって変わります。草、森の落ち葉を踏む音、砂浜のやわらかい砂、高く
岩の多い場所の石、湖や川での水しぶき、ブロックの上でのうつろな音です。
ジャンプするとヒュッ、着地するとドスンと鳴り、高いところから落ちる
ほど重くなります。乗り物に乗ると、その音が聞こえます。自転車の
タイヤとラチェット、バイクのうなり、車の低い響き、ドローンの高い音で、
速くなるほど高まり、降りると消えていきます。乗り降りにも専用の音が
あり（自転車のベルとスタンド、バイクのキックスタート、車のドアと
エンジン始動、ドローンのローターの回転の上がり下がり）、速度が出て
いるときにブレーキをかけると、タイヤやブレーキパッドが鳴き、速いほど
大きくなります。

ここでワールドに加えた変更には、エディターと同じ短い音が鳴ります。
ランドマークや地域に名前を付ける、住人を追加・削除する、動物を飾りに
したり戻したりする、元に戻す・やり直す、です。共同作業者が行った変更は
鳴りません。

周りの動物や人の音も、その方向から、遠いほど小さく聞こえます。鹿は
鼻を鳴らし、ウサギは警戒して顔を上げると足を踏み鳴らし、あなたが
近づいて驚いたときにももう一度鳴らします。歩き回る足音も聞こえます。
動物を捕まえるとカサッという音と上がっていく音、放すと同じ音が下がって
いきます。住人はあいさつしようと振り向くときに「ふんふん」と親しげに
ハミングし、話しかけると独自の声でつぶやき、そばを歩くと足音が聞こえ
ます。動物がいつ顔を上げるかはワールドの一部なので、訪れた人は全員、
同じ鹿が同じ瞬間に顔を上げる音を聞きます。

ほかの人のアバターの音も聞こえます。その人が歩いている地面に応じた
足音、ジャンプや着地の音が、その人のいる場所から聞こえます。聞こえる
のは見えている人の音だけで、他の人のアバターを隠すと静かになります。
乗り物に乗っている人は、40 m 以内なら乗っている音が聞こえます。速度に
合わせて上下するエンジン音、乗り降りの音、急に減速したときのきしみ
です（ブレーキそのものは送られないので、急停止がブレーキとして扱われ
ます）。エンジン音が鳴るのは近くの 3 人のライダーだけなので、大勢いても
ほかの音がかき消されることはありません。

周りの音は **3D** で配置されます。左右だけでなく、前後、上下にも聞こえ、
カメラを回すと一緒に回ります。ヘッドホンで聞くのがいちばんです。音量の
スライダーの横にある **3D** ボタンで、単純な左右（**ステレオ**）に
切り替えられます。性能の低いデバイスやスピーカーではこちらが合うかも
しれません。

音はすべてブラウザーの中で作られるので、何もダウンロードされず、音が
送られることもありません。ほかの人には、あなたの足音や乗り物の音が、
あなたに相手の音が聞こえるのと同じように聞こえます。相手のブラウザーが、
すでに見えているあなたのアバターの歩きや乗り物から音を作るのです。

ブラウザーは、操作するまでページが音を鳴らすことを許さないので、音は
最初のクリック、タップ、キー入力から始まります。オン・オフは、ビューの
右上（スマートフォンでは右下）の **サウンド** ボタンか、`M` を押して
切り替え、横のスライダーで音量を設定します。スマートフォンやタブレット
では、デバイス自体の音量ボタンを使ってください。ForkBuild は、3D か
ステレオかも含めて、選んだ設定をこのデバイスに記憶します。タブが
隠れている間、音は止まります。

## 方向と場所

カメラの座標の横にある小さな **コンパス** は、どちらを向いているかを
示します（読み取り専用で、カメラを動かすことはありません）。パネルの
上のほうにあるボタンの列で移動します。

- **ホーム** は、カメラとアバターの両方を、共有の地図の固定の原点
  (0,0,0) ではなく、自分の今のワールド（開いているワールド、または最後に
  フォーカスしたワールド）に戻します。そのワールドの内容がローカルの
  原点を中心にしていても、ワールドの範囲の中ではなく、すぐ外側に着き
  ます。このセッションでまだ自分のワールドにフォーカスしていなければ、
  代わりに共有の原点に戻ります。原点は下の **場所** の「ワールド」に
  いつも載っていて、いつでも行けます。（徒歩や乗り物で）遠くまで行って
  自分のワールドが読み込みから外れても、帰り道は失われません。ホームで
  いつでも戻れます。
- **場所** は、このセッションが今知っているすべての場所の一覧を開き
  ます。**ワールド**、**構造物**、**ランドマーク**、**地名** にまとめられ、
  それぞれに **フォーカス** ボタンが 1 つあります。検索やここを探索 /
  ここに何がある？と同じく、フォーカスはカメラを動かすだけで、何かを
  読み込んだり、選択したり、編集したりすることはありません。
- **👥 N オンライン** は **メンバー** ボタンです。ここにいる人の数を
  数え、クリックするとワールドのメンバーパネルが開きます。ワールドに
  公開ロビーがあるときは、その後ろに **ロビー** ボタンが続きます。
- **?** は、カメラと歩行の操作方法（ドラッグで回転、スクロールでズーム、
  アバターを操作中は WASD、Shift、Space）を表示します。もう一度
  クリックすると隠れます。

**通知** は、アプリのヘッダーのログインの横にある 🔔 ボタンなので、
ワールドビューだけでなくすべてのページにあります。あなたの
アイデンティティに宛てた通知の事実を、最近のものから順に永続的に
記録した **通知の履歴** を開きます。今のところ通知が作られるのは、
誰かがあなたの公開物にコメントしたときだけです
（[コメント](09-PublicationsAndEvidence.md#コメント) を参照）。各項目には
何がいつ起きたかが表示され、**探索** ボタンでその公開物のワールドに
行けます。ワールドビューの中ではそこへ飛び、ほかのページではそこで
ワールドビューを開きます。これはただの読み取り専用の記録で、受信箱では
ありません。既読・未読の状態も、項目を消すことも、ボタンの件数バッジも
ありません。開いたときに一度読み込まれ、あとは **更新** をクリックした
ときだけ読み込まれます。裏で自動更新されることはありません。今開いて
いるワールドやドキュメントではなく、サインインしているアイデンティティに
結び付いています。

コンパスには、方角（北、東、南、西）と今の向きの角度、近くの構造物、
共同作業者、ランドマークを示す小さな点が表示されます。点にポインターを
合わせるとラベルが表示され、コンパスの下には読みやすい一覧もあります。

### 探索、地図、地名 — 3 つの見方、同時には 1 つだけ

移動のボタンの下には、**探索**、**地図**、**地名** の 3 つのタブが
あります。これがワールドビューで見て回るための、互いに排他的な 3 つの
主な方法です。1 つを開くと、ほかのものは必ず閉じるので、重なり合う
いくつものパネルを同時に扱うことはありません。

- **探索** が既定です。到着・歓迎のパネル（誰がいるか、いくつかの
  おすすめの行き先）と、折りたためるグループを持つ **近く** セクションを
  表示します。グループは **地名**（場所）、**ランドマーク**、**人**、
  **地名**（[近くの地名](#近くの地名--誰のクレームでも見つける) を参照）、
  **主張された作品**（[主張された作品](#主張された作品--公開者が示す場所にある他の人の作品)
  を参照。あるときだけ表示）、**ワールドでの出会い**
  （[ワールドでの出会い](#ワールドでの出会い--ピアが共有している公開物とアバター)
  を参照）です。どれも名前、距離、小さな **移動** ボタンだけです
  （ワールドでの出会いと地名は、下で説明する独自の形の内容を表示します）。
  場所、ランドマーク、人は中身があるときだけ表示され、3 つとも空のときは
  その旨が 1 行で表示されます。グループの題名をクリックすると開きます。
  開いたままにしたグループは、地図や地名に切り替えて戻ってきても
  覚えています。
- **地図** は、下で説明するのと同じ、平らな上から見たワールドの地図を
  開きます。
- **地名** は、下の [地理的な場所](#地理的な場所) で説明する地理的な場所の
  一覧を開きます。

探索、地図、地名を切り替えても、ドキュメントを読み込んだり、何かを
編集したり、アバターを動かしたりすることはありません。このパネルが
今何を見せているかが変わるだけです。ワールドビューのほかのどの移動の
操作も守っている、「移動 ≠ 変更」の境界と同じです。

### ワールドでの出会い — ピアが共有している公開物とアバター

探索の近くセクションの中にある **ワールドでの出会い** のグループは、
下で説明するワールドの地図とは別の、独自の小さな平らな地図です。
接続しているピアが教えてくれた 2 種類のもの、つまり近くに置かれた
ほかの **公開物**（[公開物と外部証拠](09-PublicationsAndEvidence.md) を
参照）と、ほかの人の **アバター** を、それぞれマーカーとして、あなたの
マーカーと並べて表示します。

マーカーをクリックすると、調べるパネルが開きます。

- **公開物** のマーカーには、タイトル、公開者、署名されているか、位置、
  外部証拠のアンカーとスナップショットの配置の数が表示されます。
- **アバター** のマーカーには、表示名、持ち主、位置が表示されます。

複数の接続中のピアが同じ出会いを提供している場合は、**出所を選択** の
一覧が表示され、どのピアのコピーを調べるかを選べます。ワールドビューの
ほかのものと同じく、これは見るためだけのもので、カメラを動かしたり
何かを編集したりすることはありません。

**共有ワールドを発見**（下記）を実行して、選んだ公開物について分散型の
手がかり（Arweave か Nostr の場所）が見つかっている場合は、**Location**
（場所）の行に、どれが使われるかが表示されます。2 つ以上の手がかりが
一致する場合は、代わりに **場所を選択** の一覧が表示されます。1 つを
選ぶと、その場所から下のデータ / 検証が読み込まれます。選ぶまでは、
どこからも何も読み込まれず、ある出会いでの選択が別の出会いに引き継がれる
こともありません。

公開物を選ぶと、その下にさらに 2 つの状態のブロックが表示されます。
**データ** / **検証** は、その公開物の内容を実際に読み込み、主張されて
いたものと暗号学的に照合しようとします。このデバイスがすでに持って
いる内容ならそのままうまくいきますが、ピアが見せてくれただけのものは、
通常は **Unavailable**（利用不可）/ **Unverifiable**（検証不可）に
なります。ただし、同じ公開物について別に **共有ワールドを発見**（下記）
を実行していれば、見つかった解決済みの分散型の手がかりがここでも使われ、
直接発見したときと同じように、データ / 検証が **Available**
（利用可能）/ **Verified**（検証済み）になることがあります。どちらの
場合も、データの下の **出所** の行に、調べた内容が実際にどこから
来たか（**Local**（このデバイスにすでにあった）か **Decentralized**
（解決済みの Arweave/Nostr の手がかりから取得した））が表示されます。
これはこの 1 回の観測についての単なる事実で、信頼の点数ではありません。
このデバイスが公開物自体のデータを持つと **配信** ボタンが表示され、
クリックすると、ストレージの選択肢、ボタン、結果をずっと画面に出して
おく代わりに **配信** ダイアログが開きます。ダイアログを閉じても
（**閉じる**、外側をクリック、または Escape）、そこで作られたものが
失われることはありません。もう一度開くと、閉じたときとまったく同じ結果、
エラー、進行中の状態が表示されます。ダイアログは表示のためだけのもので、
開いているかどうかに結び付いたものは何もありません。

ダイアログは、配信するものすべてに使う 1 組の設定で開きます。
**ストレージ**（**Arweave**、**IPFS（ローカルKubo）**、
**IPFS（リモートピン留め）**（毎回エンドポイントと認証情報の入力が必要で、
何も保存されません）、または **Steem**（実験的。
[Steem](11-EvidenceAndStorage.md#steem) を参照））と、
**告知 / 発見の基盤**（**Arweave**、**Nostr**、**Steem**）です。どちらも
保存したサービスの設定で開きます。ストレージには、このデバイスが実際に
スナップショットを配置できるバックエンド（とリモートピン留め）だけが
並ぶので、途中で失敗するだけのものを選んでしまうことはありません。

下の 2 つのプロトコルが両方使える場合は、設定のすぐ下にまとめて行う
**配信** ボタンがあります。これが主な操作で、上の設定で署名済み
クレームとスナップショットを一緒に配信します。どちらのプロトコルも
何も変わりません。それぞれ独立に実行され、それぞれ下の専用のセクションに
結果を報告し、片方の失敗がもう片方に隠されたり、もう片方を止めたりする
ことはありません。ただし、2 つは同時ではなく順番に実行されます。どちらも
同じ接続中のウォレット拡張機能に署名を求めることがあり、2 つの署名要求を
同時に送るのは、拡張機能が実際に失敗するパターンだからです。下の各
セクションには、同じ設定を使う小さな **署名済みクレームのみ配信** /
**スナップショットのみ配信** ボタンもあります。片方だけがほしいときや、
失敗した半分だけをやり直したいときに便利です。（片方のプロトコルしか
使えない場合、そのセクションのボタンは単に **署名済みクレームを配信**
または **スナップショットを配信** になります。）

**署名済みクレーム** のセクションは、公開物が別途 Arweave/Nostr の配信を
通ったかどうかを追跡し、通るまでは **データ** と **発見** の両方が
**Absent**（なし）になります。配信すると、データをアップロードして
告知します。どちらの手順もブラウザー拡張機能が署名します。Arweave には
Arweave のウォレット（Wander など）、Nostr には Nostr の署名用拡張機能
（nos2x など）です。対応する拡張機能が入っていないと、理由付きの
「配信を完了できませんでした。」で終わります。成功すると、公開物の ID、
その **データ** の場所、**発見** の告知 ID が表示されます。複数の
[Nostrリレー](10-NetworkSettings.md#nostrリレー) を設定している場合は、
リレーごとに発見の行が 1 つずつになります。

同じダイアログでそのすぐ下にある **スナップショット** のセクションは、
使える条件も必要な拡張機能も同じですが、違うプロトコルを使います。
スナップショット（[公開物と外部証拠](09-PublicationsAndEvidence.md#ローカルのスナップショット)
を参照）は、署名済みクレームの配信とは独立に配置・発見されるので、
このセクションが上の署名済みクレームのセクションと状態、履歴、結果を
共有することはありません。共有するのは設定だけです。クリックすると、
返ってきたものがそのまま表示されます。**コンテンツハッシュ**、
**ロケーター**、**告知** の ID、または配置は成功したけれど Nostr の告知が
失敗したときの「告知なし」です。後者はエラーではなく、一部の結果として
報告されます。本当に失敗した場合は、単純な「スナップショットの配信を
完了できませんでした。」というお知らせが表示されます。どちらのセクションの
状態も結果も、どこにも記憶されません。別の出会いを選ぶか、ページを
離れると消えます。

**ここでピアが見せてくれた公開物は、実際に解決されると、ワールドでの
出会いに取り残されることはありません。** ピアが見せてくれた公開物の
データが **Available**（利用可能）になる、つまり内容が実際に読み込まれて
確認が取れた瞬間に、
[リポジトリ](04-PublishingAndForking.md#リポジトリ) 自体の検索とすべての
作者のページの裏にある同じカタログにも、普通の方法で見つけたときと
まったく同じように加えられます。リポジトリを検索しても、作者のページを
開いても見つかるようになり、再読み込みしても残ります。いったん加わると、
「ピア経由で見つけた」ことを示す特別なバッジやラベルはありません。
その時点では自分のデバイスが独立に内容そのものを確認しているので、
リポジトリのカードも作者のページの一覧も、どちらの経路でも同じに見え
ます。違ったのは *最初にどうやって知ったか* だけです。

### 共有ワールドを発見 — 分散型ネットワークを直接検索する

同じワールドでの出会いのグループの中にありながら、マーカーのクリックも
接続中のピアもまったく不要なのが、独自の小さなポップアップを開く
**共有ワールドの発見** ボタンです。中には **共有ワールドを発見** の
パネルがあります。**共有ワールドID** と、それを配信したときの
**発見タグ** を入力し、**共有ワールドを発見** をクリックすると、Arweave と
Nostr に直接問い合わせます。発見タグの欄には最初から ForkBuild 自身の
共有キャンペーンのタグ（このアプリの中から配信した公開物が使ったはずの
もの）が入っているので、たいていは共有ワールド ID を入力するだけで
済みます。別のタグを指定したい場合は、ふつうに自由に編集できる欄です。
結果には **発見** の行（**Unavailable**（利用不可）、**Resolved**
（解決済み）、または同じ場所について独立した手がかりが複数見つかった
ときの **Ambiguous**（あいまい））と、解決したあとは、上で説明したのと
同じデータ / 出所 / 検証の表示が、同じ項目と言葉で表示されます。今の
ところ、これが解決するのは自分の公開物（自分が署名し、まだローカルに
持っていて、自分の主張する場所がネットワークの報告と一致するもの）
だけなので、ほかの人の作品全般の検索ではなく、「自分の公開物は本当に
無事に外に出ているか？」を確かめるものと考えてください。ポップアップを
閉じても、入力したものや見つけたものは残ります。もう一度検索するか
ページを離れるまでは、開き直すと続きから使えます。

発見した結果が **Verified**（検証済み）になると、**共有ワールドを選択**
ボタンが表示されます。クリックすると、その結果が「今扱っている公開物」と
して記録され、その下に専用の小さなお知らせとして表示されます。選択は
はっきりとした選択であるだけで、配信、再検証、上のローカルの選択への
反映は一切しません。別のものを選ぶかページを離れるまでは、もう一度検索
しても残ります。選べるのは検証済みの結果だけで、**Rejected**（拒否）、
**Unverifiable**（検証不可）、まだ解決していないものには、このボタンは
表示されません。

ワールドでの出会いのマーカーによるパネルは、今または最近接続していた
ピアが実際に教えてくれたものしか表示せず、少なくとも 1 人が教えてくれる
まで、グループには **ここにはまだ出会えるものがありません。** と表示され
ます。共有ワールドを発見だけは例外で、分散型ネットワークに直接問い
合わせるので、接続中のピアがいなくても使えます。誰かと接続する方法は
[ピア接続と友達](07-PeerConnectionsAndFriends.md) を参照してください。

### 近くの地名 — 誰のクレームでも見つける

近くの 4 つ目のグループの **地名** は、接続中のピアをまったく必要と
せずに、今周りにあるワールドの地域についての、署名された地名の
クレームを表示します。上の共有ワールドを発見と同じく、分散型ネットワーク
（Nostr）を直接検索して、近くの地域のタグが付いたクレームを探します。
近くのほかのものと違い、最初は折りたたまれています。発見されただけの
未検証のクレームは、このページで見るには新しく見慣れない種類のもの
だからです。

各行には、主張された名前、だいたいどこにあるか、誰が主張したか、いつか
が表示されます。ボタンは 2 つあります。

- **移動** は、カメラをそのクレームの地域に動かします。近くのほかの場所の
  **移動** とまったく同じです。クレームを採用したり、検証したり、それに
  基づいて何かをしたりすることはなく、何かの名前を変えることもありません。
- **採用** は、クレームを自分のデバイスに保存し、接続中のピアから届いた
  クレームがすでに受けているのと同じ署名の確認を通します
  （[ピアから受け取る](09-PublicationsAndEvidence.md#ピアから受け取る)
  を参照）。採用すると、ほかのものと同じ、ただの既知のクレームになります。
  行の採用ボタンは **✓ 保存済み** に変わり、同じクレームをもう一度採用
  しても、何も変わらなかったことが確認されるだけです。

同じ土地に名前を付ける 2 つのクレームは、どちらもここに表示されます。
この一覧が「勝者」を選ぶことはなく、片方を採用しても、それがもう片方より
正しいと表明することにはなりません。発見そのものが失敗した場合（リレーに
接続できない、問い合わせのエラー）は、小さなお知らせでそう示されますが、
すでに見えていたクレームは画面に残ります。「近くにクレームがない」と
して扱われることはありません。クレームがそもそもどう公開されるかは
[場所に名前を付ける](09-PublicationsAndEvidence.md#場所に名前を付ける) を
参照してください。

### 主張された作品 — 公開者が示す場所にある他の人の作品

歩いていると、ForkBuild は近くで告知されたスナップショットを
ダウンロードします（[自分の共有ワールド](#自分の共有ワールド--ピアなしで自分のスナップショットを配信する)
の自動の経路を参照）。スナップショットの告知には、公開者がそれをどこに
置いたかが書かれていることがありますが、それは **主張** にすぎません。
誰も確認しておらず、やみくもに信じると、誰でもあなたの作品の上に作品を
置けてしまいます。そのため、主張された作品は **ゴースト**（主張された
位置に半透明で描かれたブロック）として表示され、それだけで本物の配置に
なることはありません。

例外が 1 つあり、それにはクリックも不要です。公開者がスナップショットを
配信するとき、告知には公開者自身の **署名付きの配置** も含まれます。
このデバイスがその作品の共有ワールドを知ると（リポジトリにあるか、
**検証** した場合）、ForkBuild は配置がその共有ワールド自身の鍵で署名
されていることを確認し、そうであれば、公開者が置いたとおりの場所に
作品を実体として表示します。それでも、それは公開者の配置で、あなたの
ものではないので、動かしたり取り除いたりはできません。公開者があとで
動かしてもう一度配信すると、あなたの側でも動きます。それ以外の誰かが
署名した位置は、ゴーストのままです。

ゴーストが描かれるのは、次のすべてを満たすときだけです。

- 位置が近くにある（自分の地図のセルとその周り、各方向に約 1,000
  ユニット）。離れるとまた消えます。
- 内容がダウンロードされ、そのコンテンツハッシュと一致した。
- このデバイスにその作品の配置がまだない。配置があれば、代わりに本物の
  作品が表示されます。
- このデバイスが知っているものが、ちょうどその場所にまだ置かれていない。
  主張は常に本物の配置に譲ります。

3D ビューでゴーストを選択、調査、編集、フォークすることはできません。
とても大きな作品は一部（最初の数千個のブロック）だけが描かれます。

各ゴーストには、**主張された作品** のグループに近い順に行もできます。
タイトル、距離と位置、「claimed by …」（…が主張）です。タイトルと作者は
作品自体の内容から来るもので、位置と同じく未検証です。各行には次の
ものがあります。

- **移動** — 主張された場所を見るようにカメラを動かします。ほかは何も
  変わりません。
- **検証** — このデバイスがまだその作品の署名付きの共有ワールドの記録を
  持っていない間に表示されます。Nostr と Arweave で記録を探し、署名を
  確認し、それがまさにこの作品の共有ワールドで、ゴーストが示すまさにその
  内容を指していることを確認します。すべて確認が取れると、共有ワールドが
  リポジトリに追加され、行は「*名前* が署名（鍵 did:key:…）」に変わります。
  取れなければ、行に理由が表示されます。何も告知されていない（公開者が
  スナップショットだけを配信したのかもしれません。まとめて行う **配信**
  ボタンは両方を告知します）、正しく署名されたコピーがない、または署名
  された共有ワールドが違う内容を指している、のどれかです。検証そのものが
  主張を受け入れることはありません。ただし、告知に公開者の署名付きの
  配置が含まれていた場合は、作品が公開者の置いた場所に実体として現れ
  （上記を参照）、ゴーストは消えます。
- **位置を受け入れる** — 主張を信頼する唯一の方法です。主張された位置に、
  ほかの配置と同じくあなたが署名した *あなた自身の* 配置で作品を置き、
  以後はあなたのワールドの普通の作品になります。使えるようになるのは、
  このデバイスが公開者の署名付きで検証済みの共有ワールドの記録を持った
  ときだけです。**検証** で、公開者がワールドをあなたと共有したとき
  （[接続中のピアと共有する](04-PublishingAndForking.md#接続中のピアと共有する)
  を参照。リポジトリに表示されます）、または接続中のピアのその作品の
  [ワールドでの出会い](#ワールドでの出会い--ピアが共有している公開物とアバター)
  が **Available**（利用可能）になったときです。さらに、その共有ワールドが
  ゴーストの示すまさにその内容を指している必要があります。共有ワールドの
  公開者が **自分だけが配置できる** を選んでいる場合
  （[誰が配置できるかを選ぶ](04-PublishingAndForking.md#誰が配置できるかを選ぶ)
  を参照）も使えません。使えないときは、行にその理由が表示されます。

  **検証済みの意味。** 作品が、表示された鍵で署名された共有ワールドの
  内容とまったく同じであることを証明します。その鍵を誰が持っているかは
  証明しません（誰でも鍵を作って「bob」と名乗れます）。位置も証明せず、
  位置は相変わらず主張にすぎません。位置を受け入れるは、知らない鍵でも
  使えます。信頼するかどうかはあなたが決めることです。
- **隠す** — ワールドビューを離れるまで、そのゴーストと行を取り除きます。
  何も報告も削除もされません。

### 情報 — これは何？

ほとんどの **移動** ボタンの横（探索の近くの行や場所パネル）には、
**情報** ボタンもあります。移動がカメラを動かすのに対し、情報は何も
動かさずに、選んだものを説明する小さなパネルを開きます。それが何か、
どのくらい離れているか、どの名前の付いた場所の中にあるか
（「現在地: Willow Village」）、どちらも確かでないときはどの地理的な
場所の候補の近くにあるか（「Kawahara Village の近くにいます」）です。
そこから **移動** でそこへ行くことも、**地図に表示** でワールドの地図に
表示することも、（名前の付いた場所なら）**名前** でコミュニティによる
名前を見たり公開したりすることも、**コピーを編集** でエディターに開く
こと（下記を参照）もできます。情報そのものが、これらのどれかを勝手に
行うことはありません。

### コピーを編集 — エディターに持ち込む

ワールドビューが何か特定のもの（地域、ランドマーク、配置された構造物、
ブロック、何もない地面）を表示しているところでは、それを説明する
パネルにもう 1 つボタンがあります。**コピーを編集** です。見ていた
ものを実際に含むドキュメントの独立したコピーを作り（ワールド全体や、
ほかの人のオリジナルではありません）、そのままエディターで開いて、
続きを作れるようにします。これがあるパネルは 2 つです。**フォーカス**
パネル（探索や場所の行の情報ボタンから。地域、ランドマーク、構造物用）と、
**調査** パネル（3D ビューで直接クリック。ブロック、何もない地面、
配置された構造物用）です。どちらから来ても、同じ操作、同じボタンです。

- **ランドマーク**、**地域**、**ブロック**、**何もない地面** なら、
  それが属するワールドのドキュメントです。
- **配置された構造物** なら、たまたま置かれているワールドではなく、
  構造物自身の内容です。

元のものには一切触れません。ほかのフォークとまったく同じように、コピーが
できるとすぐに ForkBuild が知らせます（[公開とフォーク](04-PublishingAndForking.md)
を参照）。コピーを作れない場合（多くは、ピアや分散型ネットワークで
見つけた共有ワールドのデータがまだ利用できないか、ライセンスがフォークを
許可していない場合）は、空のエディターのドキュメントに残す代わりに、
**フォークできません** ダイアログが理由をはっきり示し、
**共有ワールドに戻る** で元の場所に戻れます
（[フォークが完了できないとき](04-PublishingAndForking.md#フォークが完了できないとき)
を参照）。**地理的な場所** と **共同作業者** には、コピーを編集は
ありません。地理的な場所は、何人かの人のそれぞれの地域をまとめたもので、
コピーできる 1 つのドキュメントを持たず（代わりにその地域の 1 つを
開いてください）、人はそもそもドキュメントではないからです。

**これは、リポジトリ、作者のページ、ワールドでの出会いの「フォーク」
ボタンと同じ操作です** —
[フォーク: 自分のものにする](04-PublishingAndForking.md#フォーク-自分のものにする)
を参照してください。どのラベルをクリックしても、結果はまったく同じ
です。まったく新しい独立したコピーができ、元はそのまま残り、ライセンスの
ルールも同じです。ここで「コピーを編集」と言い方が違うのは、一覧から
選ぶのではなく、コピーするまさにそのものをすでに見ているからに
すぎません。

これが、ワールドビューの読み取り専用の場から外に出る *唯一の* 扉です。
ここにあるほかのもの（飛び回る、検索、ここを探索 / ここに何がある？、
コンパス、地図、情報）は、どれも見るだけです。

### ランドマーク — 覚えておきたい場所に印を付ける

構造物（あなたやほかの誰かが作って置いた建物）やコンパスの読み（立って
いる場所から毎回導かれるもの）と違い、**ランドマーク** はあなたが
意図して作るものです。「Old Bridge」「Great View」のような名前の付いた
地点で、説明も付けられ、アバターが今立っているまさにその場所に置かれ
ます。

今いるワールドの編集（EDIT）権限があれば、**場所** パネルの
ランドマークのセクションに **+ ランドマークを追加** ボタンが表示され
ます。タイトル（と、必要なら説明）を付けて **ここに置く** をクリック
すると、あなたにはすぐに、同じワールドのほかの共同作業者にも少しあとに、
コンパス、それぞれの場所パネル、移動できる行き先として表示されます。
編集権限のある人なら誰でも、作った人に限らず、ワールドのどのランドマークの
名前や説明も変えたり、削除したりできます。ランドマークはワールドの
内容で、一緒に作るほかのものすべてと同じ共同作業の権限に従います。
自分だけが見たり触ったりできる個人的なピンではありません。

### ワールドの地図

**地図** タブは、このセッションが今知っているワールドのあらゆる場所
（名前の付いた場所、ランドマーク、構造物、ここにいるほかの全員、そして
あなたのマーカー）を平らな上からの視点で表示します。スクロールか +/− で
ズームし、何もないところをクリックして地図を動かし、場所や人をクリック
するとカメラがまっすぐそこへ動きます。地図で編集できるものはなく、
見ても何も変わりません。ランドマークを 1 つずつではなく、ワールドの
共同作業者がすでに作って名前を付けた地理を、一度に見渡すための方法です。

### 地理的な場所

**地名** タブは、このセッションが特定したすべての **地理的な場所** の
一覧を開きます。何人かの人がそれぞれ独立に（地域として — 場所の地名の
セクションを参照）名前を付けたり説明したりしたものが、だいたい同じ
土地を占めているとわかったものです。行をクリックすると詳細の画面が
開き、いくつの記述とワールドにまたがっているか、独自の
**コミュニティによる名前**、**この場所へ移動** / **地図に表示** の
ボタンが表示されます。**← 戻る**（または Escape）で一覧に戻ります。
地図や探索に切り替えてからあとで地名に戻ると、詳細でも一覧でも、離れた
ときの画面がそのまま開きます。

場所のコミュニティによる名前のセクションには、最初は上位のいくつかの
名前だけが表示され、**さらに名前を表示** ボタンで順位付きの一覧全体を
見られます。「自分の名前を公開する」より先のもの（ほかの地理的な記述、
生のクレームの履歴、インポート / エクスポート）は、すべて 1 つの
**その他** の中にまとめられているので、「みんなはここを何と呼んでいて、
自分は何と呼ぶか？」というよくある使い方が、名前の仕組みでできるほかの
すべてのことと競合することはありません。

> 名前を公開すると、構造物の作者であることを主張するときと同じように、
> 接続しているピアに告知されます。このデバイスが公開した、または知った
> すべてのクレームを 1 か所で見たい場合は、
> [公開物と外部証拠](09-PublicationsAndEvidence.md) を参照してください。

## カメラと編集

ヘッダーには、本当に違うことがある 2 つのものが表示されます。

```
カメラ: Alice's Castle · 編集: Bob's Castle
```

**カメラ** は今見ている場所です。ワールドへ飛んだり、検索結果の
**フォーカス** ボタンをクリックしたりすると、カメラがそこへ動きます。
**編集** は、次の操作（ランドマークや地域の追加、メタデータの編集、
公開）が実際に適用されるドキュメントです。ブロックや配置をクリック
したり、検索や場所の結果の **選択** ボタンをクリックしたりすると、
カメラを動かさずにこれが変わります。（ブロックそのものを変えるのは
エディターだけです — 上の [コピーを編集](#コピーを編集--エディターに持ち込む)
を参照してください。）

この 2 つは通常は一緒に動きます（フォーカスは両方を行います）が、2 つの
作品がワールドのまったく同じ場所を共有することもあります。一方に
フォーカスしてからもう一方にフォーカスすると、2 回目はカメラがどこにも
動きませんが、ヘッダーには今どちらを編集しているかが表示されます。
飛び回ったり見たりするだけで、編集しているものが勝手に変わることは
ありません。変わるのは、実際にブロックやドキュメントを選択したとき
だけです。

探索の近くの行や情報パネルにある「移動」は、検索、場所、配置にある
「フォーカス」ボタンと同じ、カメラを動かす仕組みの名前で、ラベルが
違うだけです。どれもカメラを動かします。それ以外に何をするか（たとえば
[検索](#検索--どの公開物が一致する) のフォーカスのように、編集している
ドキュメントも変えるかどうか）は、それぞれのパネルのセクションで説明
しているとおり、状況によります。「フォーカス」ではなく「移動」と言っても、
そのどれも変わりません。

## マイワールド — 実際に訪れたワールド

上部のバーで **マイワールド** をクリックすると、このデバイスが以前に
訪れたすべてのワールドが、最近訪れた順に、タイトル、作者、わかって
いれば構造物とランドマークの数とともに表示されます。カードの
**探索を続ける** ボタンをクリックすると、まっすぐそこへ戻ります。
リポジトリや作者のページの **探索** ボタン
（[リポジトリ](04-PublishingAndForking.md#リポジトリ) を参照）と同じ、
ワールドビューへの新しい入り方で、初めて見つけたワールドではなく、
すでに訪れたワールド向けの言い方になっているだけです。

これは完全にローカルな個人の履歴で、共有も公開もされない一覧で、
リポジトリや検索結果とも違います。ワールドがここに載るのは実際に入った
ときだけで、自分のものを何も公開も共有もしなくても、（このデバイスにだけ）
残ります。まだどこも訪れていなければ、**リポジトリを見る** で最初の
ワールドを見つけてください。

## ワールドを見つける

共有のワールドで何かを見つける方法は 3 つあり、それぞれ違う問いに
答えます。

### 検索 — 「どの公開物が一致する？」

**検索** パネルは、今周りに読み込まれているものだけでなく、公開された
すべてのものを **タイトルや作者** で検索します。語を入力して **検索** を
クリックします。

必要なら **場所** で絞り込めます。X/Y/Z と **半径**（ワールド単位）を
入力すると、その地点からその距離以内の結果だけが返ります。普通の
テキスト検索なら、場所は空のままにします。

各結果には次のものが表示されます。

- 📍 位置
- 📏 どのくらい離れているか（場所での検索のときだけ）
- 表示されている位置が、作者が実際に選んだものではなく **既定の位置** の
  場合はその注記（下の [ワールドでの位置](#ワールドでの位置) を参照）

**フォーカス** をクリックするとそこへ飛びます。

### ここを探索 / ここに何がある？ — 「今の周りに何がある？」

探索の近くセクションの一番上にあるこの 2 つのボタンは、
**今カメラがあるところから** 検索します。タイトルを知っている必要も、
座標を入力する必要もありません。

- **ここを探索** は、カメラの周りのそれなりに広い範囲を検索し、あとから
  半径を広げたり狭めたりできます。
- **ここに何がある？** は、すぐ近くだけを確認します。「立っている
  まさにここに何かあるか？」を知りたいときに便利です。

どちらも **場所を探索** のダイアログを開きます。

```
📍 中心: 100.0, 50.0, 250.0
⭕ 半径: 25ワールド単位

発見できる3件のドキュメントのうち3件を表示中

📍 City Hall            📏 4.2ワールド単位
by alice
[フォーカス] [選択] [調べる]
```

各結果には、3 つの異なる操作があります。

| ボタン | 動作 |
|---|---|
| **フォーカス** | カメラをそこへ飛ばし、*さらに* 編集するものにします |
| **選択** | カメラを動かさ **ずに**、編集するものにします |
| **調べる** | 何も動かさずに、その場で概要（タイトル、作者、状態、位置、持ち主）を展開します |

このダイアログが、それだけで配置を動かしたり、ドキュメントを編集したり、
何かを公開したりすることはありません。見て回り、次にどこへ行くかを
選ぶためだけのものです。

### ここにあるドキュメント

配置の情報パネルに、ほかのドキュメントがまったく同じ位置にあると表示
されたら、**表示** をクリックすると **ここにあるドキュメント** が開き
ます。その場所にあるもの全員の単純な一覧で、それぞれに **フォーカス**
ボタンがあります。表示されるのは今も実際に公開されているドキュメント
だけで、公開を取り消されたものは、何もできない行として表示される
代わりに、一覧から外されます。

## ブロックや配置された構造物を調べる

ブロックをクリックすると **調査** パネルが開き、次のことがわかります。

- ブロックの種類
- 位置と回転
- どのワールドと建物に属しているか
- ワールドの作者

**ブロックにフォーカス** で拡大し、**ワールドにフォーカス** でその作品の
基準の位置へ飛びます。そのすぐ横の **コピーを編集** ボタンは、このブロックが
属するワールドをフォークして、コピーをエディターで開きます。元はその
ままです。作品の中の何もない地面をクリックしても、同じ種類のパネル
（位置と、それを含むワールド / 作者。ブロック固有の項目はなし）が、
同じ理由で専用の **コピーを編集** ボタン付きで開きます。フォークするのに
目立つものを先に見つける必要はなく、続きを作りたいワールドの中の
どこかをクリックするだけでよいのです。

**配置された構造物**（エディターから作品の中に置いた、ドキュメント
まるごとのインスタンス — [エディター](02-TheEditor.md#構造物のインスタンス-生きた参照)
を参照）をクリックすると、同じパネルに、代わりにそれが参照している
もの、つまり元のドキュメントのタイトル、ローカルとワールドでの位置、
回転、地面の高さ、それを含むワールドのタイトルと作者が表示されます。
ワールドビューでは読み取り専用で、ギズモも数値の欄もドラッグできる
ものもありません。**元を開く** をクリックすると、参照しているドキュメント
そのものをエディターで開きます。どこに置かれているほかのインスタンスにも、
そこで編集したものが反映されます。元を開くのすぐ横にある専用の
**コピーを編集** ボタンは、それを配置しているだけのワールドではなく、
同じ参照先のドキュメントを対象にします。ほかのすべてのインスタンス
（と元）に触れずに独立したコピーで作業したい場合は、元を開くの代わりに
こちらを使ってください。

ワールドビューのどの「コピーを編集」ボタンも（ここでも、地域、
ランドマーク、構造物のフォーカスパネルでも）同じ操作です。上の
[コピーを編集](#コピーを編集--エディターに持ち込む) を参照してください。

## ドキュメント情報と配置

ヘッダーの下には、今編集しているドキュメントについての 2 つのパネルが
あります。

- **ドキュメント情報** — タイトル、説明、ライセンス、誰が配置できるか、
  状態、（フォークなら）どのワールドからフォークしたか。
  **メタデータを編集** をクリックすると、タイトル、説明、ライセンス、
  誰が配置できるかを変えられます。
- **配置** — そのドキュメントが共有の空間の *どこ* にあるか。
  **ワールド単位**（ForkBuild 独自の座標系で、GPS の座標ではありません。
  1 ワールド単位は現実の長さの 1 メートルを表します）で表します。
  **移動** をクリックすると新しい X/Y/Z 座標を直接指定でき、± の微調整
  ボタン（1 / 10 / 100 ワールド単位）で今の位置からずらしてから確定する
  こともできます。**フォーカス** でそこへ飛びます。

この 2 つはあえて別々のパネルになっています。作品が *何か* と、どこに
*あるか* は別の問いで、配置を動かしてもドキュメント自体が編集される
ことはありません（逆も同じです）。

### ワールドでの位置

移動しようとしている場所に、ほかのドキュメントがすでにちょうどある
場合は、確定を求められる前に、誰がそこにいるかを示す警告が表示され
ます。場所を共有することは許されています（中庭の場面と、それを囲む
建物が同じ場所にあるのは正当です）。ForkBuild は、それを先に確実に
見せるだけです。

### 自分のものではない配置

配置がほかの人のものである場合、配置パネルには
**🔒 &lt;名前&gt;さんが配置 — この配置は閲覧できますが、移動はできません。**
と表示され、**移動** ボタンは使えません。それでも **フォーカス** したり、
調べたり、**コピーを編集** でそこにあるものの続きを作ったりはできます。
*共有の空間のどこにあるか* だけは、その人が動かすものです。

### なぜ他の人の作品を配置できるの？

現実の建物は持ち上げてほかの場所に置けないので、ForkBuild が誰の公開
作品でも好きな場所に置けるのは奇妙に思えるかもしれません。公開された
作品は、1 つの物理的な物体ではありません。ファイルや Git のリポジトリの
ように、コンテンツハッシュで特定される固定の内容です。**配置** は
「この作品をここに表示する」という、別の署名付きの記録です。作品を
指すだけで、コピーはしません。同じ作品にいくつもの配置があってよく、
どれもまったく同じ公開された内容を表示します。

そのため、ほかの人の作品を配置しても、その人のものが動いたり変わったり
することはありません。

- **その人の配置は、その人が置いた場所のままです。** 動かせるのは
  その人だけです（上の [自分のものではない配置](#自分のものではない配置)
  を参照）。
- **あなたの配置はあなたが署名したもので**、*あなたが* その人の作品を
  どこに表示するかを示すだけです。
- **作品は作者と履歴を保ちます。** それはその人が公開したとおりの内容
  で、誰でもハッシュと署名で確認できます。

また、どの土地を誰が持っているかを決める、中央の 1 つのワールドも
ありません。それぞれのワールドは、自分が受け入れた配置を表示します。
だからこそ、近くで誰かが告知した作品は、あなたが **位置を受け入れる** を
選ぶまで、ゴーストとしてしか表示されないのです
（[主張された作品](#主張された作品--公開者が示す場所にある他の人の作品)
を参照）。あなたの承諾なしに、誰かがあなたのワールドに作品を置くことは
できません。

自分で作っていない作品を置く理由には、たとえば次のようなものがあります。

- **キュレーション** — 気に入った作品を集めるギャラリーのワールドなど。
- **場面の構成** — 友達の城を自分の村の横に置くなど。
- **そのまま再利用する。** 変えずに使いたいときは配置し、変えたいとき
  だけ [コピーを編集](#コピーを編集--エディターに持ち込む) を使います。

これを望まない公開者は、公開するときに **自分だけが配置できる** を選べ
ます（[誰が配置できるかを選ぶ](04-PublishingAndForking.md#誰が配置できるかを選ぶ)
を参照）。その場合も、作品を見つけたり見たり、ライセンスが許せばフォーク
したりはできますが、配置はできません。

### なぜ 2 つの作品が同じ場所にあるの？

現実では、2 つの建物が同じ場所に立つことはできません。ForkBuild では
できます。配置は土地を占有するものではなく、「この作品をここに表示する」
という署名付きのメモにすぎず、2 つのメモが同じ場所を指すことはあり得る
からです。

ForkBuild はこれをあえて許しています。

- **土地を配る人はいません。** どちらが先にその場所を取ったかを決める
  中央のサーバーはなく、ForkBuild が 2 つの署名付きの配置から勝者を
  選ぶこともありません。どちらも有効なままです。
- **デバイスごとに知っている配置が違います。** 友達のデバイスでは
  使われている場所が、配置が届くまで、あなたのデバイスでは空いている
  ことがあります。厳密な「1 か所に 1 作品」のルールは、デバイスごとに
  違う答えを出すことになるので、ForkBuild はそれを強制するふりをしません。
- **望んでそうすることもあります。** 建物の中の中庭の場面、新しい版の
  代わりにその場所に表示する古い版、意図して重ねた展示などは、どれも
  同じ場所にあるべき作品です。

だからといって、誰でもあなたの作品の周りを埋め尽くせるわけではあり
ません。

- **先に警告されます。** **移動…** は、確定する前に、その場所にすでに
  あるものを一覧表示し、ForkBuild があなたの作品を黙ってほかの場所に
  動かすことはありません（[ワールドでの位置](#ワールドでの位置) を参照）。
- **うっかりした重複は起きません。** **ここに配置を追加** は、今いる
  まさにその場所にすでに配置があると拒否します。
- **ほかの人の主張はゴーストにすぎません。** 作品の公開者自身以外の
  誰かが告知した位置は、半透明のゴーストとしてしか表示されず、この
  デバイスが本物の配置を知っている場所には決して表示されません
  （[主張された作品](#主張された作品--公開者が示す場所にある他の人の作品)
  を参照）。
- **配置を動かしたり取り除いたりできるのは持ち主だけです**
  （[自分のものではない配置](#自分のものではない配置) を参照）。

ForkBuild が確認するのは、まったく同じ地点にある作品だけです。近くの
地点にあって、たまたまブロックが触れ合う 2 つの作品は、指摘されません。
設計の考え方は
[Overlap Is A Fact; Collision Is A Policy Decision](../../principles/placement.md#overlap-is-a-fact-collision-is-a-policy-decision-0225)
（英語）と、それに続くルールを参照してください。

### 配置とフォークの違い

どちらも、ほかの人の作品を自分のワールドに置けるようにしますが、別の
ものです。

| | 配置 | フォーク（フォーク、またはコピーを編集） |
|---|---|---|
| 作られるもの | 配置: 作品をどこに表示するかの小さな署名付きの記録 | 新しい ID を持つ、あなたのものである新しいドキュメント |
| 作品 | 公開されたとおりの同じ共有ワールド | 元へのリンクの注記が付いた、あなた自身のコピー |
| ブロックを変えられるか | いいえ | はい、エディターで |
| 作者は誰か | 元の公開者 | あなた。元は親として記録されます |
| 決めるもの | 公開者の **ワールドに配置できる人** の設定 | ライセンス |
| 公開すると | 新しく公開されるものはありません | あなたの名前で新しい共有ワールドが作られます |

配置は、別のページから同じファイルにリンクするようなもので、フォークは、
自分のコピーで作業するためにリポジトリをクローンするようなものです。
なので本当のコピーはフォークだけです。**自分だけが配置できる** を選んだ
人も、ライセンスでフォークを許可でき、そうすればフォークはあなたの
ものなので、好きな場所に置けます。

## ワールドビューは読み取り専用 — 作るのはエディター

ここには配置ツールも、変形のギズモも、コピー / 貼り付けも、グループも
ありません。クリックしても、ドラッグしても、キーを押しても、ブロックが
変わることはありません。何かの続きを作るには
**[コピーを編集](#コピーを編集--エディターに持ち込む)** を使い、
[エディター](02-TheEditor.md) で続けてください。このガイドの最初に
挙げた注釈の例外は、ここでも当てはまります。

## 他の共同作業者を見る

同じワールドに何人かいるとき:

- **ほかの人が見える** — アバターが、表示名と活動の表示（たとえば
  「**Bob — 近くを探索中**」）付きで表示されます。
- **リアルタイムの更新** — その人が公開したもの（ランドマーク、名前、
  その人自身の新しいフォーク）が、そのときにあなたにも表示されます。
- **一時的な活動フィード** — ローカルのパネルに最近の活動が表示され、
  今の視界の外で何が変わったかも把握できます。このフィードは一時的な
  もので、保存されません。

> **在席は活動を示すだけで、それだけで何かが変わることはありません。**
> 空間上の在席は、ほかの人が何をしているかを理解する助けになりますが、
> 共有の環境を変えるのは、実際の変更（エディターで行ったもの、または
> ワールドビューの注釈の例外）だけです。

## ここでも保存と公開

何かを編集しているときは、ヘッダーに **保存**、**公開**、
**メタデータを編集** のボタンがあるので、ワールドを離れずに記録して
共有できます。状態の行（**🔒 公開済み** または **✎ フォークを編集中**）
には、どちらなのかが常に表示されます。

公開されたワールドは変わることがありません。編集しているワールドが公開
されている場合、ここでの最初の変更（メタデータの編集、ランドマークや
地域の追加や名前の変更、動物での飾り付け）で、*「&lt;元の名前&gt;の
フォーク」* というタイトルの、編集できる自分のコピーが自動で作られ、
短いお知らせ（「編集可能なあなた専用のコピーを作成しました — 「…」は
変更されていません」）が表示されます。ほかのフォークと同じライセンスの
ルールに従います（[公開とフォーク](04-PublishingAndForking.md#フォーク-自分のものにする)
を参照）。

### 自分の共有ワールド — ピアなしで自分のスナップショットを配信する

パネルの下のほう、検索とアバターの下に **自分の共有ワールド** の
パネルがあり、今のワールドが実際に公開されると、そのタイトルと作者、
そして専用の **配信** ボタンが表示されます。ボタンは、上でワールドでの
出会いについて説明したのとまったく同じ種類の **配信** ダイアログを
開きます。同じ部品を共有しているので、配置、まとめて行う **配信**
ボタン、共有のストレージ / 基盤の設定、**署名済みクレーム** /
**スナップショット** のセクション、「閉じても結果は失われない」動作は、
どれも上の
[ワールドでの出会い](#ワールドでの出会い--ピアが共有している公開物とアバター)
で説明したとおりです。唯一の違いは *何を* 配信するかです。ワールドでの
出会いのダイアログは常に選んだ出会いの公開物を対象にし、こちらは常に
*あなた自身の今のワールド* を対象にします。どちらも状態、履歴、結果を
共有しません。ここの **署名済みクレームのみ配信** は、ワールドでの出会いの
ボタンと同じように、ワールドの裏にある署名済みクレームを配信します。
**スナップショットのみ配信** は、別のスナップショットのプロトコルで
配信します。この区別の意味は
[ローカルのスナップショット](09-PublicationsAndEvidence.md#ローカルのスナップショット)
を参照してください。リモート IPFS ピン留めと Bitcoin/Base のアンカリングは、
公開物ページの公開センターにあります（[IPFSへの公開](11-EvidenceAndStorage.md#ipfsへの公開)
と [Bitcoin のアンカーパイプライン](11-EvidenceAndStorage.md#bitcoin-のアンカーパイプライン)
を参照）。どちらも先にアカウントや接続したウォレットが必要なので、
ここでワンクリックのボタンにはなっていません。

自分の共有ワールドの要点は、ワールドでの出会いに何かがあるかどうかに
決して左右されないことです。ワールドでの出会いは、今または最近接続して
いたピアが教えてくれたものしか表示しないので、ほかに誰もいなければ空の
ままです。自分の共有ワールドにはそのどれも必要ありません。ほかに誰か
近くにいてもいなくても、今公開されていてもいなくても、ワールドを開いて
いればいつでもここにあります（公開するまでは、配信するものがまだない
という注記とともに、ボタンが使えないだけです）。

**配信** と共有リンクは前面にあります。あまり使わない操作は
**その他 ▾** の中にあります。**スナップショットをエクスポート**、
**スナップショットの一致を確認**、**診断ツール**（下記）、
**公開を取り消す…** です。公開を取り消すは、実行する前に一度確認します。
ワールドをカタログから取り除きますが、配置、ドキュメント、配信した
コピーは残ります。**キャンセル** でやめられます。
配信済みのコピーは取り戻せませんが、このデバイスは公開を取り消したものを
覚えているので、リポジトリによるネットワークの検索でそれが再び表示される
ことはありません。エクスポートと確認の
結果は、メニューを閉じてもパネルに残ります。

開いているワールドをほかの人が公開した場合（たとえばピアが共有して
くれたもの）は、パネルの題名が代わりに **共有ワールド** になり、
**公開を取り消す** と **配信** はなくなります。ワールドの取り消しや配信が
できるのは、そのワールドの公開者だけだからです。配置、スナップショットの
道具、共有リンク、**コメント** は残るので、誰のワールドでもコメントを
読んだり投稿したりできます。

そのすべての下に **コメント** のセクションがあり、クリックするまでは
**▸ コメント（N）** の 1 行に折りたたまれています（折りたたまれている
間も数は最新に保たれます）。このパネルのほかのすべてと同じく、今の
ワールドが対象です。誰がコメントでき、コメントするとどうなるかの全体は
[コメント](09-PublicationsAndEvidence.md#コメント) を参照してください。
スナップショットの配信と同じく、実際にコメントを投稿するには、先に
ワールドを公開する必要があります。それまでは入力欄は使えません。

**配置（N）** の一覧には、この共有ワールドが実際に配置されているすべての
場所が、見つかった順に、位置、リビジョン、（わかれば）持ち主とともに、
配置ごとに 1 行で表示されます。ここでは何も「最新の 1 つ」にまとめられ
ません。共有ワールドは本当に 2 か所以上にあり得るので、このデバイスが
発見できるすべての配置が表示され、最後に更新された 1 つがほかの代わりに
表示されることはありません。

各行には専用の **移動…** と **削除…** があり、まさにその配置だけに
働きます。**移動…** は、その配置について同じ X/Y/Z の配置の移動の
ダイアログ（重なりの警告付き）を開きます。**削除…** は、一度確認してから
その配置をワールドから取り除きます。共有ワールド、そのドキュメント、
ほかの配置は残り、最後の配置を取り除いても、もう一度置くまで作品が
どこにも表示されなくなるだけです。どちらも、ほかの人が作った配置では
使えません。動かしたり取り除いたりできるのは、その持ち主だけです。

一覧の下の **ここに配置を追加** は、同じ作品を、アバターの（アバターが
なければカメラの）位置に *もう一度* 置きます。既存の配置を動かすことは
ありません。それにはその配置の **移動…** を使ってください。追加される
のはコピーではなく配置で、作品は 1 つの共有ワールドのままです
（[配置とフォークの違い](#配置とフォークの違い) を参照）。確認には、
どこに置いたかと、共有ワールドの配置がいくつになったかが表示されます。
今いるまさにその場所にすでに配置がある場合、ボタンは拒否して、先に
移動するよう求めるので、何度クリックしても、目に見えない重複が 1 か所に
積み重なることはありません。一覧が空なのは、この共有ワールドがまだ
どこにも配置されていないという意味です。読み込みに失敗した場合は、
代わりに専用の単純なエラーが表示されます。

**その他** の中にある **診断ツール** ボタン（その裏にある機能のうち
少なくとも 1 つが使えるときだけ表示）は、自動のスナップショットの発見や
配置が期待どおりの結果を出さないときのための、手動で 1 段階ずつ進める
復旧ツールの小さなポップアップを開きます。**スナップショットを発見** は、
共有キャンペーンの発見タグで告知されたものすべてを見られます。接続中の
ピアがいなくても、ワールドでの出会いがなくても、自分の共有ワールドが
まだなくても使えます。1 つを選んで **選択したスナップショットを解決**
をクリックすると、実際に取得できるかを確認します。そこから
**選択したスナップショットの帰属を確認**（この共有ワールドの
コンテンツハッシュと一致するか？）と、それとは独立に
**選択したスナップショットを実体化**（そのバイト列をこのデバイスに
保存する）ができます。候補を選んだあとならいつでも、
**主張された位置を使う** で、スナップショット自体が主張する位置（あれば）を
採用できます。実体化したら、**実体化したスナップショットを配置** に
続けて **配置したスナップショットを登録** で、再読み込みせずに、今見て
いるワールドに実際に追加します。どれもそれぞれ別の明示的なクリックで、
ここで何かが連鎖したり、再試行したり、候補を順位付けしたりすることは
ありません。ForkBuild のほかの手動で 1 段階ずつ進める流れがすでに
守っているのと同じ控えめさです。

**このポップアップが代わりを務める自動の経路は、このデバイスだけでなく
ほかからも材料を集めます。** 歩いていると、ForkBuild は裏で定期的に
スナップショットの候補を確認します（上の **スナップショットを発見** が
手動で行うのと同じ確認です）。このデバイスがすでにローカルに持っている
もの、接続中のピアが（接続しているだけで、何の操作もなしに）受動的に
共有したもの、Nostr が報告するものを 1 つの候補の集まりにまとめます。
解決できた候補は、上で説明したのと同じ解決 → 実体化 → 配置 → 登録の
流れを静かにたどり、ほかの **ワールドでの出会い** のマーカーとまったく
同じように表示されます。「自動で発見された」専用の一覧や通知はなく、
診断ツールの手動のボタンは、この受動的な経路で探しているものが見つから
ないときのために、上で説明したとおり変わらず使えます。

自動の経路がダウンロードするのは、近くのスナップショットだけです。
自分の地図のセルとその周り（各方向に約 1,000 ユニット）に置かれた、
または置かれたと告知されたものと、どこに属するかを示していない新しい
もの 20 件です。それより遠いスナップショットは、近くまで歩くと
ダウンロードされます。同時にダウンロードするのは最大 4 件です。この
デバイスがすでにダウンロードしたスナップショットは、もう一度
ダウンロードする代わりに、同じ内容の確認をしたうえで自分のストレージ
から読み込まれます。

## 履歴 — 以前の状態のプレビューと復元

ここで行ったすべての変更（ランドマークや地域の追加、名前の変更、削除）は、
ドキュメントの履歴に記録されます。ヘッダーの **履歴** をクリックすると
開きます。次のような、時刻付きの番号の付いた一覧が表示されます。

```
1. ランドマーク「Old Bridge」を作成
2. 地域「Willow Village」を更新
3. ランドマークを削除
```

元に戻した項目には **取り消し済み** と表示されます。項目をクリックしても
選ぶだけで、ボタンを押すまで何も変わりません。

- **プレビュー** — 選んだ段階の *直後* にワールドがどう見えていたかを、
  何も変えずに、今のものと並べて表示します。**プレビューをキャンセル** で
  現在に戻ります。
- **復元** — 選んだ段階を **今の** 状態にします。ドキュメントは未保存の
  変更がある状態になるので、保存するかどうかはまだ決められます。別の
  確認はありません。
- **閉じる** — パネルを閉じます。
