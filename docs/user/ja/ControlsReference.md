# 操作リファレンス

<!-- languages -->
[English](../ControlsReference.md) · [Bahasa Indonesia](../id/ControlsReference.md) · **日本語**
<!-- /languages -->

ForkBuild のマウスとキーボードの操作をすべてまとめています。
スマートフォンとタブレットについては [タッチ画面](#タッチ画面) を参照
してください。ワールドビューは見て回り、移動するための場所です。作品を
作るための操作（編集のための選択、変形、グループ、クリップボード、配置、
コマンドパレット）は、すべてエディターでしか使えません。エディターの
ショートカットは、コマンドパレットと **⌨ ショートカット** の一覧に
表示されるものと同じです。このページとパレットの内容が食い違う場合は、
パレットが正しく、このページに誤りがあります。

エディターで `Ctrl/Cmd+K` を押すと **コマンドパレット** が開き、以下の
編集操作をすべて名前で検索できます。

## カメラ（両方のビュー）

| 入力 | 操作 |
|---|---|
| 何もないところで左ドラッグ | 回転（オービット） |
| 右ドラッグ | 平行移動（パン） |
| スクロールホイール | ズーム |
| `Home` | エディター: カメラをリセット（ギズモをドラッグしている間は無視されます）。ワールドビュー: カメラとアバターを自分の現在のワールドに戻す — [ワールドビュー](../03-WorldView.md#orientation-and-locations)（英語）を参照 |

## コマンド（エディターのみ）

| 入力 | 操作 |
|---|---|
| `Ctrl/Cmd+K` | コマンドパレット |
| `?` | キーボードショートカットの一覧（ツールバーの「⌨ ショートカット」ボタンからも開けます） — エディターのすべてのショートカット |

## 発見（ワールドビュー）

キーボードショートカットではありませんが、ワールドビューでものを
見つけるための操作です。詳しくは
[ワールドビュー](../03-WorldView.md#finding-worlds)（英語）を参照してください。

| 操作 | 動作 |
|---|---|
| 検索パネルの **検索** | タイトルや作者で公開物を検索します。座標を中心とした半径で絞り込むこともできます |
| **ここを探索** | カメラの現在位置を中心に「場所を探索」ダイアログを開きます |
| **ここに何がある？** | 同じですが、半径が小さく固定されています。「まさにここにあるもの」 |
| 結果の **フォーカス** | カメラをそこへ飛ばし、そのドキュメントをアクティブ（編集中）にします |
| 結果の **選択** | カメラを動かさずに、そのドキュメントをアクティブにします |
| 結果の **調べる** | 読み取り専用の概要をその場で展開します |

## 方向とナビゲーション（ワールドビュー）

純粋にカメラの移動だけです。どれもドキュメントを読み込んだり、選択を
変えたり、何かを編集したりはしません。
[ワールドビュー](../03-WorldView.md#orientation-and-locations)（英語）を参照してください。

| 操作 | 動作 |
|---|---|
| コンパス | 読み取り専用の方位表示。近くの構造物や地形のマーカーが表示されます |
| **ホーム** | カメラとアバターを自分の現在のワールドに戻します（このセッションでまだ自分のワールドにフォーカスしていなければ、共有の原点に戻ります） — [ワールドビュー](../03-WorldView.md#orientation-and-locations)（英語）を参照 |
| **場所** | ワールド、その構造物、ランドマーク、場所の一覧を開きます。それぞれに **フォーカス** ボタンがあります |
| **?** | カメラと歩行の操作方法を表示・非表示にします |
| 🔔 **通知**（アプリのヘッダー、全ページ） | **通知の履歴** を開きます — 読み取り専用の記録で、カメラの操作ではありません。[ワールドビュー](../03-WorldView.md#orientation-and-locations)（英語）を参照 |
| **カメラ**: 自由 / 一人称 / 三人称 / 俯瞰 | カメラを自分で飛ばす代わりに、自分のアバターから一定の位置に固定します。選択中のものをもう一度クリックすると自由に戻ります — [アバターと在席状況](06-AvatarsAndPresence.md#カメラの視点)を参照 |

### 場所に応じた説明

ワールドの中を移動すると、画面に次のような説明が表示されます。

- 「**森 · House の近く**」 — 森の中にいて、構造物から 50 ユニット以内
- 「**草原 · 川**」 — 川沿いの開けた地形
- 「**草原 · 湖 · Barn の近く**」 — 地形、水、最も近い構造物

これらの説明は、あなたの位置、地形の生態、水系、構造物の配置から
計算されます。ワールドには何も保存されません。

## サウンド（両方のビュー）

| 入力 | 操作 | 補足 |
|---|---|---|
| `M` | 音をオフ・オンにする | **サウンド** ボタンと同じです。両方のビューで共通の設定で、このデバイスに記憶されます。[ワールドビュー](../03-WorldView.md#sound)（英語）と [エディター](02-TheEditor.md#サウンド)を参照 |

## アバターの移動（ワールドビュー）

カメラを飛ばす代わりに、アバターを直接歩かせます。
[アバターと在席状況](06-AvatarsAndPresence.md#アバターを歩かせる)を参照してください。

| 入力 | 操作 | 補足 |
|---|---|---|
| `W` / `A` / `S` / `D` | 移動 / 向きを変える | 近くの建物、木、野生動物、住人は、壁と同じように通り抜けられません |
| `Shift`（押したまま） | 走る | |
| `Space` | ジャンプ | |
| `Alt` + `W` / `S` | 前進 / 後退で歩き続ける | キーを離しても動き続けます。Alt なしで `W`/`S` を普通に押すと止まります |
| `Alt` + `Shift` + `W` / `S` | 前進 / 後退で走り続ける | 止め方は上と同じです |

## 乗り物（ワールドビュー）

[アバターと在席状況](06-AvatarsAndPresence.md#乗り物)を参照
してください。アバター操作モード（**自分のアバターを操作**）が必要です。
乗れる距離まで乗り物に近づくと、自動で案内が表示されます。

| 入力 | 操作 | 補足 |
|---|---|---|
| `E` | 近くの乗り物に乗る、または乗っている乗り物から降りる | 乗り物が範囲内にあるか、乗っているときだけ表示・有効になります |
| `W` / `S` | 加速 / 後退 | 乗っている間は、徒歩の移動の代わりになります |
| `A` / `D` | アバター自身の向きを変える | 徒歩のときと同じ向きの変更です。乗り物の操舵ではありません |
| `←` / `→`（押す） | 乗り物の進もうとする方向を左右に変える | 1 回押すごとに 45° だけ曲がります。押したままにしても曲がり続けません |
| `Ctrl`（押したまま） | ブレーキ | |
| `Q`（乗っているとき） | 乗っている乗り物を持ち物にしまう | ワールドから取り除き、同時に降ります |
| `Q`（乗っておらず、乗り物を持っているとき） | 選択中のしまった乗り物を出す | 現在位置に出して乗ります。既定では最後にしまったものです |
| `[` / `]`（乗り物を 2 台以上持っているとき） | 出す乗り物の選択を、古いもの / 新しいものに切り替える | 次に `Q` で出すものが変わるだけで、それ自体で乗ったり取り除いたりはしません |

## 動物（ワールドビュー）

[アバターと在席状況](06-AvatarsAndPresence.md#動物)を参照
してください。アバター操作モードが必要です。捕まえられる動物が近くに
いるときや、動物を連れているときは、自動で案内が表示されます。

| 入力 | 操作 | 補足 |
|---|---|---|
| `F`（捕まえられる動物の近く） | 捕まえる | 持ち物に加え、ワールドから取り除きます |
| `F`（捕まえられる動物が近くになく、動物を連れているとき） | 最後に捕まえた動物を放す | 現在位置に出し、再び捕まえられるようになります |
| `G`（自分が放した動物の近く） | その動物でワールドを飾る | ワールドの内容に飾りとして保存します。もう捕まえられません。編集（EDIT）権限が必要です。`G` で何かできるときは案内が表示されます |
| `G`（動物の飾りの近くで、放した動物が近くにないとき） | 飾りを外す | ワールドから取り除き、捕まえられる生きた動物に戻します |

## 住人（ワールドビュー）

[アバターと在席状況](06-AvatarsAndPresence.md#住人)を参照
してください。アバター操作モードが必要です。アバターセクションの
**ここに住人を追加** / **住人を削除** と **話す** ボタンを使えば、
モードなしでも同じことができます。

| 入力 | 操作 | 補足 |
|---|---|---|
| `R`（開けた地面で、すぐ横に住人がいないとき） | 立っている場所を家とする住人を追加する | ワールドの内容に保存されます。編集（EDIT）権限が必要です。屋上、水中、乗り物に乗っているときはできません |
| `R`（住人の隣） | その住人をワールドから削除する | **[R] 住人を削除** と表示されます。`Ctrl/Cmd+Z` で元に戻せます |
| `T`（住人の隣） | 話す: 周りに何があるかを教えてくれます | 頭の上の吹き出しに表示されます。もう一度話すと別のことを話します。アバターセクションとタッチパッドの **話す** ボタンも同じです |
| **フォーカス: …** ボタン（住人の言葉が表示されている間） | 住人が話したものを見る | カメラだけが動き、アバターはその場にとどまります。ランドマーク、構造物、作品、乗り物について表示されます |

持ち物、置いた乗り物、放した動物はこのデバイスに保存され、再読み込み
しても残ります。
[アバターと在席状況](06-AvatarsAndPresence.md#再読み込みしても残るもの)を参照してください。

## 選択（エディター。ワールドビューでブロックをクリックしても調べるだけです）

| 入力 | 操作 | 補足 |
|---|---|---|
| ブロックをクリック | 選択する（選択を置き換えます） | ワールドビューでは調べるパネルが開くだけです — [ワールドビュー](../03-WorldView.md#world-view-is-read-only--building-happens-in-the-editor)（英語）を参照 |
| `Shift`+クリック | ブロックを選択に追加 | |
| `Ctrl/Cmd`+クリック | ブロックを選択に入れる / 外す | |
| `Shift`+ドラッグ | 範囲選択（選択を置き換えます） | `Ctrl/Cmd+Shift`+ドラッグで選択に追加します。普通のドラッグはカメラを回転します |
| `Ctrl/Cmd+A` | すべて選択 | |
| `Esc` | 選択を解除 | エディター独自の Escape の順序（下記）に従います。ワールドビューの Escape は、開いているパネルを閉じるだけです |
| `Delete` / `Backspace` | 選択を削除 — **エディターのみ** | 1 回で元に戻せる操作です。ワールドビューにはキーの割り当て自体がありません |
| 選択パネルの **フォーカス** ボタン — **エディターのみ** | 選択したブロックにカメラを即座に合わせる | キーボードショートカットはありません。カメラだけの操作で、ドキュメント、選択、元に戻す履歴には一切触れません。ブロックの選択だけが対象で、構造物の配置は対象外です |

## 変形 — キーボード（エディターのみ）

| 入力 | 操作 |
|---|---|
| `→` / `←` | 選択をワールドの X 方向に移動 |
| `↑` / `↓` | 選択をワールドの Z 方向に移動 |
| `PgUp` / `PgDn` | 選択をワールドの Y 方向に移動 |
| `R` | 選択の回転軸を中心に +90° 回転 |
| `Shift+R` | −90° 回転 |
| ギズモのドラッグ中に `Shift` | 精密モード（0.1 倍の刻み） |

## 変形 — ギズモ（エディターのみ）

| 入力 | 操作 |
|---|---|
| ハンドルにポインターを合わせる | ハイライトされます |
| 軸のハンドル（赤 X / 緑 Y / 青 Z）をドラッグ | その軸に沿って移動（スナップあり） |
| 中央のパッド（琥珀色）をドラッグ | 地面に沿って自由に移動 |
| 回転リング（紫）をドラッグ | 回転軸を中心に回転（スナップあり） |
| 離す | 確定 — ちょうど 1 回で元に戻せる操作になります |
| ドラッグ中に `Esc` | キャンセル — 何も変わらず、履歴も残りません |

複数のブロックをドラッグや微調整で動かしたとき、そのうちの 1 つでも
選択外のブロックと重なる位置に来た場合、そこで離すと確定ではなく
キャンセルになります。すべてのブロックがちょうど元の位置に戻り、
元に戻す履歴も増えません。同じ選択の中でブロックを並べ替えることは、
衝突として扱われません。

## 変形 — 数値パネル（エディターのみ）

選択パネルの **正確な位置と回転** セクションにあります。

| 入力 | 操作 |
|---|---|
| X/Y/Z/R の欄に入力 | 正確な値。空の欄は変更なし |
| 絶対 / オフセットの切り替え | 回転軸の目標値か、単純な差分か |
| `Enter` または適用 | 1 つの操作、1 回で元に戻せます — スナップはされません |
| 欄で `Esc`、または **入力欄をリセット** | 欄を空にします（選択は解除されません） |

## 整列と等間隔配置（エディターのみ）

選択パネルの **整列・等間隔配置・繰り返し** セクションと、パレットから
使えます。整列には **2 個以上のブロック**、等間隔配置には **3 個以上**
が必要です。どちらも選択全体の範囲に対して **ワールドの軸** で働き、
1 つのコマンドとして確定します。

## 繰り返し（エディターのみ）

これも選択パネルの **整列・等間隔配置・繰り返し** セクションにあります。
選択のコピーを、1 つの軸に沿って等間隔に **N** 個追加で作ります。
**1 回で元に戻せる操作** です。何かを作る前にまとめて衝突を確認するので、
途中で衝突がある場合は、一部だけ作られるのではなく、繰り返し全体が
行われません。

| 入力 | 操作 |
|---|---|
| **コピー数** 欄 | 追加で作るコピーの数（元のものには触れません） |
| **間隔** 欄 | 各コピーの間の距離 |
| **Xに繰り返し** / **Yに繰り返し** / **Zに繰り返し** | そのワールドの軸に沿って繰り返す |

## 構造物（ビルドライブラリ） — エディターのみ

組み立て、フォーク、自分のライブラリについては
[エディター](02-TheEditor.md#構造物-組み立てフォーク自分のライブラリ)を参照してください。

| 入力 | 操作 | 補足 |
|---|---|---|
| **構造物** タブのカードをクリック | 構造物の配置モードに入り、ゴーストのプレビューがポインターについてきます | 組み込みの構造物にも、自分の **マイ構造物** にも使えます |
| 配置中に `R` / `Shift+R` | 配置待ちのゴーストを ±90° 回転 | ブロックと同じプレビュー用のキーです |
| クリック | 確定 — 構造物のすべてのブロックが、1 回で元に戻せる操作として置かれます | 使われている（赤い）位置では拒否されます |
| 配置中に `Esc` | キャンセル — 何も追加されません | |
| カードの **⋮** メニューの **新しいドキュメントとしてフォーク** | その構造物のコピーから始まる、まったく新しいドキュメントを作ります | ライブラリの項目は変更されません |
| 組み込みのカードの **⋮** メニューの **マイ構造物にフォーク** | そのままマイ構造物に追加します | ドキュメントは作られず、何も取り出されません |
| カードの **⋮** メニューの **情報** | 名前、カテゴリー、ブロック数、占有範囲、高さ、出典、説明の読み取り専用パネルを表示します | 編集はできません |
| **1 個以上のブロック** を選択して **ブループリントを作成**（選択パネルの **グループとブループリント** セクション、またはコマンドパレット） | 小さなダイアログ（名前 / カテゴリー / 説明 + プレビュー）を開き、選択を **マイ構造物** の新しい項目として保存します | |
| **マイ構造物** のカードの **⋮** メニューの **名前を変更** | 自分の構造物の名前を変えます | 自分の構造物のみ |
| **マイ構造物** のカードの **⋮** メニューの **削除** | ライブラリから削除します | すでに組み込んだブロックや、そこからフォークしたものには影響しません |
| カードの **⋮** メニューの **ブループリントをエクスポート** | 持ち運べる JSON ファイルとしてダウンロードします | 組み込みでも自分のものでも |
| **ブループリントをインポート** ボタン（マイ構造物の見出しの横） | ブループリントのファイルを新しい項目としてライブラリに追加します | 同じファイルを再インポートしても、新しい ID になります |

## 構造物のインスタンス（エディター）

**構造物のインスタンス** は、保存したドキュメントまるごとを、選択できる
1 つの単位として配置します。コピーではなく、生きた参照です。
[エディター](02-TheEditor.md#構造物のインスタンス-生きた参照)を参照してください。

| 入力 | 操作 | 補足 |
|---|---|---|
| ツールバーの **最近** ドロップダウンで、ドキュメントの **配置** ボタン | そのドキュメントを対象に構造物の配置モードに入ります | ドキュメントの名前をクリックすると、代わりにそれを開きます |
| 配置中に `R` / `Shift+R` | 配置待ちのインスタンスを ±90° 回転 | ブロックと同じプレビュー用のキーです |
| 配置したインスタンスをクリック（選択ツール） | 1 つの単位として選択します。ブロックの選択とは別です | |
| ビューポート内でドラッグ、またはギズモ | インスタンスを移動 / 回転 | |
| `Ctrl/Cmd+D` | 複製 — 同じドキュメントのインスタンスをもう 1 つ配置します | [複製](#複製エディターのみ) を参照。インスタンスを選択しているときは、ブロックのコピーではなく新しいインスタンスになります |
| インスタンスパネルの **X / Z / 回転** 欄に入力して適用 | 正確な位置と向きを設定します | Y（高さ）は常に地形から決まり、指定はできません |
| インスタンスパネルの **元のドキュメントを編集** | 参照しているドキュメントを開いて、そのブロックを変更します | インスタンスは生きた参照なので、すべてのインスタンスが更新されます |
| `Delete` / `Backspace` | インスタンスを取り除きます | 参照しているドキュメントには影響しません |

## グループ（エディターのみ）

選択パネルの **グループとブループリント** セクションにあります。何も
選択していないときは、パネルにグループの一覧が表示され、クリックすると
そのグループを選択できます。

| 操作 | 使えるとき |
|---|---|
| 新しいグループ | ブロックを選択しているとき |
| グループの名前を変更 / 複製 / 削除 | グループを選択しているとき |
| グループに追加 / グループから外す | ブロックとグループを選択しているとき |

グループの変形（移動 / 回転 / 整列 / 等間隔配置 / 数値）は、グループに
含まれるブロックに対して働きます。変形によってメンバー構成が変わる
ことはありません。

## クリップボード（エディターのみ）

| 入力 | 操作 | 補足 |
|---|---|---|
| `Ctrl/Cmd+C`、または選択パネルの **コピー** | コピー | 選択が必要です |
| `Ctrl/Cmd+V`、または選択パネルの **貼り付け** | 貼り付け | ボタンは、クリップボードに何か入ると表示されます |

## 複製（エディターのみ）

| 入力 | 操作 | 補足 |
|---|---|---|
| `Ctrl/Cmd+D` | 現在の選択をその場で複製 — 1 回で元に戻せる操作 | ばらばらのブロックにも、グループにも使えます。構造物のインスタンスの選択も複製されます — [構造物のインスタンス](#構造物のインスタンスエディター) を参照。クリップボード（と、貼り付け待ちのずらし量）には触れません |

複製したものがそのまま選択になるので、すぐにドラッグや微調整が
できます。

## 履歴

| 入力 | 操作 | 場所 |
|---|---|---|
| `Ctrl/Cmd+Z` | 元に戻す | エディターとワールドビュー |
| `Ctrl/Cmd+Shift+Z` または `Ctrl/Cmd+Y` | やり直す | エディターとワールドビュー |

ワールドビューでは、元に戻す・やり直すは注釈の編集（ランドマーク、
地域名、動物の飾り）に働きます。ワールドビューの履歴パネル
（[ワールドビュー](../03-WorldView.md#history--previewing-and-restoring-earlier-states)（英語）を参照）
でも、それらをプレビューして復元できます。

## エディターのみ

| 入力 | 操作 |
|---|---|
| `1` / `2` | 選択ツール / 配置ツールに切り替え |
| `Ctrl/Cmd+S` | ドキュメントを保存 |

## 配置（エディターのみ）

これらのキーは配置ツールのものなので、コマンドパレットには表示され
ません（パレットでは、`R`/`Shift+R` は *選択* を回転します）。
ワールドビューには配置ツール自体がありません。

| 入力 | 操作 | 補足 |
|---|---|---|
| ポインターを動かす | プレビューが、ポインターの下の地面やブロックの面についてきます | 位置が使われているときは赤く表示されます |
| `R` | 配置待ちのプレビューを +90° 回転 | ブロックを切り替えても保たれ、配置モードを抜けるとリセットされます。何もポイントしていないときに押すと、次のプレビューが回転します |
| `Shift+R` | 配置待ちのプレビューを −90° 回転 | |
| クリック | プレビューを本物のブロックとして確定 | 使われている（赤い）位置では拒否されます |
| ビルドライブラリの **色** の見本 | 次に置くブロックの色を選ぶ | 別の種類のブロックを選ぶと、その種類の既定の色に戻ります — [Brick colors](02-TheEditor.md#ブロックの色)を参照 |

すでに置いたブロックの色を変えるには、それらを選択して、選択セクションの
**色** の見本を使います。変更 1 回ごとに、1 回で元に戻せる操作です。

## タッチ画面

スマートフォンやタブレットでは、同じ操作を画面上のコントロールで
行えます。デバイスにタッチ画面があれば常に表示されるので、タッチ対応の
ノートパソコンでは、キーボードとマウスと並んで表示されます。幅 720
ピクセル以下の画面では、ページのレイアウトも変わります。ページへの
リンクは **メニュー** ボタンの中に折りたたまれ、ワールドビューの
サイドパネルは **パネル** ボタンから開き、エディターのサイドバーは
**ツール** ボタンから開く引き出しになります。

### カメラ（両方のビュー）

| タッチ | 操作 |
|---|---|
| 1 本指でドラッグ | 回転（オービット） |
| 2 本指でドラッグ | 平行移動（パン） |
| ピンチ | ズーム |
| タップ | ワールドビュー: タップしたものを調べる。エディター: 現在のツールでクリックしたのと同じ |

### 歩く（ワールドビュー）

タッチパッドは、アバター操作モードがオンの間に表示されます。
ジョイスティックの上の **歩く** ボタンで、モードとパッドをオン・オフ
します。

| コントロール | 対応するキー | 補足 |
|---|---|---|
| ジョイスティック | `W` / `A` / `S` / `D` | 上に倒すと前に歩き、横に倒すと向きを変えます。斜めは両方のキーを押したことになります |
| ジョイスティックを端まで倒す | `Shift` | 走る |
| **ジャンプ** | `Space` | |
| **オートラン** | `Alt` + `W`、次に `Alt` + `Shift` + `W`、次に `W` | タップするたびに、手を離して前に歩く、走る、止まる、の順に切り替わります。動作中は **オートラン: 歩く** / **オートラン: 走る** と表示されます。ジョイスティックを前後に倒しても止まります。横に倒すと向きが変わるだけです |
| **乗る** / **降りる** | `E` | 乗り物が範囲内にあるとき、または乗っている間に表示されます |
| **しまう** / **…を出す** | `Q` | 乗っている乗り物をしまえるとき、またはしまった乗り物を出せるときに表示されます。出すボタンには乗り物の名前と、2 台以上持っているときは一覧での位置（2/3 など）が表示されます |
| 出すボタンの横の **‹** / **›** | `[` / `]` | 乗り物を 2 台以上持っているとき: 出すものを古いもの / 新しいものから選びます |
| **捕まえる** / **放す** | `F` | 捕まえられる動物が近くにいるとき、または動物を連れているときに表示されます |
| **飾る** / **飾りを外す** | `G` | 自分が放した動物の近く、または飾りの近くで表示されます。`G` と違い、飾れなかった場合（サインインしていない、編集権限がない）は理由が表示されます |
| **↶** / **↷** | `←` / `→` | 乗っている間: タップごとに 45° の操舵 |
| **ブレーキ** | `Ctrl`（押したまま） | 乗っている間 |

パッドのボタンはキーボード用の案内の代わりになるので、パッドが表示
されている間は案内は隠れます。手を離して後ろに歩く（`Alt` + `S`）
ためのタッチボタンはありません。キーボードで始めた場合は
**オートラン: 後退** と表示され、タップすると止まります。

### 編集（エディター）

タップはクリックと同じ働きをします。選択ツールでは選択し、配置ツール
では配置します。ドラッグはカメラを動かすだけなので、回転させている
うちにうっかりブロックを置いたり選択を解除したりすることはありません。
タッチにはポインターを合わせる操作がないので、配置ツールはタップする
前にプレビューを表示しません。ブロックはタップした場所に置かれます。
置くブロックや構造物を選ぶとツールの引き出しが閉じるので、次のタップは
シーンに届きます。ビューポートの下のバーがキーの代わりになります。

| ボタン | 対応する操作 | 補足 |
|---|---|---|
| **元に戻す** / **やり直す** | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | |
| **回転** | `R` | 配置中は、タップする前に次のブロックや構造物を回転します。それ以外では選択を回転します |
| **削除** | `Delete` | |
| **複数** | `Ctrl/Cmd`+クリック | オンの間、タップするたびにブロックを選択に加えたり外したりします |
| **範囲** | `Shift`+ドラッグ | オンの間、1 本指のドラッグはカメラを動かす代わりに選択範囲を描きます。**複数** もオンなら、範囲は選択に追加されます（`Ctrl/Cmd+Shift`+ドラッグ）。範囲がオンの間はカメラが動かない（2 本目の指はズームではなく範囲のキャンセルになる）ので、移動するにはオフにしてください |
| **その他** | `Ctrl/Cmd+K` | コマンドパレット。ほかのすべての編集操作を使えます |

ギズモのハンドルは、**範囲** のオン・オフにかかわらず、マウスと同じ
ようにタッチで使えます。ハンドルをドラッグしてください。

## Escape の優先順位（エディター）

Escape は状況によって働きが変わり、厳密に次の順序で処理されます。

1. **テキスト入力中** — 欄をクリアするか、フォーカスを外します。
2. **キーボードショートカットの一覧** — 一覧を閉じます（`?` でも
   閉じます）。
3. **コマンドパレット** — パレットを閉じます。
4. **ギズモの操作中** — ドラッグをキャンセルします（履歴は残りません）。
5. **範囲選択中** — 範囲選択をキャンセルします。
6. **それ以外** — 選択を解除します（配置モードでは配置を終了します）。

### ワールドビューでの Escape

テキスト入力中の Escape は同じように扱われます。それ以外では、Escape は
開いているワールドビューのパネル（フォーカスパネル、名前を付ける
パネルなど）を閉じます。
