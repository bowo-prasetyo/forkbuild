# インタラクティブ変形ギズモ

<!-- languages -->
[English](../InteractiveTransformGizmo.md) · [Deutsch](../de/InteractiveTransformGizmo.md) · [Bahasa Indonesia](../id/InteractiveTransformGizmo.md) · **日本語**
<!-- /languages -->

エディターでブロックを選択すると、選択の回転軸の位置にギズモが表示
されます。ハンドルをドラッグすると、ライブプレビューを見ながら選択を
移動・回転でき、離すと変更が **1 回で元に戻せる操作** として確定します。
エディターで [構造物のインスタンス](02-TheEditor.md#構造物のインスタンス-生きた参照)
を 1 つ選択したときもまったく同じギズモが表示されますが、1 つだけ違いが
あります。緑の Y 軸のハンドルは動きません。配置の高さは常に下の地形に
従い、ドラッグするハンドルでも入力する値でもありません。

ギズモはエディター専用です。[ワールドビュー](03-WorldView.md)は
読み取り専用の探索の場です。そこで見つけたものの続きを作るには、
**コピーを編集** ボタンでここ、エディターで開いてください。

## ギズモ

```
    Y
    ↑
    │
    │
    ●──────→ X        ●  回転軸
   /
  /
 Z

    ◯
  ◯ ● ◯               回転リング（Y 軸）
    ◯
```

| ハンドル | 色 | 動作 |
|---|---|---|
| 軸の矢印 | 赤（X） | ドラッグすると X 方向にだけ移動 |
| 軸の矢印 | 緑（Y） | ドラッグすると Y 方向にだけ移動 |
| 軸の矢印 | 青（Z） | ドラッグすると Z 方向にだけ移動 |
| 中央のパッド | 琥珀色 | 地面に沿って自由に移動（X + Z） |
| 回転リング | 紫 | ドラッグすると回転軸を中心に回転 |

ハンドルは、ポインターを合わせるとハイライトされ、ドラッグ中はさらに
明るく光ります。どれだけズームアウトしても、ギズモは画面上で扱いやすい
大きさを保ちます。

## 回転軸

ギズモの中心にある白い印が **回転軸** です。

```
┌───────────────┐
│ ■           ■ │
│               │
│       +       │ ← 回転軸（選択範囲の中心）
│               │
│ ■           ■ │
└───────────────┘
```

- ブロックを 1 つ選択 → 回転軸はそのブロックの中心にあります。
- ブロックを複数選択 → 回転軸は、それらすべてを囲む箱の中心にあります。
- 回転は常に回転軸を中心に行われます。

回転軸は自動で選択についていきます。A を選択し、B を追加し、移動を
元に戻す、というように操作するたびに、ギズモは位置を合わせ直します。

## 移動する

1. ブロックを 1 つ以上選択します。
2. 軸のハンドルをつかんでその軸に沿って移動するか、中央のパッドを
   つかんで地面に沿って自由に移動します。
3. 選択がポインターにリアルタイムでついてきます。
4. 離すと確定します。

## 回転する

1. ブロックを 1 つ以上選択します。
2. 紫のリングをドラッグします。ドラッグに合わせて、選択が回転軸を
   中心に回転します。
3. 離すと確定します。

複数選択では、すべてのブロックが共通の回転軸の周りを回り、*さらに*
同じ角度だけ向きを変えるので、並びの形が保たれます。

## 確定、キャンセル、何もしない

| 操作 | 結果 |
|---|---|
| マウスを離す | 変更が確定します。動いたブロックの数にかかわらず、元に戻す履歴には **ちょうど 1 つ** の項目ができます |
| ドラッグ中に `Escape` を押す | キャンセル — すべてがちょうど元の位置に戻り、履歴には何も残りません |
| 動かさずにクリックして離す | 何も起きません — コマンドも履歴の項目もありません |

`Ctrl/Cmd+Z` は操作全体を 1 回で元に戻し、`Ctrl/Cmd+Y`（または
`Ctrl/Cmd+Shift+Z`）でやり直します。

## ドラッグ中は、その操作がポインターを占有します

ドラッグ中は、カメラは回転せず、ほかのものは選択できず、ショート
カットは無視されます。ドラッグがカメラの操作とぶつかることはありません。
離す（確定）か `Escape`（キャンセル）で、すべて普段どおりに戻ります。
ビューポートの *外* でマウスを離しても、きちんと確定します。

## グループ

グループを選択すると、そのメンバーのブロックが選択されます。ギズモは
それを、ほかの複数選択とまったく同じように扱います。

- ドラッグはすべてのメンバーを動かし、回転はすべてのメンバーを共通の
  回転軸の周りで回します。
- グループ自体には触れません。変形によってメンバー構成が変わることは
  ありません。（ギズモはグループがあることさえ知りません。）
- 1 回元に戻すと、すべてのメンバーが元の位置に戻ります。

## スナップ

ドラッグは既定でスナップします。移動は 1 ワールド単位（矢印キーで
動かすのと同じ幅）、回転は 15°（`R` で回す 90° より細かい）です。
ドラッグ中に **Shift** を押したままにすると **精密モード** になり、
通常の 0.1 倍の刻み（0.1 ワールド単位、1.5°）になります。既定の
グリッドでは粗すぎる細かな調整に使います。

**数値パネル** と **整列・等間隔配置** は意図的な例外です。正確なもの
を入力（または指示）しているので、スナップせず、指定したとおりの値や
幾何学的に正確な結果を常に適用します。

## 衝突すると確定できません

選択を移動・回転すると、置いてよいかを決める前に、結果を選択 *外* の
すべてのブロックと照合します。メンバーのどれかが既存のものと重なる
場合、そこで離しても確定しません。1 つのブロックを使われているマスに
置こうとしたときにクリックが拒否されるのと同じように、選択内の
すべてのブロックがちょうど元の位置に戻り、元に戻す履歴も増えません。
同じ選択の *中* でブロックを並べ替えること（たとえば回転でメンバー
どうしが入れ替わること）は、衝突として扱われません。この確認は、
ギズモのドラッグ、キーボードでの微調整、回転のすべてに適用されます。
整列、等間隔配置、数値パネルは、自由な移動ではなく、正確で意図された
結果を計算するので、この確認の対象外です。

## ギズモにできないこと

- **拡大縮小** — ブロックの大きさは変えられないので、拡大縮小の
  ハンドルはありません。
- **ドラッグで複製** — ドラッグしながらコピーする修飾キーはありません。
  まず `Ctrl/Cmd+D` で選択をその場で複製し（[エディター](02-TheEditor.md#コピー貼り付け複製)
  を参照）、そのコピーをドラッグしてください。

## ヒント

- 細かく操作したいときは、回転リングにポインターを合わせてゆっくり
  ドラッグします。回転は距離ではなく角度で測るので、回転軸の近くでの
  小さな動きでも正確です。
- 2 つの座標を完全に固定したまま動かしたいときは、軸のハンドルを
  使います。制約は見た目だけでなく正確です。
- 操作を組み合わせましょう。矢印キーで 1 単位ずつ動かし、最後に Shift を
  押しながらドラッグして細かく位置を決めます。元に戻す・やり直すは
  どちらも同じように扱い、1 回の操作が 1 ステップです。
