# 06 — アバターと在席状況

<!-- languages -->
[English](../06-AvatarsAndPresence.md) · [Bahasa Indonesia](../id/06-AvatarsAndPresence.md) · **日本語**
<!-- /languages -->

**アバター** は、ワールドビューで他の人からあなたがどう見えるかです。
その外見、位置、動き方です。このガイドでは、アバターのカスタマイズ、
誰に見えるかの設定、ほかの人のアバターとのやり取りについて説明します。

## アバターをカスタマイズする

上部のバーで **マイアバター** を開きます。

1. ドロップダウンから **テンプレート**（体の種類。たとえば
   「Humanoid 01」）を選びます。選ぶと平面のプレビューがすぐに更新
   されます。
2. テンプレートが用意している各パーツ（組み込みのテンプレートでは
   **肌、髪、シャツ、ズボン**）について、ドロップダウンから選択肢を
   選び、テンプレートが許す場合は色も選びます。
3. テンプレートが用意している **アクセサリー** を、チェックリストで
   オン・オフします。（複数を同時に選べるパーツは、このように
   チェックリストで表示されます。ページには、選んだテンプレートが
   用意しているパーツがそのまま表示されます。）
4. **表示名**（最大 60 文字）を設定します。アバターと一緒に、またピアや
   会話で表示される名前です。
5. **保存** をクリックします。

テンプレートを切り替えると、外見はそのテンプレートの既定値に戻ります。
選んだものがテンプレート間で引き継がれることはありません。ここには
3D のプレビューはありません。実際のアバターは、ワールドビューで初めて
あなた（またはほかの誰か）が見たときに目にすることになります。

## 誰に見えるか: 2 つの独立した設定

マイアバターページには、2 つの別々の公開範囲の設定があります。混同し
やすいので、区別しておいてください。

| 設定 | 決めるもの |
|---|---|
| **在席状況の公開範囲** | あなたの *リアルタイムの位置* を誰が受け取るか — ワールドビューで動き回るあなたが、そもそも表示されるか、どこに表示されるか |
| **プロフィールの公開範囲** | あなたの *外見* を誰が受け取るか — テンプレート、色、アクセサリー、表示名 |

どちらにも同じ 4 つの段階があり、どちらも最初は **公開** です。

- **公開** — 接続している人なら誰でも見られます。
- **友達** — 相互の友達と、明示的に書いたアイデンティティ（アイデン
  ティティ ID を 1 行に 1 つ貼り付けます）。これは単純な許可リストで、
  リクエストと承認の流れではありません。「友達」の意味は
  [ピア接続と友達](07-PeerConnectionsAndFriends.md) を参照してください。
- **ローカル** — 同じブラウザーで開いているほかの ForkBuild のタブだけ。
  どのピアにも、友達にさえ送られません。
- **非表示** — 誰にも一切知らせません。見えなくなる方法です。

各セクションにはそれぞれ **保存** ボタンがあり、一方を保存してももう
一方は保存されません。「保存しました。」は保存後に表示され、その
セクションをまた変更するとすぐに消えるので、常に今見ているものの状態を
表しています。

誰かの友達であること自体では、あなたのアバターは **見えるようになり
ません**。実際に何を共有するかは、この 2 つの設定がそれぞれ独立して
決めます。また、これらは *これからの* 更新にしか影響しません。すでに
あなたの位置や外見を受け取った人は、それを持ち続けます。遠隔で
「忘れてもらう」方法はありません。

ワールドビューでも、**自分のアバターを表示** と **他の人のアバターを
表示** を、自分の画面だけの表示切り替えとしてオン・オフできます。
自分のアバターを持つまでは、ワールドビューのアバターセクションには
**他の人のアバターを表示** と作り方の案内だけが表示されます。自分の
アバターが必要な操作は、アバターを作ると表示されます。

## ワールドビューで他の人を見る

あなたが受け取れる在席状況（相手自身の在席状況の公開範囲による）の
人は、あなたが動き回ると自動で表示されます。公開されているアバターを
見るのに友達リクエストは不要です。アバター（または **近くのアバター**
パネルの項目。近くにいる全員を、距離と現在のアニメーション付きで
並べた簡単な一覧です）をクリックすると、**アバター情報パネル** が
開きます。

- 表示名とアバターのテンプレート
- 状態の行 — **在席 / 応答なし / 不在** と、このアバターのデータが
  どれだけ確かめられているかを示す信頼のラベル（**信頼済み / 未署名 /
  競合**）
- 位置、距離（ワールド単位）、現在のアニメーション（歩行、待機など）
- **アバターを追う** — カメラをその人の動きに固定します
- **あいさつ / 手を振る / 指さす** — そのアバターに 1 回だけの
  ジェスチャーを送ります
- **作品をフォロー** — アバターの背後にいるアイデンティティをフォロー
  するので、その人の新しい作品が **フォロー中** ページに表示されます
  （[人をフォローする](07-PeerConnectionsAndFriends.md#人をフォローする)
  を参照）。誰のアバターかを証明するのは署名なので、アバターの在席
  状況に署名があるときだけ表示されます。

それ以外では、ほかの人のアバターは見るだけです。他人のアバターを
動かしたり、編集したり、削除したりする方法はなく、見る、追う、
ジェスチャーを送ることだけができます。

近くのアバターが表示されるかどうかは、自分のアバターが歩いている向き
ではなく、**カメラ** が今どこを向いているかで決まります。この 2 つは
別の方向を向くことがあり、特にカメラを自由に回転させた直後によく
起こります。歩いている道の真正面に立っている人でも、カメラがほかを
向いていると完全に見えないことがあります。カメラをその人の方へ回すと、
また表示されます。

## アバターを歩かせる

カメラを飛ばす（[ワールドビュー](03-WorldView.md#飛び回る)）
のも移動の方法の 1 つですが、**アバター操作モード** でアバターを直接
歩かせることもできます。オンにするには、ログインして **マイアバター** で
アバターを保存している必要があります。そのうえで、ワールドビューの
**アバター** セクションで **自分のアバターを操作（WASD、Shift、Space）**
にチェックを入れます。そうするまでキーは何もせず、テキスト欄に
フォーカスがある間も無視されます。先に 3D ビューをクリックしてください。

| キー | 操作 |
|---|---|
| **W / A / S / D** | 移動 / 向きを変える |
| **Shift** | 走る（速く移動） |
| **Space** | ジャンプ |
| **Alt + W / S** | 手を離したまま前進 / 後退で歩き続ける — キーを離しても動き続けます |
| **Alt + Shift + W / S** | 同じですが、歩く代わりに走ります |

スマートフォンやタブレットでは、画面上のジョイスティックとボタンが
これらのキーの代わりになります。ジョイスティックを倒すと歩き、端まで
倒すと走り、**ジャンプ** をタップします。
[タッチ画面](ControlsReference.md#歩くワールドビュー) を参照してください。

歩くときは、近くに読み込まれた建物、木、野生動物との衝突が考慮され
ます。周りに読み込まれた構造物も、地形の一部として生成された木も、
近くで草を食べている鹿やウサギも、通り抜けることはできません
（[ワールドビュー](03-WorldView.md#飛び回る)を参照）。
野生動物は、どこへ歩いていっても、木と同じように道をふさぐだけです。
あなたを見ようと首を向けることはあっても、道を空けることも傷つくことも
なく、乗り物はそのまま通り抜けます。止められるのは徒歩だけです。
捕まえた動物は何もふさぎません。アバターは、配置された構造物の上を
歩き、垂直な面を登り、でこぼこの地形を進めます。移動に合わせて、
カメラが自然にアバターを追います。

**アバターを追う** は、カメラを自由に回転させる代わりに、動くアバターに
カメラを固定し続けます。ほかのプレイヤーのアバターを追って、どこへ
行くのかを見ることもできます。

### カメラの視点

アバターを追うの隣には **カメラ** があり、**自由**、**一人称**、
**三人称**、**俯瞰** の 4 つのボタンが並んでいます。カメラを自分で
飛ばす代わりに、自分のアバターから一定の位置に固定します。アバターを
追うと同じく、使うには自分のアバター（マイアバター）が必要です。

- **自由** は普通の回転カメラです。ワールドビューの既定で、このガイドの
  ほかのカメラ操作はすべてこれを前提にしています。
- **一人称** は、カメラをアバター自身の目の高さに置き、アバターが
  向いている方向を見ます。
- **三人称** は、アバターの後ろの少し上から、少し見下ろします。
  「自分のキャラクターが見える」おなじみの構図です。
- **俯瞰** は、はるか上空から真下を見下ろし、アバターの位置には
  ついていきますが、向きはあえて無視するので、向きを変えても視界が
  回転しません。

すでに選ばれているボタンをクリックすると **自由** に戻ります。カメラの
視点は完全にローカルで、共同作業者に共有されることも、相手の見え方に
影響することもありません。

向きを変えたときの動きは 2 つのモードで異なります。視点を固定して
いる（一人称または三人称）と、カメラは動くたびにアバターの現在の
向きに合わせて構図を取り直すので、あなたが向きを変えたとおりに視界も
回ります。**自由** を選んでいると、カメラはあえて向きを気にしません。
その場で向きを変えても、歩いても、乗り物に乗っても、カメラが自分で
動いたり回ったりすることはなく、動かすのはあなた自身のドラッグ・
パン・ズームだけです。ある方向を見るように自由に回転させてから別の
方向へ歩き出すと、カメラはあなたを追わずに、最後に向けた方向を見続け
ます。

### 手を離したままの移動

**Alt** を押しながら **W** か **S** をタップすると、アバターがその方向に
歩き続けます（**Shift** も押していれば走り続けます）。クルーズ
コントロールのように、すべてのキーを離しても動き続けます。Alt を
押さずに **W** か **S** をもう一度タップすると止まり、普通のキーを
押している間だけの移動に戻ります。同じように反対方向をタップしても、
逆向きにはならずに止まります。キーボードでは、これが動作中であることを
示す画面上の表示はありません。アバターが勝手に歩き続けていることだけが
しるしです。

スマートフォンやタブレットでは、タッチパッドの **オートラン** ボタンが
同じ働きをします。1 回タップすると手を離して前に歩き、もう 1 回で
走り、3 回目で止まります。動作中は **オートラン: 歩く** または
**オートラン: 走る** と表示されます。ジョイスティックを前後に倒しても、
**W** や **S** をタップしたときと同じように止まります。横に倒すと
向きが変わるだけなので、オートラン中に方向を変えられます。

### 乗り物

ワールドによっては、歩く代わりにアバターが乗れる自転車、バイク、車、
ドローンが置かれています。十分近づくと、どのキーで乗れるかを示す
案内が表示されます。

| キー | 操作 |
|---|---|
| **E**（乗り物の近く） | 乗る |
| **E**（乗っているとき） | 降りる |
| **W / S** | 加速 / 後退 |
| **A / D** | アバター自身の向きを変える — 徒歩のときと同じ連続した向きの変更で、乗り物の操舵ではありません |
| **← / →**（押す） | 操舵 — 1 回押すごとに、乗り物の進もうとする方向が 45° 変わります。押したままにしても曲がり続けず、曲がるたびに押し直す必要があります |
| **Ctrl**（押したまま） | ブレーキ |

乗ると、**W/S** と **Ctrl** で乗り物を運転し、**←/→** で操舵します。
別に「運転モード」をオンにする必要はありません。**A/D** は徒歩のときと
まったく同じようにアバター自身の体の向きを変え、操舵とは独立して
います。降りると、乗り物の横の空いている場所に徒歩で戻ります。最高
速度、加速、ブレーキ、曲がり方はすべて乗り物の種類によって違い、
衝突の大きさもそれに合わせてあります。現在それは自転車、バイク、車、
ドローンで、ワールドに実際に置かれて描画される 4 種類です。バイクは
自転車より速く、見つけにくく、車はバイクよりさらに速く、さらに見つけ
にくく、ドローンはいちばん速く、いちばん珍しい乗り物です。

ドローンは、ほかの 3 つとまったく同じように、乗って動き始めるまで
地面で止まっています。**W** か **S** を押したままにすると地面から
浮き上がり、離すと下りてきます。いったん飛ぶと木の上を越えますが、
高い建物には車と同じようにぶつかるので、飛んでもワールドの形を
無視できるわけではありません。空中でドローンから降りることはできません。
先に地面に戻してください。

#### 乗り物を持ち運ぶ

あとで必要な場所から遠いところで乗り物を見つけましたか？乗っている間に
**Q** を押すと持ち物にしまえます。乗り物はワールドから消え、同時に
降ります。どこかほかの場所まで歩いて、乗っていない状態でもう一度
**Q** を押すと、選択中のしまった乗り物がその場に現れ、すでに乗った
状態になります。今のところ、一度に持ち運べる乗り物の数に制限はなく、
しまった乗り物が見つけた場所に再び現れることもありません。

既定では、**Q** は最後にしまった乗り物を出します。2 台以上持っている
場合は、**[** か **]** で持っているものを前後に切り替えられます。
案内にはどれが選ばれているかと、その位置（たとえば「[Q] 自転車を出す
（1/3）」）が表示されるので、出したりしまったりを繰り返さずに古いものを
見つけられます。切り替えは次に **Q** で出すものを変えるだけで、それ
自体で何かを出したり取り除いたりはしません。

#### 他の人がいるところで乗る

あなたのアバターが見える人には、あなたが乗っているものも見えます。
あなたの自転車、バイク、車、ドローンが、相手の画面ではあなたの下に、
進む方向を向いて描かれ、エンジン音、乗り降りの音、ブレーキの音も
聞こえます（[03 — World View](03-WorldView.md)の「Sound」を
参照）。あなたにも、相手のものが同じように見え、聞こえます。これは
在席状況の設定に従い、あなたが見えない人には、何に乗っているかも
わかりません。

ほかの人が乗り物に乗っている間、あなたの側のその乗り物は消え、乗る
ことはできません。自分が乗っている乗り物は、常にあなたのものです。
ただし、誰も乗っていない乗り物がどこに置かれているかは共有されません。
相手が降りると、あなたの画面では、最後に止まっているのを見た場所に
再び現れます。それは相手が置いた場所とは限りません。**Q** でしまったり
新しい場所に出したりした乗り物も同じく、持ち主が乗るまでは持ち主の
画面にしかありません。

### 動物

ワールドによっては野生動物がいます。森には鹿、開けた草原にはウサギ
です。野生動物は、ワールドが置いた場所の周りをゆっくり歩き回り、数歩
以上離れることはありません。十分近づくと、**F** で捕まえるよう案内が
表示されます。捕まえると持ち物（しまった乗り物と同じ持ち物）に加わり、
ワールドから取り除かれます。

どこかほかの場所まで歩いて、もう一度 **F** を押すと、捕まえられる
動物が近くにいなければ、最後に捕まえた動物をその場に放します。放した
動物はすぐにまた捕まえられます。放した動物は放した場所にとどまり
ますが、止まっているわけではありません。草を食べ、周りを見回し、
ときどき向きを変え、近づくと首を向けてあなたを見ます。
今のところ、持ち運べる動物の数に制限はなく、動物を捕まえても、
同じく持っている乗り物に影響することはなく、その逆もありません。
同じリュックを使っていても、混ざることはありません。

#### 動物でワールドを飾る

放した動物は、あなた自身のセッションの中にしかいません。動物を
ワールドのずっと残る一部にする（たとえば、作ったものの上にウサギを
座らせる）には、自分が放した動物の隣に立って **G** を押します。それは
**動物の飾り** になります。ワールド自体の内容に保存されるので、その
ワールドを公開・配信すると一緒に含まれ、開いた人全員に、元の動物と
まったく同じ姿で見えます。選んだ場所にとどまり（なので屋上の
ウサギが歩いて落ちることはありません）、その場で草を食べ、周りを
見回し、向きを変えます。ワールドを開いた全員に、同じ瞬間に同じ動きが
見えます。

飾りは飾るためだけのもので、**F** で捕まえることはできません。気が
変わったら、隣に立ってもう一度 **G** を押します。飾りはワールドから
取り除かれ、捕まえられる生きた動物に戻ります。両方が近くにある場合、
**F** が放すより捕まえることを優先するのと同じように、**G** は新しく
放した動物を飾るほうを優先します。飾れるのは自分が放した動物だけで、
ワールドが自分で置いた野生動物は飾れません。**G** で近くの何かを
飾ったり外したりできるときは、案内が表示されます。
[ランドマーク](03-WorldView.md#ランドマーク--覚えておきたい場所に印を付ける)
を追加するのと同じく、飾るには、サインインしていて、今いるワールドの
編集（EDIT）権限が必要です。ほかの人が公開したワールドでは、ライセンスが
フォークを許可している限り、飾りはあなた自身のコピーに入ります。
どれにも当てはまらない場合、**G** は何もしません。タッチパッドの
**飾る** ボタンは、代わりに理由を表示します。

### 住人

ワールドには **住人** を置けます。そこに暮らし、自分の家と呼ぶ場所の
あたりを散歩しながら、あなたの建物の間で日々を過ごす人たちです。
追加するには、住んでほしい開けた地面に立って **R** を押します（または
**アバター** セクションの **ここに住人を追加** をクリックします）。
住人はすぐ横に現れ、それ以降はワールド自体の内容の一部になります。
[ランドマーク](03-WorldView.md#ランドマーク--覚えておきたい場所に印を付ける)
と同じように、ワールドと一緒に保存、公開、フォークされます。追加するには、
サインインしていて、今いるワールドの編集（EDIT）権限が必要です。ほかの
人が公開したワールドでは、住人はあなた自身のコピーに入ります。気が
変わったら、住人の隣に立ってもう一度 **R** を押す（**[R] 住人を削除**
と表示されます）か、**Ctrl/Cmd+Z** で元に戻します。

住人は家からおよそ 6 歩以内にとどまります。壁や木や水は回り込み、
通り抜けることはなく、ときどき立ち止まって周りを見回します。住人の
位置はプレイヤーの間で送り合うものではなく、ワールドと時刻から
決まるので、ワールドを開いた全員に、各住人が同じ瞬間に同じ場所に
見えます。住人には実体があり、木と同じようにぶつかります。ただし、
あなたのために止まったりよけたりはしないので、あなたが立ち止まって
いると、通り抜けていくことがあります。

住人はあなたに気づきます。立っている住人の前や横、数歩以内にいると、
こちらを向き、すぐそばまで歩いていくと手を振ります。近づくたびに
1 回手を振ります。動物と同じく、これはあなたの画面で、あなた自身の
アバターに対してだけ起こります。

住人は自分の近所のことも知っています。住人の横に立って **T** を押すと
（**[T] 話す** と表示されます。アバターセクションとタッチパッドにも
**話す** ボタンがあります）、周りにあるものについて、頭の上の吹き出しで
ひとつふたつ教えてくれます。近くの自転車や鹿、ランドマーク、ワールドに
配置された構造物（タイトルと作者付き）、近くにいる誰か、住人が暮らして
いる場所、少し離れた別の作品などです。たとえば *「北東へ約3.6 km行った
ところにbobさんの「Hill Fort」という作品があります。」* のように
話します。距離は丸められ、方向は住人の立っている場所から見たもの
（北はコンパスが指す方向）です。もう一度話しかけると、別のことを話し
ます。吹き出しは数秒後か、あなたが離れるとすぐに消えます。

吹き出しが出ている間、住人が話したもののうち動かないもの（ランド
マーク、構造物、作品、乗り物。動物や人は移動するので対象外です）
ごとに、ビューの下に **フォーカス** ボタンが表示されます。クリック
すると、場所パネルの **フォーカス** と同じように、カメラがそちらへ
向かいます。アバターは住人の横にとどまり、アバターを追うがオンなら、
また歩き出すとカメラが戻ります。

住人が話すのは、*あなたの* ForkBuild が知っていることです。あなたの
カタログにある作品、一緒にいる人、あなたが持っていっていない乗り物や
動物です。同じ住人にほかの人が話しかけると違うことを聞くかもしれず、
住人があなたに話したことをほかの誰かが見ることもありません。あなたが
しまった乗り物や乗っている乗り物、ほかの人が乗っている乗り物、あなたが
捕まえた動物について話すことはありません。作品は、アプリのほかの場所と
同じく、公開物に書かれたタイトルと作者で呼ばれます。

住人を置くには、乾いた開けた地面が必要です。屋上や水の上では置けず、
乗り物に乗っている間も置けません。今立っている場所に置けないときは、
アバターセクションに理由が表示されます。住人は人ではありません。
プロフィールはなく、人や近くの一覧には表示されず、クリックして情報を
見ることもできず、クエストやタスクや報酬を与えることもありません。
ただそこに暮らし、尋ねれば周りに何があるかを教えてくれるだけです。

#### 再読み込みしても残るもの

持ち物、つまり持ち運んでいるすべての乗り物と動物は、このデバイスに
保存されます。どこかに置いたり乗ったりした乗り物と、放した動物も、
置いたままの場所に保存されます。ページを再読み込みしても、あとで
戻ってきても、そのままの状態から続けられます。

### 空間の把握と活動

ほかの人がいると、その人が何をしているかを示す、状況に応じた表示が
見えます。

- 「**Bob — 近くを探索中**」は、その人が飛んだり歩いたりしていると、
  アバターの近くに表示されます。
- 「**Alice — 近くで調査中**」は、誰かが何かを変えずに、じっくり見て
  いることを示します。

これらの活動の表示は空間上の在席データから導かれ、言葉でやり取り
しなくても、ほかの人が何を見ているかを理解する助けになります。

活動の表示は、誰かが何をしているかを示すだけで、何かを変えることは
ありません —
[他の共同作業者を見る](03-WorldView.md#他の共同作業者を見る)
を参照してください。
