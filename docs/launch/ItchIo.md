# itch.io

itch.io is where people look for small browser games. ForkBuild can't run
inside itch's own frame as the full app: it keeps your builds in its own
site's storage, installs from its own address, and its rendezvous server
answers only the official site. So the itch page is a storefront that sends
players to the site.

**Link:** <https://bowo-prasetyo.github.io/forkbuild/?ref=itch>

## The project

- **Kind of project:** HTML.
- **Upload:** a zip of [itch/index.html](itch/index.html), a page with one
  big button that opens ForkBuild in a new tab (with `?ref=itch`), marked
  **This file will be played in the browser**. Set the embed to 800 × 500.
- **Classification:** Games; genre Simulation or Other; tags `building`,
  `sandbox`, `3d`, `creative`, `browser`, `open-source`, `multiplayer`.
- **Pricing:** No payments.
- **Screenshots:** from [the press kit](press/).
- Check itch.io's current rules for HTML projects that link out before
  publishing; if a launcher isn't allowed, publish the page with the link in
  its description instead.

## Short description

> Snap bricks into castles and villages, fork anyone's build, and share it
> as a link.

## Description

> ForkBuild is a 3D building sandbox that runs in your browser. Start from a
> ready-made castle, harbor island or village, or an empty plot; every build
> you see can be copied and changed, and remembers who made the original.
>
> - A weekly build challenge with a new theme every Monday
> - Share a build as a link that opens on any device, no account
> - Walk and swim through worlds, and build with friends
> - Export to glTF, OBJ and STL for Blender or a 3D printer
>
> Free and open source. Your builds stay on your device until you share
> them.
